# 品牌与设计方向融合指南

> 此文件指导如何在 ppt-master 的品牌预设（电信正式身份）与 huashu-design 选定的设计方向之间做融合，确保"电信皮+丰富骨"。


## 三层约束模型

### 第一层：不可变（电信铁律）

以下参数在任何设计方向下都不可更改，ppt-master 的 spec_lock.md 必须强制引用：

| 参数 | 值 | 说明 |
|------|---|------|
| 主色 | #0077BE | 所有标题栏、重点标记、章节号 |
| 正文字色 | #333333 | 所有段落文字 |
| 页面背景 | #F5F7FA / #FFFFFF | 内容页用浅灰，重点页用白 |
| 主字体 | 微软雅黑 | 标题Bold，正文Regular |
| 页饰结构 | 标题栏+页脚+装饰线 | 每页必须包含 |
| 封面结构 | 电信蓝渐变+居中标题 | 必须遵循 |

### 第二层：可调范围（设计方向影响）

| 参数 | 可调范围 | 默认值 |
|------|---------|--------|
| 辅助色 | 可引入1-2色，饱和度降30% | #3399D6 浅蓝 |
| 卡片圆角 | 0-12px | 4px |
| 内容间距 | 24-64px | 40px |
| 标题字号 | 22-28pt | 24pt |
| 正文字号 | 14-18pt | 16pt |
| 指标卡样式 | 方形/圆角/带阴影 | 方形+浅阴影 |
| 图表风格 | 简约/轻装饰 | 简约 |
| 页面节奏 | anchor/dense/breathing | dense（汇报默认） |

### 第三层：自由发挥（ppt-master 自由排版）

| 参数 | 说明 |
|------|------|
| 内容布局 | 完全自由——双栏/三栏/卡片网格/时间线/对比/全幅图+叠字等 |
| 图表选择 | 柱状/折线/饼图/雷达/矩阵/金字塔——按内容需求选择 |
| 信息密度 | 按页面功能自然调节（封面疏、数据页密） |
| 装饰层次 | 可在页饰范围内增加轻微分割线、背景形状、色彩方块 |

## ppt-master 品牌预设应用流程

### Step 1: 复制品牌预设到项目

```bash
PROJECT_PATH=<ppt-master创建的项目路径>
cp -r ${SKILL_DIR}/assets/telecom-formal-brand/* ${PROJECT_PATH}/templates/
```

### Step 2: 在 Strategist Phase 回读

Strategist 读取 `templates/design_spec.md`，识别 `kind: brand`，锁定 Identity 段（配色/字体/语调/图标风格）。

### Step 3: 融合设计方向参数

在 Eight Confirmations 中，以下项目预填电信默认值但允许用户微调：

| 确认项 | 电信默认值 | 可调范围 |
|--------|----------|---------|
| e. Color scheme | 电信蓝主色+浅灰底 | 可加1-2辅助色 |
| f. Icon usage | stroke icons (tabler/lucide) | 不变 |
| g. Typography | 微软雅黑 Bold/Regular | 不变 |
| h. Image usage | 高清低饱和度+科技底纹 | 可调 |

### Step 4: spec_lock.md 中的品牌强制校验

在 Executor 的逐页 spec_lock 回读中，以下字段必须与品牌预设一致：
- `colors.primary` = #0077BE
- `colors.neutral_dark` = #333333
- `colors.bg` = #F5F7FA or #FFFFFF
- `fonts.title` = Microsoft YaHei Bold
- `fonts.body` = Microsoft YaHei Regular

## 封面页设计规范

封面页是唯一允许"自由发挥"的页面，但必须满足：

1. **背景**：电信蓝(#0077BE)渐变（从 #0077BE 到 #3399D6），支持水平/对角/径向渐变
2. **标题**：居中，微软雅黑 Bold，28-36pt，白色
3. **副标题**：居中，微软雅黑 Regular，14-18pt，白色/浅色
4. **LOGO**：右下角或底部居中，白色反色版本
5. **日期/单位**：底部居中，微软雅黑 Regular，12-14pt，白色/浅色
6. **可选装饰**：浅色曲线/几何线条/网络纹理，低透明度(10-20%)作背景装饰

## 章节标题页设计规范

章节标题页是"换气页"，视觉上与内容页形成对比：

1. **背景**：可使用电信蓝全幅或左侧电信蓝右侧白的双色布局
2. **章节号**：大号 Times New Roman Bold，48-72pt
3. **章节名**：微软雅黑 Bold，24-32pt
4. **描述**：微软雅黑 Regular，14-16pt，不超过60字
5. **装饰**：可加入渐变色带/几何形状，但保持克制

## 内容页设计规范

内容页追求"丰富而不花哨"：

1. **背景**：#F5F7FA 浅灰，重点卡片区域用 #FFFFFF 白底
2. **标题栏**：电信蓝色带 + 白色标题文字（必选页饰）
3. **内容区**：完全自由排版——双栏/三栏/卡片/列表/图表/时间线/矩阵
4. **数据呈现**：指标卡(大数字+标注)、对比表、流程图、雷达图等
5. **页脚**：LOGO + 单位 + 页码（必选页饰）
6. **一页一结论**：标题尽量是判断句或行动句

## 融合示例

### 示例1：信息建筑派 + 电信品牌

```
选择：Massimo Vignelli式结构理性
融合结果：
- 配色：电信蓝(#0077BE)主色 + Vignelli的黑色结构线(#1A1A1A, 降饱和) + 白底
- 排版：严格网格系统，四栏或五栏布局，数据密集但不凌乱
- 页饰：电信标准标题栏+页脚
- 特色：信息层级极度清晰，数据呈现理性克制
```
