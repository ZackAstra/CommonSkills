# 电信正式风格设计约束

> 此文件约束 huashu-design 在 teleppt-pro 工作流中的推荐范围，确保设计方向符合央企内部汇报的正式严谨要求。

## 核心原则

**内部汇报 ≠ AI展示**。电信央企PPT的核心受众是领导、同事、客户，视觉风格必须克制、专业、可信赖。

## 可用设计流派（huashu-design 3选1时，只从以下流派推荐）

| 流派 | 视觉气质 | 适合场景 | 推荐权重 |
|------|---------|---------|---------|
| 信息建筑派（01-04） | 理性、数据驱动、克制 | 工作报告、指标展示、复盘 | ★★★ 最高 |
| 极简主义派（09-12） | 秩序、留白、精致 | 高端汇报、战略发布 | ★★☆ 次高 |

## 禁用设计流派（正式汇报中绝不使用）

| 流派 | 原因 |
|------|------|
| 运动诗学派（05-08） | 过于动感和沉浸，不符合正式汇报的克制要求 |
| 实验先锋派（13-16） | 视觉冲击过强，央企领导不适 |
| 东方哲学派（17-20） | 过于诗意和思辨，汇报场景不匹配 |

## 配色融合规则

选定设计方向后，其配色必须**服从电信品牌体系**：

1. **主色** → 强制回退为电信蓝 #0077BE（设计方向的主色仅作为"氛围参考"）
2. **辅助色** → 可从设计方向中选取1-2色，但饱和度降低30%，融入电信审美
3. **强调色** → 可从设计方向选取1色作为点缀，但仅用于数据标注和小面积标识
4. **背景色** → 锁定 #F5F7FA 或 #FFFFFF，不允许暗色系背景
5. **文字色** → 锁定 #333333 主文字 / #64748B 辅助文字

## 排版融合规则

1. **内容密度** → 中等偏密（央企汇报信息量大），但遵守一页一结论
2. **装饰元素** → 极简克制，线条和色块为主，禁止复杂图形装饰
3. **数据呈现** → 优先图表，图表配色用电信蓝渐变体系
4. **留白** → 保持呼吸感，但不做空旷的极简展示
5. **动效** → 零复杂动画（正式汇报场景），仅简单淡入
