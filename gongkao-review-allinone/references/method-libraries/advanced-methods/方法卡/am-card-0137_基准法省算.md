# 方法卡：基准法省算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基准法省算 |
| 适用题型 | 资料分析·多列数据逐个算值比较（如5年单价是否>150） |
| 触发场景 | 算出第一年的值恰好等于或非常接近阈值，后续年份只需与第一年做分数比较 |
| 步骤逻辑 | 1. 老实算出第一年的精确值 2. 若发现该值非常接近阈值（如151≈150）→它是基准 3. 后续年份不重新计算，只比较分子/分母相对于基准年的增速 4. 分子涨得快→超阈值，分母涨得快→低于阈值 |
| 高频错因 | 每一年都按第一年方式精算，浪费时间；看不出第一年是"设计好的基准" |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第7题中5年出让单价需判断>150万/亩的年份。算出2018年=151万/亩，恰好是基准。后续4年只需用趋势法判断：19年分子涨10%>分母涨→超150；20年分子涨3%<分母涨20%→低于150；21年分子涨30%>分母涨→超150；22年类似20年。全题只算了一次精确值。讲解中指出"出题人就这么设计的，要不然他给这么大的计算量他准备干嘛"。
