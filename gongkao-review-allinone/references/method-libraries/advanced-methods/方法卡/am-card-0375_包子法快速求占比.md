# 方法卡：包子法快速求占比

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 包子法快速求占比 |
| 适用题型 | 资料分析——分数比较或求比重时需要快速估算百分比 |
| 触发场景 | 多个分数需要比较大小，或需要快速算出某个比重的百分比值 |
| 步骤逻辑 | ①把分母的1%当作一个"包子"→②分子中有多少个包子就约是百分之多少→③多个分数比较时只需数各分子包含的包子数即可排序 |
| 高频错因 | 算1%时小数点位置错（如10282的1%是102.82不是10.282）；比较时忘记统一量级 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q4演示：东部121÷(10282的1%=102.82)≈1.2个包子→1.2%；中部126÷97≈1.3个包子→1.3%；东北390÷99.5≈3.9个包子→3.9%，东北最大。本质是把除法转化为"数倍数"的口算问题，分母位数越少越好算。
