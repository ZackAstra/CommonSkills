# 方法卡：基准值法求平均数

| 字段 | 内容 |
|------|------|
| 方法名 | 基准值法求平均数 |
| 适用题型 | 资料分析-求平均数（数据少且数值接近） |
| 触发场景 | 题目求4~5个数的平均值，数据之间差距小、数值接近 |
| 步骤逻辑 | 1. 观察数据，选一个中间偏合理的数作为基准值 → 2. 算每个数与基准值的偏差（正/负） → 3. 偏差求和后除以个数 → 4. 平均值 = 基准值 + 平均偏差 |
| 高频错因 | 年均值和年均增长搞混（有"增长"除以n-1，无"增长"除以n）；除以几搞错 |
| 来源文件 | source-0040.md |
| confidence | high |

补充说明：例如求45、45、47、49的平均值，选46为基准值，偏差分别为-1、0、+1、+3，偏差和=3，3÷4≈0.75，平均值≈46.75。此法比直接加总再除更快。注意年均值÷n（4个数据÷4），年均增长÷(n-1)。
