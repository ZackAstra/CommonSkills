# 代入验证法（综合分析题）

| 字段 | 内容 |
|------|------|
| **方法名** | 代入验证法（综合分析题） |
| **适用题型** | 资料分析 - 综合分析题（"以下说法正确/不正确的是"） |
| **触发场景** | 综合分析题中选项给出具体数值（如"增量超过X"），与其反向推算不如直接代入验证 |
| **步骤逻辑** | 1. 不要从材料算出结果再去匹配选项<br>2. 拿选项给出的数值当已知量代入条件<br>3. 例如：选项说"增量超6800"，材料给现期17037增速64.3% → 假设增量=6800，则基期=10237，增速=6800/10237≈66% > 64.3% → 说明增量给多了 → 实际增量<6800 → 选项错<br>4. 比正向计算快，尤其适合大数估算 |
| **高频错因** | ①习惯正向计算浪费时间 ②代入后不比较方向（大于/小于）③忘了"相差X倍"要减1 |

| **confidence** | high |
