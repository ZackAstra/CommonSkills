# 方法卡：对策五种表达识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策五种表达识别 |
| 适用题型 | 言语理解——片段阅读主旨题（识别文段中的对策句） |
| 触发场景 | 需要在文段中快速定位对策表述，不一定是"应该""必须"等显性词 |
| 步骤逻辑 | 五种对策表达：① 祈使型——"应该""需要""要""必须"；② 反面/禁止型——"不可以再""不能""要防止"；③ 逻辑关键词型——"只有……才……""除非……否则……""如果想……必须……"；④ 必要条件型——"前提""基础""关键""离不开""必不可少""不可或缺"；⑤ 语义表对策——"有利于""是必经之路""是时代命题"等间接表达。看到任何一种，都应视为对策句 |
| 高频错因 | 只认祈使型对策，忽略逻辑关键词和语义型对策；把"只有……才能……"中的条件当作论证而非对策 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第5题是典型例题："在公共服务的提供上需要考虑老年人需求"属于必要条件型（"需要"），很多考生因没认出这是对策而选错。第10题"只有回到群众回归生活才能获得新的生命力"属于逻辑关键词型（只有……才……），看到即可确定对策方向。语义型较隐晦，如"是当代年轻人的时代命题"暗含"必须做"之意。
