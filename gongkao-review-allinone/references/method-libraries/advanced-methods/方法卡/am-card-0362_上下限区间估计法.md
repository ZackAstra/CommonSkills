# 上下限区间估计法

## 字段

| 字段 | 内容 |
|------|------|
| **方法名** | 上下限区间估计法 |
| **适用题型** | 资料分析 - 假设增速求后期/范围题 |
| **触发场景** | 多月增速各不相同，要求后期总量的范围；选项区间较大，不需要精确计算 |
| **步骤逻辑** | 1. 先算出基期（限期）的总值<br>2. 找到各月增速的最小值和最大值<br>3. 用最小增速乘基期算下限，用最大增速乘基期算上限<br>4. 确定范围后匹配选项；若区间足够窄可直接锁定答案 |
| **高频错因** | 拿单一增速做精确计算，浪费时间且易错；不敢用区间估计法怕选错 |
| **来源文件** | internal-source |
| **confidence** | high |
