# 方法卡：以偏概全与他因择优

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 以偏概全与他因择优 |
| 适用题型 | 加强削弱——题干以偏概全，选项有"举反例"和"他因"两种质疑方向 |
| 触发场景 | 题干用打印机消耗量衡量全部纸张使用量（只统计了打印机，遗漏传真机和手写），问哪个最能削弱 |
| 步骤逻辑 | ① 识别逻辑漏洞：以偏概全（只统计了打印机这一种渠道）；② 优先找直接命中漏洞的选项（"员工也使用传真机和手写"=指出遗漏渠道）；③ C选项（也用复印扫描）=反向支持（说主要耗纸都在打印机上），排除；④ 若多个选项都能质疑，取力度最强的 |
| 高频错因 | 被C选项"也使用打印机进行复印和扫描"迷惑，以为是在指出不完整，实际反而支持了"耗纸主要在打印机上"的结论 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第10题核心：题干用打印机消耗量估算人均纸张消耗=以偏概全。D选项"也使用传真机和手写"直接命中漏洞——统计范围不完整。A（双面打印=还是打印机）和B（周末也用=还是打印机）都没跳出打印机的范围。C（也用复印扫描）反而说明耗纸主要在打印机上=支持。区分"以偏概全类削弱"的关键：找选项是否指出了题干统计/论证范围之外的遗漏。
