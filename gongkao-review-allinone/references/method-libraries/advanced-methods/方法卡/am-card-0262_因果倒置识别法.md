# 方法卡：因果倒置识别法

- **方法名**：因果倒置识别法
- **适用题型**：归因类论证题（支持/削弱）
- **触发场景**：选项出现"XX的特征""XX的表现"等暗示先患病后表现的表述
- **步骤逻辑**：
  1. 题干结论为"A导致B"（如玩手机导致抑郁）
  2. 选项出现"XX是B的特征"——特征意味着先患病后显现，即**先B后表现**
  3. 若该选项中"表现"恰好是A（如逃避现实→玩手机），则因果顺序被颠倒：B先于A
  4. 结论是A→B，选项暗示B→A，构成因果倒置，不能支持
- **高频错因**：看到"抑郁的特征"就认为在解释因果，忽略了"特征"一词暗含的时序关系——先有病才有特征
- **来源文件**：source-0038.md
- **confidence**：high

> 补充：用糖尿病类比——"患糖尿病的特征是体重减轻、多饮多尿"意味着先患病后出现这些症状。同理，"抑郁的特征是逃避现实"意味着先抑郁后逃避，而题干结论是"玩手机导致抑郁"，时序完全颠倒。
