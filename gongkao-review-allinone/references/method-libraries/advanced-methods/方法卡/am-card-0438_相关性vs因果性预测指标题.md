# 方法卡：相关性vs因果性-预测指标题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 相关性vs因果性-预测指标题 |
| 适用题型 | 判断推理-逻辑判断-削弱/支持题 |
| 触发场景 | 题干结论是"X是预测Y的重要指标"或"X与Y相关"，而非"X导致Y" |
| 步骤逻辑 | 1. 先看清结论问的是"预测指标/相关性"还是"谁导致谁/因果性" 2. 若问相关性→不论因果方向（A导致B、B导致A、C同时导致AB）都说明有相关性，都支持 3. 若问相关性→削弱应质疑预测的准确性（如存在其他干扰因素） |
| 高频错因 | 把"预测指标"题当成"归因"题，选了继发关联选项当削弱（其实继发关联也说明有相关性，是支持） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

关键区分：因果性问"谁导致谁"，相关性问"能不能根据一个推另一个"。只要A和B相伴发生（不管因果方向），A就能当B的预测指标。继发关联（A和B都是C导致的）反而说明A和B高度相关，是支持而非削弱。
