# 方法卡：对比实验支持题看对比维度匹配

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对比实验支持题看对比维度匹配 |
| 适用题型 | 判断推理——支持类（选项均为对比实验型论据） |
| 触发场景 | 结论涉及"不同X对Y有影响"，四个选项都是对比实验设计，需要选最能支持的 |
| 步骤逻辑 | ① 预判完美对比实验：应有两种不同背景（对照变量）+两种不同结果（因变量），形成双维度对比；② 看选项对比维度是否与论点匹配：如论点说"不同文化背景的语言影响数学处理方式"，完美对应该是两种具体语言（如英语vs中文）对应两种不同处理方式（如语言区vs视觉区）；③ 排除维度不匹配选项：如"亚洲vs欧洲"是地域对比不是语言对比，"不同方言区"不能代表不同文化背景 |
| 高频错因 | 看到选项都在做对比就纠结每个选项的细节差异；有完美匹配选项时仍花时间分析模棱两可的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第2题核心：四个选项都是对比实验，但只有C是"英语vs中文"（语言维度匹配）+"语言区vs视觉区"（处理方式维度匹配），构成完美双维度对比。A是地域对比（亚洲vs欧洲，不等于语言对比），B是方言区对比（可能同一文化），D是专业背景对比（不涉及语言）。考场策略：找到维度完美匹配的选项后直接走人，不纠结其他选项。
