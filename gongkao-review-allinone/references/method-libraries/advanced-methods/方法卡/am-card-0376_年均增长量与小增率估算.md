# 方法卡：年均增长量与小增率估算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增长量与小增率估算 |
| 适用题型 | 资料分析——年均增长量/率计算 |
| 触发场景 | 题干出现"X年到Y年年均增长约多少" |
| 步骤逻辑 | ①确定基期：材料直接给基期数据→不前推；未给但可算出→除江苏外一般也不前推；②分段求增量：增率<10%时可直接用 现期×增率 当增量（省去求基期）；③总增量=各分段增量之和→除以年份差（=末年-首年）→得年均增长量；④年均增长率判断：总增率÷年数 是年均增长率的上限（因复合效应使年均率一定小于该值） |
| 高频错因 | 年份差算错（应为末年-首年，不是年份数-1）；前推基期时多此一举（材料未直接给基期数据时不前推） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q3演示：17~22年，年份差=5。18年增率0.6%→用288×0.6%≈1.74，18~22年增量=726，总增量900÷5=180。Q6演示年均增长率上限判断：21%÷4=5.25%是上限，实际年均率<5.25%→直接选B。估算误差因最后除以年份差被压缩，大胆估即可。
