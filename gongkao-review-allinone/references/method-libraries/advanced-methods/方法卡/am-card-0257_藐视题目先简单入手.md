# 方法卡：藐视题目先简单入手

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 藐视题目先简单入手 |
| 适用题型 | 资料分析——排序题、比较题等有多个选项的题型 |
| 触发场景 | 题目要求排序或判断复杂关系，但某个简单特征（如最小值、最大值）能直接排除选项 |
| 步骤逻辑 | ① 不要上来就算，先扫一眼数据找最简单的突破口；② 先定性后定量——像盐水类问题一样先看趋势再算；③ 能用简单特征排除就排除，再考虑是否需要精确计算 |
| 高频错因 | 拿到题就埋头硬算，浪费时间；没有先观察选项特征就动笔 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

直播中的实例：年均增速排序题，先找同城增速末除初值（最小），发现只有D选项把同城排在最后，直接秒选D。强调"我认为这个题他可能不会考的那么难，就算他考的难，我一会再分析"——先尝试简单路径，不行再升级。
