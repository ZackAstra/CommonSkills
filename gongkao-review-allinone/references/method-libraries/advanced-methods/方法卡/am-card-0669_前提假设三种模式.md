# 方法卡：前提假设三种模式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提假设三种模式 |
| 适用题型 | 逻辑判断——前提假设题（问"必要前提""假设"） |
| 触发场景 | 题目问"需要什么前提""必要假设是什么" |
| 步骤逻辑 | ① 断点搭桥：结论有新内容，选项连接论据和结论；② 补充漏洞：题干有未考虑的方面，选项补上；③ 必要条件：其他选项都不够强时，选"没他就不行"的选项 |
| 高频错因 | 选了重复论据的选项；选了加强结论但不是必要前提的选项；忽略反向代入验证 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 前提假设是特殊的支持，推理过程不完整时使用。三种模式优先级：① 断点搭桥最常见（结论有新内容时）；② 补充漏洞（题干有未考虑的方面）；③ 必要条件（其他选项都不够强时的退而求其次）。验证方法：反向代入——如果没有这个前提，结论是否一定不成立？如果是，就是必要前提。
