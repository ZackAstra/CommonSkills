# 方法卡：高频切入法

- **方法名**：高频切入法
- **适用题型**：排列匹配/组合对应题（一拖五、条件匹配）
- **触发场景**：多个元素需要放入时间/位置格子中，存在重复出现的元素
- **步骤逻辑**：
  1. 统计每个元素在所有条件中出现的次数
  2. 找出出现次数最高的元素（高频元素）
  3. 从高频元素入手，结合限制条件确定其位置
  4. 高频元素确定后，连锁推出其他元素
- **高频错因**：从低频元素入手，信息不足导致大量试错；忽略"连续""不连续"等约束条件对高频元素的连锁影响
- **来源文件**：source-0038.md
- **confidence**：high

> 补充：Q5中无人机出现2次（高频），结合"必须连续两天下午"和"周六不卖"，立刻推出周五也不能卖，只能在周一至周三中选连续两天，周三必卖。Q15预测名次题中，每个名次下频次最高的人假设为正确，可以最大化正确率。
