# 方法卡：十字交叉法求混合比例
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 十字交叉法求混合比例 |
| 适用题型 | 数量关系-溶液混合/浓度问题 |
| 触发场景 | 两个部分混合成整体，已知各自浓度和混合后浓度，求溶液质量比 |
| 步骤逻辑 | 1.列出两个部分浓度和混合后浓度，画十字交叉；2.交叉相减得差值；3.差值之比为溶液（分母）质量之比；4.用实际量反推另一实际量 |
| 高频错因 | 混淆十字交叉得到的是溶质之比还是溶液之比；记住分母是溶液 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
十字交叉法得到的比值对应的是分母之比。浓度=溶质/溶液，所以交叉相减得到的是溶液质量之比。用已知的实际量（如甲16L）对应份数即可求出另一方。该方法同样适用于增长率、利润率等一切A/B型比值的混合。
