# 方法卡：背景加新结构识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 背景加新结构识别 |
| 适用题型 | 中心理解/态度理解（题干含"你肯定听过""大家都知道""一直以来"等铺垫） |
| 触发场景 | 第一句话铺垫一个已有的理论/普遍认知，暗示"我要讲点不一样的"；问作者态度或文段重点 |
| 步骤逻辑 | ① 识别首句的铺垫语气（"你肯定听过""深入人心""煞费苦心"暗示作者对旧理论持怀疑/否定态度）；② 后续内容必然是作者要提出的新观点/新认识；③ 主旨抓"新"的部分，态度选"怀疑"或"不一定"；④ ABC若延续旧理论的内容均为干扰项 |
| 高频错因 | 被首句的普遍认知带偏，选了延续旧理论的选项；没听出"你肯定听过"背后的言外之意（"我偏要说点不一样的"） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

类似《爱莲说》的行文逻辑："世人皆爱牡丹"（背景）→ "予独爱莲"（新观点）。考试中看到"你肯定听过""众所周知"之类的铺垫，立刻预判作者要提新东西。态度题选"不一定"/"怀疑"，主旨题抓新认识部分。
