# 方法卡：配对条件选人排除

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 配对条件选人排除 |
| 适用题型 | 形式推理——N选M配对约束题（如七选四，配对至少选一个但不能都选） |
| 触发场景 | 题干给出多组配对条件"至少一人参加但不能都参加"，求必然能推出的结论 |
| 步骤逻辑 | ① "至少一个但不能都参加"=异或（要么A要么B）=每对只出一人；② 从总名额减去已锁定的配对名额，算出剩余名额；③ 剩余名额 > 剩余组人数 - 1时，该组任意两人的"或/且"都必然成立；④ 用"3选2时任意两人都至少有一个"的逻辑直接判断 |
| 高频错因 | 只盯着给定条件推导，忘记用总名额做排除；把"至少一个但不能都参加"误当成"至少一个"（或关系），忽略了"不能都参加"的额外约束 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第19题核心：7选4，条件1李→午，条件2前→周，条件3王和周至少一个但不能都参加，条件4李和赵至少一个但不能都参加。王周=出一人，李赵=出一人，已用2个名额剩2个名额从吴郑钱3人中选2人=3选2。3选2=最多只能排除1人→任意两人"或"都必然成立。因此"吴或郑参加""吴或钱参加""郑或钱参加"都必然对。B选项"李或钱"不行——让李和钱都不参加（选赵，吴郑赵）也满足所有条件。答案=C。
