# 间隔增长率逆运用

| 字段 | 内容 |
|------|------|
| **方法名** | 间隔增长率逆运用 |
| **适用题型** | 资料分析 - 增长率计算 |
| **触发场景** | 已知间隔增长率R和某一年同比增速R1，求另一年R2（材料给的是两年对比三年的数据） |
| **步骤逻辑** | 1. 识别题型：材料给的是"比XX年增长X%"（间隔）和其中一年同比，求另一年同比 → 典型间隔逆运用<br>2. 用公式 R2 = (R - R1) ÷ (1 + R1)<br>3. 先判断符号：若R < R1且均为正 → R2为负值，可快速排选项<br>4. 口算：分子=间隔-同比（本题23.3-105≈-82），分母=1+R1≈2.05，结果≈-40 |
| **高频错因** | ①不识别题型，按普通增长率算 ②忘记R1是百分数要÷100参与运算 ③符号判断错误 |

| **confidence** | high |
