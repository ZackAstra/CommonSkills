# 方法卡：基期倍数放缩法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期倍数放缩法 |
| 适用题型 | 资料分析——求基期倍数（A/B × (1+B率)/(1+A率) 形式） |
| 触发场景 | 题目给出两个主体的现期值和各自增长率，要求求基期倍数，且右边分数 (1+B率)/(1+A率) 接近1 |
| 步骤逻辑 | ① 列式：基期倍数 = (A/B) × (1+B率)/(1+A率)；② 观察右边分数：若两个增长率接近，右边接近1，可用放缩；③ 放缩方法：给分子分母同时加减相同量，使其中一个分数变成整数或简单分数，约分后只剩一步计算 |
| 高频错因 | 不识别放缩适用场景，对右边分数强行直除；放缩时加减量不匹配分子分母的比例关系 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

放缩的关键判断：右边分数 A/B × (1+B率)/(1+A率) 中，右边的 (1+B率)/(1+A率) 与1的差距决定了放缩的精度。差距越小，放缩越准。当右边约等于1时，"稍微调吧就变成一了"，是放缩的最佳适用场景。
