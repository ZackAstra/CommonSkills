# 环比月份差传递估算

## 字段

| 字段 | 内容 |
|------|------|
| **方法名** | 环比月份差传递估算 |
| **适用题型** | 资料分析 - 已知环比增速求单月值，问某月与另一月的差值 |
| **触发场景** | 题目给1-5月、1-4月等累计值和同比增速，要求5月与3月的差值大小 |
| **步骤逻辑** | 1. 用累计值做差得到目标单月值（如5月 = 1-5月 - 1-4月）<br>2. 找到中间月份（4月）的值，算出5月比4月少了多少<br>3. 用4月增速估算4月比3月多了多少<br>4. 传递关系：5月比3月少的量 ≈（5月比4月少的量）-（4月比3月多的量），锁定选项 |
| **高频错因** | 不会用中间月份做传递，直接算3月基期再做差，浪费时间且精度不够 |
| **来源文件** | internal-source |
| **confidence** | high |
