# 方法卡：极限思维法

- **方法名**：极限思维法（上下限取值法）
- **适用题型**：排列推理/预测类量化题
- **触发场景**：题干出现"超过一半""至少""不超过"等上下限表述
- **步骤逻辑**：
  1. 遇到"超过一半"（>50%）→ 取下限，按恰好50%算
  2. 遇到"不超过"（≤50%）→ 取上限，按恰好50%算
  3. 七人预测名次，"超过一半"即至少对4个（7×50%取上整）
  4. 为使尽可能多人满足条件，每个名次下频次最高的预测者假设为正确
  5. 只有某个预测者在所有名次上正确数仍不够4个时，才需要额外调整
- **高频错因**：纠结"超过一半到底是60%还是70%"，不确定导致无法下手；不知道取边界值简化计算
- **来源文件**：source-0038.md
- **confidence**：high

> 补充：此题型多次出现，属固定思维。核心是：不确定具体数值时用边界值（极限）代替，配合高频元素假设正确来最大化满足条件的人数。Q15中乙丙丁各对4个满足条件，甲只对3个，补上第三名即甲对4个满足。
