# 方法卡：断点搭桥法

- **方法名**：断点搭桥法
- **适用题型**：前提假设题、支持题
- **触发场景**：论据和结论中出现不同关键词/不同话题时
- **步骤逻辑**：
  1. 找出论据中的核心关键词
  2. 找出结论中的核心关键词
  3. 判断二者是否为同一话题（若不一致则存在断点）
  4. 正确答案必须同时包含论据关键词和结论新关键词，将其搭成桥
  5. 若选项只涉及一侧关键词而未覆盖另一侧，直接排除
- **高频错因**：只看到选项提到了论据中的关键词就选，忽略了结论中的新内容必须在选项中有所体现
- **来源文件**：source-0039.md
- **confidence**：high

补充说明：例如论据说"成交量上涨"，结论说"楼价调控压力大"，则正确选项必须同时包含"成交量"和"楼价"，如"成交量增长会带动楼价上涨"。质疑题中对应操作是断点拆桥。
