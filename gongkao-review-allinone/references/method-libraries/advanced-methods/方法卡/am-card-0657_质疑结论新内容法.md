# 方法卡：质疑结论新内容法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 质疑结论新内容法 |
| 适用题型 | 逻辑判断——一般质疑（结论含论据未提及的新内容） |
| 触发场景 | 结论中出现了论据里完全没有涉及的新关键词（如"预防""颠覆""大大改善"等），且该新内容无依据支撑 |
| 步骤逻辑 | ① 定位结论中的新关键词（论据里没有的词）；② 检查论据是否支持这个新内容；③ 如果不支持，针对该新内容进行质疑 |
| 高频错因 | 忽略结论中的新词，只盯着论据和结论的表面逻辑；选了浮于表面的万金油选项（如"仍在进行临床实验"） |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

典型实例：① 论据说"检测标志物可判断冠心病"，结论多出"预防"→质疑：得病后标志物才异常，检测只能确诊不能预防（[2:49:16]）；② 论据说"原子制造很牛"，结论多出"颠覆性"→质疑：它是线性发展，不颠覆现有制造业（[2:58:22]）。识别技巧：读题时特别注意结论中有没有论据里没出现过的"突兀"新词，这往往就是出题人的漏洞设置点。
