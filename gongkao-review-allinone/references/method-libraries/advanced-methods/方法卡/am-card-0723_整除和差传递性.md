# 整除和差传递性

## 适用题型
判断某数是否为某因子的倍数，涉及多个部分之和/差的整除关系

## 触发场景
已知整体和部分都是某数的倍数，或需要通过"和与差"推导整除关系

## 步骤逻辑
1. 若 A 是 d 的倍数，B 也是 d 的倍数
2. 则 A + B 和 A - B 都是 d 的倍数
3. 原理：A = d×N，B = d×M → A+B = d(N+M)，A-B = d(N-M)

## 高频错因
- 只考虑单个数的整除性，忽略"和/差也是倍数"的传递性质

## 补充说明
- 例9应用：总页数和(1+2+...+204)是85倍数，剩余200页也是85倍数→被污染页也必是85倍数
- 此性质是整除问题的第二个常考点，常与分数占比整除特性配合使用
