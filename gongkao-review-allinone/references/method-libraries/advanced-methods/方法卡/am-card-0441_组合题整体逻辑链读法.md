# 方法卡：组合题-整体逻辑链读法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 组合题-整体逻辑链读法 |
| 适用题型 | 判断推理-逻辑判断-组合削弱/支持题（问"哪项组合"） |
| 触发场景 | 题目问"以下哪几项组合为真最能质疑/支持"，而非单个选项 |
| 步骤逻辑 | 1. 认清题目要求：选出来的几个选项要串成一条完整逻辑链 2. 把候选组合（如选项4、1、3）按顺序读，看是否构成因果递进 3. 检查是否遗漏环节（如需要说明起源→迁移→传播的完整链条） 4. 排除虽相关但逻辑链不完整的选项（如"农牧业发展"含糊不清） |
| 高频错因 | 没意识到是组合题，按单选项思维做；选入概念含糊的选项（如"农牧"同时出现无法支持单方） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

组合题的关键是：选出来的几个选项读起来要像一篇完整的论证。每个选项承担论证链中的一个环节，缺一不可。选项中如果出现概念含糊（如"农牧业"既含农又含牧），无法明确支持某一方，则不宜入选。
