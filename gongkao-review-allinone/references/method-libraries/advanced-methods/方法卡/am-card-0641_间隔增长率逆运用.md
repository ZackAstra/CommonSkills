# 方法卡：间隔增长率逆运用

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率逆运用 |
| 适用题型 | 资料分析——已知总增长率和其中一个分段增长率，求另一个分段增长率 |
| 触发场景 | 题目给出23年比21年的总增长率R和23年比22年的R1，求22年比21年的R2 |
| 步骤逻辑 | ① 画时间轴确定各段；② 判断正负：总R>R1则R2为正，总R<R1则R2为负；③ 估算数值：R2 ≈ R - R1，但比|R-R1|稍小（因为要减去R1×R2这个小正数） |
| 高频错因 | 符号判断错误；忘记乘积项的影响 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 核心判断技巧：R2的数值总是比|R-R1|稍小。因为R = R1 + R2 + R1×R2，所以R2 = R - R1 - R1×R2，比R-R1少了一个小正数。正数时比差值小一点，负数时绝对值比差值小一点。
