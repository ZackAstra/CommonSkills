# 方法卡：比重差秒杀公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重差秒杀公式 |
| 适用题型 | 资料分析-比重差（上升/下降多少个百分点） |
| 触发场景 | 题目问"比重约上升了多少个百分点"或"下降了多少个百分点" |
| 步骤逻辑 | 1.先算R1-R2（分子增率减分母增率）；2.根据正负排除方向错误的选项（正→上升，负→下降）；3.再用现期比重×(R1-R2)/(1+R1)精算或根据选项差距直接选 |
| 高频错因 | 把比重差当成增率之差直接选；不先判断正负就急着算 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

核心公式：比重差 = (A/B) × (R1-R2)/(1+R1)。其中A/B为现期比重，R1为分子增率，R2为分母增率。考试时先算R1-R2的符号排除选项，再根据现期比重大小判断量级。选项通常设置为10倍关系（如0.17和1.7），量级一眼可辨。词义辨析原话：20秒解决，如果还去算会很心痛。
