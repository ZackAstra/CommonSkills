# 方法卡：断点搭桥法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点搭桥法 |
| 适用题型 | 判断推理——加强类（前提假设/搭桥） |
| 触发场景 | 题干从A越来越少推到C越来越少，但A和C之间缺少逻辑连接；选项需要补上A→C的桥梁 |
| 步骤逻辑 | ① 提取前提A和结论C的关键词；② 发现A和C之间存在断点（如"自由流动河流减少"→"河流利益减少"，断点是"自由流动"与"利益"的关系）；③ 正确选项必须建立A与C的联系——"自由流动的河流能带来多种利益"；④ 无关选项（只介绍背景、没有自己观点）直接排除 |
| 高频错因 | 被背景介绍类选项迷惑（如A说"首次评估"、B说"大坝数量"，均无观点，不能搭桥）；忽视断点，选了与结论话题不完全对应的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

此题Q2为典型搭桥题：前提"自由流动河流仅剩1/3"→结论"河流利益减少"。断点在于"自由流动"和"利益"的关系。D选项"自由流动的河流支持淡水鱼繁衍、维系生物多样性"直接搭桥。类比理解："我金钱少了所以欢乐少了"——需要搭桥"金钱带来欢乐"。
