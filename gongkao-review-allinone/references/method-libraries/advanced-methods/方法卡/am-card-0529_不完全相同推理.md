# 方法卡：不完全相同推理——用"排除法"防止完全相同

## 适用题型
排列组合/分析推理（判断推理）

## 触发场景
题干要求"四人调研的城市不完全相同"，即允许有一个相同但不允许两个都相同

## 步骤逻辑
1. "不完全相同"= 可以有一个相同，但不能两个都相同
2. 若某人的两个选项都被确定 → 检查其他人若也选这两项是否违反"不完全相同"
3. 若违反 → 另一人在该位置不能选叉 → 该位置必须打勾
4. 本质上是利用"排除完全相同"来推出确定信息

## 高频错因
- 把"不完全相同"理解为"完全不同"（过于严格）
- 忘记利用这个约束来推理
