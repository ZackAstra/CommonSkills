# 盐水混合定全年增速

## 字段

| 字段 | 内容 |
|------|------|
| **方法名** | 盐水混合定全年增速 |
| **适用题型** | 资料分析 - 已知上半年同比增速，假设下半年相同，求全年增速或全年值 |
| **触发场景** | 材料给出上半年同比增速，题目要求"按上半年增速测算全年"；其他年份只有全年数据 |
| **步骤逻辑** | 1. 上半年增速是与上年同期相比的同比增速<br>2. 若假设下半年也按相同同比增速增长，则上半年和下半年各自较上年同期涨了相同比例<br>3. 根据盐水混合原理：两部分增速相同时，整体增速等于该增速<br>4. 因此全年增速 = 上半年增速，直接用全年基期 ×（1+增速）得到全年现期 |
| **高频错因** | 把"按上半年增速测算"误理解为环比关系，错误地用上下半年做差再算 |
| **来源文件** | internal-source |
| **confidence** | high |
