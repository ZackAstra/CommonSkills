# 方法卡：因果类与并列类文段区分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 因果类与并列类文段区分 |
| 适用题型 | 言语理解——中心理解题 |
| 触发场景 | 文段描述了多个信息点，选项中有"原因"类选项（"XXX的原因"）和"A且B"类并列选项，需要判断文段是因果结构还是并列结构 |
| 步骤逻辑 | ① 看文段是否全文围绕一个"结果"反复出现来寻找原因：若前文提出结果、中间分析原因、结尾回扣结果，则为因果/果因类；② 若文段只是分别介绍两个方面（如成因+影响），没有反复围绕结果讨论，则为并列类；③ 并列类选"A且B"选项（如"成因与影响"），因果类选"原因"选项 |
| 高频错因 | 看到文段末尾有结果就认为是因果类，但文段其实只在末尾提了一句结果，并非全文反复围绕该结果讨论；选了"原因"类选项但文段实际是并列结构 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第6题(00:32:42)是典型例题：文段介绍北大西洋暖流的成因（西风+北冰洋海水+墨西哥湾暖水）和影响（为西欧带去热量），是并列结构，选"成因与影响"的A且B选项。若文段改成"同在北半球，欧洲冬季气温明显更高...之所以出现这一现象，关键在于北大西洋暖流...最终让这里的冬季远比同纬度其他地区温暖"，则为因果类，才能选"原因"选项。讲解中特意给出了两个改写版本来对比说明。
