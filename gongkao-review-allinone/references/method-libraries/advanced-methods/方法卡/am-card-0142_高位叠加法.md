# 方法卡：高位叠加法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 高位叠加法 |
| 适用题型 | 资料分析·多个数据求和（如六个产业增加值加总求比重） |
| 触发场景 | 需要把3个以上数据相加，选项差距较大（≥20%） |
| 步骤逻辑 | 1. 优先从百分位（最高位）开始叠加 2. 百分位算完得到大数后，十分位和个位"意思意思"即可 3. 不追求低位精确，因为选项差距足够大 |
| 高频错因 | 从个位开始逐位精确叠加浪费时间；低位算太准但选项差距根本不需要 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第4题中需要把六个产业增加值加总后求占总体比重。讲解中演示从百分位叠加（8+1=9, +6=15, +2=17, +3=20, +15=35），再粗略加十分位得到约3750。选项差距约20%，所以低位不需要精确。核心理念：根据选项差距决定计算精度，高位决定数量级，低位只影响细调。
