# 方法卡：正推逆推链式推理

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 正推逆推链式推理 |
| 适用题型 | 逻辑——推出类·正推和逆推（题干给出逻辑链 A→B→C→D，问已知某条件能推出什么/需要什么条件） |
| 触发场景 | 题干构建了多个逻辑命题形成的传导链，已知某个条件成立问能推出什么（正推），或问某结论成立需要什么前提（逆推） |
| 步骤逻辑 | 正推（顺着推）：已知A成立→顺着链条推到底→能推出D；或已知非D→逆否推到非A。逆推（倒着推）：想要D成立→需要C→需要B→需要A，一步一步沿链条回溯到起点。实际做题不用画出整个链条，利用题干材料在原文上标记即可 |
| 高频错因 | 正推时跳步导致推错中间环节；逆推时方向搞反，把"需要什么"和"能推出什么"混为一谈 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

正推和逆推本质是同一个逻辑链的两个方向。正推是从已知条件出发沿箭头方向逐级传递，逆推是从目标结论出发逆向寻找必要条件。讲解中强调不要把整个逻辑过程都写出来浪费时间，利用题干原文标记推理路径即可。逆推常用场景："想要D成立需要什么"，答案是链条起点A或其必要条件。
