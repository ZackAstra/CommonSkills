# 方法卡：三选二配合限制推出必然入选

## 适用题型
排列组合/分析推理（判断推理）

## 触发场景
"N选M"的排列题中，部分元素受到"不能同时入选"限制，需要推出确定性信息

## 步骤逻辑
1. 将"不能同时入选"翻译为"非A或非B"
2. 观察"N选M"条件与限制条件能否联动
3. 若其中两个元素受限为"至多选一个"，且整体要选M个，则第M+1个位置必然是剩余元素入选
4. 举例：三选二，甲丙至多入选一个 → 乙必然入选
5. 推出确定信息后，继续代入其他条件链式推理

## 高频错因
- 看不到"N选M"和"至多一个"之间的联动关系
- 推出一步确定信息后忘记继续往下代入

## 补充说明
第1题核心技巧。男员工三选二+甲丙至多选一 → 乙必然入选 → 乙入选带入条件四"乙庚不能同时入选" → 庚必然不入选 → 女员工变三选二 → 同法推出庚必然入选。形成链式推理。
