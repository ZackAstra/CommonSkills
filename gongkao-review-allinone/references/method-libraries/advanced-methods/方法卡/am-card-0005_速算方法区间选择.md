# 方法卡：速算方法区间选择

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 速算方法区间选择 |
| 适用题型 | 资料分析——根据增长率大小选择最优速算方法 |
| 触发场景 | 需要求基期、增量、比重等，增长率落在不同区间时 |
| 步骤逻辑 | ① 增长率在 -10%~0%：用化除为乘（B/(1+R) ≈ B×(1-R)）；② 增长率在 0%~20%：用假设分配最合适；③ 增长率能凑到某个简单分数附近（如1/4、1/3等）：用百化分（分数法）；④ 增长率很大（>50%）且凑不到分数：各方法无明显优势，直除即可 |
| 高频错因 | 增长率较小时仍选择直除而不用假设分配，效率低下；不判断增长率区间而随机选择方法 |
| 来源文件 | internal-source|
| confidence | high |
