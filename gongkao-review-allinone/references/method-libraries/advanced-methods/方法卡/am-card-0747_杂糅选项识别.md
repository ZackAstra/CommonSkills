# 方法卡：杂糅选项识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 杂糅选项识别 |
| 适用题型 | 言语理解——片段阅读（主旨/意图题） |
| 触发场景 | 选项中的短语看似来自原文，但实际是从不同句子中各取一两个字拼凑而成 |
| 步骤逻辑 | ① 看到选项中某个短语，回原文定位其出处；② 检查该短语是否完整来自同一句话，还是从两句话中各取部分拼凑；③ 如果是拼凑（杂糅），该选项有误，不能选；④ 正确概括应使用原文的完整表述或忠实同义替换 |
| 高频错因 | 被拼凑出的"时髦短语"迷惑，感觉"听着好像是那么回事"就选了；未逐词核对原文 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

典型杂糅示例：原文一处说"现代需求"，另一处说"表现形式"，选项拼出"现代化的表达"——看似合理，实则是创造性拼凑。一般概括应使用原文中的词，不是从不同句子各取两个字组合。另外还需注意：选项如果只覆盖了分号后半部分而忽略了前半部分，则犯了"片面"的错误。
