# 方法卡：直接原因vs根本原因

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 直接原因vs根本原因 |
| 适用题型 | 判断推理——削弱加强类（双方观点对立归因） |
| 触发场景 | 题干存在原观点（A导致C）和反对者（B导致C），问支持/质疑某一方 |
| 步骤逻辑 | ① 画出两条因果链：原观点 A→C，反对者 B→C；② 支持谁→让谁当根本原因（排在前面）：支持原观点选"A→B→C"，支持反对者选"B→A→C"；③ 质疑谁→让谁当表面原因（排在后面）：质疑反对者选"A→B→C"（B只是表面原因，A才是根本）；④ 直接看选项中谁"导致"谁即可匹配 |
| 高频错因 | 把"支持谁让谁是根本"和"质疑谁让谁是表面"搞反；题目让支持反对者时（如四川事业编创新题），习惯性只看原观点方向 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q11为典型题：原观点"细胞端粒减少导致阿尔兹海默"，反对者"脑部神经突起减少导致阿尔兹海默"。质疑反对者→让细胞端粒减少是根本→选"细胞端粒减少引起脑部神经突起减少，然后才导致阿尔兹海默"。此为套路题，考场可秒杀。
