# 方法卡：小丑法化除为乘

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 小丑法化除为乘 |
| 适用题型 | 资料分析——基期计算、负增速的现期转基期 |
| 触发场景 | 选项非常接近，需要精确计算基期；BR直接相乘（化除为乘）有误差不够选；增速≤5% |
| 步骤逻辑 | ① 先用BR直接乘得到近似增量X₁；② 对增速做修正：上升时用R−R²，下降时用R+R²；③ 用修正后的增速重新乘现期得到更精确的增量X₂；④ 基期=现期±X₂ |
| 高频错因 | 正增长误加R²（应减R²），负增长误减R²（应加R²）；增速超过5%仍强行使用导致误差过大 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

推导原理：B/(1+R) 分子分母同乘(1−R)，分母变成1−R²，再乘(1+R²)得1−R⁴（极小可忽略），展开分子为B(1−R+R²)。R²很小，4%时仅0.16%，修正后精度大幅提升。
