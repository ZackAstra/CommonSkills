# 方法卡：环比份数法求单月数据

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 环比份数法求单月数据 |
| 适用题型 | 资料分析——已知某月环比变化率和累计量，反推其中某个月的数据 |
| 触发场景 | 题目给出1~2月累计量、2月环比变化率，要求计算1月数据；或类似的用环比关系反推单月 |
| 步骤逻辑 | ① 标记时间：识别题目问的是单月，而材料只给累计和环比；② 设份：被比月（1月）设为100份，根据环比变化率计算另一月份数（下降26.3%→73.7份）；③ 加总：100+73.7=173.7份对应累计量52.5；④ 求目标：1月份=52.5÷173.7×100，有效数字锁定即可选答案 |
| 高频错因 | 搞混环比方向（谁比谁下降）；把"下降26.3"当百分点直接减，而不是算份数；忘记1月份本身也是100份要加进总份数 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

此方法本质是利用份数思想将环比关系转化为加法问题，避免列方程。方程法（设1月为X，X+0.737X=52.5）与份数法等价，但份数法更直观。讲解中强调此题是"好题"（星号题），因为逆向利用环比求单月在考试中较创新。
