# 方法卡：连续自然数积差化简
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 连续自然数积差化简 |
| 适用题型 | 数量关系-数字特性/连续自然数问题 |
| 触发场景 | 两组连续自然数的积之差已知，求中位数之和或其他量 |
| 步骤逻辑 | 1.设第一组中间数为A，则为(A-1)·A·(A+1)=A(A²-1)；2.第二组和差3，中间数为A+1，积为A·(A+1)·(A+2)；3.提公因式A·(A+1)，剩余(A+2)-(A-1)=3；4.得3·A·(A+1)=差值，即A·(A+1)=差值÷3；5.分解因数求A |
| 高频错因 | 未利用"和差三"条件确定两组的关系；提公因式时符号错误 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
三连续自然数之积：A-1, A, A+1 → A(A²-1)。若两组连续自然数和差3，则中间数差1，即(A-1)A(A+1) vs A(A+1)(A+2)。提公因式A(A+1)后，差=3·A(A+1)。题目给差=468，则A(A+1)=156=12×13，中位数之和=12+13=25。核心技巧是提公因式后只剩一个简单因子。
