# 方法卡：多多大于少少

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 多多大于少少 |
| 适用题型 | 判断推理——多维度划分类推理题（"由此可以得出"类问法） |
| 触发场景 | 总量固定，从两个维度对同一集合进行划分（如借阅/自购 × 中文/英文），且每个维度内部都是矛盾关系（非此即彼、无剩余） |
| 步骤逻辑 | ① 画出二维表格，填入已知数量；② 确认两个划分维度各自是矛盾关系（总量恰好被完全划分，无"其他"）；③ 找出两个维度中"多"的一方，交叉得到"多多"；找"少"的一方，交叉得到"少少"；④ 恒成立结论：多多 > 少少 |
| 高频错因 | 在维度不构成矛盾关系（有剩余类别）时误用此法；维度数量加总不等于总量时仍套用 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q3示范：15本书 = 借阅9 + 自购6（矛盾），15 = 中文8 + 英文7（矛盾）。借阅比自购多，中文比英文多，所以"借阅中文"（多多）恒 > "自购英文"（少少），差值恒为2（A vs A-2）。若划分不完整（如15 = 中文8 + 英文4，则必有其他语种），此法不适用。
