# 方法卡：选项分析三要素

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项分析三要素 |
| 适用题型 | 言语理解-中心理解题（主旨都正确时的最终筛选） |
| 触发场景 | 两个或多个选项都看似正确，需要最终比较筛选时 |
| 步骤逻辑 | 1. 先比形式：是否为对策/问题/意义表述，形式不对直接排除 2. 再比针对性：哪个选项更针对文段的核心问题 3. 最后比支撑：哪个选项有论证支撑、非无中生有 4. 三个维度依次比较，逐步筛选出最优选项 |
| 高频错因 | 一开始就纠结选项细节（片面、用词等），忽略了形式和针对性的优先判断 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

强化方法在第3题（B和C比较）中完整展示了选项分析的三步法。B是"应该去关注中华文化因素"（傻瓜对策，只抓了问题一半），C是"应该在教育中发挥主体作用"（针对占比失衡问题且有前文论证支撑）。最终C胜出。强化方法强调："一般情况下我们不需要去分析选项"，只有当主旨都正确时才做选项分析，这是"阅读的最后一步"。不要在最开始就用"片面"逻辑排除选项，先看主旨是否正确。
