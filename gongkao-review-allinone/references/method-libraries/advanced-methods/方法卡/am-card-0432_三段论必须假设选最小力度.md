# 方法卡：三段论-必须假设选最小力度

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三段论-必须假设选最小力度 |
| 适用题型 | 判断推理-逻辑判断-三段论前提假设 |
| 触发场景 | 三段论题目问"必须假设"，且C选项是"所有"、D选项是"有些"，两者都能推出结论时 |
| 步骤逻辑 | 1. "所有"可以推出"有些"，所以"所有"和"有些"都能让结论成立 2. 但题目问"必须假设"=必要条件=最小限度 3. "有些"已经够用→选"有些"；"所有"程度过重→不选 |
| 高频错因 | 看到"所有可以推有些"就选了"所有"，忽略了"必须假设"要求的是最小必要条件 |

## 补充说明

"所有可以推有些"是对的，但前提是假设题问的是"必须假设"，等同于"最小限度的必要条件"。只需要一部分成立就足够了，不需要全部，所以选"有些"而非"所有"。这是出题人常见的坑。
