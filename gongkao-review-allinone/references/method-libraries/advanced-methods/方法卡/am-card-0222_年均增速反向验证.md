# 方法卡：年均增速反向验证

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增速反向验证 |
| 适用题型 | 资料分析——判断同比增速是否高于年均增速 |
| 触发场景 | 题目问"某年同比增速是否高于X~Y年的年均增速"，不需要开根号，反向验证即可 |
| 步骤逻辑 | ① 算出同比增速（待判断值）；② 把这个增速代入，用复合公式算出N年的总增速；③ 再算实际N年的总增速（末年/初年-1）；④ 代入总增速 < 实际总增速 → 年均增速高于该值 → 同比低于年均 |
| 高频错因 | 反向操作（去开根号求年均）；年数搞错；复合计算时把简单乘法当成复利 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第20题完整演示：同比增速约8%，代入4年总增速≈36%，但实际总增速（2.79→4.45）超50%，36%<50% → 实际年均高于8% → 同比低于年均。词义辨析强调"不会开四次方"，此题正确率仅8%。
