# 乘积增长率

- **方法名**: 乘积增长率
- **适用题型**: 资料分析 - 已知总量和占比增速，求其中一部分的增速
- **触发场景**: 题目给总出口规模+某类型占比，求该类型增速；或已知A=B*C形式的两个因子增速
- **步骤逻辑**:
  1. 判断题目是否为乘积形式（如：B2C出口 = 总出口 × B2C占比）
  2. R1 = 总量增速（如总出口从6.3到7.1，R1≈12.5%）
  3. R2 = 占比增速（如B2C占比从19%到19.7%，R2≈3.7%）
  4. 乘积增长率 R = R1 + R2 + R1×R2
  5. R1×R2 通常很小，口算即可，约等于 R1+R2
- **高频错因**: 拿B2B占比直接算增速（B2B占比下降不代表B2C增速就是那个数）；混淆占比方向（应算B2C而非B2B）
