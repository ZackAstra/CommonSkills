# 不谈剂量质疑

- **方法名**: 不谈剂量质疑
- **适用题型**: 判断推理 > 削弱质疑（实验→日常应用类）
- **触发场景**: 题干用"某提取物/成分对动物有效"推出"日常摄入该食物有好处"
- **步骤逻辑**:
  1. 实验结论 → 日常应用，存在"剂量/浓缩度"的跳跃
  2. 关键质疑：只有大剂量/提取浓缩后的有效成分才起效，日常摄入量远远不够
  3. 选项中含"只有""提取浓缩后""大剂量"等限定词时高度警惕——可能是正确答案
  4. 典型例子：秋葵素对动物有效≠秋葵泡水降血糖；大蒜提取物致癌≠炒菜用大蒜致癌
- **高频错因**: 误以为"有效果"就能直接推到日常；没注意剂量差异

- **confidence**: high
