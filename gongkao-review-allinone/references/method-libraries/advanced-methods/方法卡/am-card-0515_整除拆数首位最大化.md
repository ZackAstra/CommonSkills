# 方法卡：整除拆数首位最大化
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 整除拆数首位最大化 |
| 适用题型 | 数量关系-整除/数字构造 |
| 触发场景 | 用1-9各用一次组成若干能被9整除的多位数，求和最大/最小 |
| 步骤逻辑 | 1.被9整除→各位数字之和为9的倍数（9或18） 2.1-9总和45，拆成3组每组和为15→每组都是9的倍数（9/18/18或9/9/27不可行） 3.和为9的组首位最大只能到6（7+2无0可用），故为621 4.和为18的组：首位尽可能大→9和8开头，9开头两个数和为9→54；8开头两个数和为10→73 5.三数为621、954、873，看尾数1+4+3=8 |
| 高频错因 | 漏算27的情况（27需要三个9，数字不能重复）；不优先排大数到百位导致和非最大 |

## 补充说明
关键约束：1-9各用一次且三位数不能含0。拆成三组时，每组和必须是9的倍数，而45只能拆为9+18+18（27不可行）。首位越大整个数越大，所以18的组优先9和8做百位。
