# 方法卡：间隔增长率秒杀

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率秒杀 |
| 适用题型 | 资料分析——间隔增长率、跨年增速比较 |
| 触发场景 | 题干出现"间隔一年"（如2022比2020），选项为百分数；或材料给出"增速比上年回落/上升X个百分点"，需反推另一年增速 |
| 步骤逻辑 | ① 从材料提取今年增速R1，通过百分点加减得去年增速R2（回落则加、上升则减）；② 算R1+R2；③ 若只有一个选项>R1+R2，直接选定，跳过R1×R2精算；④ 若需精算，R1×R2取近似（如11.2%×17.7%≈2%），加回R1+R2即得 |
| 高频错因 | 百分点方向搞反（"回落"应加而非减）；错认年份用今年数据算答案；纠结R1×R2精确值浪费时间 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

秒杀核心在于选项差距大时，R1+R2已能锁定唯一答案。公式纸面只需写"11.2 / 17.7 / 29+"三个数字即可。
