# 混合比例法（总价比值混合）

- **适用题型**: 数量关系 — 经济利润 / 折扣促销题
- **触发场景**: 已知整体的现价/原价（或总价比），各商品有不同折扣方式，汢单价
- **步骤逻辑**:
  1. 将整体现价/原价写成比值（如55/80），这是"混合后的比值"
  2. 分别求出每个商品的现价÷原价的比值（数量不变时，总价值比=单价之比）
  3. 利用混合比的"十字交叉"或"交叉相减"得到各商品原价之比
  4. 结合已知单价或数量关系求解
- **高频错因**: 分不清现价/原价方向（现价/原价<1不能反）；忘记"数量不变"前提才能用单价比代替总价值比
