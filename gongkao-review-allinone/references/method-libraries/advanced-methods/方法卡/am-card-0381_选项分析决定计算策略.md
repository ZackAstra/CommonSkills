# 方法卡：选项分析决定计算策略

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项分析决定计算策略 |
| 适用题型 | 资料分析——所有计算题的前置判断 |
| 触发场景 | 拿到任何资料分析计算题，动笔之前必须先看选项 |
| 步骤逻辑 | ①看选项差距：误差<1%→必须精算（直除）；误差10%~100%→大胆估算；②看首位特征：ABCD分别为1/2/3/4开头→只算首位有效数字，忽略量级和单位；③看选项形式：比例选项且两边加起来=100→转化为部分比总体的单值再比较 |
| 高频错因 | 不看选项直接精算浪费时间；选项差距大时仍逐位精算；选项为比例形式时仍算原始比值 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

三种典型场景贯穿全课：Q1选项差<1%精算直除；Q8选项为1/2/3/4开头→只看首位选A；Q2选项39:61等加起来=100→转为部分/总体的百分比。此策略是所有后续方法选择的前提。
