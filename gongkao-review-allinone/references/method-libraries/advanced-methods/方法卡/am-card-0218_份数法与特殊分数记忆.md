# 方法卡：份数法与特殊分数记忆

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 份数法与特殊分数记忆 |
| 适用题型 | 资料分析——已知现期和增速求增量/基期 |
| 触发场景 | 增速接近某个特殊分数（11.1%≈1/9，18%≈1/5.5，20%=1/5，25%=1/4，33.3%=1/3，50%=1/2），求增量或基期 |
| 步骤逻辑 | ① 识别增速接近哪个特殊分数；② 建立份数关系（如11.1%→基期:增量:现期=9:1:10）；③ 现期÷总份数=每份量；④ 增量=每份量×增量份数 |
| 高频错因 | 记错分数对应关系；用现期代替基期算增量（应为基期÷份数） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

学习材料在第6题（11:56）用11.5%≈1/9（份数法），第14题（27:42）用18%=1/5.5。词义辨析特别强调18%≈1/5.5这个对应"经常考"，建议背熟。与假设分配本质相同，只是第一步"分"得更精确。
