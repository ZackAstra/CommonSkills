# 方法卡：练难拉开差距策略
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 练难拉开差距策略 |
| 适用题型 | 行测全科 / 备考难度选择策略 |
| 触发场景 | 选择练习卷或练习题难度时；纠结练简单题刷信心还是练难题提能力时 |
| 步骤逻辑 | 1. 平时练习选择高于真题平均难度的题目/套卷<br>2. 考到简单卷时正常发挥，不会吃亏<br>3. 考到难卷时优势凸显——因为大多数人练简单题，遇到难题会崩<br>4. 结果：难度越高，拉开的差距越大 |
| 高频错因 | 为求信心只练简单题；或觉得"难题不考"而跳过难题训练 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
词义辨析用自己的经历背书：24年山东极难（3.1万进面，过70仅143人，过75仅5人），他考了80分，因为平时就带着学员练难题。他指出山东24年26.6%进面考生行测没过60，78%没过60。当别人因为试卷突然变难而崩盘时，练过难题的人心态稳、正确率高，差距自然拉开。这是一个不对称收益策略：练难无额外成本（简单卷照样能做），但遇难时收益巨大。
