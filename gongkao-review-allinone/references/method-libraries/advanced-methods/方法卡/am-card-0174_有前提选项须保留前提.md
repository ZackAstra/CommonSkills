# 方法卡：有前提选项须保留前提

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有前提选项须保留前提 |
| 适用题型 | 言语理解——片段阅读（细节判断、主旨题均可涉及） |
| 触发场景 | 原文结论附带前提条件（"如果C不变""在……情况下"），选项去掉前提直接说结论 |
| 步骤逻辑 | ① 识别原文结论是否带有前提条件；② 若选项将前提省略、直接给出结论，该选项犯了"无中生有扩大范围"的逻辑错误；③ 排除去掉前提的选项 |
| 高频错因 | 看到选项和原文最后一句话"长得像"就选，忽略前提条件被省略；不理解前提条件的逻辑意义 |

| confidence | high |

## 补充说明

第7题是典型例题：原文说"消费者剩余大小取决于两个因素"（买方意愿价格和实际成交价），最后一句补充"如果成交价不变，意愿价格越高消费者剩余越大"。C选项"消费者剩余的大小取决于买方意愿价格"省略了"成交价不变"的前提，实际上消费者剩余同时受两个因素影响，不能说"只取决于"意愿价格。用行测/申论的类比更容易理解：不能因为"行测不变时取决于申论"就得出"取决于申论"。
