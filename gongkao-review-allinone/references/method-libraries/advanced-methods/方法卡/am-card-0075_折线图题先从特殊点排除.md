# 折线图题先从特殊点排除

- **方法名**: 折线图题先从特殊点排除
- **适用题型**: 资料分析 - 折线图识别题（选出对应哪种类型的折线图）
- **触发场景**: 题目给12个月的增量折线图（4个选项），让你判断是哪种车辆类型
- **步骤逻辑**:
  1. 不要从1月入手（1月增量需和上年12月比，跨度大不好判断）
  2. 从特征明显的月份入手（如3月是否最高、9月vs8月谁大）
  3. 逐个排除：先看最明显的特征点，不符合就排掉
  4. 再用辅助特征点（如10/11/12月的走势）确认剩余选项
  5. 排除法优先于逐项计算
- **高频错因**: 从1月份开始算，浪费大量时间；逐个算12个月的增量，体力不支
