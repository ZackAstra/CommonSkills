# 方法卡：两项和递推（爬楼梯模型）
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 两项和递推（爬楼梯模型） |
| 适用题型 | 数量关系-排列组合/爬楼梯/路径方案 |
| 触发场景 | 每次走1步或2步，求到达第N步的方案数 |
| 步骤逻辑 | 1.确定初始值D1=1、D2=2 2.递推公式Dn=D(n-1)+D(n-2)（最后一步迈1阶=D(n-1)方案，迈2阶=D(n-2)方案） 3.逐项算到目标项即为答案 |
| 高频错因 | 初始值D2误算为1（正确应为2：走两次1步或一次2步）；若允许走1/2/3步则变成三项递推，误用两项递推 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
本质是斐波那契数列。若条件改为每次走1/2/3步，递推变为三项和Dn=D(n-1)+D(n-2)+D(n-3)，此时D3=4（不是3）。讲解中强调"先记结论再理解原理"：要走到第N级，要么先到N-1再迈1步，要么先到N-2再迈2步，两类方案互斥，直接相加。
