# 方法卡：加法=混合增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 加法=混合增长率 |
| 适用题型 | 资料分析·涉及时间区间拆分（如1-6月=1-3月+4-6月） |
| 触发场景 | 题干给出累积量，问某子区间增速，且数据关系呈"总体=部分1+部分2" |
| 步骤逻辑 | 1. 先列出关系式（如1-6=1-3+4-6） 2. 识别加法→混合增长率 3. 画线段：总体增率写中间，已知部分写一侧 4. 根据"混合增率在两部分之间"推断未知部分方向 5. 若需进一步区分，带入选项验证距离之比与量之比的反比关系 |
| 高频错因 | 不列关系式直接找数据；把同比增速当环比混用盐水法；忘记混合增率必须在两部分之间 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

贯穿全篇的核心方法。第2题用线段法判断4-6月增率>4.7%，排掉AB后通过代入D选项发现距离之比(3.3:1.7≈2:1)与量之比(5200:5600≈1:1)不符，排除D选C。第3题同理判断4月>1-4月>1-3月。第20题将其扩展到非增率场景（月均收入×人数=总收入，月均与人数成反比），用盐水法求人数之比。关键区分：混合增长率用基期量（因为增率×基期=增量），非增率场景用现期量。
