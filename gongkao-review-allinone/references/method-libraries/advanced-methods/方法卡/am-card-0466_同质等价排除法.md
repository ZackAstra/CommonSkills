# 同质等价排除法

- **方法名**: 同质等价排除法
- **适用题型**: 判断推理 > 真假推理/排列组合
- **触发场景**: 真假话问题中，两个对象在所有相关条件中出现方式完全一致（或关系中等价替换）；单选题中两个选项条件相同
- **步骤逻辑**:
  1. 逐句翻译每个人的话，找出涉及相同对象的条件
  2. 若甲和丙在所有相关语句中扮演相同角色（如"丁或丙"与"丁或甲"结构一致），则甲丙等价
  3. 等价的两个人若有一个是正确答案，另一个也是——单选题不可能有两个答案
  4. 排除等价对，在剩余对象中检验
- **高频错因**: 只看单句条件不看全局，未发现等价关系；忽略"或"关系中谁和谁可以互换

- **confidence**: high
