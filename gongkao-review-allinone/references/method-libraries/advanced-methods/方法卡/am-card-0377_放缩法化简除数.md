# 方法卡：放缩法化简除数

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 放缩法化简除数 |
| 适用题型 | 资料分析——分数除法中除数位数多、直除困难时 |
| 触发场景 | 遇到如121÷293之类除数不好算的分数，且选项误差允许近似 |
| 步骤逻辑 | ①把除数往最近的整十/整百靠（如293→300，加了7）→②分子按分母与分子的比值关系做同比例调整（分母是分子的2倍多→分子加7的一半少一点≈加3）→③调整后除数只有一位有效数字，可直接口算 |
| 高频错因 | 分子分母未同比例调整导致方向性偏差；放缩幅度过大超过选项间距 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

放缩的核心目的是减少除数有效位数从而降低除法难度。在第15题中再次使用：74→70（减6%），分子104也减6%→98，104/74≈98/70=1.4。强化方法称此为分数运算中最实用的方法。
