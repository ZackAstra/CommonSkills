# 继发关联识别

- **方法名**: 继发关联识别
- **适用题型**: 判断推理 > 削弱质疑（归因题）
- **触发场景**: 题干发现A和B同时出现，归因为A→B；实际可能A和B都是C的结果
- **步骤逻辑**:
  1. 题干模式：A发生时B也发生 → 结论A导致B（相关≠因果）
  2. 继发关联：存在C，C既导致A又导致B；A和B只是同时出现的两个结果
  3. 正确质疑选项结构：C导致A，也导致B（两者并列，非因果）
  4. 识别标志：选项出现"也导致""同时"等并列措辞
- **高频错因**: 只会"另有他因"和"因果倒置"两种质疑，不知道"共同原因导致两个并列结果"这种第三种归因质疑
