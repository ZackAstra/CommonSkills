# 方法卡：部分解决不等于整体解决

- **方法名**：部分解决不等于整体解决（以偏概全削弱法）
- **适用题型**：论证题（削弱），结论为"X是解决Y的重要途径"
- **触发场景**：题干背景给出Y由多个来源构成（如工业+生活），结论只针对其中一个来源提出解决方案
- **步骤逻辑**：
  1. 看清论证链条：问题Y = 来源A + 来源B + ...
  2. 结论只解决了来源A（如生活固废），就声称能解决整体问题Y
  3. 削弱方向：来源A占整体的比例很小，即使全部解决也解决不了Y
  4. 选项出现"XX主要由其他来源引起，本来源威胁较小"→直击占比问题→有效削弱
- **高频错因**：看到"并非所有地区都适用"就选，但"有些不行"范围不明，无法确定整体是否受大影响；看到结论有"重要"二字就纠结，忽略题干背景已暗示占比关系
- **来源文件**：source-0038.md
- **confidence**：high

> 补充：Q14中"并非所有"（D选项）只说有些地方不行，但不知道多少地方不行、行的地方能否解决问题，所以力度不够。C选项直接指出"生活固废威胁小"，即使全部解决也称不上"重要途径"，切中要害。题干首句给出工业vs生活利用率对比（46% vs <10%）就是在暗示占比关系，做题时要留意背景信息。
