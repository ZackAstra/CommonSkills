# 混合增速推断缺失项

| 字段 | 内容 |
|------|------|
| **方法名** | 混合增速推断缺失项 |
| **适用题型** | 资料分析 - 整体与部分增速关系 |
| **触发场景** | 整体增速已知，部分项增速已知但有1项缺失，需要判断该项增速大小或进行增量比较 |
| **步骤逻辑** | 1. 整体增速在已知各部分增速之间（盐水混合原理）<br>2. 已知部分混合后的增速 < 最高已知增速（因低增速项拉低）<br>3. 整体增速 - 已知部分混合增速 → 缺失项的增速方向<br>4. 若整体 > 已知部分混合 → 缺失项增速 > 整体增速<br>5. 结合增量比大小规则：B大R大则X大，判断缺失项增量大小 |
| **高频错因** | ①误以为整体增速等于各部分平均 ②忽略"混合"方向 ③遗漏某项的基数大小比较 |

| **confidence** | high |
