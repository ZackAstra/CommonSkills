# 方法卡：充要条件双向理解

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 充要条件双向理解 |
| 适用题型 | 加强削弱——法条/规则解释类，题干只写了A→B但隐含A↔B |
| 触发场景 | 题干引用一条法条或规则只写了正向（如"越过停止线可以通行"），问哪个选项能支持"应当理解为"包含反向条件 |
| 步骤逻辑 | ① 识别原文是A→B（如果越过则可通行）；② 交警/解释者认为还暗含非A→非B（未越过则不可通行）；③ 找选项时注意"如果那么"=前推后，加"才"=后推前，"如果那么…才"=双向（充要）；④ 支持交警的选项只要包含B→A（等价于非A→非B）即可 |
| 高频错因 | 把"只有才"理解为纯粹后推前而忽略"如果那么"的前推后，导致D选项（只含单向）优于C选项（含双向）的误判；或者认为支持交警就必须完全否定原文 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第2题：原文"黄灯亮时越过停止线的可以继续通行"=越过→通行(A→B)。交警认为应理解为"没越过不可通行"=非A→非B（即B→A）。C选项"如果车辆已越过，那么才可以继续通行"用"如果那么…才"同时表达了前推后和后推前，完美对应充要条件。D选项只表达了后推前（单向），忽略了法条本意中的正向含义，相当于否定了条文本身，不合理。
