# 方法卡：比值增长率（平均数增长率）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比值增长率（平均数增长率） |
| 适用题型 | 资料分析——求平均数/人均/单价/占比等比值的增长率，材料未直接给出该比值 |
| 触发场景 | 题目出现"均价""人均""平均每万元"等平均/比值字样，但材料中找不到该比值的直接数据 |
| 步骤逻辑 | ① 想表达式确认是A=B/C形式；② 确认谁在上谁在下（后除前：如"人均消费"→消费÷人数）；③ 找R1（分子增长率）、R2（分母增长率）；④ 套公式 R = (R1 - R2) / (1 + R2) |
| 高频错因 | R1/R2标反（分子对应R1，分母对应R2）；忘记分母"1+"；带正负号时计算出错 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

"后除前"口诀：读题时从后往前读，后面的量做分子（除），前面的量做分母。如"人均消费"→消费在后÷人数在前。大多数比值增长率就是平均数增长率，但也有特殊情况（如外贸总值=进出口总额÷占比）。如果材料直接给了比值数据，则直接用一般增长率公式即可。
