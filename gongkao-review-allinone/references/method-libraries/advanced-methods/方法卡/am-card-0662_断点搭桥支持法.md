# 方法卡：断点搭桥支持法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点搭桥支持法 |
| 适用题型 | 逻辑判断——支持题（论据和结论之间有断点） |
| 触发场景 | 结论中有新内容（论据中没有的关键词），需要在选项中找能连接论据和结论的桥 |
| 步骤逻辑 | ① 找结论中的新内容（论据里没有的词）；② 在选项中找能连接"论据关键词"和"结论新内容"的选项；③ 搭上一个桥就够，不需要全部搭上 |
| 高频错因 | 选了重复论据的选项（重复不是搭桥）；选了B推A方向的选项（方向反了） |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 断点搭桥是支持题的固定解法。例如：论据"吃蓝莓提高记忆力"→结论"蓝莓降低老年痴呆风险"，断点是"记忆力"和"老年痴呆"的关系。选项"增强记忆力可以降低老年痴呆发病几率"就是搭桥。注意：① 重复论据不是搭桥（如"蓝莓确实能提高记忆力"）；② 搭桥方向必须是论据→结论（A推B），不能反过来（B推A）；③ 带逻辑关联词的选项（只有才、只要就）常用于搭桥。
