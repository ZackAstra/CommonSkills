# 方法卡：有的是有的不是（至少一真可同真）

| 字段 | 内容 |
|------|------|
| 方法名 | 有的是有的不是（至少一真可同真） |
| 适用题型 | 逻辑判断——真话假话题/集合关系题 |
| 触发场景 | 陈述中出现"有人会""有人不会"这类"有的是/有的不是"表述 |
| 步骤逻辑 | 1. "有的是"涵盖范围：情况一（所有人都X）+ 情况二（部分人X） |
| | 2. "有的不是"涵盖范围：情况二（部分人X）+ 情况三（所有人都非X） |
| | 3. 两者关系：至少一真（涵盖全部三种情况），可以同真（在情况二时都真）→不是矛盾 |
| | 4. 矛盾关系：只有"所有A是B"与"有的A非B"、"所有A非B"与"有的A是B"才是矛盾 |
| | 5. 应用：只有一句为真时，真话必在"有的是"和"有的不是"之间→第三句必假 |
| 高频错因 | ①把"有的是"和"有的不是"当成矛盾（实际上可以同真）②误用"有的是/有的不是"来破题（它们不能推出一真一假） |
| 来源文件 | source-0070.md |
| confidence | high |

**补充说明：**
- 四组矛盾关系（必有一真一假）：所有是vs有的非、所有非vs有的是。
- "有的是"vs"有的不是"：至少一真、可以同真，绝不可当矛盾用。
- 解题口诀：两个"有些"必有一真，两个"所有"必有一假。
