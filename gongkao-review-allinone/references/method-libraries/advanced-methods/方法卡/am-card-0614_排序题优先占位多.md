# 方法卡：排序题优先占位多

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排序题优先占位多 |
| 适用题型 | 判断推理——排序/排列组合 |
| 触发场景 | 已知若干约束条件（间隔几人、先后顺序），问可能的排列 |
| 步骤逻辑 | ① 统计每个约束条件的"占位数"（如"乙丙间隔3人"占5个位置）；② 优先从占位最多的条件入手（限制最强，可能性最少）；③ 多个高频条件同时使用，逐步缩小可能排列；④ 逐一验证选项是否在可能排列中 |
| 高频错因 | 从占位少的条件入手导致可能性过多、分析混乱；遗漏顺序固定的条件（如"丁在前"） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

例：7个位置，条件②乙丙间隔3人占5位，条件③丁戊间隔3人（丁前）也占5位，两者合用只剩1个空位给甲。位置越少，排列可能性越少，越快出答案。
