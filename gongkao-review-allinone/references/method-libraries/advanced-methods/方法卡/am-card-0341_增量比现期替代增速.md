# 方法卡：增量比现期替代增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增量比现期替代增速 |
| 适用题型 | 资料分析——多个增速的大小排序 |
| 触发场景 | 题目要求"增速最快/最慢的是哪个"；材料直接给出增量和现期（无需自己算基期） |
| 步骤逻辑 | ① 用X/B（增量÷现期）替代R（增速=增量÷基期）；② 对每个选项算出X/B的近似值；③ 比较大小排序；④ 若分母可进一步简化（如4986≈5000，除以5000=乘以2/10000），直接口算 |
| 高频错因 | 用此法计算具体增速值（只能比大小，不能算精确值）；基期和现期差距大时替代误差增大 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

口算技巧：分母看成整千数（如4986→5000），增量÷5000=增量×2÷10000。如657÷5000≈13.1%。另一题中7492≈7500，803÷7500≈10.7%，快速排序。
