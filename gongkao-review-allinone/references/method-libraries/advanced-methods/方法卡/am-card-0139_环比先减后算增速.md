# 方法卡：环比先减后算增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 环比先减后算增速 |
| 适用题型 | 资料分析·已知累积量求环比趋势 |
| 触发场景 | 题干给1-2月、1-3月、1-4月等累积数据，问各月环比增速趋势 |
| 步骤逻辑 | 1. 累积相减得出每月数值（如3月=1-3月-1-2月） 2. 用相邻月份数值算环比增速（如4月环比=4月值/3月值-1） 3. 比较各月环比增速的方向（上升/下降）判断趋势 |
| 高频错因 | 只减出每月数值就直接比大小，忘记还要再算环比增速；把同比混入环比 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第5题中规上工业的环比趋势需从累积数据(5240, 6970, 8770, 10950, 13000)减出每月值(约2100, 1700, 1800, 2100)，再判断增速方向。注意：比较的是增速而非绝对量——5月值虽比4月高，但增速可能不同。正确率仅27%，高错因是停在"减出每月数值"就比大小，没有继续算环比增速。另外，混合增长率只能用于同比，不能用于环比。
