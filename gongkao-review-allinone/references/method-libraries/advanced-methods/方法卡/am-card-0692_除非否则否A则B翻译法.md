# 方法卡：除非否则否A则B翻译法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 除非否则否A则B翻译法 |
| 适用题型 | 逻辑——翻译推理（题干含"除非…否则…"/"A否则B"/"必须A否则B"等句式） |
| 触发场景 | 题干或选项中出现"除非A否则B"、"A否则B"、"必须A否则B"等表述，需要翻译成逻辑语言 |
| 步骤逻辑 | ① 核心口诀"谜底就在谜面上"：把"否则"拆成"否"+"则"，A插中间变成"否A则B"；② 翻译结果：非A→B；③ 等价变体："除非努力否则上不了岸" = "必须努力否则上不了岸" = "不努力→上不了岸"；④ "除非"可替换为"必须"，句式更清晰 |
| 高频错因 | 把"除非否则不"当成独立关联词死记硬背，不如统一用"否A则B"万能公式；混淆方向——"除非A否则B"是 非A→B，不是 A→B |

| confidence | medium |

## 补充说明

讲解中推荐不要死记"除非否则不/除非不否则/除非不否则不"等多种变体，统一把"不"放进内容里处理。例如"除非不努力否则考不上"，A="不努力"，B="考不上"，非A=努力，翻译为"努力→考不上"。另一个实用技巧：在"除非否则"句式中，把"除非"替换成"必须"句意不变，更容易看出逻辑方向。
