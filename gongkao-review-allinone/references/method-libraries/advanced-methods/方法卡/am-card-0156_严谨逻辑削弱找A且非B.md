# 方法卡：严谨逻辑削弱找A且非B

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 严谨逻辑削弱找A且非B |
| 适用题型 | 判断推理——削弱类（题干含"只有才""只要就"等严谨逻辑关联词） |
| 触发场景 | 结论中出现"只有A才B""只要A就B"等关联词，问削弱/反驳 |
| 步骤逻辑 | ① 翻译逻辑关系：只有A才B→后推前=B推A；只要A就B→前推后=A推B；② 找矛盾削弱：A推B的矛盾=A且非B，即"前件成立但后件不成立"；③ 如"只有实行目标责任制才能经济增长"→经济增长推目标责任制→矛盾=经济增长且未实行目标责任制；④ 主体一致的A且非B力度最强，类比推理（不同主体的A且非B）力度次之 |
| 高频错因 | 把"只有才"方向翻译反；选了他因削弱（力度弱于直接矛盾）；忽略主体一致性的力度差异 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

此题型考查形式逻辑推理，与归因类削弱（对比实验、因果倒置）是不同题型。区分标志：结论中有明确逻辑关联词"只有才""只要就"。如第10题"只有实行目标责任制才能经济增长"，D选项"甲公司经济稳步增长但未实行目标责任制"=标准A且非B，力度最强。B选项"乙公司同样情况"=类比推理，有削弱力但不如D。AC是他因削弱，力度弱于直接矛盾。第15题同理："只有安装杀毒软件才不中病毒"→C"未安装也很少中病毒"=A且非B。
