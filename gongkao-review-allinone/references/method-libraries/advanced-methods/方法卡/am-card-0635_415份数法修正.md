# 方法卡：415份数法修正

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 415份数法修正 |
| 适用题型 | 资料分析——增长率不在标准分数附近时的增量/基期计算 |
| 触发场景 | 增长率不正好是1/6、1/7等标准分数，需要修正时 |
| 步骤逻辑 | ① 把增长率当做最近的标准分数（如17.7%当1/6）；② 用415份数法算出初步增量X1；③ 计算实际增长率与假设增长率的差值ΔR；④ 增量修正：X = X1 + X1×ΔR×系数 |
| 高频错因 | 系数记错；修正方向搞反（实际R大则加，小则减） |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 修正系数口诀"三上上按按3322"：33%附近乘2.2，50%附近乘1.3，66%附近乘0.9，100%附近乘0.5。增长率在1/6附近时，系数为5（即n-1）。修正本质：实际R比假设R大多少，增量就要相应扩大。
