# 方法卡：柱形图增速比较-高度差比基期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 柱形图增速比较-高度差比基期 |
| 适用题型 | 资料分析——柱形图中比较多个年份的同比增速大小（增速比较题） |
| 触发场景 | 题干问"增速最大/最小的年份"，且材料为柱形图 |
| 步骤逻辑 | ① 增速=增量/基期=X/A；② 柱形图中X=相邻柱的高度差，A=前一年柱的高度（基期）；③ 要增速最大→找"高度差大且基期小"的年份；④ 标记各选项年份的高度差，先排除下降年份（负增速），再比较高度差/基期的视觉比例 |
| 高频错因 | 只看高度差大就选，忽略基期也很大导致增速并不高；未排除同比下降年份 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

此法本质是把"现期比基"转化为"高度差比基期"的图感判断。词义辨析称之为"教同学们怎么瞪"，六七十%的此类题可通过此法秒杀无需动笔。
