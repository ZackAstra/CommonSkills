# 方法卡：逆否命题推理法

- **方法名**：逆否命题推理法
- **适用题型**：翻译推理题、条件推理题
- **触发场景**：题干出现"如果...那么..."条件句，需要从结果反推条件时
- **步骤逻辑**：
  1. 将原命题翻译为 A → B 的箭头形式
  2. 写出逆否命题：非B → 非A（方向反转、两边都加非）
  3. 肯定后件（B成立）时无法正向推出任何结论
  4. 否定后件（非B成立）时可通过逆否推出非A
  5. 否定前件（非A成立）时也无法推出结论
- **高频错因**：误以为"后件成立可推出前件"（肯后推肯前是错误的）；混淆"否后推否前"与"肯后推肯前"
- **来源文件**：source-0039.md
- **confidence**：high

补充说明：如"如果选青山村则甲也选"，逆否为"甲不选则丙不选青山村"。肯后不能推——拿对颜色不代表识别出了颜色（可能蒙对），只有拿错才能确定没识别出来。
