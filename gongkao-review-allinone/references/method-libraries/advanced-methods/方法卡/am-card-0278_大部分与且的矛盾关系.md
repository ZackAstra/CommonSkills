# 方法卡：大部分与且的矛盾关系

- **方法名**：大部分与且的矛盾关系
- **适用题型**：逻辑判断中涉及"大部分"量词和选言/联言转换的题
- **触发场景**：题干说"大部分A或B"，选项涉及A且B的数量判断时
- **步骤逻辑**：
  1. "大部分A或B"的矛盾是"大部分A且B"（或变且、两边加非、大部分不变）
  2. 因此"小部分非A且非B"（即A且B只能是小部分）一定成立
  3. 若选项说"一半地区既干旱又寒冷"，因一半与大部分矛盾，该选项一定为假
  4. 或命题只需一边成立即可为真：全部都是干旱但不寒冷的情况也可以满足"非干旱或非寒冷"
- **高频错因**：不理解"或"只需一边成立即可；误以为或命题两边都得满足
- **来源文件**：source-0039.md
- **confidence**：high

补充说明：德摩根律——(A或B)的矛盾=非A且非B。"大部分(A或B)"的矛盾="大部分(非A且非B)"，因此"小部分(非A且非B)"一定成立。或命题为真有三种情况：两者皆真、一真一假（两种）；只有两者皆假时才为假。
