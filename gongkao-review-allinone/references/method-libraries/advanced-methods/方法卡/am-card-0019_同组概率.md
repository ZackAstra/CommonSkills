# 方法卡：同组概率（逐人放置法）
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 同组概率（逐人放置法） |
| 适用题型 | 数量关系-概率（分组/同排/同桌问题） |
| 触发场景 | N人分组或排列，求特定人同组/同排/不同组/不相邻的概率 |
| 步骤逻辑 | 1.先定位一个人（放甲到某组） 2.依次放入其他人，每步计算满足条件的剩余位置数与总剩余位置数之比 3.连乘各步概率即为结果 |
| 高频错因 | 直接用组合公式算复杂；放完人后忘记剩余位置变化 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
讲解中用此法通解多种变体：4人两两分组同组概率=1/3；6人三三分组三人同组=2/5×1/4；4×4方格同排=3/15；不同排不同列=9/15×4/14；5人圆桌不相邻=2/4。核心逻辑：固定一个，逐个放人，每步算满足/剩余比值并连乘。相同棋子需"降序"（除以A33）去除内部顺序重复。
