# 方法卡：区别比较联系类选项反推法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 区别比较联系类选项反推法 |
| 适用题型 | 言语理解——片段阅读主旨题 |
| 触发场景 | 选项中出现"独特""与众不同""不同之处""优势大于劣势"等区别/比较/联系表述 |
| 步骤逻辑 | ① 识别选项属于区别比较联系类（含"独特""与众不同""优势劣势"等关键词）；② 反推原文结构：如果选该选项，原文应该有双主语，既有A的介绍也有B的介绍，再做对比；③ 回文验证：原文是否真的在对比两个事物，是否双方都有详细介绍；④ 若原文只讲一个事物、没有双方对比，则排除该选项 |
| 高频错因 | 看到选项"听起来有道理"就选，不回文验证对应结构；把"简单提及另一事物"误认为"双方对比" |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

区别比较联系类选项对应的文段结构相对固定：双主语、双方都有介绍和分析、有对比。若原文只有单方面介绍而未做对比，就不应选此类选项。第1题B选项"混居模式的独特之处"被排除，因为原文只讲了混居的好处，没有和其他模式做对比；第2题"文学艺术家眼中的理想社会与众不同"被选中，因为原文确实对比了文学艺术家与政治家/科学家/经济学家的看法。
