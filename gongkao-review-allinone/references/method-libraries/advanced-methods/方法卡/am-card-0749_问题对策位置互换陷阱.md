# 方法卡：问题对策位置互换陷阱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 问题对策位置互换陷阱 |
| 适用题型 | 言语理解——片段阅读（主旨/意图题，对策类） |
| 触发场景 | 选项将原文"问题→对策"的因果方向颠倒，变成"对策→问题"或把问题内容塞进对策位置 |
| 步骤逻辑 | ① 提炼原文结构：明确哪个是要解决的问题（目标），哪个是对策内容；② 用"想考公务员要努力"类比：对策核心是"努力"，问题是"考上公务员"；③ 检查选项：如果选项变成了"改变现状需要考上公务员"，就是把问题放到了对策位置——不能选；④ 类似逻辑推理的充分必要条件，各自在对应位置不能互换 |
| 高频错因 | 只关注选项是否"提到了原文关键词"，不检查关键词所处的逻辑位置；把问题内容误当对策内容选入 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

核心口诀：对策内容在必要条件的位置待着，问题/目标在充分条件的位置待着，不可互换。例如原文"如何进行劳动者权益保护需要法律协同"，问题位置是"劳动者权益保护"，对策位置是"法律协同"。选项如果说"维护劳动者权益才能促进数字经济发展"，就把原文问题变成了对策、把目标变成了新问题——完全颠倒。
