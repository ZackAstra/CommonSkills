# 方程法-和差倍比

- **适用题型**: 数量关系-和差倍比问题、基础方程应用题
- **触发场景**: 题目给出若干量之间的和、差、倍、比关系，存在明显的等式条件
- **步骤逻辑**:
  1. 找等式关系（和、差、积、商的条件）
  2. 设未知数（优先设与多个量都有关联的那个）
  3. 用未知数把其他量都表示出来
  4. 代入等式关系列方程、解方程
- **高频错因**: 等式关系找漏；未知数设得不好导致后续计算麻烦；求差时顺序与题干不一致导致正负号错误

- **补充说明**: 这是本课核心方法，例题1-6均围绕方程法展开。词义辨析强调"不要排斥方程法"，秒杀没有普适性且考场上不一定敢用，方程法才是稳妥的考场策略。"甲比乙"就甲减乙，顺序与题干保持一致可避免正负号错误。
