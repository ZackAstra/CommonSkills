# 方法卡：比重差公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重差公式 |
| 适用题型 | 资料分析——求今年比重与去年比重的具体差值 |
| 触发场景 | 题目问"比重约上升/下降了多少个百分点" |
| 步骤逻辑 | ① 比重差 = 现期比重 × (R部分 - R整体) / (1 + R部分)；② 先判断升降（看R部分和R整体大小）；③ 再估算数值 |
| 高频错因 | 混淆百分点和百分比；公式记错 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 公式推导：比重差 = 今年比重 - 去年比重 = 现期比重 - 现期比重×(1+R整体)/(1+R部分) = 现期比重 × [(R部分-R整体)/(1+R部分)]。先用两期比重比较判断升降，再用公式估算数值。
