# 方法卡：整数基本值法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 整数基本值法 |
| 适用题型 | 资料分析-减法-涉及借位的多位数相减 |
| 触发场景 | 两个数字相减需要借位，希望口算完成时 |
| 步骤逻辑 | 1. 找到两个数之间的整百/整千中间值 2. 分别算出被减数与中间值的差、减数与中间值的差 3. 两个差相加即为结果 |
| 高频错因 | 中间值选错导致拆分后仍需借位；两个差相加时符号搞反 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

例如632-589，取中间整百值600：632-600=32，600-589=11，32+11=43。核心思路是把一个需要借位的减法拆成两个不需要借位的简单减法。熟练后可直接想"零头32加上它距离600差的11"。强化方法特别指出这个方法的目的是口算完成，避免在考场上紧张时还需要列竖式借位。
