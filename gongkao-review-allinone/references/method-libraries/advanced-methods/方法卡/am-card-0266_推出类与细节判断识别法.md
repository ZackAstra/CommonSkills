# 方法卡：推出类与细节判断识别法

- **方法名**：推出类与细节判断识别法
- **适用题型**：定义判断/推出类（逻辑判断中的"下列哪项能/不能推出"）
- **触发场景**：问法为"由此可以推出""以下哪项正确/一定为真"
- **步骤逻辑**：
  1. 先看题干和选项是否出现大量逻辑关联词（如果...则、只有...才）
  2. 若有逻辑关联词 → **推出类**：写条件、逆否等价、推导
  3. 若无逻辑关联词 → **细节判断**：当言语题做，逐项比对题干
  4. 细节判断中警惕三种设错：绝对化（"最重要"偷换"重要"）、无中生有、杂糅
- **高频错因**：推出类题目用言语方式做（逐句比对）；细节判断题强行翻译逻辑符号
- **来源文件**：source-0038.md
- **confidence**：high

> 补充：Q3为典型细节判断（题干无逻辑关联词），用言语方式逐项排除：A无中生有（"最宝贵"题干未提）、B正确（同义转述）、C杂糅+绝对化（"好人"+"局部"混搭且"几乎"→"所有"）、D绝对化（"最重要"偷换"重要"）。也可当推出类做：友谊只存在于好人之间→逆否→不是好人→没有友谊→选B。
