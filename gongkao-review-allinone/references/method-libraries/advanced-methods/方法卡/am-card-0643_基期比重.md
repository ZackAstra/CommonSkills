# 方法卡：基期比重

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比重 |
| 适用题型 | 资料分析——求去年的比重（材料给的是今年的数据） |
| 触发场景 | 题目问"上年XX占XX的比重"，材料给的是今年的部分、整体和各自增长率 |
| 步骤逻辑 | ① 先算现期比重 = 部分/整体；② 套公式：基期比重 = 现期比重 × (1+R整体)/(1+R部分)；③ 用拆分法计算修正系数 |
| 高频错因 | 把现期比重当答案选（选项陷阱）；R1/R2位置搞反 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 公式本质是比值增长率的变形。选项中通常会设一个"现期比重"作为陷阱，千万别选。修正系数(1+R整体)/(1+R部分)通常接近1，用拆分法估算即可。
