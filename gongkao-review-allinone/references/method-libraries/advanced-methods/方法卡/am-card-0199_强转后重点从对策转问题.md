# 强转后重点从对策转问题

- **方法名**：强转后重点从对策转问题
- **适用题型**：中心理解
- **触发场景**：文段先有对策/成就，后接强转折（"但是…还面临…""但还…"），转折后出现新问题
- **步骤逻辑**：
  1. 强转折后出现的问题成为新的重点
  2. 若问题后又接对策→最终重点在最后的对策
  3. 转折前的对策/成就不再是最核心
  4. 不要刻板套"有对策选对策"——要看对策在哪个位置
- **高频错因**：刻板执行"有对策选对策"，忽略了强转折已将重点转移到问题/新对策上
- **来源文件**：source-0028.md
- **confidence**：high
