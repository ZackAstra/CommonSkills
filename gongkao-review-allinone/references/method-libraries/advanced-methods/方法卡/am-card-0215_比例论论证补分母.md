# 方法卡：比例论论证补分母

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比例论论证补分母 |
| 适用题型 | 判断推理——削弱/质疑类（题干用绝对数量下结论） |
| 触发场景 | 题干只给出分子（如事故数量、某群体数量）就得出"某群体更危险/更突出"的结论，缺少分母（总量/基数）信息 |
| 步骤逻辑 | ① 识别题干只看分子不看分母的漏洞；② 正确选项应同时提供分子和分母（如"男女司机比例7:3，女司机肇事仅占4%"），用比例而非绝对数说话；③ 计算实际比例进行比较（如男13% vs 女3%，实际男更危险）；④ 考场上不需要精确计算，判断方向正确即可 |
| 高频错因 | 被选项中的绝对数量误导；选了"描述优点"类选项（缺乏数据支撑，力度不够） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

"数量词"出现的选项往往力度更强（如"11个省""重灾区"）。用数据事实说话比笼统描述优点更有说服力。
