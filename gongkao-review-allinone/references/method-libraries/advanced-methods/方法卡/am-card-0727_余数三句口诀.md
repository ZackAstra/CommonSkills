# 余数三句口诀

- **适用题型**: 余数问题（同余、同和、同差三种情况）
- **触发场景**: 题干给出"除A余a，除B余b"，且余数相同、和相同、或差相同
- **步骤逻辑**:
  1. 判断属于哪种情况：
     - **余同**：余数相同 → 表示为 lcm(A,B) × n + 余数
     - **和同**：(除数+余数)相同 → 表示为 lcm(A,B) × n + (除数+余数)
     - **差同**：(除数-余数)相同 → 表示为 lcm(A,B) × n - 差值
  2. 用 n=1,2,3... 依次代入，结合题目范围筛选答案
- **高频错因**: 三种情况混淆，"和同"误用减法或"差同"误用加法
- **来源文件**: internal-source
- **confidence**: medium
- **补充说明**:
  - 例题：3名社工一组剩2名，4名一组也剩2名 → 余同，12n+2，减2是12的倍数
  - 例题：1-9循环报数报7（除9余7），1-11循环报9（除11余9）→ 差同（9-7=2，11-9=2），99n-2
  - 词义辨析原话："和同加和；余同加余；差同减差...记住就行，做题可用不到（指推导过程）"
  - 315n-1 型：5、7、9的最小公倍数315，n取1/2/3代入即可
