# 蒙题选BC策略

- **适用题型**: 数量关系全模块，用于不会做的题蒙答案
- **触发场景**: 已做出部分题目，剩余题目完全不会需蒙答案
- **步骤逻辑**:
  1. 先尽全力做出有把握的题目（如10道做出5道）
  2. 统计已做题目的答案分布（如B选了几个、C选了几个）
  3. 已做中选B多则剩余全蒙C，选C多则剩余全蒙B
  4. 利用答案分布的"均衡性"提高蒙对概率
- **高频错因**: 全蒙同一个选项（如全蒙B）；没有统计已做答案分布就盲目蒙
- **来源文件**: internal-source
- **confidence**: medium
- **补充说明**: 词义辨析的考场策略：基础一般的同学10分钟做5道（每道2分钟），做出来的基本能对，剩下5道用此法蒙，"对七道，你的对手吭哧瘪肚做出八九道，其实咱俩差不太多"。本质是利用答案选项分布的统计规律，适用于没时间硬算的情况。
