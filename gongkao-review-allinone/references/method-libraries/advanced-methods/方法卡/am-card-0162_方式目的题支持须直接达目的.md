# 方法卡：方式目的题支持须直接达目的

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 方式目的题支持须直接达目的 |
| 适用题型 | 判断推理——支持/削弱类（方式目的型论证） |
| 触发场景 | 结论为"通过方式X达到目的Y"，问支持或削弱 |
| 步骤逻辑 | ① 明确方式和目的：如方式="培育基因改造蚊子"，目的="根绝疟疾"；② 支持项必须表明方式能直接达到最终目的：如"转基因蚊子让野生蚊子种群灭亡→切断传播→根绝疟疾"；③ 只说方式有优势但不达目的的选项≠支持：如"有生存优势"不等于"根绝疟疾"，"存活率一样"也推不出结论；④ 削弱项=方式不能达到目的，如"野外容易死亡→达不到根绝" |
| 高频错因 | 把"方式有某个优势"当成"方式能达到目的"；忽略选项是否真正回应了目的端 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第5题：方式=基因改造蚊子，目的=根绝疟疾。A（野外容易死亡）=削弱；B（有生存优势但无疟疾后存活率一样）≠支持，生存优势推不出根绝；C（让野生蚊子种群灭亡）=直接达到目的，支持；D（后代突变产生新型蚊子）效果不明确。核心：支持项要从方式到目的之间有一条完整因果链。
