# 方法卡：对策的对策陷阱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策的对策陷阱 |
| 适用题型 | 言语理解-中心理解题（对策类文段） |
| 触发场景 | 文段结构为"目标/问题→对策"，选项用"如何+对策"来表述时 |
| 步骤逻辑 | 1. 识别文段的"目标"和"对策"分别是什么 2. 对策类文段的话题是"如何解决目标"，不是"如何执行对策" 3. 排除把对策本身当作讨论话题的选项（即"对策的对策"） 4. 正确选项应表述为"解决XX问题的方法/策略" |
| 高频错因 | 把对策的下一层当作主旨，如文段说"想考上要努力"，选了"如何努力"而非"如何考上" |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

强化方法用"想考上要努力"做类比：目标是"考上"，对策是"努力"。文段讨论的是"如何考上"这件事，而非"如何努力"。出题人常设置"如何努力"这类选项来制造干扰。第2题文段讨论"如何解决农村人力资源短缺问题"，对策是"提升农村劳动者整体素质"，选项应围绕前者而非后者。第1题也呼应了这一点：讨论的是"如何做好城市更新"而非"如何做好老旧小区改造"。
