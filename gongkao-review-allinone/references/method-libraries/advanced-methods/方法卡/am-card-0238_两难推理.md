# 方法卡：两难推理——A和非A都推出B则B必真

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 两难推理 |
| 适用题型 | 判断推理——复合命题推理（推出具体事实） |
| 触发场景 | 题干给出多个条件命题（如果…则…），没有具体事实，却能推出某个具体结论 |
| 步骤逻辑 | ① 观察题干结构：是否有"A→B"和"非A→C"的两条路径；② 检查两条路径能否汇合——看C是否能进一步推出B（通过逆否等）；③ 若A和非A（矛盾的，必有一真）都推出同一个结论B，则B一定成立；④ 答案直接选那个确定的事实 |
| 高频错因 | 不会利用条件命题的逆否命题来打通两条路径；看到多个条件命题就发懵，没想到"两难"的解法 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q17中：摄影→旅游（第一句），非摄影→驾车（第二句），驾车→旅游（第三句逆否）。无论喜不喜欢摄影，都喜欢旅游。强化方法评价"这种题是送分的"。关键是第三句的逆否——"不旅游则不驾车"等价于"驾车则旅游"，把两条路径接通。
