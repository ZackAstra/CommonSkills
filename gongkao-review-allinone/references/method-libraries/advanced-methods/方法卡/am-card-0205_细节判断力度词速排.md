# 细节判断力度词速排

- **方法名**：细节判断力度词速排
- **适用题型**：细节判断（说法正确/理解正确）
- **触发场景**：细节判断题，选项中含强力度词（"主要""越来越""重要"等）
- **步骤逻辑**：
  1. 先看选项而非文段
  2. 识别力度词："主要"需文段体现占比过半；"越来越"需有逐年递进过程；"重要"力度很弱几乎不约束
  3. 含"主要""越来越"的选项大概率错误，优先跳过
  4. 先验B和D等不含强力度词的选项
- **高频错因**：忽略力度词需要文段强支撑，凭感觉选"主要"或"越来越"

- **confidence**：high
