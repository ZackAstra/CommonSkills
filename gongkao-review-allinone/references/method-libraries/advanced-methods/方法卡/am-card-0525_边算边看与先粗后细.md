# 方法卡：边算边看与先粗后细

## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 边算边看与先粗后细 |
| 适用题型 | 资料分析-所有计算题（尤其是区间选项题） |
| 触发场景 | 开始计算前/计算过程中，需要判断粗算够不够还是必须精算 |
| 步骤逻辑 | 1. 先看选项差距：具体数值选项看间距，区间选项无法预判精度<br>2. 大胆粗算（如增率当成简单分数、保留两位有效数字）<br>3. 粗算结果能区分选项→直接选<br>4. 粗算卡在边界→回到误差分析或精算<br>5. 精算时保留三位有效数字 |
| 高频错因 | 一开始就精算浪费时间；区间选项题不知道何时该切换到精算模式；粗算结果模棱两可时不做误差分析就猜 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明
- 核心思想：你不可能在计算开始前就知道需不需要精算，只能边算边看。
- 区间选项（如A.400以下 B.400~450 C.450~500 D.500以上）无法提前判断精度，必须先粗算再决定。
- 具体数值选项（如A.412 B.425 C.438 D.451）如果间距大于5%，粗算通常够用。
- 直除作为最后一步时，不需要简便方法，直接除到能区分选项那一位即可停止。
- 增率很小时（如1.3%），可以用"现期×增率"近似替代增量计算（线集成增率）。
