# 方法卡：2112分段法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 2112分段法 |
| 适用题型 | 资料分析-减法-多位数相减 |
| 触发场景 | 两个数字相减，希望避免借位、分段口算时 |
| 步骤逻辑 | 1. 观察个位是否够减：够减则从百位和十位之间切开（前两位减前两位，后两位减后两位）2. 个位不够减则从十位和个位之间切开（前三段 vs 后三段）3. 两段各自独立相减，结果直接拼接 4. 若某段不够减，引入负数处理（如80+(-1)=79） |
| 高频错因 | 分段位置选错仍需借位；不够减时忘记用负数处理 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

"2112"指分段模式：2位|1位 vs 1位|2位，或类似组合，核心原则是"怎么不借位就怎么分"。当某段结果为负数时（如221-142，分段后1-2=-1），用80+(-1)=79得到79。强化方法强调这需要改变二十年的计算习惯，但一两天就能适应，且能显著提高速度。课上多次用这个方法配合增量判断题，是后续"分段法速判增量"的基础。
