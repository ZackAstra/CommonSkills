# 方法卡：冠军模型

| 字段 | 内容 |
|------|------|
| 方法名 | 冠军模型 |
| 适用题型 | 逻辑判断——真话假话题（多选一场景） |
| 触发场景 | 多人预测同一结果的归属（如谁偷吃了、谁是冠军），只有N句为真 |
| 步骤逻辑 | 1. 将所有人的预测正向表述（含否定的要转为肯定方向） |
| | 2. 统计每个候选人被提及的次数（出场次数） |
| | 3. 正确人数 = 该候选人的出场次数→直接锁定对应候选人 |
| | 4. 未被提及的候选人（出场0次）= 所有人都说错时的答案 |
| 高频错因 | ①在非多选一场景（如四人抽四花色各不同）误用冠军模型②统计出场次数时遗漏或误数 |
| 来源文件 | source-0070.md |
| confidence | high |

**补充说明：**
- 冠军模型适用条件严格要求"多选一"（只有一个结果、多个候选），不适用于"四人各抽一花色"这类全分配问题。
- 出场次数的本质：如果预测正确人数=N，则恰好有N个预测命中，被提及N次的那个候选人就是答案。
- 举例：甲→乙，乙→丙，丙→甲乙，丁→乙丙；出场次数：甲1次、乙3次、丙2次、丁0次。1人说真话→甲是偷鱼贼。
