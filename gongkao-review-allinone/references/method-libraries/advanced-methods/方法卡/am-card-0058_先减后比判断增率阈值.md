# 方法卡：先减后比判断增率阈值

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 先减后比判断增率阈值 |
| 适用题型 | 资料分析-增率是否超过某百分比 |
| 触发场景 | 需要判断多个年份的增率是否超过10%/15%/25%等阈值 |
| 步骤逻辑 | 1.用今年数据减去去年数据得到增量；2.将增量与去年数据的阈值百分比比较（如判断是否超10%，就看增量是否>去年×10%）；3.直接读有效数字前几位即可判断 |
| 高频错因 | 用"先乘再加"法（去年×(1+R)再和今年比），计算量大且易错 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

对比两种方法：先减后比只需一次减法+一次比较；先乘再加需要乘法+加法+比较，计算量更大。先减后比只需看增量的前几位有效数字与基期的十分之一（判断10%）比较。词义辨析原话：加法会慢一点。建议多做此类题目感受两种方法的速度差异，特别是15%、25%这类不好直接看出的阈值。
