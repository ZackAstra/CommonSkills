# 方法卡：年均增速前推规则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增速前推规则 |
| 适用题型 | 资料分析-年均增速（年均增长率） |
| 触发场景 | 题目问"按照XX~XX的年均增速"，需要计算或预测 |
| 步骤逻辑 | 1.确认区间首年是否包含在内（如18~22包含18年）；2.18年的增速是和17年比的→基期必须前推到17年；3.公式：末年/前推首年 = (1+R)^N；4.N=末年-前推首年（用哪两年数据就做差）；5.求预测值时：预测年/末年 = (1+R)^N'，R与之前相同 |
| 高频错因 | 1.不前推导致指数N算错（少1）；2.忘记预测年也要以末年为基期，导致分子分母对不上 |

| confidence | high |

## 补充说明

核心逻辑：区间18~22包含18年，18年增速=18年数据/17年数据，所以基期要前推到17年。公式为：22年/17年=(1+R)^5（N=22-17=5）。预测27年时：27年/22年=(1+R)^5（N=27-22=5），R相同。因此27年/22年=22年/17年，可用已知数据直接代算。关键结论：凡涉及增速的比较，只要前一年数据可得，就一定要前推。
