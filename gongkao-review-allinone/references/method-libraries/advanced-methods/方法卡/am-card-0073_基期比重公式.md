# 基期比重公式

- **方法名**: 基期比重公式
- **适用题型**: 资料分析 - 求基期某部分占总体的比重
- **触发场景**: 题目问"XX年A占B的比重"，但数据是当年的产量/销量和增速
- **步骤逻辑**:
  1. 基期比重 = (A/B) × (1+Rb)/(1+Ra)
  2. 其中Ra为A的增速，Rb为B的增速
  3. 可做拆分或放缩简化：先算A/B（现期比重），再乘修正系数
  4. 修正系数约等于 1+(Rb-Ra)，当增速接近时可忽略
- **高频错因**: 直接拿现期比重当基期比重；忘记增速是同比还是环比导致用错R值；搞混分子分母的增速方向
