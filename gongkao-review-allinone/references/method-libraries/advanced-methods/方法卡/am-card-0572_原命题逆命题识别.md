# 方法卡：原命题逆命题识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 原命题逆命题识别 |
| 适用题型 | 形式推理——找推理方式与题干一致的选项 |
| 触发场景 | 题干先给出A→B（如"凡对顶角都相等"），结论却用了B→A的推理（先验证相等，再推对顶角），要求找同样犯了"逆命题"错误的选项 |
| 步骤逻辑 | ① 拆解题干：原命题A→B + 逆命题B→A（先正后逆）；② 原命题只与逆否命题等价，与逆命题不等价，但题目的要求是"推理方式一致"而非"推理正确"；③ 逐个选项判断是原命题、逆命题、否命题还是逆否命题；④ 排除推理正确的选项（如从"所有"推到"个例"=正确推理）和命题类型不匹配的选项 |
| 高频错因 | 把"推理方式一致"误理解为"推理正确"；把因果倒置概念与形式推理的逆命题概念混为一谈 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第12题核心：题干"对顶角→相等"(A→B)，结论先验证"相等"再推"对顶角"(B→A)=逆命题。A选项=否命题（发表推记录，没发表推没记录）→不匹配；B选项=原命题推理正确（所有推个例）→不匹配；C选项=逆命题（运动员推训练→训练推运动员）→匹配；D选项=等价转换→不匹配。形式推理与逻辑推理（加强削弱中的因果倒置）是不同分类，不要混淆。
