# 方法卡：乘法拆分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘法拆分 |
| 适用题型 | 资料分析——乘法，乘数在50%、100%、10%附近或90%-105%区间 |
| 触发场景 | 需要计算A×某百分比，该百分比接近50%、100%或10%等好算基准 |
| 步骤逻辑 | ① 将百分数拆成好算基准±小调整（如98%→100%-2%，103%→100%+3%）；② 先算基准部分（如一半、原数、十分之一）；③ 用"一个包子"法估算调整量：百分之一=原数小数点前移两位；④ 基准结果±调整量=答案 |
| 高频错因 | "一个包子"（1%）的数值算错；拆分后加减方向搞反；非典型百分数（如65%）强行拆分反而更慢 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

"包子法"是核心隐喻：把原数看成100个包子，1%就是一个包子的价格。乘7个包子≈7×单价，允许粗略估算。最适用区间：50%附近、100%附近、10%-20%附近、90%-105%。65%等中间值也可用但优势不明显。
