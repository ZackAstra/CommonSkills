# 间隔增长率反推基期增速

## 基本信息
- **方法名**: 间隔增长率反推基期增速
- **适用题型**: 资料分析 - 增长率
- **触发场景**: 给出两年平均增速和其中一个年份的实际增速，求另一个年份增速；或出现"三个时间节点"求其中一端增速
- **confidence**: high

## 步骤逻辑
1. 由两年平均增速 r̄ 求间隔增长率：R间 = r̄ + r̄ + r̄×r̄ ≈ 2r̄ + r̄²
2. 设所求年份增速为 x，代入间隔公式：R间 = r₁ + x + r₁×x
3. 由于 x 前还加一个正数乘积项，可快速判断 x < R间 - r₁（取差值上界）
4. 根据选项范围直接选答案，不必精确求解

## 高频错因
- 混淆"年均增速"与"间隔增速"的含义，误认为年均=间隔
- 忘记间隔公式中的乘积项 r₁×x，导致上界判断偏大
- 三个时间节点没有画清，导致 r₁ 和 x 的对应关系搞反
