# 时间坑识别（上年末vs同比）

| 字段 | 内容 |
|------|------|
| **方法名** | 时间坑识别（上年末vs同比） |
| **适用题型** | 资料分析 - 综合分析题、直接查找题 |
| **触发场景** | 材料数据标注"比上年末"但题目问"同比"，或材料是累计期但题目问某月 |
| **步骤逻辑** | 1. 圈出材料中每个数据的时间基准（上年末=去年12月末，同比=去年同期末）<br>2. 圈出题目问的时间点<br>3. 对比两者是否一致，不一致则该选项可能错<br>4. 典型坑：材料给"比上年末（2020年12月末）"，题目问"同比（2020年2月末）"→ 时间不匹配 |
| **高频错因** | ①看到"上年"就认为是同比 ②忽略"末"字 ③审题时只看数字不看时间 |
| **来源文件** | internal-source |
| **confidence** | high |
