# 方法卡：线段法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 线段法（盐水类） |
| 适用题型 | 资料分析——盐水类问题（已知两R和量之比，求另一个R） |
| 触发场景 | 材料给出两部分的浓度/增长率和量之比，求整体的浓度/增长率 |
| 步骤逻辑 | ① 画线段，左端A浓度，右端B浓度；② 按量之比反比分线段（量大距离短）；③ 量大那边靠近，确定混合浓度位置；④ 用份数计算具体数值 |
| 高频错因 | 距离比和量之比搞反（成反比）；份数计算错误 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 线段法核心：距离比和量之比成反比（天平原理：重量大力臂短）。谁量大，混合浓度就靠近谁。适合已知两R和量之比求第三个R的场景，比十字交叉更直观。
