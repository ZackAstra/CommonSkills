# 方法卡：作者概括用词优先

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 作者概括用词优先 |
| 适用题型 | 言语理解——片段阅读主旨题（选项用词取舍） |
| 触发场景 | 两个选项意思接近，一个用的是总结句中的用词，另一个用的是分析/论证中的用词 |
| 步骤逻辑 | ① 优先关注文段总结句（首句或末句）中作者精心挑选的概括性用词；② 总结句的用词权重高于分析论证中的用词；③ 选择与总结句用词一致的选项 |
| 高频错因 | 被分析部分的细节用词吸引，忽略了总结句中更精炼的概括性表达；认为分析部分用词更具体就更好 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第11题是典型例题：原文分析部分出现"抢跑速成式教育""揠苗助长"等词，但总结句用的是"违背孩子成长规律"。选项A用"揠苗助长式教育"来自分析部分，选项B"教育要遵循成长规律"来自总结句的反面表达。选B而非A，因为作者做总结时已用"成长规律"概括了问题，这个用词是作者的"小骄傲"，选项应优先匹配。
