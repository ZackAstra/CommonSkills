# 方法卡：隔级比重连乘法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 隔级比重连乘法 |
| 适用题型 | 资料分析——求"部分的子部分"占"最外层整体"的比重 |
| 触发场景 | 题目要求A占C的比重，但材料只给出A占B的比重和B占C的比重（多级嵌套占比） |
| 步骤逻辑 | ① 识别出部分→中间整体→最外层整体的三层关系；② 将各级比重依次连乘，中间变量自动消掉；③ 对连乘结果做粗估即可选答案 |
| 高频错因 | 没有理清指标之间的包含关系，把不同层级的占比搞混 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

典型场景：求"乡村到大中城市人口"占"全省人口"的比重，材料给出该部分占"省内外来人口"48.8%、"省内外来人口"占"外出人口"49.8%、"外出人口"占"全省"26%，三者连乘即得答案。关键难点是识别"省内外来"和"外出省内"是同一个指标。
