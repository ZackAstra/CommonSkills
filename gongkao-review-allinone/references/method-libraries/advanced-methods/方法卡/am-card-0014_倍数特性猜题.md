# 方法卡：倍数特性猜题
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 倍数特性猜题 |
| 适用题型 | 数量关系-比例/倍数关系问题 |
| 触发场景 | 题干出现"是其余的几分之几"等比例描述 |
| 步骤逻辑 | 1.从比例中提取倍数关系（如"是其余的3/7"→数学是3的倍数） 2.用倍数约束排除选项 3.剩余选项用试数验证（赋值总量反推各量是否合理） |
| 高频错因 | 不会从"几分之几"中提取倍数约束；试数时忽略"四种类别"约束 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
讲解中演示：语文是其余的1/4→总数5份→总量100则语文20；数学是其余的3/7→总数10份→数学30或60；英语是其余的7/13→总数20份→英语35。赋值总量100后，假设数学30，反推科学=100-20-30-35=15<30，不满足"科学比数学少"→数学应为60。快速排除+验证。
