# 方法卡：逐年区间不往前推

| 字段 | 内容 |
|------|------|
| 方法名 | 逐年区间不往前推 |
| 适用题型 | 资料分析-含"逐年"表述的判断题 |
| 触发场景 | 题目说"2019~2022年逐年增加/下降"，判断趋势是否正确 |
| 步骤逻辑 | 1. "逐年"指给定区间内每相邻两年 → 2. 2019~2022年逐年=19→20→21→22，共3段比较 → 3. 不需要推算2018年数据 → 4. 但需确认区间内每个年份数据都可求 |
| 高频错因 | 误以为需要往前推到前一年的增速或数据；或忽略区间内某年数据不可求 |
| 来源文件 | source-0040.md |
| confidence | high |

补充说明：强化方法特别强调"逐年不用往前推"。但注意：如果区间内某一年的数据/增速不可求（如没有2018年基期数据），则"逐年增速逐年下降"无法验证，该选项应判断为错误。
