# 方法卡：排除优先于验证

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排除优先于验证 |
| 适用题型 | 资料分析·所有题型（尤其混合增长率验证、综合分析） |
| 触发场景 | 需要判断选项对错时；混合增长率需要验证CD哪个合理时 |
| 步骤逻辑 | 1. 优先选倍数/距离最夸张的选项代入验证 2. 若能证明该选项一定错→直接排除 3. 若代入一个"看起来对"的选项，无法100%确认正确 4. 排除错误选项后，剩余的即为答案 |
| 高频错因 | 代入"正确选项"验证后就选它，但无法确认100%正确；应该代入最夸张的选项来排除 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第2题混合增长率中，讲解中强调"你带D一定能排除，但是带C你还不好保证他一定是"。排除错误选项比验证正确选项更快更可靠。此原则在综合分析题中尤为重要——逐项验证每个选项正确性远不如先排除明显错误的选项。讲解中提到："排除错误选项一定比验证正确的要更快。"
