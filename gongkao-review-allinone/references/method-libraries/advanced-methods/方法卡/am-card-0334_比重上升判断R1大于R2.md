# 比重上升判断R1>R2

| 字段 | 内容 |
|------|------|
| **方法名** | 比重上升判断R1>R2 |
| **适用题型** | 资料分析 - 比重变化判断 |
| **触发场景** | 问"占比/比重提高的地区有几个"或"哪一年占比上升"——不需要算比重差，只需比较增速 |
| **步骤逻辑** | 1. 占比重提高 → 部分增速(R1) > 整体增速(R2)<br>2. 先口算或估算整体增速R2（取位除法，如387÷1020≈38%）<br>3. 逐一比较各部分增速与R2，大于R2的即为"提高"<br>4. 计数即可得出答案 |
| **高频错因** | ①直接算比重再比较（浪费时间）②整体增速算错导致全部判错 ③混淆"提高"和"最高" |

| **confidence** | high |
