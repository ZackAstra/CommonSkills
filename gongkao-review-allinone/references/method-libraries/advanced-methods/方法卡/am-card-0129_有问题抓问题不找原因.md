# 方法卡：有问题抓问题不找原因

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有问题抓问题不找原因 |
| 适用题型 | 言语理解-中心理解题（文段只有问题无对策时） |
| 触发场景 | 文段提出明确问题，但没有对策表述时 |
| 步骤逻辑 | 1. 判断文段是否有对策 2. 没有对策时，主旨就是归纳这个问题本身 3. 选项必须是对问题的同义转述 4. 不要选问题的"原因分析"或"深层解读"，不要自己脑补 |
| 高频错因 | 抓问题的原因或深层含义而非问题本身；或者明明有对策却选了问题表述 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第7题（乡村儿童阅读声音消散）是典型示范。问题明确："乡村儿童阅读过程中声音消散了"。有同学选B"青壮年劳动力重要性"，认为这是"根本原因"；选D"乡村儿童教育严重落后"，认为这是"更深层的问题"。强化方法逐一反驳：B不是问题表述且分析论证部分不支撑它；D是自己脑补，"你有问题就抓问题，你不要自己去脑补"。问题的同义转述就是C"乡村儿童的阅读正在变得沉默"。记住：有问题抓问题，有问题有对策抓对策，不要越级。
