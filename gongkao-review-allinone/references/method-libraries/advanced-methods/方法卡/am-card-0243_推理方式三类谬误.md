# 方法卡：推理方式题——三类常见谬误

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 推理方式题——三类常见谬误 |
| 适用题型 | 判断推理——推理方式/推理结构类 |
| 触发场景 | 题目问"与题干推理最为类似/犯了相同错误"，需要匹配推理结构 |
| 步骤逻辑 | ① 写出题干的推理结构（如A推B，B发生推出A）；② 对照三类常见错误：逆命题（A推B变成B推A）、否命题（A推B变成非A推非B）、分割谬误（整体属性误归于个体）；③ 在选项中找犯了同类型错误的；④ 不用管推理对错，"对要对的一样，错要错的一样" |
| 高频错因 | 把逆命题和否命题搞混；忽略分割谬误这种情况 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

分割谬误：整体特有的属性被误认为每个个体都有。例子："中国人分布在全球各地，某人是中国人，所以某人分布于全球各地"——整体属性不能分割到个体。本课Q3中"停电→冰箱不能用"是逆命题错误（后件发生推出前件）。
