# 基期差=现期差-增量差

- **方法名**: 基期差=现期差-增量差
- **适用题型**: 资料分析 - 基期差值计算
- **触发场景**: 题目求两个量的基期差值，且选项差距较大（如几千以上），不必精确到个位
- **步骤逻辑**:
  1. 计算现期差 B1-B2
  2. 分别估算两个量的增量 X1、X2（可粗估）
  3. 基期差 = (B1-B2) - (X1-X2)
  4. 若选项差很大，先算现期差即可判断方向，无需继续
- **高频错因**: 直接拿基期分别列式再相减，浪费时间且容易出错；不注意增速大小关系导致增量差方向搞反
