# 方法卡：A而不是B句式看"是什么"

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | A而不是B句式看"是什么" |
| 适用题型 | 言语理解——片段阅读主旨题 |
| 触发场景 | 文段出现"A而不是B""不是A而是B"句式，需要判断哪半部分更重要 |
| 步骤逻辑 | ① 识别"A而不是B"或"不是A而是B"句式；② "是什么"（肯定的那一半）比"而不是什么"（否定的那一半）更重要；③ 例如"公益慈善是每个人的权利，而不是社会精英的特权"，重点是"每个人的权利"；④ 选项应优先体现肯定部分的核心含义 |
| 高频错因 | 把"而不是什么"（否定/排除的部分）当成重点选入选项；只关注被否定的内容，忽略了作者真正肯定的观点 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第1题是典型例题："与其说这是完成他的社会责任，不如说这会给他带来助人的喜悦和欢愉，这既是本性也是权利。"加上反面论证"片面的将公益慈善视为社会精英特权是错误的"，整合后主旨为"公益慈善是每个人的权利"——肯定部分是核心，否定部分（"而不是社会精英的特权"）只是反衬。强化方法用"不是这么学，也不是这么学，而我们要这么学"做类比：最后一个"要怎么学"才是重点。此句式在对策类、观点类文段中高频出现。
