# 方法卡：下文推断题六大行文结构

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 下文推断题六大行文结构 |
| 适用题型 | 言语理解——下文推断题（"接下来文章最可能讲述的是"） |
| 触发场景 | 问法为"接下来最可能讲什么"，需根据尾句或全文结构推断下文内容 |
| 步骤逻辑 | ① 全文通读，重点关注尾句话题；② 对照六种结构判断下文方向：(1)尾句提出新话题→下文围绕新话题展开；(2)尾句提出问题→下文分析问题或解决问题（已分析则直接选解决）；(3)尾句给出宏观对策/原因→下文具体展开；(4)尾句说"过去不行"→下文说"现在行"；(5)开头是总句含两方面并列→验证后文是否只展开了一个方面，下文展开另一方面（基于全文结构）；(6)尾句转折→下文围绕转折后内容；③ 选"最先发生"的内容，不是选最终会提到的 |
| 高频错因 | 只看尾句不看全文结构，忽略了结构(5)的并列未展开情况；选了已被前文论述过的内容（重复项）；选了转折前的内容 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第13题(01:09:11)示例：尾句说"硅在遇到锂时会大幅膨胀，可能导致阳极破裂粉化"——这是问题。A选项"攻克锂电池阳极粉化难题的重要性"是分析问题（为什么重要），符合结构(2)。B选项"开发锂电池阳极的必要性"已被前文论述过（重复）。C选项"硅如何提高性能"是转折前内容（已论述）。D选项"如何解决石墨烯电池问题"话题错误（文段已从石墨转到硅）。第15题(01:22:23)示例：开头说"一方面...另一方面..."，后文只展开了"另一方面"，下文应展开"一方面"未被论述的内容——这属于结构(5)。
