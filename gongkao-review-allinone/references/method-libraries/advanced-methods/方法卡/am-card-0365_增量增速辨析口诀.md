# 增量增速辨析口诀

## 字段

| 字段 | 内容 |
|------|------|
| **方法名** | 增量增速辨析口诀 |
| **适用题型** | 资料分析 - 审题防错 |
| **触发场景** | 题目问"增长最多"或"增长最快"，需区分求的是增长量还是增长率 |
| **步骤逻辑** | 1. 记住口诀：多少/高低 → 增量（绝对值）；快慢 → 增速（百分比）<br>2. "增长最多"= 增长量最大，看柱状图直接做减法<br>3. "增长最快"= 增速最快，需算百分比<br>4. 审题时先判断关键词属于哪一类，再选择对应方法 |
| **高频错因** | 把"增长最多"误当成增速来算，或者把"增速"当成绝对增量来比较 |
| **来源文件** | internal-source |
| **confidence** | high |
