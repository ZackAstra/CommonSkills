# 方法卡：矛盾命题三组速查

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 矛盾命题三组速查 |
| 适用题型 | 判断推理——真假话类、矛盾推理类 |
| 触发场景 | 题干给出多句话，告知"只有一真""只有两真"等条件，要求推出事实 |
| 步骤逻辑 | ① 记忆三组矛盾：A与非A；A且B与非A或非B；A或B与非A且非B；以及所有/有些不互换、A推B与A且非B；② 在多人发言中找矛盾对——矛盾必然一真一假；③ 若"只有N真"，且找到两组矛盾（各占一真一假），则剩余发言必为假；④ 从假话推出事实；⑤ 另一种用法：A推B为假时，A且非B为真（如Q18"只有懂英语才是大学生"为假→"懂英语且不是大学生"为真） |
| 高频错因 | 将反对关系（可同假）误认为矛盾关系（必一真一假）；不熟悉"所有/有些"互换的矛盾形式；忘记A推B的矛盾是A且非B |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q18："只有懂英语才是大学生"为假→矛盾"懂英语且不是大学生"为真→选A。Q19：甲乙两组矛盾（非礼灰钱 vs 非礼且非钱；非孙且非皂 vs 孙或皂），各占一真一假，题说只有两真→丙为假→周去了。三组矛盾必须背熟，考场现找基本都是反对关系而非矛盾。
