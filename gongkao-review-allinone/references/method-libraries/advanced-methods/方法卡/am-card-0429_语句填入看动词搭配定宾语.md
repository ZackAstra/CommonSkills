# 方法卡：语句填入看动词搭配定宾语

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语句填入看动词搭配定宾语 |
| 适用题型 | 言语理解——语句填入题 |
| 触发场景 | 待填入句前面有多个并列动词（如"认定""核查""治疗"），需要确定它们共同的宾语 |
| 步骤逻辑 | ① 找到待填入句中需要搭配的并列动词；② 用最"挑剔"的动词来约束宾语范围（如"治疗"只能接"病/疾病/健康问题"，不能接"机理""规律"）；③ 验证其他动词是否也能搭配该宾语（"认定疾病""核查疾病""治疗疾病"都通顺）；④ 选择与最挑剔动词搭配最自然的选项 |
| 高频错因 | 只看部分动词搭配通顺就选，忽略了某个动词（如"治疗"）对宾语的特殊限制 |

## 补充说明

第18题是典型例题。"如何认定、如何核查、如何治疗"三个动词需要共用一个宾语。"治疗"是最挑剔的动词——只能接"病/疾病/健康问题"，不能接"分类和目录"（B选项）、"机理和发生规律"（C选项）、"出现和新关系"（D选项）。只有A选项"新的职业危害引发的安全和健康问题"能让三个动词都通顺搭配。强化方法指出这种题"有点像逻辑填空"，核心是动宾搭配的语感。方法本质：并列动词取交集，找所有动词都能搭配的宾语。
