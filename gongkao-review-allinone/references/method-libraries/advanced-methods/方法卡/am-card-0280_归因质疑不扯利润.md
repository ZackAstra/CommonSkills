# 方法卡：归因质疑不扯利润

- **方法名**：归因质疑不扯利润
- **适用题型**：可行性/有效性质疑题（非归因题也适用）
- **触发场景**：题干讨论某措施"能否达到目的"，选项从经济利益角度反驳时
- **步骤逻辑**：
  1. 先确定题干讨论的核心问题是什么（能否达到效果 vs 是否划算）
  2. 若题干问的是"能否增加乘客求生机会"（保命问题），则利润/成本类选项跑题
  3. 若题干问的是"是否可行"，利润/利益角度通常不是正确答案
  4. 正确选项应从"能否达到目的"的角度直接回应
- **高频错因**：习惯性用"企业不愿花钱""成本太高"等经济理由做质疑，但题干讨论的是可行性而非经济性
- **来源文件**：source-0039.md
- **confidence**：high

补充说明：词义辨析举例——人命关天时航空公司出于利益拒绝配降落伞，这不是"能不能保命"的问题，而是利润问题，跑题了。类似地，别把归因题的方法（另有他因）套用到非归因题上，题型识别要准确。
