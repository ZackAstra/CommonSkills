# 方法卡：等比例混合折扣取均值

## 基本信息
- **方法名**: 等比例混合折扣取均值
- **适用题型**: 数量关系 - 折扣/利润问题（买一送一类型）
- **触发场景**: 买多件商品享受不同折扣，且折扣商品原价相同，求整体等效折扣
- **confidence**: high
- **来源文件**: source-0041.md

## 步骤逻辑
1. 识别各商品的折扣率（如四折=40%，一折=10%）
2. 确认是否"等比例混合"（即原价相同的商品数量相等）
3. 等比例混合时，整体折扣 = 各折扣率的算术平均值
4. 例如：40% + 10% = 50%，÷2 = 25%，即2.5折

## 高频错因
- 不识别"等比例混合"条件，直接用加权平均算
- 混淆"折扣"和"折后比例"（2.5折 = 25%折后价 = 75%原价）

## 补充说明
此技巧在"买一送一"、"第二件半价"等促销问题中非常实用。关键前提：折扣商品原价相同且数量相等。满足时直接取折扣率平均值，省去复杂的金额计算。
