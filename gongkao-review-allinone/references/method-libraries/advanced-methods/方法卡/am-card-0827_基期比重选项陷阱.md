# 方法卡：基期比重选项陷阱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比重选项陷阱 |
| 适用题型 | 资料分析——基期比重选择题 |
| 触发场景 | 基期比重题的选项中，通常会有一个现期比重（本期比重）作为干扰项；可利用这个规律快速猜出左边那个数是多少 |
| 步骤逻辑 | ① 知道选项中必有一个现期比重（本期比重）做干扰；② 看选项猜出左边数的值（拆分验证）；③ 右侧乘一个比1稍大或稍小的数，直接判断选哪个 |
| 高频错因 | 没注意年份，直接用现期比重选了答案；时间审题不仔细把"去年"看成"今年" |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

出题人故意把现期比重设为选项，考生如果不注意年份就会选错。反过来利用这个规律：看到选项后，左边那个数大概等于选项中的某个值，再乘以右侧略大于或略小于1的因子就能锁定答案。实际做题时"一边看选项一边猜左边数"可以极大提速。
