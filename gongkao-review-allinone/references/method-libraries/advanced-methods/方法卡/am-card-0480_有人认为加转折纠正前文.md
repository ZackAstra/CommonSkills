# 有人认为+转折=纠正前文错误

## 方法名
有人认为+转折=纠正前文错误

## 适用题型
中心理解题 / 意图判断题

## 触发场景
文段前半部分出现"有人认为""某些专家认为""某个人认为""有一种论调"等引用他人观点的表述，后半部分出现转折词（然而、事实上、实际上、不过），构成"他人观点 + 转折 + 作者反驳"的结构。

## 步骤逻辑
1. 识别前文"有人认为……"的表述，标记为被反驳的观点
2. 看到转折词后，确认文段结构为"纠正型"
3. 作者写作意图 = 将前文观点**反过来/降级**
4. 后续尾句即使很长（论证、对策等），也**只是在论证转折后的观点**，不是文段重点
5. 正确选项通常含"纠正""纠偏""错误认识""正确认识"等纠偏类表述
6. 对策类选项（如何、应该）如果出现在尾句且仅论证转折观点，则不选

## 高频错因
- 把尾句的对策/分析当成文段重点，选了对策类选项
- 没有识别出"有人认为+转折"的标配结构，逐句分析导致抓不住重心
- 对"纠正"类表述不敏感，反而选了看似全面的对策选项
