# 方法卡：尾数法适用条件

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 尾数法适用条件 |
| 适用题型 | 资料分析——纯加减运算求精确值，选项尾数各不相同 |
| 触发场景 | 题目要求做加减法（如累计量推算），观察选项最后一位数字各不相同，且数据为精确值无四舍五入 |
| 步骤逻辑 | ① 确认选项尾数各不相同；② 确认题目为精确值加减运算（无估算）；③ 只算各数最后一位的加减；④ 得出结果尾数，匹配选项 |
| 高频错因 | 减法借位时算错尾数（如5-9应借位得6）；在有四舍五入的题目中误用尾数法 |

| confidence | high |
