# 方法卡：对比实验他因削弱必须回归分组

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对比实验他因削弱必须回归分组 |
| 适用题型 | 判断推理——削弱类（对比实验型归因论证） |
| 触发场景 | 题干做了两组对比实验（如A组vs B组），结论归因于某差异，选项以"另有他因"方式削弱 |
| 步骤逻辑 | ① 识别对比实验的两组（如火星组vs地球组、>2h组vs<2h组）；② 真他因削弱：必须回到分组，指出实验组中存在另一个未被控制的变量（如"地球上还有河流限制火山生长"）；③ 伪他因削弱（无力度）：随便找一个别的因素但未回归分组（如"其他星体表面构造变化也能影响火山"），无法破坏实验严谨性；④ 直接排除伪他因选项 |
| 高频错因 | 看到"另有他因"就选，不检查是否回归分组；把伪他因（只提别的因素但不分组）当作有效削弱 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第4题（火星vs地球巨大火山）：B选项回到地球组，指出地球上还有河流限制山峰生长→真他因，有削弱力。D选项讨论其他星体表面构造变化→未回归火星vs地球的分组→伪他因，无削弱力。第6题（学习时长vs语文成绩）：D是因果倒置，C回到分组指出"兴趣高的那组学习习惯更好"→真他因但力度不如因果倒置。
