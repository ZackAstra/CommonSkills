# 对策类文段选对策选项

## 方法名
对策类文段选对策选项

## 适用题型
中心理解题（对策类文段）

## 触发场景
文段中出现对策标志词：应该、需要、必须、应当、应、有赖于、关键在于、基石/支撑/保障/前提等，或文段结构为"问题→对策"。选项中有表对策的表述。

## 步骤逻辑
1. 文段有对策 → **一定选对策**，不选意义、影响、原因类选项
2. 对策类选项有三种长相：纯对策、对策+目的、对策+意义
3. 文段尾句如果是意义/好处，且前文有对策 → 选对策不选意义
4. 若多个选项都表对策 → 选**更具体**的那个（参见"具体>宏观"卡）
5. "有对策选对策"优先级高于"全面概括"

## 高频错因
- 文段明明提了对策，却被意义/好处类选项吸引
- 不识别"基石/支撑/保障/前提"等隐性对策标志词
- 对策选项与意义选项纠结时，错误选择意义
