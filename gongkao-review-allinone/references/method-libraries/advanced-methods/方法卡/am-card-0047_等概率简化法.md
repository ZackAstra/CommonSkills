# 方法卡：等概率简化法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 等概率简化法 |
| 适用题型 | 数量关系-概率问题 |
| 触发场景 | 两个主体在相同天数内事件发生的概率相同（均为1/2），求一方比另一方多的概率 |
| 步骤逻辑 | 1.找出两主体条件相同的部分（如前6天都营业且概率相同）；2.相同部分中A比B多的概率=B比A多的概率，可对消忽略；3.只关注条件不同的部分（如甲营业第7天、乙休业）；4.不同部分的概率直接决定最终结果 |
| 高频错因 | 未识别出相同概率部分可以忽略；误认为需要完整计算所有天数的组合概率 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
当两主体在相同条件下事件发生概率相同时（如每天打折概率都是1/2），对称性使得"A多于B"和"B多于A"的概率完全相同。因此只需关注条件不对称的部分。例如甲营业7天乙营业6天，前6天对称可忽略，仅看第7天甲是否打折（概率1/2）。如果概率不是1/2（如一个1/2一个1/3），则无法用此简化。
