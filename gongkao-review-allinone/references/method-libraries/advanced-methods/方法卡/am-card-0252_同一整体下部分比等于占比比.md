# 方法卡：同一整体下部分比等于占比比

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 同一整体下部分比等于占比比 |
| 适用题型 | 资料分析——求同一整体下两个部分的倍数/比值关系 |
| 触发场景 | 两个部分属于同一整体，题目要求比较或求它们的比值，材料只给出了各自占整体的比重 |
| 步骤逻辑 | ① 确认两个部分属于同一整体；② 部分之比 = 占比之比（整体可以消掉）；③ 直接用占比做除法即可 |
| 高频错因 | 没有确认是否同一个整体就套用；分母整体不同导致方法不适用 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

此方法在比较平均值（如"平均每件收入"）时尤其高效：中部平均每件收入/西部平均每件收入 = (中部收入占比/中部件数) / (西部收入占比/西部件数)，整体收入消掉后只需算占比和件数的比值，计算量大幅减少。
