# 方法卡：否定之否定等于肯定

- **方法名**：否定之否定等于肯定
- **适用题型**：题干出现双重否定结构的质疑/支持题
- **触发场景**：题干先提出观点A，然后否定观点A（说它不对），选项要求再质疑这个否定
- **步骤逻辑**：
  1. 识别题干结构：观点A → 质疑A → 选项要求质疑"质疑A"
  2. 质疑"质疑A" = 支持A（否定之否定等于肯定）
  3. 因此选项方向应为支持原始观点A
  4. 直接将题意转化为"支持A"来选答案
- **高频错因**：被绕晕，分不清该支持还是反对哪一层
- **来源文件**：source-0039.md
- **confidence**：high

补充说明：考场上遇到"题干先有观点、又否定该观点、再让你质疑否定"的三层结构，直接翻译为"支持原始观点"。如：有人认为胡狼导致眼镜蛇减少→但这种说法难以成立（因为胡狼不吃眼镜蛇）→要质疑"难以成立"，即要支持"胡狼确实导致眼镜蛇减少"。
