# 方法卡：对策句核心是动宾短语

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对策句核心是动宾短语 |
| 适用题型 | 言语理解-中心理解题（选项高度同义替换时） |
| 触发场景 | 抓到对策句后，选项不是原词原句而是做了大幅同义替换时 |
| 步骤逻辑 | 1. 找到对策句 2. 提取对策句的动宾短语（核心行为），如"调整专业链""强化前置功能" 3. 选项必须体现该动宾短语的核心含义 4. 主语、定语、高频词等修饰成分可以省略，动宾短语不可缺失 |
| 高频错因 | 要求选项包含文段的全部关键词（主语、定语），因选项"缺东西"而不敢选 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

强化方法在第19题（高空坠物，强化法律前置功能）和补充的精讲课例题（职业院校调整专业链）中详细讲解。补充例题的对策句很长："要求职业院校把握专业方向，根据制造业产业链智能化变化，对专业链进行及时调整"，但核心动宾短语只有"调整专业链"。选项A只剩"调整专业"，主语、定语全省了，但仍可选，因为包含核心动宾。第19题同理，"强化前置功能"是动宾短语，选项必须体现"前置"含义，不体现的（如B"规定不完善"）直接排除。
