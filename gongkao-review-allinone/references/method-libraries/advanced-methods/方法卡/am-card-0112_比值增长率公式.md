# 方法卡：比值增长率公式

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比值增长率公式 |
| 适用题型 | 资料分析·单价/均价/效率等比值的同比增速 |
| 触发场景 | 题干问"单价同比增速""均价同比增速"等，且数据给的是总额和数量（或分子分母的各自增速） |
| 步骤逻辑 | 1. 判断题型：单价=额/量，属于比值增长率 2. 确定R1（分子增速）和R2（分母增速） 3. 套公式：(R1-R2)/(1+R2) 4. 若增速未知，需先从现期和基期数据中求出R1、R2 |
| 高频错因 | R1和R2搞反（额和量的增速弄混）；未注意增速的正负号对分子分母的影响 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第20题专门考查比值增长率。强化方法指出"进口单价同比增速"对应"比值增长率"，公式为(1+R2)分之(R1-R2)。本题难点在于题干未直接给出增速，需要先用17年和16年的数据算出R1和R2再代入。该方法的应试策略是：先算完A选项（R1正、R2负，导致分子很大、分母很小，值很大），再用A作为参照物快速排除BCD。
