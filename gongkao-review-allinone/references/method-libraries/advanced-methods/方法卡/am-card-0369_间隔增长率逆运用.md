# 间隔增长率逆运用

## 字段

| 字段 | 内容 |
|------|------|
| **方法名** | 间隔增长率逆运用 |
| **适用题型** | 资料分析 - 已知间隔增速和同比增速，求基期增速 |
| **触发场景** | 题目给出现期较基期的增速（间隔增速）和同比增速，要求中间基期那年的增速 |
| **步骤逻辑** | 1. 间隔增长率公式：r12 = r1 + r2 + r1×r2<br>2. 由间隔增速和r1（同比增速），先做差 r12 - r1 得到粗略r2<br>3. 因为r1×r2为修正项，绝对值一定小于 r12 - r1<br>4. 所以r2的绝对值一定小于 r12 - r1 的绝对值，结合选项快速锁定 |
| **高频错因** | 忘记交叉项 r1×r2 的存在，直接用间隔增速减同比增速当精确答案 |
| **来源文件** | internal-source |
| **confidence** | high |
