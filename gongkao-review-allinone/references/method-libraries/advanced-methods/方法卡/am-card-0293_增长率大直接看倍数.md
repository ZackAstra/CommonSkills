# 方法卡：增长率大直接看倍数

| 字段 | 内容 |
|------|------|
| 方法名 | 增长率大直接看倍数 |
| 适用题型 | 资料分析-比较多个增长率大小 |
| 触发场景 | 多个指标增长率差距很大（如有接近3倍的，有不到2倍的），直接比倍数比算百分比更快 |
| 步骤逻辑 | 1. 观察现期值和基期值的倍数关系 → 2. 倍数 = 现期 ÷ 基期 → 3. 倍数越大，增长率越大（因为增长率 = 倍数 - 1） → 4. 倍数差距明显时直接淘汰 |
| 高频错因 | 在倍数差距已经很大时仍逐个算增长率百分比，浪费时间 |
| 来源文件 | source-0040.md |
| confidence | high |

补充说明：当增长率差距大时（如一个接近3倍，其他远不到3倍），直接看现期÷基期的倍数关系即可判断。强化方法强调"这是一个解题的提醒"——倍数上已有明显区别时，马上切换思路。
