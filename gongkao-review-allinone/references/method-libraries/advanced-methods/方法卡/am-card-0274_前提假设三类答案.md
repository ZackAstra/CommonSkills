# 方法卡：前提假设三类答案

- **方法名**：前提假设三类答案
- **适用题型**：前提假设类（问"以下哪项是上述论证的前提/假设"）
- **触发场景**：题干问"前提""假设""隐含的条件"时
- **步骤逻辑**：
  1. 识别题型为前提假设类
  2. 第一反应判断是否属于断点搭桥（占比约80%）
  3. 若论据与结论存在话题跳跃，则选搭桥选项
  4. 若涉及条件变化（如原来A现在B），则考虑补充漏洞（约10%）
  5. 若选项讨论"能与不能"，则考虑必要条件（约10%）
- **高频错因**：不区分三类，盲目排除；看到"能与不能"选项却忽视
- **来源文件**：source-0039.md
- **confidence**：high

补充说明：断点搭桥是最常见的前提假设正确答案形式，核心是把论据和结论中不一致的关键词连接起来。补充漏洞针对条件变化需补原状态。必要条件关注"能与不能"。
