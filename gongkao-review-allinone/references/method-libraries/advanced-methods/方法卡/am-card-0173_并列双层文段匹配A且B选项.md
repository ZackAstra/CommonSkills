# 方法卡：并列双层文段匹配A且B选项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 并列双层文段匹配A且B选项 |
| 适用题型 | 言语理解——片段阅读主旨题（A且B结构选项） |
| 触发场景 | 选项呈现"A且B"结构（同时提及两个方面），文段前后恰好分两层，各对应A和B |
| 步骤逻辑 | ① 看到A且B结构的选项，回文将文段分成两层；② 检查前半部分是否正好对应A、后半部分是否正好对应B；③ 两层要"严丝合缝"对应，不能字面对应但语义跑偏；④ 如果文段确实分两层且分别对应A和B，则该选项正确 |
| 高频错因 | 只看字面有对应词就选，不验证语义是否匹配；把文段中提及但非重点的词当成对应 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第14题是典型例题：文段前半讲水资源短缺制约发展（=海水淡化的必要性），后半讲海水淡化成本降低、可大规模推广（=可行性）。A和B选项都含"海水淡化"且都是A且B结构。但A说"经济性和实用性"——前半不是"经济"而是"制约发展的必要性"，语义不对；B说"必要性和可行性"——前半对应必要性、后半对应可行性，严丝合缝。选B。
