# 方法卡：科普类客观概括法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 科普类客观概括法 |
| 适用题型 | 言语理解——主旨概括/意图判断（科普介绍类文段） |
| 触发场景 | 文段属于科普介绍类——客观介绍某事物、某现象、某知识，无作者主观倾向和价值判断 |
| 步骤逻辑 | ① 判断文段为科普介绍类（客观表达，无主观倾向）；② 选客观概括性选项；③ 排除对策类选项（即使看起来精彩、符合主流）；④ 排除有主观倾向或价值判断的选项 |
| 高频错因 | 科普类文段选了对策性选项（因为对策选项看起来更"深刻"）；把科普类文段当成说理类去选对策 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

- 逆推检验：如果选项明显是科普介绍类的表达，而原文是说理类，该选项基本不选——文段类型和选项类型要匹配。
- 即使选项给出的对策符合当下主流、看着很精彩，如果文段是科普类，也不选。
