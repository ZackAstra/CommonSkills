# 方法卡：原文细节匹配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 原文细节匹配法 |
| 适用题型 | 言语理解-细节判断题、语句填空题 |
| 触发场景 | 语句填空的横线处需要与上下文具体内容匹配时 |
| 步骤逻辑 | 1. 仔细读上下文，提取关键词和核心概念 2. 将选项与原文逐点匹配，看是否一一对应 3. 不能凭常识或"感觉差不多"就选 4. 排除与原文具体表述不一致的选项 |
| 高频错因 | 题目没读明白就凭直觉选，看几个词对上了就选，不做深入理解 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第3题讨论企业声誉（基于过往交易经验），学生常凭"知名度""行业地位"等常识选错。强化方法强调必须用原文中的"交易经验""过往交易记录"来匹配选项，而非用生活常识替代原文信息。即使选项内容看起来合理（如"行业地位和影响力"），只要原文没这样说就不能选。
