# 方法卡：看指标想表达式

| 字段 | 内容 |
|------|------|
| 方法名 | 看指标想表达式 |
| 适用题型 | 资料分析-全题型（判断题型、列式） |
| 触发场景 | 读题时看到具体指标名称（如"市场份额""平均每支""同比增速"），需要快速判断该指标对应什么数学表达式 |
| 步骤逻辑 | 1. 读题圈出指标名 → 2. 由指标名判断是比值/增长率/增量/比重差等哪种题型 → 3. 对应列式 → 4. 找数代入 |
| 高频错因 | 看到指标名不分析表达式，直接盲目找数列式；把比值题当增长量题做 |
| 来源文件 | source-0040.md |
| confidence | high |

补充说明：这是强化方法反复强调的核心方法论。"市场份额"→占比→比值→考比值增长率或比值倍数；"平均每X"→后边是分母；"同比增速"→考增长率比较。看到指标名就能锁定题型和列式方向。
