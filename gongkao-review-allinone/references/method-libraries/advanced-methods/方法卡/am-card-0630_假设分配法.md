# 方法卡：假设分配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配法 |
| 适用题型 | 资料分析——求基期值和增量（已知现期B和增长率R） |
| 触发场景 | 需要求 B÷(1+R) 的基期值A，以及增量X=AR，且增长率在0%~25%附近 |
| 步骤逻辑 | ① 本质：假设分配是直除的变形，底层逻辑相同；② 第一步：选一个比B稍小的整百数作为假设基期A₁（如B=645选A₁=600）；③ 计算假设增量：X₁ = A₁ × R（如600×5.6%=33.6，可近似写34）；④ 计算剩余：剩余 = B - (A₁+X₁)（如645-634=11）；⑤ 第二步分配剩余：剩余很小时可近似把剩余都给“师傅”（基期），得A和X |
| 高频错因 | 第一步选数不当（选太小导致需要多步）；第二步不会调节，导致误差偏大 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 假设分配的核心优势：同时求出基期A和增量X两步完成。第一步要"认真算"（精确），第二步可以"不那么精确"（大头分完后剩余很小）。"师傅/徒弟"是原课中的分配比喻：师傅对应基期份额，徒弟对应增量份额。增长率越小，假设分配越快越准。
