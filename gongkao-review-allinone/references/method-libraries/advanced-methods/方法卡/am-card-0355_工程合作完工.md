# 方法卡：工程合作完工时间
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 工程合作完工时间 |
| 适用题型 | 数量关系-工程问题/多人同时开工同时完工 |
| 触发场景 | 多人合作完成各自工程，同时开工同时完工；或某人中途调换工地 |
| 步骤逻辑 | 1.同时开工同时完工→工作时间相同→T=总工作量÷效率和 2.求某人转场时间：先算固定工人的工作量→求剩余工作量→用此人效率算在原工地天数→转场日=工作天数+1 3.已知时间求效率比→设总量为时间的公倍数→效率=总量÷时间 |
| 高频错因 | 转场日误算为"干完当天"（应为下一天）；效率比与时间比搞反（时间越长效率越低）；两个工程总量设为相同值时效率变化但比值不变，不必纠结 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
统筹问题核心口诀："干擅长的"。比较各人做甲乙工作的时间比（横比或纵比均可），时间短的代表擅长该项。讲解中特别澄清"总量设不设一样无所谓"，因为效率随总量变化而时间比值恒定。
