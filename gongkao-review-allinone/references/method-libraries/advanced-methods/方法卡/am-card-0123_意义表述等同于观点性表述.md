# 方法卡：意义表述等同于观点性表述

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 意义表述等同于观点性表述 |
| 适用题型 | 言语理解-中心理解题 |
| 触发场景 | 文段末尾出现意义/好处/价值表述（"不仅...还...""能够..."） |
| 步骤逻辑 | 1. 识别文段中的意义表述（如"不仅让非遗得到传承，还能改善生活水平"） 2. 意义表述体现作者的价值判断（认为某事物好），具有观点性 3. 意义表述优先级高于客观事实/中性描述 4. 中性表述和意义表述同时出现时，选意义表述对应的选项 |
| 高频错因 | 把意义表述当成不重要的补充信息，选了中性描述对应的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

强化方法在第4题（非遗生产性保护）中重点讲解。文段最后一句"不仅让非遗得到传承和保护，还能改善生活水平"是意义表述，虽然没有直接说"应该"，但"能够...还能..."体现作者认为生产性保护是好的——这就是观点性。当选项中有中性描述（如"理念应运而生"）和意义描述时，意义表述优先。精讲课会进一步展开"观点的几种形式"。
