# 方法卡：盐水混合

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水混合 |
| 适用题型 | 资料分析·当月增速与累计增速比较、部分占比与总体占比推断 |
| 触发场景 | 累计值由两个分段混合得到，需要判断分段值与混合值的大小关系时 |
| 步骤逻辑 | 1. 识别混合数据（如1~6累计由1~3和4~6混合得到） 2. 确认混合比重在两个分段比重之间 3. 已知一个分段比重和混合比重，推断另一个分段比重的范围 |
| 高频错因 | 搞混谁是混合值谁是分段值；未注意同比/环比的时间基准 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

盐水混合是强化方法资料分析的高频考点方法。本课中至少在三个场景使用：第5题（出口占比环比判断，混合58.1在57.8和二季度之间）、第8题（当月增速>累计增速，即当月累计混合后增速在当月和前期累计之间）、第12题（增速范围在-21.6%和-13.6%之间）。核心原理：混合后的值一定介于两个组成部分的值之间。第8题的简化判断规则是"当季度累计增速只要比上个月高，当月增速就大于累计增速"。

### 补充场景：去除部分后判断剩余部分范围（source-0026, 17:38~19:00）
当已知整体比重和若干部分比重，求去除某部分后的比重时：被去除部分的混合比重必大于其中最小值。若最小值仍高于整体比重，则剩余部分必低于整体比重。例：中部地区四省最小覆盖率88.9 > 中部整体83.8，故去除四省后X < 83.8。
