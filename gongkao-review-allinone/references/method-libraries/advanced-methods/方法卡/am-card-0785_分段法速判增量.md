# 方法卡：分段法速判增量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分段法速判增量 |
| 适用题型 | 资料分析-增量判断-判断某月/年增量是否超过某阈值 |
| 触发场景 | 题目问"增量超过X百万/万的有几个"，需要快速逐个判断时 |
| 步骤逻辑 | 1. 将阈值换算为对应位数（如500万=百位为5后有两个零，从倒数第三位看起）2. 用分段法只看前几位：减完该位>阈值对应位则肯定超过，直接计入 3. 减完该位<阈值则不够，直接排除 4. 恰好等于时看后一位是否够减 |
| 高频错因 | 忽略起始年份需与前一年比较（如问2012-2020，2012需减2011）；忘记时间段限制 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

这是2112分段法的实战应用。课上以"增量超过500万户"为例：只看百位相减的结果，大于5直接判够，小于5直接判不够，等于5再看后两位是否够减。同样原理可用于"超过1200万吨"等场景，只需看对应位数。关键易错点：问"2012年到2020年增量超过X的有几个"时，2012年的增量需要用2012年数据减2011年数据，不是从2013年才开始算。
