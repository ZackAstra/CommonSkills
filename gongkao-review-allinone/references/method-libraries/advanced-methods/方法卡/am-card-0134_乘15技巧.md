# 方法卡：乘15技巧

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘15技巧 |
| 适用题型 | 资料分析·涉及15倍关系的计算（如公顷转亩、1.5倍等） |
| 触发场景 | 需要把某数乘以15（公顷转亩=×15，或增率15%时的增量估算） |
| 步骤逻辑 | 1. 任何数×15 = 该数×10 + 该数×5 = 该数×10 + 该数×10÷2 2. 即：先取10倍，再加上10倍的一半 3. 例如26×15=260+130=390 |
| 高频错因 | 直接硬乘15计算慢；不会用10+5的拆分 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第7题中26万公顷转万亩需算26×15。讲解中演示：26×10=260, 260÷2=130, 260+130=390。口算即完成。此技巧在涉及公顷→亩换算时高频出现。
