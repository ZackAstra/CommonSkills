# 方法卡：最不能支持三种选项类型

- **方法名**：最不能支持三种选项类型
- **适用题型**：论证题，问"最不能支持"
- **触发场景**：问法为"以下哪项最不能支持上述观点"
- **步骤逻辑**：
  1. 理解"最不能支持"有三种可能答案类型：
     - 有削弱选项 → 选削弱（削弱最"不能支持"）
     - 无削弱选项但有无关 → 选无关
     - 四个都能支持 → 选支持力度最弱的
  2. 先逐项判断是否能削弱，有削弱直接选
  3. 无削弱则找无关项
  4. 若四个都支持，比较支持力度，选最弱的
- **高频错因**：只考虑"选无关"一种路径，忽略了可能四个都能支持需要比力度的情况
- **来源文件**：source-0038.md
- **confidence**：high

> 补充：Q16中ABD都能支持，C选项"农村有农药影响存活率"不等于"城里适宜"（被迫来城不等于宜居），属于支持力度最弱的选项。做此类题要意识到选项设置的多样性，不能默认只有"选无关"一条路。
