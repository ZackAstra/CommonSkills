# 方法卡：前提假设三优先级

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提假设三优先级 |
| 适用题型 | 前提假设题（"上述论证依赖的假设是"） |
| 触发场景 | 题干从论据推出结论但中间有断点或未排除的干扰变量，问需要什么前提才能成立 |
| 步骤逻辑 | ① 搭桥优先：论据和结论之间的概念有跳跃时，找连接两者的选项；② 修补漏洞次之：排除其他可能的干扰变量（如教育水平、上辅导班等）；③ 必要条件兜底：否定该选项后结论不成立；④ 纯支持选项（补充对比实验等）不能选，因为它游离于论证体系之外 |
| 高频错因 | 把前提假设题当支持题做，选了"补充正向论据"的选项（如"不超过1小时能力会提高"）；忽略了修补漏洞选项的"并不比…差很多"这类精确表述恰恰是正确答案的信号 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第7题核心：甲乙两市看电视时长与数学能力的关系。A（兴趣小）和B（训练多）=他因方向=削弱，排除；C（不超过1小时能力提高）=纯支持=游离体系外，排除；D（教育并不比乙市差很多）=修补漏洞，排除教育差异这个他因。"并不比…差很多"的严谨表述是出题人有意为之的信号——典型题对应典型答案。
