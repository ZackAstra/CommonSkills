# 方法卡：份数法（415份数法）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 份数法（415份数法） |
| 适用题型 | 资料分析-增量计算/基期计算 |
| 触发场景 | 增长率R接近常见分数（25%=1/4、20%=1/5、12.5%=1/8、10%=1/10等） |
| 步骤逻辑 | 1.识别R接近哪个分数（如23.4%≈1/4，12.7%≈1/8）；2.写出基期:增量:现期的份数比（如1/4→四比一比五）；3.用现期数据除以对应的份数得到每份值；4.乘以增量份数得到增量（或乘以基期份数得到基期） |
| 高频错因 | 1.分数选择不准确导致误差大；2.忘记区分基期份数和现期份数的对应关系 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

常用映射：1/4（25%）→四比一比五；1/5（20%）→五比一比六；1/8（12.5%）→八比一比九；1/10（10%）→十比一比十一。核心思路是把百分比转化为整数比，避免直接乘除。估算精度足够应对大多数题目，若R略大于分数值则算出的增量偏小，反之偏大，需注意方向性。
