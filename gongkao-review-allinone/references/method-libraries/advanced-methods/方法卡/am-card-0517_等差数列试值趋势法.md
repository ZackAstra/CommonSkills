# 方法卡：等差数列试值趋势法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 等差数列试值趋势法 |
| 适用题型 | 数量关系-等差数列/工程累加 |
| 触发场景 | 两人分别以常数和等差数列速度工作，总量给定，求完成天数或谁多谁少 |
| 步骤逻辑 | 1.估天数范围：取平均日产量粗估（如每天约30-40个→20-25天） 2.试算中位天数的前n项和：常数项=值×n，等差项=n×中间项 3.若不足则增大天数，重复直到总量够 4.最后一天（等差数列外的项）单独处理 5.比较趋势：若常数方已在后期每日少于等差方，差距只会扩大，不必精确算最后一天 |
| 高频错因 | 忽略"除最后一天外"的条件导致最后一天产量处理错误；不估天数直接从头枚举浪费时间 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
核心是"先估后试再判断趋势"：不用精确计算最终差值，只要证明某一方在之后每一天都更少，差距必然扩大。最后一天若不在等差数列中，需单独算其值，但若差值已足够大（远超选项分界），可直接选。
