# 方法卡：百分数相乘速算法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 百分数相乘速算法 |
| 适用题型 | 资料分析——间隔增长率/乘积增长率中需要计算R1×R2（两个百分数相乘） |
| 触发场景 | 公式中有R1×R2项，需要快速估算两个百分数的乘积 |
| 步骤逻辑 | ① 把其中一个百分数换成分数或小数（如31%→1/3，5%→0.05）；② 另一个百分数的百分号当作单位保留；③ 用分数/小数乘以另一个数值；④ 结果直接加百分号 |
| 高频错因 | 两个百分号都消掉导致量级错（应只消一个）；换分数时方向反了（31%应换1/3，不是3） |

## 补充说明

核心思路：两个百分数相乘，消一个百分号，结果还是百分数。常用换算：5%→0.05或1/20，10%→0.1或1/10，25%→0.25或1/4，33%→1/3。估大估小可互相补偿：一个数估大0.5%×4%就用0.05×4%=0.2%，而非精确算。误差在不知不觉中抵消。
