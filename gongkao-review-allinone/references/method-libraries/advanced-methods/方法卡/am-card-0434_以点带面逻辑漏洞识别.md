# 方法卡：以点带面-逻辑漏洞识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 以点带面-逻辑漏洞识别 |
| 适用题型 | 判断推理-逻辑判断-削弱/支持题 |
| 触发场景 | 题干论据只涉及某个具体方面（"点"），结论却上升到更宏观的层面（"面"） |
| 步骤逻辑 | 1. 识别论据只是"一个点"（如仅讨论网购服饰、化妆品、家居用品） 2. 识别结论扩展到了"一个面"（如"在家庭中拥有更大控制权"） 3. 削弱方向：强调这个"点"不重要（如只占家庭消费25%） 4. 支持方向：强调这个"点"非常重要 |
| 高频错因 | 把"以点带面"和"以偏概全"混淆；后者是数量/样本代表性问题，前者是论域从小到大的跳跃 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

以点带面与以偏概全的区别：以偏概全是数量上的以少推多（如用部分样本推总体），以点带面是论域上的从小推大（如从网购行为推到家庭控制权）。针对逻辑漏洞的直接削弱，力度最强，是"梦中情答"。
