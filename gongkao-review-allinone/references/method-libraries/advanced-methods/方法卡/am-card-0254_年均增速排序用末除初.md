# 方法卡：年均增速排序用末除初

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增速排序用末除初 |
| 适用题型 | 资料分析——比较年均增长率大小或排序 |
| 触发场景 | 多个指标的年均增速排序，且增长次数（年数差）相同 |
| 步骤逻辑 | ① 确认各指标增长次数相同（都是n年）；② 用末期值÷初期值代替年均增长率来比较（因为n相同，根号下末/初的大小关系与末/初一致）；③ 瞪算各比值大小，完成排序或排除 |
| 高频错因 | 考虑去开n次方根，浪费时间；不确认增长次数是否相同就直接比较 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

该方法本质：年均增长率 = (末/初)^(1/n) - 1，当n相同时，只需比较末/初的大小即可。直播中具体应用：同城110÷74≈1.5不到，异地150÷23≈6.5多，跨境14÷6≈2.3多，同城最小排最后，直接选D。
