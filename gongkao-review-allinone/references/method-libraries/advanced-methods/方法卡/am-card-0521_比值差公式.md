# 方法卡：比值差公式

## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 比值差公式 |
| 适用题型 | 资料分析-两个时期比值之差（如人均、日均、亩产等） |
| 触发场景 | 题目问"每日XX比XX少多少"或"人均XX差多少"，本质是两个比值相减 |
| 步骤逻辑 | 1. 识别题型为比值差（两个比值相减）<br>2. 确认分子（总量A）和分母（天数/人数等B）及其增长率R1、R2<br>3. 套公式：比值差 = (A/B) × (R1 - R2) / (1 + R1)<br>4. 计算A/B的现期比值和增速差，得出结果 |
| 高频错因 | 分不清R1是分子增速还是分母增速；忘记分母的增速需要自行计算（如天数从29天到31天） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明
- 公式中R1是分子（被除数）的增速，R2是分母（除数）的增速。
- 本例中：A=总次数9929，B=天数31天，R1=总次数环比增率59%，R2=天数增率(31-29)/29≈7%。
- 比值差公式有时比"分别算两个比值再做差"更快，但前提是能快速找到R1和R2。
- 注意区分环比和同比，此处问的是环比（3月vs2月），不要错用同比数据。
