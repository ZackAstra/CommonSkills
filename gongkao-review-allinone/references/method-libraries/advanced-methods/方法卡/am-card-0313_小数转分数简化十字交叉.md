# 方法卡：小数转分数简化十字交叉

## 基本信息
- **方法名**: 小数转分数简化十字交叉
- **适用题型**: 数量关系 - 涉及百分比/小数的混合比例计算
- **触发场景**: 十字交叉中小数（如56.25%、31.25%）不好约分时
- **confidence**: high
- **来源文件**: source-0041.md

## 步骤逻辑
1. 识别关键小数：6.25% = 1/16，12.5% = 1/8，25% = 1/4
2. 将百分数拆分为整数部分 + 特殊小数部分，再转分数
3. 例如 56.25% = 50% + 6.25% = 1/2 + 1/16 = 9/16
4. 用分数进行十字交叉，直接约分得到最简比

## 高频错因
- 用小数硬算（如31.25和43.75去约分），耗时且易错
- 不记得6.25% = 1/16这个关键换算

## 补充说明
需要记忆的常用换算：1/8=12.5%，3/8=37.5%，5/8=62.5%，1/16=6.25%。这些在资料分析和数量关系中高频出现。强化方法强调"分数好约分"，遇到类似小数优先转分数再计算。
