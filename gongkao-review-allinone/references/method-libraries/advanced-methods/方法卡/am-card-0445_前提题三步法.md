# 方法卡：前提题三步法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提题三步法 |
| 适用题型 | 前提/假设题——问法为"补充以下哪项为前提/假设" |
| 触发场景 | 问法出现"前提""假设""必须补充"等关键词 |
| 步骤逻辑 | ① 先找论据和结论，定位断点（论据中的关键词与结论中的关键词之间的跳跃）；② 若有断点→直接搭桥（选项同时包含断点两端的概念，建立联系）；③ 若无断点→没它不行（否定代入验证：假设该选项不成立，结论是否还能推出，不能则为答案） |
| 高频错因 | 没找准论据和结论就选选项；混淆断点与无关概念；无断点场景下选了补充漏洞而非必要条件 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q5示例：论据"面试能了解能力"→结论"面试不可取代"。断点："了解能力"→"不可取代"，直接搭桥选项不存在→转向补充漏洞→D"应聘者能力很难通过其他环节展示"，因为只有面试能证明能力→面试才不可取代。Q16示例：论据"投入了但论文数没增长"→结论"投入对科研发展没用"。断点："论文数"→"科研发展"→C"发表文章数量是衡量科研发展的重要指标"直接搭桥。
