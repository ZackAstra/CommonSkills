# 方法卡：截三位速算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 截三位速算 |
| 适用题型 | 资料分析·多位数加减比较 |
| 触发场景 | 题干数据位数较多（如千位以上），需要快速做差或比较大小时 |
| 步骤逻辑 | 1. 将大数截取前三位有效数字 2. 在截取后的数字上进行加减运算 3. 用截取后的结果进行大小比较 |
| 高频错因 | 截取位数不一致导致比较失误；对精度要求高的题目不宜使用 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

强化方法在第2题（求季度进出口总额最大值）时使用此法，将多个千位数截取前三位后快速做差比较。该方法适用于选项差距较大的比较类题目，配合"大大则大"的逻辑可以进一步减少计算量。
