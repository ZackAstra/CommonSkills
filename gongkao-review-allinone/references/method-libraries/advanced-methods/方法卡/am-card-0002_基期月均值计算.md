# 方法卡：基期月均值——先除后基期

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期月均值计算顺序选择 |
| 适用题型 | 资料分析——求基期月均值（已知现期总量、增长率、月数） |
| 触发场景 | 题目给出年度总量和年增长率，要求求去年月均值 |
| 步骤逻辑 | ① 方案A：先求现期月均（总量÷12），再除以 (1+R) 求基期月均；② 方案B：先求基期总量（总量÷(1+R)），再÷12；③ 选择原则：先做无误差的运算（除法精确无误差），把有误差的运算（÷(1+R)）放后面，因为无误差步骤不影响后续精度 |
| 高频错因 | 误以为月均值的增长率与整体增长率不同；先做有误差运算导致误差累积 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

核心原则：先做精确运算，把需要估算的步骤放最后。月均值的增长率与整体增长率相同（"整体涨10%，平均每个人涨10%"）。
