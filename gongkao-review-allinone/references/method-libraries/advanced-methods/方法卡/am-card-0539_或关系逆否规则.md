# 方法卡：或关系逆否——否或得且，或且互换

## 适用题型
推理题中涉及"或"关系的逆否推理（逻辑判断）

## 触发场景
条件为"若A或B则C"，需要逆否推理时

## 步骤逻辑
1. 原命题：若(A或B) → C
2. 逆否命题：非C → 非(A或B)
3. 非(A或B) = 非A 且 非B（德摩根律）
4. 口诀：或关系的否定，前后都否，同时或且互换
5. 即"A或B"的否定变成"非A且非B"

## 高频错因
- 逆否时只否一个分支，忘记否另一个
- 把"或"的否定仍写成"或"而非"且"
