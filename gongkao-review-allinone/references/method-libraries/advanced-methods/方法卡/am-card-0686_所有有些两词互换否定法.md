# 方法卡：所有有些两词互换否定法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 所有有些两词互换否定法 |
| 适用题型 | 逻辑——推出类/真假分析（题干含"所有/有些"的命题，需要取矛盾或取否定） |
| 触发场景 | 需要判断"所有A是B"为假时实际情况是什么，或需要找与"有些A是B"矛盾的命题 |
| 步骤逻辑 | ① 取矛盾（为假时）：两词互换 + 后面加"不"。"所有A是B"为假→实际情况"有些A不是B"；"有些A是B"为假→实际情况"所有A不是B"；② 推出关系：所有→有些→特例（单向推出，不可逆）；③ 互换关系：有些A是B 可互换为 有些B是A |
| 高频错因 | 取否定时只加"不"不换词（如把"所有A是B"的否定写成"所有A不是B"，应该是"有些A不是B"）；把"有些是"推出"有些不是"——推不出 |

| confidence | medium |

## 补充说明

口诀"两词互换后面加不"：互换的是"所有"和"有些"这对量词，"不"加在后面的谓语前。推出链条：所有→有些→特例（单向，不可反推）。"有些是"推不出"有些不是"（可能所有人都满足）。"有些是"推不出"所有"和"特例"。这个知识在真假话分析题和推出推理题中都用得上。
