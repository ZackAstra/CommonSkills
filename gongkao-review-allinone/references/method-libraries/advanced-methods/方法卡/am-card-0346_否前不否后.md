# 方法卡：否前不否后——前件未满足推不出

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 否前不否后——前件未满足推不出 |
| 适用题型 | 判断推理——翻译推理类（条件命题推理） |
| 触发场景 | 题干给出A→B且C类条件命题，但前提A不成立（非A），问能推出什么 |
| 步骤逻辑 | ① 翻译条件命题为A→B且C；② 检查前提是否满足——如果给的是非A（前件为假），则箭头不成立，推不下去；③ 后件B和C的发生与否均未知：可能去了也可能没去，什么也推不出来；④ 只有肯前（A成立）才能推出后件；否前+肯后均不能推出确定结论；⑤ 类比："写完作业带你去公园和游乐场"→没写完→去没去公园不知道，去没去游乐场也不知道 |
| 高频错因 | 看到非A就想当然推出"非B且非C"（否前否后谬误）；误以为A推B切C的逆否可以对单个后件推出结论；被选项中的"紫金山林区"等具体名词迷惑，忘记检查前件是否满足 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q20为典型：条件为"野生灵芝→湿度高且光线昏暗"，前提"紫金山林区没有野生灵芝"（非A）→湿度高不高、光线昏不昏暗均推不出来→三个选项都推不出→选"三个都不能"。本题迷惑性在于选项看似合理，但只要前件不成立就什么也推不出。口诀：否前无必然，推不出后件。
