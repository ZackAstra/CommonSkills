# 方法卡：归因类削弱嵌套因果链

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因类削弱嵌套因果链 |
| 适用题型 | 加强削弱——归因类，存在"支持谁让谁做根本原因"或"反对谁让谁做直接原因"的判断 |
| 触发场景 | 题干A认为原因是X，反对者认为不是X而是Y，问"最能削弱反对者"或"最能削弱原观点" |
| 步骤逻辑 | ① 削弱反对者→让反对者的Y做直接原因，X做根本原因：X→Y→结果（如缺水→受凉→感冒）；② 削弱原观点→反过来：Y→X→结果；③ 快速判断方向：看选项是否建立了"谁导致谁"的因果链；④ 注意"类似症状"不等于"就是症状"，"某人声称"不等于"事实" |
| 高频错因 | 看到A选项建立了强因果链却觉得"太直接了"不敢选，转而去选有瑕疵的干扰项；把削弱反对者和支持反对者的方向搞反（缺水→受凉=削弱反对者，受凉→缺水=支持反对者） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第17题核心：一方说感冒因缺水，反对者说因受凉。削弱反对者→让受凉变成缺水的中间环节=缺水→受凉→感冒=A选项。D选项（受凉→缺水）=支持反对者。B选项（发烧→缺水）=因果倒置质疑原观点。C选项（没受凉也有类似感冒症状）="类似"≠"就是"，削弱力度不足。归因类削弱的关键：先确认支持/削弱的方向，再建立因果链。看到A这种"直接根本原因"型选项建立了强因果链，通常就是正确答案，不需要找其他瑕疵。
