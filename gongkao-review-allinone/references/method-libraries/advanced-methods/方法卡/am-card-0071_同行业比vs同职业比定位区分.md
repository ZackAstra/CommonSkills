# 同行业比vs同职业比的定位区分

- **方法名**: 同行业比vs同职业比的定位区分
- **适用题型**: 资料分析 - 交叉表格（行业×职业）中的比较定位
- **触发场景**: 表格有行业行和职业列，题目说"同行业"或"同职业"，需要确定比较对象在表格中的位置
- **步骤逻辑**:
  1. "同行业"→ 和该行业前面的总计列（行业平均工资）比
  2. "同职业"→ 和最上面全省同职业的数值比
  3. 例如：采矿业办事人员 vs 同行业 → 比采矿业平均工资；vs 同职业 → 比全省办事人员
  4. 关键：看"同"字修饰的是行业还是职业
- **高频错因**: 把"同行业"理解为和全省同职业去比；把办事人员和上面的全省办事人员数值比较，而题目要求的是同行业总计
