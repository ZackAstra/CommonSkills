# 方法卡：断点搭桥

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点搭桥 |
| 适用题型 | 判断推理——前提假设题 |
| 触发场景 | 论据和结论之间存在信息断层，结论中出现论据未提及的新概念 |
| 步骤逻辑 | ① 读结论，圈出结论中的新概念（论据中没出现过的词）；② 回到论据，找到与新概念相关联的旧概念；③ 选一个选项同时包含新概念和旧概念，将论据与结论串成链；④ 其他选项若缺少结论中的新概念，直接排除 |
| 高频错因 | 不识别结论中的新概念，选了没有"桥接"功能的选项；被结论以外的细节干扰 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

本课中Q1、Q7、Q19三道题均用断点搭桥解决。Q7（肥皂清洁）把"不溶解"和"不起清洁作用"串成串；Q19（冰场温度）把"可移动水分子最多"和"冰面越光滑"串成串。核心思路一致：结论有新内容，选项必须包含该新内容并与论据相连。
