# 方法卡：平均数差值-直接做差法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 平均数差值-直接做差法 |
| 适用题型 | 资料分析——比值差/平均数差值（求两年平均数之差的具体数值） |
| 触发场景 | 题干问"同比约减少/增加多少"（求具体差值而非比率），且分子分母两年数据均已知或可求 |
| 步骤逻辑 | ① 判定题型：A/B的差值→比值差/平均数差值；② 确认两年的分子（如收入）和分母（如人次）是否全部已知；③ 若全部已知，直接用"2022年收入/人次 - 2021年收入/人次"做差；④ 注意量级还原（如万亿÷亿需换算为元/人次）；⑤ 精算到选项所需精度 |
| 高频错因 | ① 忽略量级换算（分子万亿、分母亿，差值单位是元而非万元）；② 未利用前题结果（如第一题已求增速可用于求基期人次）导致数据缺失；③ 选项首位相同看似差距大实则差距极小，误以为可估算 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

词义辨析不推荐用比值差公式（小A比大B乘R1-2），因为该公式涉及多步乘除，容易产生累积误差。当两年数据均可直接获取时，分别算出两个平均数再做差更直接可靠。此题另一难点是需要利用第一题结果求基期人次，形成"连环题"。
