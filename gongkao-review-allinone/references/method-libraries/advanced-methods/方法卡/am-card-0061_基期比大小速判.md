# 方法卡：基期比大小速判

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期比大小速判 |
| 适用题型 | 资料分析-基期排序/基期比较 |
| 触发场景 | 多项基期需要排序比大小，且现期和增率都已知 |
| 步骤逻辑 | 1.基期=现期/(1+R)；2.现期大+增率小→基期一定大（分子大分母小）；3.现期小+增率大→基期一定小（分子小分母大）；4.差距悬殊时直接按现期排序即可，增率在10%以内几乎不影响大小关系 |
| 高频错因 | 逐项精算12个基期再排序；不利用现期差距排除选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

本质公式：基期=现期/(1+R)。关键速判规则：(1)现期差距大时，增率小（<10%）根本翻不了大小关系，直接按现期排；(2)现期相近时才需要比较增率对基期的影响。本集用此法快速排除A、B、C选项，只在必要时精算D选项。增率正负也要注意：负增率意味着基期大于现期。
