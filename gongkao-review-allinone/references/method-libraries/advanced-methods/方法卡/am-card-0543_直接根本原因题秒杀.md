# 方法卡：直接根本原因题——支持谁就让谁成为根本原因

## 适用题型
直接/根本原因题（逻辑判断）

## 触发场景
题干有原观点和反对者两个立场，问"支持谁"或"削弱谁"

## 步骤逻辑
1. 识别原观点（A）和反对者（B）两个立场
2. 明确任务：支持谁 → 让谁成为根本原因
3. 构造因果链：根本原因 → 直接原因 → 结果
4. 若支持原观点A：选"A导致B"的选项，让A成为根本原因
5. 若削弱反对者B：同样选"A导致B"，把B降格为直接原因（被A推导）
6. 若削弱原观点A：选"B导致A"的选项

## 高频错因
- 看到两个观点就蒙了，不知道该支持谁、怎么构造因果链
- 把A选项"之前科学界公认"当成因果倒置（但时间不一致，实际是无关）
