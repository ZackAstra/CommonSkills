# 方法卡：分数含金量换算法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 分数含金量换算法 |
| 适用题型 | 资料分析 / 省考分数横向对比、估分定位 |
| 触发场景 | 拿到某省分数后想知道在另一省大概什么水平；或跨省交流分数时防止误判 |
| 步骤逻辑 | 1. 确认本省分数及大致排名百分位<br>2. 查目标省同百分位对应的分段区间<br>3. 得出等价分数（如湖北75 ≈ 河南60） |
| 高频错因 | 直接拿绝对分数跨省对比，得出错误的"我比你高所以比你强"结论 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
本质是省际分差估算法的逆向应用：不是估难度差多少，而是"我这个分数换个省值多少"。词义辨析举例：湖北是今年最放水的省份，75分在湖北排名中等偏下；河南最难，60分进面前四分之三。两者等价。备考时不要被绝对分数迷惑，要看自己在进面人群中的相对位置。
