# 方法卡：趋势法判分数大小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 趋势法判分数大小 |
| 适用题型 | 资料分析·分数比较（增率/比重/单价等分子分母形式的比较） |
| 触发场景 | 需比较A/B与C/D的大小，或判断某年分数值是否比基期大/小 |
| 步骤逻辑 | 1. 分子增速>分母增速→分数数值变大 2. 分子增速<分母增速→分数数值变小 3. 直接比较分子和分母的相对增长率即可判断趋势 |
| 高频错因 | 习惯性把分数算出来再比；不看增速关系直接硬算 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第6题中比较19-22年增速大小时，讲解中用趋势法：19→20分子涨50%分母涨10%，分子快所以20>19；20→22分子涨15%分母涨20%，分母快所以20>22。全程不计算实际分数值。第7-8题同理用来判断出让单价是否>150万/亩、出让率最高最低差等。此法贯穿整套题，是资料分析分数比较的核心思路。
