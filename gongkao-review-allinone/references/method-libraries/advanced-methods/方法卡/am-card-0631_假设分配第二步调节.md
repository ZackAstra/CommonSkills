# 方法卡：假设分配第二步调节规则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配第二步调节规则 |
| 适用题型 | 资料分析——假设分配法的第二步精细化 |
| 触发场景 | 假设分配第一步分完后，剩余金额需要第二步分配 |
| 步骤逻辑 | ① 当R在0%~10%附近：第二步用剩余×10%近似，然后根据R与10%的差距微调（R<10%则往下取整，R>10%则往上取整）；② 当R在分数附近（1/4、1/3、1/2等）：第二步直接用剩余除以(n+1)（即四幺五法）；③ 当R≈25%：第二步除5；④ 当R≈33%：第二步除4；⑤ 当R≈50%：第二步除3；⑥ 当R≈67%：第二步×0.4；⑦ 当R接近100%：第二步直接平分 |
| 高频错因 | 第二步过度精确计算，浪费时间；不根据R大小选择不同的调节策略 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 第二步的核心原则："大头分完，小头随意"——第一步精确分配后，剩余金额很小，第二步的微小误差不会影响最终选项判断。强化方法强调："最后一步差一不是毛病"。
