# 方法卡：日常分析高频信息+逆向思维

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 日常分析高频信息+逆向思维 |
| 适用题型 | 日常分析——多人多条件匹配/排序题 |
| 触发场景 | 题干给出多个人物（赵一、孙三等）与多个事物（菜品）的交叉条件，要求一一匹配 |
| 步骤逻辑 | ① 高频信息切入：找被多个条件提及的关键词（如"排骨"出现两次→串联不等式）；② 逆向思维：注意隐含信息（如"猪肚不是三就是四"隐含"猪肚不是一也不是二"）；③ 利用排除法逐步确定：结合已知关系和隐含信息，排除不可能的选项后锁定答案 |
| 高频错因 | 只看直接条件忽略隐含条件；不找高频信息串条件，导致推导链断在中间；不会逆向理解间接表述 |

## 补充说明

Q14详解：条件①赵一>排骨，④排骨>番茄→串联：赵一>排骨>番茄。条件⑤猪肚=孙三或李四→逆向推出：猪肚≠赵一≠孙二。结合不等式，赵一不等于排骨/番茄/猪肚→赵一只能是肥牛。找到肥牛关联条件③"肥牛<猪肚"→猪肚最大。②孙三<孙二→孙三不是最大→猪肚≠孙三→猪肚=李四。全部确定。
