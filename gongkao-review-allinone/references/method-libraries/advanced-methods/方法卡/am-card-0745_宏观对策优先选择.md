# 方法卡：宏观对策优先选择

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 宏观对策优先选择 |
| 适用题型 | 言语理解——片段阅读（主旨/意图题，对策类） |
| 触发场景 | 文段先给宏观对策，后文展开为多条具体措施，具体措施过于细碎不好概括 |
| 步骤逻辑 | ① 识别"宏观对策 + 具体展开"的前对策结构；② 后文具体措施分条罗列（健全制度、巩固成果、开展行动、加强保护等），难以用一个选项全部概括；③ 此时选宏观对策即可——它已经对后文所有具体措施做了概括；④ 不要试图把所有具体措施拼凑成一个选项 |
| 高频错因 | 试图概括所有具体措施导致选了一个片面或杂糅的选项；选了只对应某一条具体措施的选项（片面） |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

典型场景：文段先说"农业生态方面要有一个科学规划"（宏观对策），后文展开为长江要怎么治理、黄河要怎么治理等多条具体措施。具体措施太细致无法逐一概括，此时"科学规划"四个字就是宏观对策核心，选项直接选"做好科学规划"。指示代词（如"这方面"）常作为宏观对策的概括标志。
