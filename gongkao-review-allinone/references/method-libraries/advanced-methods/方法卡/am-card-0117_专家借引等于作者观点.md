# 方法卡：专家借引等于作者观点

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 专家借引等于作者观点 |
| 适用题型 | 言语理解-中心理解题 |
| 触发场景 | 文段结尾通过"因此XX认为""XX指出"引出专家/权威的话作为结论 |
| 步骤逻辑 | 1. 判断前文分析论证的方向是什么 2. 结尾引用的专家观点是否与前文分析一致 3. 如果一致，专家观点就是作者想表达的观点（借权威之口增强说服力） 4. 如果不一致，作者不会引用该专家 5. 按主旨题正常处理，不要因为是"专家说的"就排除 |
| 高频错因 | 纠结"道金斯不是作者"，不敢选专家说的话作为主旨 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第8题（道金斯"自私的基因"）是典型示范。作者先论证"基因很自私→基因自私决定个体自私"，然后"因此道金斯认为，生物的利他性不过是自私的一种表象"。强化方法用生动的比喻解释：如果我分析了半天该选B，最后说"某专家也选B"，意思就是我认为该选B，引用某专家只是为了增加权威性。"他要是说选C的话，我就根本就不会引他的观点。"所以只要专家引言与前文分析方向一致，它就是主旨。
