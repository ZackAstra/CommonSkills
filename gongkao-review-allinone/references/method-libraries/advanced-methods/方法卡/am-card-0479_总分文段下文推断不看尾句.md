# 总分文段下文推断不看尾句

## 方法名
总分文段下文推断不看尾句

## 适用题型
下文推断题（总分结构文段）

## 触发场景
文段结构为"总对策 → 具体而言（分一、分二……）"，属于总分结构。尾句是分论点之一（并列结构的其中之一），不是全文总结。

## 步骤逻辑
1. 识别"具体而言""例如""一方面……另一方面"等提示词 → 确认总分结构
2. 总分文段中尾句 = 并列分句之一，**不能只看尾句推断下文**
3. 应基于**全文结构**考虑：总对策讲了"是什么/为什么" → 下文应讲"怎么做"
4. 对比选项时，选与总对策话题一致且逻辑在先的（如先立法再执法）
5. 出现在分句中的细节（如"执法"）≠ 文段重点方向

## 高频错因
- 惯性看尾句推下文，在总分文段中被尾句的分论点误导
- 把分句中的细节当成下文展开方向
