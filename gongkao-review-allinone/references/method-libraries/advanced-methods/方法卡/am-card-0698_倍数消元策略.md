# 倍数消元策略

- **适用题型**: 三元不定方程组（三个未知数两个方程），需消元降维后用奇偶/倍数法求解
- **触发场景**: 消元时有多个变量可选消，需要决定消谁使剩余方程最简单
- **步骤逻辑**:
  1. 两个方程都乘以适当倍数使某个变量系数相同
  2. 优先消去系数最大的变量（使乘的倍数最小，结果数最接近原方程）
  3. 消元后两个未知数的和越小，后续枚举试算的可能性越少
  4. 用奇偶性或倍数法对消元后的二元方程求解
- **高频错因**: 消去了系数最小的变量导致剩余方程数值过大、枚举困难；消元后忘记验证被消变量是否为正整数

- **补充说明**: 例题11中消Z（系数4，乘后为160接近201），得8X+5Y=41，两个数的和仅41，枚举快。词义辨析解释："两个数的和越小，可能性就越小"，避免消后得到200多的大数而试不完。消元是不定方程组的通用前置步骤，配合倍数法/奇偶法使用。
