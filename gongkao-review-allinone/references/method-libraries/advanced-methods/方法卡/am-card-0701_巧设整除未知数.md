# 巧设整除未知数

- **适用题型**: 方程法中系数含小数/分数/百分比的题型
- **触发场景**: 题目中出现倍数关系如"是A的1.2倍""比B多25%"等，设未知数后需要做除法
- **步骤逻辑**:
  1. 看清各量之间的倍数/分数关系（如1.2倍、1.5倍、多25%即多1/4）
  2. 求这些分母的最小公倍数（如1.2=6/5、1.5=3/2，公倍数为6）
  3. 将基准量设为公倍数乘以X（如设为6X），则其他量均为整数倍X
  4. 后续方程计算全程无小数，降低出错率
- **高频错因**: 直接设3月为X导致后面X/1.2出现小数；没注意到多25%意味着系数含分母2，设奇数导致半次出现

- **补充说明**: 课程反复强调"tip1是设未知数，尽量能整除就整除"。例题1中3月是1月的1.2倍、2月的1.5倍，设3月=6X则1月=5X、2月=4X，全程整数。例题2中第二天比第一天多25%，应设第一天=2X则第二天=3X。
