# 方法卡：严谨逻辑关系削弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 严谨逻辑关系削弱 |
| 适用题型 | 削弱论证——结论含逻辑关联词（只有…才、只要…就、必须、除非等），问法为削弱 |
| 触发场景 | 结论出现"只有A才B""只要A就B"等逻辑关联词，且问法是"最能削弱" |
| 步骤逻辑 | ① 把结论写成A→B的形式（只有A才B→B→A，只要A就B→A→B）；② 找A且非B（前件成立但后件不成立）的选项即为最强削弱；③ 必须在主体一致的前提下找，选项的主体要与题干一致 |
| 高频错因 | 主体不一致（如题干说"某中学"，选项说"A中学"→偷换主体）；忽略"只有才"要后推前；找不到严格A且非B时选了看似相关但逻辑不对的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

识别方法：结论有逻辑关联词 + 问法削弱/加强 → 考虑严谨逻辑关系。Q18示例：结论"只有实行岗位责任制，升学率才稳步增长"→B→A（升学率增长→实行责任制）→找A且非B："升学率增长了，但没实行责任制"。D"若不实行责任制升学率会上升更快"→没实行责任制（非B）+ 升学率上升（A的变体）→符合。变形下核心不变：主体一致，有A有非B。
