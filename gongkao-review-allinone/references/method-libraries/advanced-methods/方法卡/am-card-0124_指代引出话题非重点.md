# 方法卡：指代引出话题非重点

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 指代引出话题非重点 |
| 适用题型 | 言语理解-中心理解题 |
| 触发场景 | 文段中用"这种""这样的"等指代词承接上文话题，将话题转移到新领域时 |
| 步骤逻辑 | 1. 识别指代词引出的话题顺承（如"这种不平衡体现在教育中"） 2. 指代词所在句子只是过渡，本身非重点 3. 重点看指代后新领域具体说了什么问题/对策 4. 选项要围绕指代后的新话题（如"教育中"），而非指代前的旧话题（如"文化认知"） |
| 高频错因 | 选项围绕指代前的旧话题（如"对文化的认识"），忽略了话题已顺承到新领域（如"教育"） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第3题是典型示范。前文讲"中华文化的智慧"，然后"然而"转折指出"认识存在不平衡"，再用"这种不平衡"指代并顺承到教育领域。后面的问题变成"教育中中华文化关注度不够，西方文化比重太大"。A选项"对文化的认识存在误区"错在没抓住指代后的"教育"话题，D选项"文化交流中"同样没抓住"教育"。强化方法强调：指代只是过渡手段，重点是指代后新领域中具体讨论的问题或对策。
