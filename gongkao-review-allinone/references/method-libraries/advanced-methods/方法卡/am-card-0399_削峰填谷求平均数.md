# 方法卡：削峰填谷求平均数

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 削峰填谷求平均数 |
| 适用题型 | 资料分析——求多个数值的平均数（如年均值、时期均值） |
| 触发场景 | 给出若干年的数据值，要求年均值或时期平均值；数据有大有小、不宜简单取中 |
| 步骤逻辑 | ① 假设一个接近中间的整数为平均值（如208）；② 计算每个数与假设值的偏差（正/负）；③ 将所有偏差求和；④ 总偏差÷个数=每个数应调整的量；⑤ 假设值+调整量=真实平均值 |
| 高频错因 | 年均值与年均增长混淆——年均值是普通平均数不往前推，年均增长才需往前推一年；假设值选得离实际太远导致偏差计算困难 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

此法本质是将各数对假设均值的正负偏差互相抵消。讲解中特别提醒：年均值就是平均数，不需要往前推基期；只有"年均增长"才需用(末期-初期)/年份差。十一五=2006~2010，十二五=2011~2015，十三五=2016~2020。
