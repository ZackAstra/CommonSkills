# 方法卡：比值差-符号决定方向

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比值差-符号决定方向 |
| 适用题型 | 资料分析——比值差/平均数差值，用公式法计算时需判断差值正负 |
| 触发场景 | 用比值差公式（A/B×(R1-R2)/(1+R1)）计算后，结果的有效数字需要判断是"加"还是"减"来确定最终答案 |
| 步骤逻辑 | ① 用比值差公式算出有效数字（如首位为9）；② 观察R1-R2的符号：若R1<R2（分子增速低于分母增速），则比值下降→结果为"9减"而非"9加"；③ 根据符号判断最终值是略大于还是略小于该有效数字，锁定选项 |
| 高频错因 | ① 只算有效数字不看符号，把"9减"误判为"9加"导致选错相邻选项；② 混淆R1和R2的对应关系（谁是分子增速谁是分母增速） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

词义辨析在讲解第四题时特别强调此点。当选项首位不同但实际差值计算后首位相同（如810 vs 896），符号决定最终选B还是C。此技巧在选项"看起来差距大实际差距小"的题目中尤为关键。
