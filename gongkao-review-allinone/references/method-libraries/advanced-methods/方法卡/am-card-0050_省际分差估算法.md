# 方法卡：省际分差估算法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 省际分差估算法 |
| 适用题型 | 资料分析 / 省考难度对比、备考择省决策 |
| 触发场景 | 需要判断不同省份行测难度差异、评估自己分数在不同省的竞争力时 |
| 步骤逻辑 | 1. 收集各省进面名单的行测分段占比（80+/70-80/60-70/60-）<br>2. 找两省同一分段占比交叉点或倍数关系<br>3. 由占比差推算等价分差（如占比拐点差几分）<br>4. 将分差解读为"该省比另一省简单/难X分" |
| 高频错因 | 误把绝对分数当实力指标；忽略各省考生基数和岗位竞争比不同 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
词义辨析用湖南80+占比1.7% vs 辽宁70+占比2.7%的交叉关系，推算出两省等价分差约8-9分。同理湖北80+占比3.1%已超过辽宁70+占比2.7%，推算湖北比辽宁简单约11分。核心逻辑：各省考生智力水平无本质差异，分数分布差异主要源于试卷难度，因此可反推难度系数。
