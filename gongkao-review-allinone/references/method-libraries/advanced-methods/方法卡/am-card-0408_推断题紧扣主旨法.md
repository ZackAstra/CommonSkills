# 方法卡：推断题紧扣主旨法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 推断题紧扣主旨法 |
| 适用题型 | 推断最准确（非下文推断、非简单细节判断） |
| 触发场景 | 题目问"推断最准确的是"，四个选项均为比较类或需要推理的表述 |
| 步骤逻辑 | ① 推断题虽说是推断，但正确选项往往紧扣文章主旨，与作者核心观点契合；② 若某选项推断的点是作者根本没想讨论的事（如讨论经典力学vs相对论谁更简单），直接排除；③ 选择无需过多脑补、直接对应主旨的选项，比需要推理链条更短的选项更"准确" |
| 高频错因 | 选了语感上"有道理"但与主旨无关的推断；对需要推理链较长的选项误认为"最准确" |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

以第5题为例：文章主旨是"人类对世界了解太少，祖先更了解"。D选项直接对应主旨，C选项（经典力学比相对论更容易理解）虽然语感上有道理，但作者根本没想讨论这件事，推理链更长，不是"最准确"的推断。
