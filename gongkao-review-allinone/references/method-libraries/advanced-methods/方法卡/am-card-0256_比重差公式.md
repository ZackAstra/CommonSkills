# 方法卡：比重差公式——增速差×小A÷大B

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重差公式——增速差×小A÷大B |
| 适用题型 | 资料分析——两期比重差（比上年上升/下降多少个百分点） |
| 触发场景 | 题目问某部分占整体的比重比上年增加/减少多少个百分点，给出部分和整体的现期值及增长率 |
| 步骤逻辑 | ① 算增速差：部分增长率 - 整体增长率；② 估算小A÷大B（小A=基期部分值，大B=现期整体值）；③ 比重差 ≈ 增速差 × (小A÷大B)；④ 增速差为正则上升，为负则下降 |
| 高频错因 | 用现期值直接算比重相减（计算量大且易错）；增速差的正负方向搞反；把小A错取为现期部分值 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

直播中多次使用此公式（第17题、第20题等）。关键是"小A÷大B"只需粗估即可，因为选项差距通常较大。增速差很小时比重差也小，增速差为0时比重不变。
