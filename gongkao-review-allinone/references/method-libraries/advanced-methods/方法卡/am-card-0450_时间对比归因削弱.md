# 方法卡：时间对比归因削弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 时间对比归因削弱 |
| 适用题型 | 削弱/另有他因——题干出现"近年来/最近/自…以来"等时间变化标志，将变化归因于某因素 |
| 触发场景 | 论据结构：某时间点前后出现结果变化（如"近年来受伤病例明显增加"），结论归因于某因素（如"老师缺乏安全意识"） |
| 步骤逻辑 | ① 识别时间对比结构：分组为"变化前vs变化后"；② 削弱时必须回归时间——找另一个也"在该时间点发生了变化"的因素作为他因；③ 排除常见设错：选项中的因素"一直存在"（如逐年提高=一直有），无法解释"近年来的突然变化" |
| 高频错因 | 选了"一直存在的因素"（常见设错）；选了"近年来也存在"但没有明确变化的选项；未回归时间，选了与时间变化无关的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

"一直存在的没法解释变化"是核心逻辑。例如Q7：近年来幼儿受伤病例增加→归因老师缺乏安全意识。削弱：近年来学舞蹈幼儿人数也明显增加（基数变大→受伤病例自然增加）。BCD都没回归时间，直接秒排。Q10蜂鸟同理：A说栖息地被砍伐（平均每年消失→一直存在，无法解释"急剧"减少），C说引进其他物种（回归发现后的时间点变化）。
