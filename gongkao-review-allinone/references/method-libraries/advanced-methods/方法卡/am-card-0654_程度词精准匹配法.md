# 方法卡：程度词精准匹配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 程度词精准匹配法 |
| 适用题型 | 逻辑判断——一般质疑（结论含"大大""所有""大部分"等程度限定词） |
| 触发场景 | 结论使用了程度限定词（如"大大改善""所有""大部分"），需判断选项是否在程度上有效质疑 |
| 步骤逻辑 | ① 识别结论中的程度限定词；② 判断选项是否在程度上与之精准对应；③ 如选项说"大部分发生X"而结论说"大大改善"，则"大部分"足以质疑"大大" |
| 高频错因 | 忽略程度词的精确含义；认为"大部分"留有余地就不能质疑"大大改善" |

## 补充说明

典型实例（[43:20]~[46:27]）：结论说虚拟号能"大大改善"信息泄露，B选项说"大部分"泄露发生在发货之前。虽然B没说"全部"，但既然大部分泄露发生在前，那么虚拟号最多只能解决小部分问题，不能叫"大大改善"。讲解中点评：选项说的是"大大改善"，B说的是"大部分"发生在前面，即使有极少部分在发货时泄露，这个方法也不能叫做"大大改善"，在程度上还是能对得上。
