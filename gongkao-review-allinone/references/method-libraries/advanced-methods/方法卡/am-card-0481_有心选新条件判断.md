# 有心选新的前提条件

## 方法名
有心选新的前提条件

## 适用题型
并列结构的中心理解题

## 触发场景
文段前后两部分都在讨论同一话题的不同面向（如都是在说"特点"），出现并列结构，且后半部分引入了新信息。此时"有心选新"（选含新信息的选项）才成立。

## 步骤逻辑
1. 先判断前后是否讨论**同一话题**
2. 如果前文说"怎么来的"，后文说"有什么新变化"——前后话题不同 → **不能有心选新**，应选概括全面的并列选项（A且B）
3. 如果前文说"旧特点"，后文说"新特点"——同一话题 → **可以有心选新**
4. 核心判断依据：前后话题是否一致，而非仅仅看有没有"新"字

## 高频错因
- 看到后半部分有新内容就盲目选新，忽略前后话题是否一致
- 不区分"话题转换"和"话题深化"
