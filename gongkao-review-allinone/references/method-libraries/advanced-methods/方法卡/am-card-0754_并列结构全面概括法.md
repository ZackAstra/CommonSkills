# 方法卡：并列结构全面概括法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 并列结构全面概括法 |
| 适用题型 | 言语理解——主旨概括（并列/大并列结构文段） |
| 触发场景 | 文段为并列结构（分分）或大并列结构（分分分），各句分别说一件事，无总括句 |
| 步骤逻辑 | ① 识别并列结构：各句地位平等，每句说一个事，无明显的主次关系；② 此结构没有现成的主旨句，必须自己概括全文；③ 不能盯着单一句子提炼重点（尤其不能只盯第二句或某一句的关键词）；④ 选"A且B"类选项——一个选项等于另外几个选项之和，概括最全面 |
| 高频错因 | 只看部分句子就下结论（如盯住第二句的"党建"不放）；选了只概括部分内容的选项；用单句重点法处理并列文段 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

- 典型案例：文段每句说一个不同的事（如直播、党建、产业等），选"社会变迁促进家政业发展"这种能概括多个分论点的选项。
- 并列文段错误模式：看到某个关键词（如"党建"）就移不开眼，被带跑偏。正确做法是每句话分析，看哪个词能很好地概括所有句子。
- "A且B"判断技巧：如果一个选项的含义约等于其他几个选项之和，这个选项往往是对的。
