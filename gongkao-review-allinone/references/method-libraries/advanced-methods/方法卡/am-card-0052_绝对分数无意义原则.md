# 方法卡：绝对分数无意义原则
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 绝对分数无意义原则 |
| 适用题型 | 判断推理-类比推理 / 行测备考心态管理 |
| 触发场景 | 给自己设定"一定要考到XX分"的目标时；练习卷后因绝对分数焦虑时 |
| 步骤逻辑 | 1. 不设绝对分数目标<br>2. 关注自己在练习卷人群中的相对排名百分位<br>3. 用分段占比数据评估当年难度<br>4. 目标转为"在进面人群中排前X%" |
| 高频错因 | 因为练习卷没过70就焦虑；看到别人80+就觉得自己差——忽略试卷难度差异 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
词义辨析举例：同一个人考75，在湖北可能排名中下，在某省可能进全省前十。分数含金量完全取决于当年当地难度。所以绝对分数没有任何指导意义，备考阶段应以正确率和排名百分位为标尺，不要被分数绝对值绑架。
