# 方法卡：前提假设口诀——选无它不行，不选有它更好

| 字段 | 内容 |
|------|------|
| 方法名 | 前提假设口诀——选无它不行，不选有它更好 |
| 适用题型 | 逻辑判断——前提假设题 |
| 触发场景 | 题干给出论据→结论，问"需要补充的前提""使结论成立的假设" |
| 步骤逻辑 | 1. 找出论据和结论之间的逻辑断点（话题跳跃处） |
| | 2. 按优先级匹配正确选项：①搭桥（断点连接）②修补漏洞 ③必要条件 |
| | 3. 用否定代入验证：否定选项后结论是否仍成立——成立则非前提，不成立则为前提 |
| | 4. 区分"完美条件"（力度过强、非必要）和"前提条件"（最低限度必要） |
| 高频错因 | ①把前提题当支持题做，选力度最强的②选"完美条件"（如"所有人都被抓到"）而非"必要条件"（如"受处罚者足以形成威慑"） |
| 来源文件 | source-0070.md |
| confidence | high |

**补充说明：**
- 前提=必要条件（没有它结论就不成立），不是充分条件（有它更好但没有也行）。
- 优先级排序：搭桥 > 修补漏洞 > 必要条件（逐步往下）。
- 典型错误辨析：结论"一半以上上岸"→前提"至少501人上岸"正确，"1000人全上岸"错误（力度过强、非必要）。
