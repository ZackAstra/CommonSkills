# 方法卡：隔板法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 隔板法（插板法） |
| 适用题型 | 数量关系-排列组合/相同元素分配/每人至少N个 |
| 触发场景 | 将相同物品分给若干人，每人至少1个（或至少N个） |
| 步骤逻辑 | 1.每人至少1个：n个物品有n-1个空，分给m人需m-1块板→C(n-1,m-1) 2.每人至少k个(k>1)：先给每人预分k-1个，剩余元素转化为"每人至少1个"再隔板 3.关键：必须是相同元素，且分配对象有区别 |
| 高频错因 | 每人至少2个时忘记先预分1个导致公式套错；元素不同时不能用隔板法；分组对象无区别时不能直接用（需除以排列） |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
讲解中用"切火腿肠"类比：7个橘子分3人每人至少1个＝火腿肠切3段要切2刀＝6个空中选2个放板＝C(6,2)=15。对于"管理层至少2个，普通至少1个"，先给管理层预分1个使其变成"至少1个"，剩余再统一隔板。本质是把不等约束转化为等约束。
