# 方法卡：语句填入的逻辑关系推导法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 语句填入的逻辑关系推导法 |
| 适用题型 | 语句填入题（横线在句中或句尾） |
| 触发场景 | 横线位于句子中间（前后有逗号），前后文有明确的逻辑关系（否定+转折、对比、并列） |
| 步骤逻辑 | ① 看横线前的句式判断逻辑方向（"并非X"→后面接"而应该是Y"）；② 看横线后的论据/解释，反推Y应该是什么（后面的论据说明舞蹈是动态过程→Y=动态的过程）；③ 排除与前后文逻辑关系不匹配的选项（如D说"动与静交替"但论据只说了"动态"） |
| 高频错因 | 只看横线前不看后面的论据支撑，导致选了过度推断的选项；忽略"并非X"后面对应的否定→肯定句式 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

以第3题为例：横线前"并非摄影这种单一特定的造型"→后面应接肯定表述。下方论据讲"舞者从一个位置运动到另一个位置""绵延的过程""完整的旋律"→都是在说动态，不是静态，也不是动静交替。所以B（动态的过程）对，D（动与静的交替）错。
