# 方法卡：假设分配高增长率平分法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配高增长率平分法 |
| 适用题型 | 资料分析——假设分配中增长率较大（约30%以上）的情况 |
| 触发场景 | 增长率较大导致"徒弟"占比高，不能忽略，常规取整修正不适用 |
| 步骤逻辑 | ① r在30~50%附近：第二步用四幺五联动，如r≈25%按4:1分余数，r≈33%按3:1分余数；② r接近100%：直接1:1平分再微调（师徒份额差不多大）；③ r在50%附近：第二步按2:1分 |
| 高频错因 | 在高增长率时仍用小r的取整修正法，导致徒弟份额严重低估 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

此方法是假设分配法在高增长率场景下的延伸。核心判断依据：看余数中"徒弟"占比是否大到不能忽略。r越大，徒弟占比越高，第二步越需要精确分配。当r接近100%时，基期和增量几乎一样大，平分是最快的处理方式。
