# 方法卡：比重差识别与秒杀

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重差识别与秒杀 |
| 适用题型 | 资料分析——两期比重比较·定量分析（比重差），求比重上升/下降了几个百分点 |
| 触发场景 | 题干含"比重/占比/赞…比上年"且选项单位为"百分点"（百分数做差得到百分点） |
| 步骤逻辑 | ① 识别题型：题干有比重/占比/赞 + 选项百分点 → 确定考比重差；② 先判断方向：R1大于R2则比重上升（排除两个下降选项），反之排除两个上升选项；③ 尝试秒杀：比重差的数值（绝对值）一定小于增速差的数值（绝对值），即|R1-R2| > |比重差|，据此排除不符选项；④ 若仍无法确定，套公式：比重差 = 去年的部分/今年的整体 × (R1-R2)，其中"去年的部分"用假设分配第一步估算（选项间距远时粗估即可，间距近时用假设分配精确算） |
| 高频错因 | ① 百分点和百分数混淆（10%减5%=5个百分点，不是5%）；② 秒杀时把增速差算反或忘取绝对值；③ 找R1/R2时把分子分母对应指标搞反；④ 用假设分配第一步时过于粗糙导致选项间距小时选错 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

秒杀依据：公式中"去年的部分/今年的整体"是一个部分÷整体的关系，一般小于1（因为部分 < 整体），所以比重差 = 小于1的数 × 增速差 → 数值一定小于增速差。公式中"去年的部分"题目不直接给，需要用假设分配求基期的第一步近似。选项间距大时（如0.2和1.2差6倍），粗估误差不影响选择；选项间距小时（如0.6/0.7/0.8/0.9），需认真用假设分配算出去年的部分。比值差（如平均单价、亩产）的计算见"非比重比值差"卡。
