# 方法卡：对比实验归因缺对照组质疑

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 对比实验归因缺对照组质疑 |
| 适用题型 | 判断推理——削弱/质疑（归因论证类） |
| 触发场景 | 题干通过实验组与对照组对比得出因果结论，但对照组信息不完整或缺失 |
| 步骤逻辑 | ① 识别对比实验结构：A条件→X结果，无A条件→无X结果，结论"因A致X"；② 画图标注：新环境/一半一半/睡不好 vs 旧环境/？；③ 漏洞 = 缺少对照组（旧环境的脑部状态未知）；④ 用"同因异果"质疑：补充对照组（如"在家也一半一半但睡得好"→同因异果→因果不成立）；⑤ 该选项直接构成完整对比实验，补上实验后结论才能得出 |
| 高频错因 | 选对策类选项（如带枕头）而非补对照组；选另起实验的无关项（如讲波的C选项） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

漏洞在哪就往哪找选项。归因题首要检查：有无对照组、变量是否唯一。一般归因（无对比实验）反而可能选"另有他因"。
