# 平均分堆除以A去重

- **方法名**: 平均分堆除以A去重
- **适用题型**: 排列组合-平均分堆问题
- **触发场景**: 将N个不同元素平均分成若干堆（每堆数量相同），求分法数
- **步骤逻辑**:
  1. 先用组合数依次选堆：C(n,r1)×C(n-r1,r2)×...
  2. 判断各堆数量是否相同（平均分堆）
  3. 若有k堆数量相同，则除以A(k,k)去重
  4. 例：2222分四堆→除以A44；222分三堆→除以A33；221分三堆→只除以A22（只有两组相同）
- **高频错因**: 忘去除重因子导致结果偏大；分不清该除A几几（只除相同堆数的排列，非总堆数）
