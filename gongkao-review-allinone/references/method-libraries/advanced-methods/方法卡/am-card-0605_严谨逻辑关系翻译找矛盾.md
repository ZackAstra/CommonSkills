# 方法卡：严谨逻辑关系翻译找矛盾

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 严谨逻辑关系翻译找矛盾 |
| 适用题型 | 判断推理——削弱/反驳（结论含逻辑关联词） |
| 触发场景 | 结论中出现"除非…否则…""只有…才…""只要…就…""如果…那么…""所有"等逻辑关联词，且问法为削弱/反驳 |
| 步骤逻辑 | ① 识别题型：结论含逻辑关联词 + 削弱问法 → 严谨逻辑关系；② 先翻译结论为逻辑式：如"除非A否则B" → 非A→B；③ 找矛盾（A→B的矛盾为A且非B）；④ 选与矛盾形式匹配的选项 |
| 高频错因 | 翻译错误（如把"除非A否则B"搞反）；选了逆否方向的选项而非矛盾方向 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

例："除非星座预测正确，否则不会有很多人相信"→ 非正确→不相信 → 矛盾 = 不正确且相信，选D。"只有才""只要就""如果那么""除非否则""所有"均为严谨逻辑关联词触发标志。
