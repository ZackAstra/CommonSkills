# 方法卡：话题不一致是常见无关陷阱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 话题不一致是常见无关陷阱 |
| 适用题型 | 判断推理——加强削弱类（选项看似相关但偷换话题） |
| 触发场景 | 选项讨论的问题表面与题干相关，但关键词（主体/属性/范围）与论点不一致 |
| 步骤逻辑 | ① 锚定论点核心关键词（主体+属性+范围）；② 逐个检查选项是否严格对应这些关键词；③ 常见偷换方式：a) 主体偷换——论点说"犯罪率"，选项说"更容易实施犯罪"（倾向≠实际率）；b) 范围偷换——论点说"火山形成"，选项说"火山爆发"；c) 属性偷换——论点说"词语来源"，选项说"词语含义"；d) 论据否定向——否定论据（"茶叶还有没营养的物质"）不等于拆桥 |
| 高频错因 | 被选项表面相关性迷惑，不回到论点核对关键词；把"否论据"当成"拆桥" |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第4题A选项：论点是"火山为何长得这么高（形成）"，A讨论"火山爆发的原因是地脉运动"→话题从"形成"偷换到"爆发"，无关。第16题B选项：论点是"学历越高犯罪率越低"，B说"学历越高越容易钻空子实施犯罪"→"更容易实施犯罪"不等于"犯罪率更高"，话题偷换。第20题ABC：论点是"意象这个词是否为中国原生"，A讨论含义是否相同（偷换为含义），BC讨论文化影响（偷换为文化渊源），只有D讨论词语本身的历史出现时间。
