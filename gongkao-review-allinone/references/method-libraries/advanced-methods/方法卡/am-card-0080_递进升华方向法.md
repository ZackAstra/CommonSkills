# 方法卡：递进升华方向法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 递进升华方向法 |
| 适用题型 | 言语理解-中心理解题（说理类文段，语句填空题） |
| 触发场景 | 文段出现"小切口→中层次→大升华"的递进结构，需要填入最后一层结论 |
| 步骤逻辑 | 1. 识别文段中的递进层次：小（切入点）→中（扩展层面）→大（升华层面）2. 结论句必须在中层基础上做"大的升华"，不能回到小层或中层 3. 排除"回落"到前文已提内容的选项 4. 升华内容不必在原文中逐字出现，属于合理引申 |
| 高频错因 | 选了跟前文重复的选项（回落到小或中层），误认为升华内容是"无中生有" |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

强化方法用"速算→压缩资料时间→行测整体从容"的类比来解释：如果递进结构是小→中→大，结论选"练好速算"就回落到了小层，选"资料提速"是中层，正确答案应该落在"整个行测提升"这个大层。文段第1题中"老旧小区改造→城市开发建设模式转型+基层社会治理新格局构建→城市治理体系现代化"，最后一个层次虽原文未直接出现，但属于递进结构的合理升华，不能因"原文没出现"就排除。
