# 方法卡：连续周概率平方法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 连续周概率平方法 |
| 适用题型 | 数量关系-概率（连续时间段内重复事件） |
| 触发场景 | 问"连续两周""连续N次"恰好都能发生的概率，且每周/每次独立 |
| 步骤逻辑 | 1.先求单周概率P 2.连续两周概率=P的平方 3.找选项中P²的表达式秒选 |
| 高频错因 | 用组合公式过度计算；不识别"连续"暗示独立重复 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
讲解中演示：小李选4天、小王选2天，单周相遇概率=4/5×3/4=3/5，两周概率=(3/5)²=9/25。猜题时直接在选项中找"几分之几的平方"，排除非平方项即可大幅缩小范围。
