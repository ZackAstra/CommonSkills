# 方法卡：饼状图三原则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 饼状图三原则 |
| 适用题型 | 资料分析——饼状图比重判断选项 |
| 触发场景 | 题目给出饼状图选项，需要根据数据判断哪个图正确，或根据饼状图快速定位数据 |
| 步骤逻辑 | ① 抓特殊比例：看某部分是否占25%（1/4）、50%（1/2）等一眼可辨识的面积；② 看几部分之间的比例关系（如100:50对应2:1面积比）；③ 软件生成的饼图从12点钟方向顺时针依次排列各部分 |
| 高频错因 | 忽略饼图排列顺序规律，导致对应关系错乱；没有利用25%/50%等特殊比例快速排除选项 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

三个原则是层层递进的：先用特殊比例（25%、50%）快速排除明显错误选项；再用两部分之间的倍数关系缩小范围；最后用顺时针排列规则确认。极端情况下（出题人手画饼图）排列可能不满足第③条，但极少出现。
