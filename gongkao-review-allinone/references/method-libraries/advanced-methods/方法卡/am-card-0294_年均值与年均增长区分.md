# 方法卡：年均值与年均增长区分

| 字段 | 内容 |
|------|------|
| 方法名 | 年均值与年均增长区分 |
| 适用题型 | 资料分析-含"年均"二字的题目 |
| 触发场景 | 题目出现"年均"，需要判断是求平均值还是年均增长率 |
| 步骤逻辑 | 1. 看"年均"后是否有"增长"二字 → 2. 无"增长"→年均值=总量÷年份数（除以n） → 3. 有"增长"→年均增长率=末期÷初期开(n-1)次方减一（除以n-1） |
| 高频错因 | 看到"年均"就激动，把年均值当年均增长率做；年均值除以n-1而非n |
| 来源文件 | source-0040.md |
| confidence | high |

补充说明：如19年到22年共4个数据点，年均值÷4，年均增长÷3。"逐月""逐年"不用往前推起点，如2019~2022年只看这四年内的数据。
