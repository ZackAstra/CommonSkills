# 方法卡：混合增长率区间判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 混合增长率区间判断 |
| 适用题型 | 资料分析——总体由两部分构成，求总体增速或判断某部分增速范围 |
| 触发场景 | 出现"A+B=C"的加法关系，给出两部分增速判断总体增速，或给出总体和一部分判断另一部分 |
| 步骤逻辑 | ① 识别总体由哪两部分构成；② 总体增速一定介于两部分增速之间；③ 已知总体和一部分增速 → 另一部分在另一侧 |
| 高频错因 | 分不清哪部分高于总体、哪部分低于总体；误认为总体是两部分增速的平均值（仅在两部分量相等时成立） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

学习材料中两次使用此方法：第8题（16:09~16:37）本外币存款=本币+外币，本币9.2%、外币9%→总体在9%~9.2%之间；第15题（32:52~33:43）一到四月=一到三月+四月，总体8.6%、四月17.3%→一到三月低于8.6%。
