# 方法卡：容斥原理三集合最小交集

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 容斥原理三集合最小交集公式 |
| 适用题型 | 数量关系——容斥原理 |
| 触发场景 | 题目给出三个集合的各自元素个数和全集大小，要求三集合交集的最小值 |
| 步骤逻辑 | ① 三集合交集最小值公式：A∩B∩C最小 = A + B + C - 2×全集；② 两集合最小值：A∩B最小 = A + B - 全集；③ 四集合：A+B+C+D - 3×全集；④ 规律：N集合交集最小值 = 各集合之和 - (N-1)×全集 |
| 高频错因 | 公式中系数记错（三集合是减2倍，四集合是减3倍）；混淆"最小值"与"最大值"公式 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

原理：三集合求交集最小值时，每个两两交集的最小值 = A+B-全集，再与第三集合取交集最小值。本质是"让尽量多的元素不重叠"。
