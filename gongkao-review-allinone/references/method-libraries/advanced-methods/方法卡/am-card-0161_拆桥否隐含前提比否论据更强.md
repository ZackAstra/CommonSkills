# 方法卡：拆桥否隐含前提比否论据更强

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 拆桥否隐含前提比否论据更强 |
| 适用题型 | 判断推理——削弱类（论证过程存在隐含前提/默认假设） |
| 触发场景 | 论据→论点的推理链条中存在一个未明说的前提，问"最能削弱/反驳" |
| 步骤逻辑 | ① 分析论证过程，找出隐含前提：如"茶叶有营养→应该吃"，隐含前提="该不该吃取决于有没有营养"；② 拆桥削弱（力度最强）：直接否定隐含前提，如"喝茶只是习惯，不在意有没有营养"；③ 否论据削弱（力度较弱）：只否定论据本身，如"茶叶还有很多没营养的物质"→仍默认"有营养就该吃"的前提成立；④ 看到拆桥选项可直接选 |
| 高频错因 | 只在论据层面打转（否论据），忽略了可以直接攻击隐含前提的拆桥选项；对隐含前提不敏感 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第8题（茶叶题）：论据="茶叶有营养物质"，论点="应该吃茶叶"。A（还有很多没营养的物质）=否论据，但默认"有营养就该吃"仍成立；C（喝茶只是习惯，不在意营养）=拆桥，直接否定"该不该吃取决于有没有营养"这个隐含前提，力度最强。同一模式在"地球一小时"题中重复出现：论据="节电量微乎其微"，论点="没有实际效果"→隐含前提="效果取决于节电量"→D拆桥="目的不是省电而是唤醒意识"。
