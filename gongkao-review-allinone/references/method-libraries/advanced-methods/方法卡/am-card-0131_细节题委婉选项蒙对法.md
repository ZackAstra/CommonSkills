# 方法卡：细节题委婉选项蒙对法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节题委婉选项蒙对法 |
| 适用题型 | 言语理解-细节判断题/细节推断题 |
| 触发场景 | 时间紧张需要快速蒙答案，或对正确选项犹豫不决时 |
| 步骤逻辑 | 1. 扫描四个选项，找用词最委婉/保守的选项 2. 委婉标志词："一定程度上""可能""影响""往往""适度"等 3. 含这类词的选项大概率正确（选D正确率80%以上） 4. 含绝对化表述（"一定""完全""所有""必须""高于"）的选项大概率错误 |
| 高频错因 | 不敢选委婉选项，觉得"说得不够明确"；或选了有对比/绝对化表述的选项 |

| confidence | high |

## 补充说明

第11题（书法与长寿）中，D选项"精神状态在一定程度上能影响人的一个生理功能"用了"一定程度上"和"影响"，非常委婉，强化方法直接判断大概率正确。而A"书法家的寿命要高于普通人"和C"写作和科研专注度要求更高"都含比较级/绝对化表述，容易错。强化方法特别指出："你要是没时间了，题干都不用看，直接选D。"这是时间紧迫时的应急策略。注意此方法是蒙题辅助，不是做题主方法。
