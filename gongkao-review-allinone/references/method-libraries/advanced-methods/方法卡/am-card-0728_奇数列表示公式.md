# 奇数列表示公式

- **适用题型**: 等差数列求和中涉及奇数项的序列，或组合数列中需要表示奇数部分
- **触发场景**: 数列包含奇数数列（1,3,5,7...）或偶数数列（2,4,6,8...），需要用通项公式代入计算
- **步骤逻辑**:
  1. 奇数数列通项公式：第n项 = 2n - 1（第一项为1）
  2. 偶数数列通项公式：第n项 = 2n（第一项为2）
  3. 当题目说"和为某奇数"，直接令 2n-1 = 该奇数，解出n即可定位项数
  4. 代入选项对应的项数，检验和是否匹配
- **高频错因**: 忘记奇数列首项是1（n=1时2×1-1=1），误用2n+1导致偏移

- **补充说明**:
  - 例题8：数列由循环部分(1,2,3,4)和奇数部分组成，和为2021。2021是奇数，直接令 2n-1=2021，得 n=1011
  - 词义辨析强调此公式必须背下来："给我背下来，哪来的奇数项啊？用它来表示"
  - 代入验证：第1012项是4的倍数（循环末位），代入得和为2027 > 2021，故选B（1011）
