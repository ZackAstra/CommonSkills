# 方法卡：后对策文段优选对策项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 后对策文段优选对策项 |
| 适用题型 | 言语理解——中心理解题（对策类文段） |
| 触发场景 | 文段结构为"问题/背景+对策"（后对策），选项中同时出现对策项和问题项时 |
| 步骤逻辑 | ① 识别文段结构：前面描述问题或背景，后面用"需要/应该/应/必须/不能"等提出对策，判定为后对策；② 选项中若同时有对策和问题，优选对策；③ 对策项必须精准对应文段的主体和具体做法 |
| 高频错因 | 选了问题项（只概括了前半段）；对策项的主体不对（如文段说银行应做，选项说金融体系应做）；对策项表述过于绝对或偷换了文段的程度词 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

讲解中在本套题中用多道题反复印证这个原则。后对策是国省考和事业单位考试中必考的高频结构。选对策项的理由是"我们是要当公职人员，考察的是解决问题的能力，而不是归纳概括问题的能力"。具体参见第1题(00:01:59)、第2题(00:05:23)、第3题(00:11:56)、第10题(00:49:54)、第11题(00:56:06)、第12题(01:02:54)、第16题(01:27:24)、第19题(01:40:50)的讲解。
