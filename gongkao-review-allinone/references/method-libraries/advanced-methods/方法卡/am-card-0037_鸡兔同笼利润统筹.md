# 方法卡：鸡兔同笼利润统筹
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 鸡兔同笼利润统筹 |
| 适用题型 | 数量关系-统筹优化/利润最大化问题 |
| 触发场景 | 两种产品总数量固定，有成本约束，求利润最大时各产品数量 |
| 步骤逻辑 | 1. 确定总数量和成本上限；2. 假设全部生产高利润品，算出总成本；3. 与实际成本上限求差值；4. 差值除以两产品单件成本之差，得低价品数量 |
| 高频错因 | 混淆"利润高"和"利润率高"；忘记成本约束直接全产高价品 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
本质是鸡兔同笼的假设法。先假设全部生产利润率高的产品，算出成本与上限的差值，再用单件成本差来"降成本"。售价用于判断谁利润率更高（确定生产方向），成本用于最终计算。关键：利润最大化时一定卡在成本约束的边界上。
