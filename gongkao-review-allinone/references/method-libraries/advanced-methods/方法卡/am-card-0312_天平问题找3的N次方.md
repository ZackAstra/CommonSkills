# 方法卡：天平问题找3的N次方

## 基本信息
- **方法名**: 天平问题找3的N次方
- **适用题型**: 数量关系 - 天平称重/找次品
- **触发场景**: 天平称重求"保证找到至少称几次"，物品总数已知
- **confidence**: high
- **来源文件**: source-0041.md

## 步骤逻辑
1. 一次称重可区分3包（称两包：同重→第三包，不同→轻的）
2. 两次称重可区分 3×3=9 包（每组3包，先找组，再找包）
3. N次称重可区分 3^N 包
4. 找比总数大的最小 3^N，该N即为最少称重次数

## 高频错因
- 题目问"至少称几次"但未说"保证"时，答案可以是1次（运气好一次就称出）
- 记住是找**比目标数大**的那个 3^N，不是最接近的

## 补充说明
天平每称一次三等分能力，所以是3的幂次。考试中注意题目措辞："保证找到"才取最坏情况，否则可取最好情况。
