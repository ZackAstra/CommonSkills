# 方法卡：三段论-三项判断排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三段论-三项判断排除法 |
| 适用题型 | 判断推理-逻辑判断-三段论（前提假设型） |
| 触发场景 | 题目给出两句话前提+一个结论，问第三句前提应是什么；或问哪句话是必须假设的 |
| 步骤逻辑 | 1. 看量词：已有"所有"→第三句大概率补"有些"，排除补"所有"的选项 2. 看肯否：已有肯定+否定→第三句大概率补否定；已有两个肯定→补否定亦可，排除不匹配的 3. 看主体：ABC各出现两次，找出哪个主体还缺一次，锁定选项主体 |
| 高频错因 | 看到题干有"所有"推出"有些"就以为一定选"有些"，忽略出题人可能挖坑设两个都推的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

三段论三要素：(1) 量词——至少一个"所有"（三个"所有"也行，或特殊情况两个"所有"+一个"有些"）；(2) 肯否——至少一个肯定，可配两个否定；(3) 主体——ABC各出现两次。用这三项依次排除，通常只剩一个选项。画圈法（文氏图）可作为辅助验证。
