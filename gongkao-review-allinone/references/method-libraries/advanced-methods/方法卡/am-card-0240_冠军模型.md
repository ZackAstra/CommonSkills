# 方法卡：冠军模型——多人猜对看谁出现N次

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 冠军模型（数出现次数法） |
| 适用题型 | 判断推理——真假分析（多人猜测同一结果） |
| 触发场景 | 多人（如甲乙丙丁）各自猜测"是谁做了某事"，已知其中有N人说对，要推出实际是谁 |
| 步骤逻辑 | ① 将每人的猜测简化为"我认为是X"或"我认为是X或Y"；② 统计每个被猜测者被提及的次数；③ 若N人说对，则被提及恰好N次的那个名字就是答案；④ 被提及次数不等于N的名字直接排除 |
| 高频错因 | 被"或"的表述搞晕，忘记把"乙说的对"翻译成"我认为是丙"再统计；不看选项就猜多人合作 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q18中：甲说"乙或丙或丁"，乙说"丙"，丙说"甲或乙"，丁说"乙说的对"（即丙）。丙被提及3次（乙、甲含丙、丁），甲被提及1次（丙含甲），乙被提及2次（甲含乙、丙含乙），丁被提及1次（甲含丁）。两人说对→乙出现2次→答案是乙；三人说对→丙出现3次→答案是丙。
