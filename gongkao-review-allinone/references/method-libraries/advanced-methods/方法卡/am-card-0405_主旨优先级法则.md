# 方法卡：主旨优先级法则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 主旨优先级法则 |
| 适用题型 | 所有言语理解中心理解题（通用原则） |
| 触发场景 | 一个选项主旨方向正确但有细节瑕疵（如"国家"vs"社会"），其他选项主旨方向完全错误（选了问题而非对策、选了背景而非观点） |
| 步骤逻辑 | ① 先判断各选项的主旨方向是否正确（是否在说对策/问题/观点）；② 主旨方向错误的选项没有资格与主旨方向正确的选项竞争，即使后者有小瑕疵；③ 不要在主旨已对的前提下纠结"国家哪里来的""花哪里来的"等吹毛求疵的细节 |
| 高频错因 | 主旨方向正确但有小瑕疵的A被排除，选了主旨方向完全错误的B/C/D；过度纠结出处细节而忽略了主旨匹配 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

以第2题为例：A说"国家和社会要承担更多生育成本"，主旨方向完全正确（对应对策"加快优化社会分担机制"）。弹幕纠结"国家哪来的"，但BCD连对策都没说（说的是问题/现状），根本没资格挑战A。选题时先扫一眼哪些选项在说主旨，再做选择。
