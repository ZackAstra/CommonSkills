# 方法卡：415分数法求增量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 415分数法求增量 |
| 适用题型 | 资料分析——求增量、增量比较、增量倍数 |
| 触发场景 | 增速接近常见分数（10%≈1/10，14.3%≈1/7，11.1%≈1/9）；选项差距大不需精算 |
| 步骤逻辑 | ① 将增速近似为分数 1/n（如10.6%→1/10或1/9，14.3%→1/7）；② 增量=现期÷(n+1)；③ 比较两个增量的倍数时，分别算出X₁、X₂后口算比值；④ 1/10和1/9差距0.5个百分点，选项差距大时不纠结 |
| 高频错因 | 纠结1/10还是1/9选哪个（差距不大时随意取）；忘记分母是n+1而非n |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

速度对标：1/10=10%，1/9=11.1%，1/8=12.5%，1/7=14.3%，1/6=16.7%。差值在0.5个百分点以内时，选哪个对最终结果影响极小，不要纠结。
