# 方法卡：归因题根本原因削弱

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因题根本原因削弱 |
| 适用题型 | 削弱论证——结论出现"根本原因"等限定词 |
| 触发场景 | 归因结论中出现"根本/根源/最根本"等程度限定，问法为"最能削弱" |
| 步骤逻辑 | ① 识别结论中的"根本原因"限定词；② 向"根儿"的方向找选项——找到比题干原因更深层的原因即可削弱；③ 核心逻辑：题干说A是根本原因，选项说B→A（B促进了A），则A不是根，B才更像根 |
| 高频错因 | 忽视"根本"限定词，按普通归因题选"另有他因"；选了"还有其他原因也是原因"的选项（如D：工业化也是原因），但这只能说明不唯一，不能否定根本性 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

典型选项对比：B说"经济发展促进了城市发展，进而带动拆迁"→城市发展不是根，经济发展比它更根；D说"工业化也是原因"→两者都是原因，但谁是根本仍不明确，削弱力度不如B直接。关键区分：程度副词（根本/主要/往往）出现时，削弱方向要对应该限定词。
