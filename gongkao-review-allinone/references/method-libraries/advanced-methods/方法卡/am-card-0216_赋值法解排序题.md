# 方法卡：赋值法解排序题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 赋值法解排序题 |
| 适用题型 | 判断推理/数量关系——多个不等式排序比较 |
| 触发场景 | 题干给出多个大小关系（如A+B=C+D，交换后不等号方向变化），要求排出各元素的大小顺序 |
| 步骤逻辑 | ① 从等式入手列出第一个关系（如福州+三明=宁德+南平）；② 从"互换后大小变化"推单个元素大小（如南平换到左边变大→南平>三明）；③ 根据推导结果赋具体数值（如三明=5，则南平=6），注意保留足够取值空间；④ 代入剩余约束验证并得出完整排序 |
| 高频错因 | 写了一堆不等式最后自己绕晕；赋值时空间不够（如两个数之和需要大于某值，应至少赋到5以上） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

赋值法比纯不等式推导更直观，不易出错。赋值原则：让自己好算，保证取值空间足够（两个数加一起不能刚好等于边界值）。
