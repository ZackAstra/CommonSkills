# 方法卡：等差数列求和化完全平方

## 基本信息
- **方法名**: 等差数列求和化完全平方
- **适用题型**: 数量关系 - 等差数列求和（两个对称数列合并）
- **触发场景**: 两组等差数列（广告页和非广告页）各为1到X，再加上一个X+1，求总页数
- **confidence**: high
- **来源文件**: source-0041.md

## 步骤逻辑
1. 两个等差数列各为 1,2,...,X，加上一项 X+1
2. 合并两个1到X：用求和公式 ×2 = X(X+1)
3. 再加 X+1 → X(X+1) + (X+1) = (X+1)(X+1) = (X+1)²
4. (X+1)² ≤ 200 → X+1 ≤ 14 → X ≤ 13
5. 广告页 = 1到14求和 = 15×7 = 105

## 高频错因
- 分别算两个等差数列再加总，计算繁琐易错
- 不会提公因式化简为完全平方

## 补充说明
核心技巧：两个相同的1到X等差数列求和后加上(X+1)，恰好能提公因式化为(X+1)²。这个化简步骤是关键——直接得到平方数后，找不超过200的最大平方数（14²=196），即可确定X=13。
