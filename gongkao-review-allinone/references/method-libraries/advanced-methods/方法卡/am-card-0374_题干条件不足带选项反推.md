# 题干条件不足带选项反推

- **方法名**: 题干条件不足带选项反推
- **适用题型**: 数量关系（题干条件极少，无法正面列方程）
- **触发场景**: 题干只描述了一个操作过程，未给任何具体数值，正面做无从下手
- **步骤逻辑**:
  1. 确认正面条件确实不足（未知数多于方程数）
  2. 将四个选项分别代入，模拟题干描述的操作过程
  3. 验证哪个选项能使所有约束同时满足（如总数为平方数、余数条件等）
  4. 排除不满足的选项，仅剩一个即为答案
- **高频错因**: 坚持正面硬解浪费时间；带入选项时遗漏某个约束条件
- **来源文件**: internal-source
- **confidence**: high
