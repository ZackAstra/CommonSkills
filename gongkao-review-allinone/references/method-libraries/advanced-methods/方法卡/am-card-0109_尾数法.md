# 方法卡：尾数法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 尾数法 |
| 适用题型 | 资料分析·简单加减计算 |
| 触发场景 | 选项精确到的量级（小数点后位数）与题干数据一致时 |
| 步骤逻辑 | 1. 确认选项与题干数据的精确量级是否一致 2. 只算各项的末位尾数进行加减 3. 用计算出的尾数锁定选项 |
| 高频错因 | 未确认量级一致就使用，导致尾数对应位错误 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

强化方法在第1题和第19题均使用尾数法快速求解。使用条件的关键判断标准是：选项保留的最后量级与题干数据的精确度相同。本课中还有一段专门回答"尾数法什么时候能用"的答疑（约01:03:11~01:03:42），核心表述为"你选项的单位保留的那个最后那个量级，精确度跟题干中数据是一样的，就可以"。
