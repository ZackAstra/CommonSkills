# 方法卡：同因异果质疑归因

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 同因异果质疑归因 |
| 适用题型 | 判断推理——削弱/质疑（归因论证，需补充对照组） |
| 触发场景 | 实验只观察了新环境下的脑部状态，缺少旧环境（熟悉环境）的对照数据 |
| 步骤逻辑 | ① 画出实验图：新环境 + 一半一半 → 睡不好；② 发现缺少对照组（旧环境的脑部状态）；③ 找"同因异果"选项：旧环境也一半一半 → 但睡得好 → 因果不成立；④ 该选项直接构成完整对比实验，质疑归因 |
| 高频错因 | 选了对策选项（B带枕头不出现首夜效应）；选了另起实验讲别的机制的选项（C讲波） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

这是"缺对照组质疑"的具体操作方式。同因（都一半一半）异果（一个睡好一个睡不好）→ "一半一半"不是"睡不好"的原因。实验都没做完，先补实验再谈结论。
