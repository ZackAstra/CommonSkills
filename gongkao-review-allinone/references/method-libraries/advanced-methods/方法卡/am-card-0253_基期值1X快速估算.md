# 方法卡：基期值用1/X快速估算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 基期值用1/X快速估算 |
| 适用题型 | 资料分析——已知现期值和增长率，求基期值 |
| 触发场景 | 现期值÷(1+增长率)的列式，选项差距较大时需要快速估算 |
| 步骤逻辑 | ① 算1+增长率的值（如增长241%则1+R=3.41）；② 看选项特征，把分数关系化为简单分数（如1/8=12.5%）；③ 用选项反推分母是否约为分子的N倍来快速定位答案 |
| 高频错因 | 逐位精算除法浪费时间；没有先观察选项差距决定精确度 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

直播实例：435÷3.41，看到选项差距大，先排除AB（差距明显），剩CD后把127近似看成125=1/8，对应分母应为分子8倍左右，验证4×8=32与分母34.1接近，选C。核心是根据选项差距决定估算精度。
