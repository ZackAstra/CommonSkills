# 方法卡：善用五百

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 善用五百 |
| 适用题型 | 资料分析——假设分配法中的快速估算技巧 |
| 触发场景 | 假设分配第一步需要选整百数，且现期B在500~1500之间时 |
| 步骤逻辑 | ① 500 = 1000的一半；② 先算1000×R，再÷2即得500×R（如R=12.3%，1000×12.3%=123，500×12.3%≈62）；③ 优势：1000×R只需移动小数点，心算极快 |
| 高频错因 | 不熟悉500的便捷性，强行计算500×R而非利用1000×R÷2 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] "善用五百"是假设分配法中的加速技巧。当现期B在500~1500之间时，500往往是最佳的假设基期起点，因为500×R = (1000×R)/2，而1000×R只需移动小数点。quote支撑较弱——原话是口诀式重复"要善用五百要会用五百"，此处换为解释性原话。
