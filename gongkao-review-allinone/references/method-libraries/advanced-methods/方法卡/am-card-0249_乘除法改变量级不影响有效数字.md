# 方法卡：乘除法改变量级不影响有效数字

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘除法改变量级不影响有效数字 |
| 适用题型 | 资料分析——乘除法运算中简化计算 |
| 触发场景 | 需要做多步乘除法计算，选项有效数字不同但小数点位置不同 |
| 步骤逻辑 | ① 在乘除法中，可以随意改变各数的量级（移动小数点）；② 改变后结果的有效数字不变，只影响小数点位置；③ 只看有效数字即可选出答案（因为选项的有效数字不同） |
| 高频错因 | 因为数字看起来"不对"而不敢忽略小数点；在不该纠结小数点的题目上浪费时间 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

直播中具体应用：中部占比113/中部件数819 vs 西部占比85/西部件数47，整理后只需算有效数字，不用管小数点。原理：2×3=6，2×0.3=0.6，2×0.03=0.06，有效数字都是6。当选项之间有效数字不同时，忽略量级直接算有效数字即可。
