# 方法卡：百化分份数法求增量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 百化分份数法求增量 |
| 适用题型 | 资料分析——增率接近常见分数（如1/5、1/7、1/8等）时求增量或基期 |
| 触发场景 | 增率可近似为某个简单分数（如19.6%≈1/5、14.3%≈1/7、12.5%≈1/8） |
| 步骤逻辑 | ①把增率化为分数形式→②直接得出基期:增量:现期的份数比（分母为1/n→基期:增量:现期=n:1:(n+1)）→③用已知的现期或基期数值除以对应份数得单位值→④乘以增量份数得增量 |
| 高频错因 | 增率不接近常见分数时强用此法导致误差过大；对份数对应关系记混（基期对应分母、增量对应分子1、现期对应分母+1） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q8演示：增率14.8%≈1/7，基期:增量:现期=7:1:8，现期约10万→增量=10万÷8=1.25万，首位为1→选A。Q17演示：增率19.6%≈1/5，基期:增量:现期=5:1:4，现期48.7→增量=48.7÷4≈12.2，选D。百化分表格需熟背，看到25/33/125等数要条件反射。此法优势在于可同时求出基期和增量。
