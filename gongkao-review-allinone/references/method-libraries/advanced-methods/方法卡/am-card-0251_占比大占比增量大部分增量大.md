# 方法卡：占比大且占比增量大则部分增量大

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 占比大且占比增量大则部分增量大 |
| 适用题型 | 资料分析——在同一整体下比较两个部分的增长量大小 |
| 触发场景 | 已知各部分占整体的比重及其变化（占比增量），需要快速判断哪个部分的增长量更大 |
| 步骤逻辑 | ① 确认两个部分属于同一整体；② 比较占比大小和占比增量大小；③ 若某部分占比更大且占比增量也更大（或占比更大且占比增量相同），则该部分增长量一定更大 |
| 高频错因 | 误记结论方向（把大小关系搞反）；没有确认"同一整体"前提就套用 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

这是强化方法在直播中推导并强调可以直接背的结论。推导过程：设整体A、占比M>N、占比增量X>Y，两个部分的增量分别为 A'×M + A'×X 和 A'×N + A'×Y（A'为基期整体），因为M>N且X>Y，上面一定更大。注意：此结论只需要一个条件更大即可（占比大或占比增量大，有一个大就行），但两个都大更保险。
