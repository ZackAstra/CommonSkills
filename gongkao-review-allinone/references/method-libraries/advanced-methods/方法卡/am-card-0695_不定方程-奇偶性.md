# 不定方程-奇偶性

- **适用题型**: 不定方程中系数有明显奇偶特征时，用于缩小解的搜索范围
- **触发场景**: 两数之差为偶数、方程右边为奇数而某项系数为偶数等奇偶矛盾场景
- **步骤逻辑**:
  1. 判断目标变量或方程的奇偶约束（如差为偶数说明两数同奇同偶）
  2. 利用"奇+奇=偶、偶+偶=偶、奇+偶=奇"等基本规则
  3. 排除不符合奇偶条件的选项或取值
  4. 在剩余取值中代入验证
- **高频错因**: 忽略奇偶性导致试算范围过大；误判奇偶关系（如把偶数系数项误认为可奇可偶）
