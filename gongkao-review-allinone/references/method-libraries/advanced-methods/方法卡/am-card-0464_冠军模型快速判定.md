# 冠军模型快速判定

- **方法名**: 冠军模型快速判定
- **适用题型**: 判断推理 > 真假推理（冠军/唯一人选类）
- **触发场景**: N人猜冠军，只有M人说对，判断冠军是谁；各人猜测多为"或"表述
- **步骤逻辑**:
  1. 把每句话翻译成逻辑表达式（如"乙"、"丁或丙"、"甲或丁"、"非甲且非丙"→乙或丁）
  2. 先用等价排除法排除等价对（如甲丙等价，排除）
  3. 对剩余候选，分别假设为冠军，数真假句数
  4. 哪个候选的真句数等于题干要求（如"两人说对"），即为答案
  5. 规律：两人说对→找出现两次的；三人说对→找出现三次的
- **高频错因**: 未翻译就直接猜；忘记"唯一冠军"前提导致多重计算；等价对象未排除浪费时间
