# 方法卡：断点搭桥法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 断点搭桥法 |
| 适用题型 | 判断推理——前提假设类（"补充前提""必须为真"等问法） |
| 触发场景 | 论据与结论之间存在概念跳跃（断点），选项需要建立断点两端的联系 |
| 步骤逻辑 | ① 找到结论和论据，定位两者之间的概念断点；② 若断点明显，直接找搭桥选项（连接断点两端概念）；③ 若断点被题干进一步解释（如植物属性→没活性），需追踪到最底层断点再搭桥；④ 有断点必搭桥，没搭桥的选项一律排除 |
| 高频错因 | 没有准确识别断点位置，被论据中的中间概念干扰；有断点还纠结其他未搭桥选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q2（转基因植物/基因突变）示范了"多层断点"场景：论据说"转基因植物有植物属性→没活性"，结论说"不突变"，断点在"没活性"和"不突变"之间。Q6（感冒/病毒性）也用同一方法，断点在"没细菌感染的感冒"和"大多数感冒"之间。Q7（医生/用心/高超/集中）则是推出链条中的断点搭桥——写清推出关系后找中间缺环即可。
