方法名: 经济利润利润率与乘积增长率
适用题型: 数量关系-经济利润问题
触发场景: 题目涉及钱、利润、标价、成本、打折、提价等关键词
步骤逻辑: |
  1. 识别题型：出现钱/利润/标价/成本 → 经济利润问题
  2. 利润率定义：数量关系中 = 利润÷成本（注意：资料分析中 = 利润÷收入，二者不同！）
  3. 由利润率和售价反推成本：成本 = 售价 / (1+利润率)
  4. 先涨R1再降R2 ≠ 原价！实际变化率 = R1 + R2 + R1×R2
     例：涨10%再降10% → 10%-10%+10%×(-10%) = -1%，实际变为原价的99%
  5. 多段变化逐次连乘：最终价格 = 原价 × (1+R1) × (1+R2) × ...
高频错因: 误以为涨10%再降10%等于原价；混淆数量关系和资料分析中利润率的定义
