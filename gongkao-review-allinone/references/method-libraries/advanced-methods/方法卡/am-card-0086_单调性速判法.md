# 单调性速判法（正负相关）

## 适用题型
资料分析-调查问卷中"收入与选择是否完全正/负相关"

## 触发场景
题目说"收入高低与某选择倾向完全正相关/负相关"，需要从表格中判断哪些选项满足条件

## 步骤逻辑
1. 正相关 = 从上到下（收入递增方向），该列数据也递增
2. 负相关 = 从上到下（收入递增方向），该列数据递减
3. 逐一检查每一列：要么一直变大，要么一直变小 → 符合
4. 出现"先大后小再大"的波动 → 不符合任何相关性 → 排除
5. 不用管具体数值，只看单调性即可

## 高频错因
- 花时间理解"正相关""负相关"的概念，其实只需看递增/递减
- 漏看某一列的波动，误判为单调
