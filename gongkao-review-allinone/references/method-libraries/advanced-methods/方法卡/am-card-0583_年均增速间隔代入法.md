# 方法卡：年均增速间隔代入法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增速间隔代入法 |
| 适用题型 | 资料分析——年均增速/年均增长率的精确计算 |
| 触发场景 | 题目问"年均增长率"，选项差距小需要精确判断 |
| 步骤逻辑 | ① **第一步：求整体R**。末期值-基期值÷基期值，得到整体增速R；② **第二步：R÷N估算范围**。用整体增速÷年份差得到年均增速的大致范围，缩小候选选项；③ **第三步：居中代入**。找选项中的居中值（如BC之间的值），代入间隔公式计算；④ **间隔计算**：二二分段，每段R%→间隔=2R+R²，再将两段间隔合并（加和+乘积）；⑤ **比较判断**：代入值算出的整体增速与实际R比较，偏大→年均增速应减小→选更小的选项 |
| 高频错因 | 忘记算乘积部分R²（只算加和部分会偏小）；年份差算错（2015→2019年份差是4不是5）；代入值算完后比较方向搞反（算大了应选更小的） |

| confidence | high |

## 补充说明

讲解中反复强调这是年均增速的"最优解"，优于格式法和泰勒展开。核心是二二分段的间隔计算：13%代入→26%+1.69%（13²）→27.69%→两段间隔合并55.4%+7.84%（28×28）→63.24%。实际增速60%<63.24%，说明13%代大了，应选比13%小的B选项。讲解中在答疑阶段又用另一道题（5年年份差）演示了完整流程，并解释了R÷N的作用——用于判断先从哪两个选项的居中值开始代入。
