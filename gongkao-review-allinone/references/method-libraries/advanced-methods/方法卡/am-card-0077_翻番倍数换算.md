# 翻番倍数换算

- **方法名**: 翻番倍数换算
- **适用题型**: 资料分析 - "翻番"类表述转换
- **触发场景**: 题目出现"翻一番""翻两番"等字眼
- **步骤逻辑**:
  1. 翻一番 = 2倍
  2. 翻两番 = 4倍
  3. 翻N番 = 2的N次方倍
  4. 求翻番年份：算出目标值（基期×倍数），逐年观察何时达到
- **高频错因**: 把"翻一番"误理解为增长一倍（变成100%+100%=2倍，实际翻一番就是2倍没问题，但有人搞混成3倍）；翻两番误当成2倍
