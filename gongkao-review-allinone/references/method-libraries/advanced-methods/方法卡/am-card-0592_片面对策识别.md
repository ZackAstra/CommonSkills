# 方法卡：谨防对策中的对策（片面对策）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 谨防对策中的对策（片面对策） |
| 适用题型 | 言语理解——中心理解题（对策类文段，尤其文段含多个并列对策） |
| 触发场景 | 文段给出多个并列对策（如对策1+对策2），选项只选取其中一个对策进行了展开说明，或选项虽是对策但遗漏了部分对策主体 |
| 步骤逻辑 | ① 识别文段是否给出多个对策，标出对策1、对策2...；② 检查选项是否只展开了其中一个对策，若是则为"对策的对策"，片面；③ 正确选项应对所有对策进行概括，而非单独展开某一个 |
| 高频错因 | 选项把其中一个对策展开得很具体，看起来很"对应"文段，但实际上片面；误认为"展开得越具体越正确"；忽略了文段的另一部分对策 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第3题C选项(00:16:02)是典型例子：文段给出两个对策——(1)积累生活经验、(2)将生活经验转化为心灵体验。C选项只展开了对策(1)"作家应该如何不断积累生活的经验"，既片面又将对策进行了展开。正确选项D"如何提高文学的原创力"用"如何"概括了两个对策并加上了问题（原创力萎缩），更全面。讲解中用行测的例子做了类比：文段说"提高速度+准确率"，C选项只说"如何提高速度"就是对策中的对策。
