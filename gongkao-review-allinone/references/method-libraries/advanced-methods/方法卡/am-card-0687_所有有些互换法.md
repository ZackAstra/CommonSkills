# 方法卡：所有有些互换法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 所有有些互换法 |
| 适用题型 | 逻辑判断——范畴推理题（涉及所有、有些、特例的否定） |
| 触发场景 | 题目问"以下哪项如果为真，最能质疑上述观点"，涉及"所有都是""有些是""某个是"等表述 |
| 步骤逻辑 | ① 所有的否定=有些不（两词互换，后面加不）；② 有些的否定=所有不（两词互换，后面加不）；③ 所有→有些→特例（推出关系，向下推）；④ 有些推不出所有，也推不出特例；⑤ 有些A是B能推出有些B是A（位置互换） |
| 高频错因 | 把"有些"理解成"只有部分"（逻辑中"有些"包含"所有"）；把"有些是"的否定理解成"有些不是"（实际是"所有不是"） |

## 补充说明

[?] 所有有些互换是范畴推理的基础。核心口诀"两词互换后面加不"：① "所有都是"的否定="有些不是"；② "有些是"的否定="所有不是"。推出关系：所有→有些→特例（向下推），但反过来推不出。"有些"在逻辑中包含"所有"（即"有些是"不等于"只有部分是"）。
