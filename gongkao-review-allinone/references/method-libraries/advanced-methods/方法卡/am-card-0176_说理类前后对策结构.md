# 方法卡：说理类前后对策结构

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 说理类前后对策结构 |
| 适用题型 | 言语理解——片段阅读主旨题（说理类文段） |
| 触发场景 | 问法含"应该""做法""建议""启示"等对策类提示词，或文段作者在输出观点/指挥行动 |
| 步骤逻辑 | ① 判断文段为说理类（作者有观点或指挥做法）；② 对策只在两个位置找：前对策=第一句后直接给出对策+后文论证；后对策=引出话题+中间分析+结尾给出对策；③ 忽略引出话题和分析论证，只聚焦对策句；④ 对策句即主旨，选项必须体现对策的核心内容 |
| 高频错因 | 逐句精读分析论证部分，浪费时间；把分析中的细节当成主旨选入选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

说理类是片段阅读最常见的文段类型。识别方法：问法中出现"要""应该""做法"等关键词，或者作者在文中明确输出观点。对策位置只有两个——首句之后（前对策）或文末（后对策），直接在这两个位置定位即可，分析部分可以快速略读。第3题"建筑设计建造者要尊重建筑本土性"即前对策结构，对策在首句之后。
