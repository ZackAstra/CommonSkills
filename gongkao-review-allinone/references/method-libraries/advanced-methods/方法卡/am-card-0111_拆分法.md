# 方法卡：拆分法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 拆分法 |
| 适用题型 | 资料分析·乘法精算（百分比乘法、数据接近时的整理计算） |
| 触发场景 | 两个乘法项的百分比非常接近，需要提出公因式简化计算时 |
| 步骤逻辑 | 1. 将其中一个百分比拆分为相同部分+差值（如65.4%=64.8%+0.6%） 2. 提取公因式合并相同部分 3. 单独计算差值部分 4. 合并结果 |
| 高频错因 | 拆分后符号搞反；差值部分遗忘或计算错误 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

拆分法是强化方法资料分析的核心速算手段之一。第3题中，讲解中将65.4%拆成64.8%+0.6%，提取64.8%公因式后得到(8317-4230)×64.8%-4230×0.6%，大幅降低了计算难度。课末答疑中也提到"拆分肯定是好用的""拆分就应用一些50%的一些精算是比较好用的"。该方法在选项差距偏小时尤其关键。
