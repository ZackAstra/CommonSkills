# 方法卡：年均增量计算与前推判定

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 年均增量计算与前推判定 |
| 适用题型 | 资料分析-年均增量 |
| 触发场景 | 题目问"年均增加多少"或"年均增量" |
| 步骤逻辑 | 1.确定末年数据和首年数据；2.判断是否前推：若起始年前一年数据已给出则前推，未给出则不前推；3.用末年数据减首年数据得到增量；4.年份差=末年减首年（用哪两年数据就用哪两年做差）；5.增量除以年份差得到年均增量 |
| 高频错因 | 1.搞不清首年是哪一年，该前推时不前推；2.年份差算错，忘记用哪两年数据就用哪两年做差 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

前推规则：题给区间如18~22年，18年的增速是和17年比的，所以首年要前推到前一年。若前一年数据未给出（如第1题没有12年数据），则无法前推也不需要前推。年份差的关键是"你用的哪两年的数据就用哪两年的年份做差"。
