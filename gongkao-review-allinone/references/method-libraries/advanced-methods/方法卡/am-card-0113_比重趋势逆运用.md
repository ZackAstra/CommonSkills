# 方法卡：比重趋势逆运用

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重趋势逆运用 |
| 适用题型 | 资料分析·部分增速与总体增速比较 |
| 触发场景 | 题干问"部分增速高于/低于总体增速"，或"比重比上年上升/下降"时 |
| 步骤逻辑 | 1. 识别题干：部分R是否大于总体R 2. 正向：R1>R2 → 比重上升 3. 逆向：比重上升 → 反推R1>R2 4. 比较两个时期的比重即可判断增速关系 |
| 高频错因 | 分不清R1和R2分别对应部分还是总体；同比/环比的时间基准搞混 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第5题是比重趋势逆运用的典型案例：题干问"出口额环比增速高于进出口总额环比增速"，即部分R>总体R。讲解中将其转化为"只要环比比重上升即可"，再结合盐水混合判断二季度占比（58.1）一定大于一季度（57.8），从而秒杀。第10题C选项也用到此方法：前六省市R1与全国R2=15.2%比较，R1>R2的有3个，刚好一半而非"不到一半"。
