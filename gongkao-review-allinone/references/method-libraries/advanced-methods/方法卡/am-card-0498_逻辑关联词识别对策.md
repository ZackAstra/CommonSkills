# 逻辑关联词识别对策

## 基本信息
- **方法名**: 逻辑关联词识别对策
- **适用题型**: 主旨概括、意图判断、语句填入
- **confidence**: high

## 触发场景
文段中出现"只有才""必须否则""如果那么"等逻辑关联词时，需要判断哪半截是对策、哪半截是目标/问题。

## 步骤逻辑
1. **只有A才B** → A是必要条件=对策，B是充分条件=目标。翻译：想B，需要A
2. **必须A否则不B / 除非A否则不B** → A=对策，B=目标。翻译：想B，必须A
3. **如果A那么B** → 注意含蓄表达。"如果更努力，就更可能考上"=隐性对策，让我们努力
4. 必要条件位置一般是对策的具体做法，充分条件位置一般是想达成的目标

## 高频错因
- 看到"只有才"不翻译，直接选了充分条件那半截
- 不识别含蓄的"如果那么"表达，漏掉隐性对策
