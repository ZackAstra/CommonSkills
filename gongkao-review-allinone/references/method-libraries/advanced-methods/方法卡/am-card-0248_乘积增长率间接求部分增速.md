# 方法卡：乘积增长率间接求部分增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘积增长率间接求部分增速 |
| 适用题型 | 资料分析——已知整体增速和占比关系，间接求部分增速 |
| 触发场景 | 需要比较两个部分的增长量，但材料只给出整体增长率和各部分占比（没有直接给出部分增长率） |
| 步骤逻辑 | ① 记住公式：部分增速 = 整体增速 + 占比增速 + 整体增速×占比增速；② 算占比增速 = 占比增量÷基期占比；③ 若占比增速很小（增量1-2个点、基数很大），则部分增速 ≈ 整体增速；④ 两部分增速差距很小时，增长量大小主要由现期值（占比）决定 |
| 高频错因 | 不知道部分增速可以通过整体增速和占比增速推导；忽略占比增速很小可以近似忽略的情况 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

本质是乘积增长率公式：A=B×C时，r_A = r_B + r_C + r_B×r_C。直播中具体应用：快递业务收入整体增速约20%多，东部和中部的占比增速分别只有0.2/80和0.1/11（都很小），因此两部分增速都约20%多且差距很小，比较增长量只需看现期值大小（东部80.2%远大于中部11.3%），东部增量大于中部。
