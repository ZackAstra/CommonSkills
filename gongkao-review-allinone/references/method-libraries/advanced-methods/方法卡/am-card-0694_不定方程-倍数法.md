# 不定方程-倍数法

- **适用题型**: 不定方程（未知数多于方程个数），尤其系数较大或含5、10等易识别倍数时
- **触发场景**: 列出不定方程后，观察到方程右边和某项系数有公因数/倍数关系
- **步骤逻辑**:
  1. 观察方程中哪些项是某个数的倍数（如25大是5的倍数，555也是5的倍数）
  2. 由"若A和B都是k的倍数，则A±B也是k的倍数"推出另一项也必须是k的倍数
  3. 从最小可行倍数开始依次代入试算
  4. 结合奇偶性可进一步缩小试算范围
- **高频错因**: 没有识别出隐含的倍数关系，导致从1逐一代入浪费时间；忘记验证第三个未知数是否为正整数

- **补充说明**: 词义辨析强调"倍数法用的最多也最快"。例题10中25大+18小=555，25和555都是5的倍数，则18小也必须是5的倍数，小只能是5的倍数（5、10、15...），直接从10代入就得到答案。注意有三个未知数时还需验证第三个未知数是否为正整数且满足题意约束。
