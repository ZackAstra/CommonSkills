# 方法卡：最大信息假设法

| 字段 | 内容 |
|------|------|
| 方法名 | 最大信息假设法 |
| 适用题型 | 逻辑判断——真话假话题（无矛盾时） |
| 触发场景 | 多人说话、找不出矛盾关系、需假设判断真假 |
| 步骤逻辑 | 1. 先尝试找矛盾关系，找不到则进入假设路径 |
| | 2. 统计各信息出现次数，选出现次数最多的（最大信息）优先假设 |
| | 3. 根据题干约束决定假设方向：题干说"只有1人说谎"→先假设该信息为假（因假是特殊的，假设为假可一次性获得其余均为真的确定信息） |
| | 4. 推出矛盾则假设不成立，该信息必为真 |
| 高频错因 | ①误将不同主语的判断识别为矛盾（如"乙抽中红桃"vs"丙抽中非红桃"不是矛盾）②未从最大信息入手，随意假设导致效率低 |
| 来源文件 | source-0070.md |
| confidence | high |

**补充说明：**
- 假设方向口诀：题干说"只有N人假"→先假设为假（一下子得到其余N-1+1个确定信息）；题干说"只有N人真"→先假设为真。
- 冠军模型适用条件是"多选一"（一人夺冠），非多选一场景（如四人抽四花色各不同）不可用冠军模型。
