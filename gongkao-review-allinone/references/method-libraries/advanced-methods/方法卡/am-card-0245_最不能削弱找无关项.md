# 方法卡：最不能削弱题——找完全无关项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 最不能削弱题——找完全无关项 |
| 适用题型 | 判断推理——最不能削弱类 |
| 触发场景 | 题目问"以下哪项最不能削弱"，其他选项都有一点质疑力度但不强，需要挑出完全无关的选项 |
| 步骤逻辑 | ① 识别结论中的核心要素（如因果关系中的因和果）；② 逐个检查选项是否与结论的任何要素相关；③ 选完全无关的选项——它对结论既不支持也不削弱；④ 警惕"实验瑕疵"类选项（样本少、年龄跨度大等），这类选项有一丁点质疑力度但不强，最不能削弱题中一般不选它 |
| 高频错因 | 被有"极弱质疑力度"的选项（实验瑕疵）迷惑，误选为不能削弱；忽略完全无关选项的排除功能 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

本课Q8和Q12都体现了这一思路。Q8中ABD都是实验瑕疵（样本少、年龄跨度大、服药时间短），力度不强但都有；C选项"治疗成年患者无效"则是主体不一致+治疗/预防混淆，完全无关。Q12中"演奏乐器"与"听古典音乐"是两个人/两件事，完全无关。
