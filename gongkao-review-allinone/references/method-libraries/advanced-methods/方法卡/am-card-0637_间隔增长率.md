# 方法卡：间隔增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率 |
| 适用题型 | 资料分析——求前年的量（跨两年，材料给的是今年） |
| 触发场景 | 材料给23年数据，问21年；已知23年比22年增速R1、22年比21年增速R2 |
| 步骤逻辑 | ① 间隔增长率公式：R = R1 + R2 + R1×R2（口诀：1+2加一二）；② R1×R2一般很小可忽略（两个10%相乘才1%）；③ 求出总增长率后，用23年的量和R求21年的量 |
| 高频错因 | 忘记R1×R2项（虽然小但有时需要）；时间方向搞反 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 间隔增长率本质：23年比21年增长了R1+R2+R1×R2。R1×R2是交叉项，通常很小（两个10%相乘才1%），一般可忽略。求出总增长率后，按常规ABRX方法求基期即可。
