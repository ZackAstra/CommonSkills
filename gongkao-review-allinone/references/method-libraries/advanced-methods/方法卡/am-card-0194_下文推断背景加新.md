# 下文推断背景加新

- **方法名**：下文推断背景加新
- **适用题型**：下文推断（接语题）
- **触发场景**：文段有过去时态提示词（"从来""一直以来""此前"等），表达"过去做不好"
- **步骤逻辑**：
  1. 判断不是总分结构→看最后一句
  2. 注意最后一句是否有过去时态提示词
  3. 有时态→选"背景+新"结构（体现"现在和以前不一样"的突破/变化）
  4. 无时态→按"问题+分析/对策"结构推断
- **高频错因**：无脑套"问题+对策"，忽略时态差异；选了不体现"新"的对策
- **来源文件**：source-0028.md
- **confidence**：high
