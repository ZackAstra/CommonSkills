# 方法卡：削弱切断机制链条

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 削弱切断机制链条 |
| 适用题型 | 判断推理——削弱题（归因有明确机制链条） |
| 触发场景 | 题干给出了A通过机制M导致B的具体路径，问削弱 |
| 步骤逻辑 | ① 识别题干机制链：植物油→降低总胆固醇→保护心脏；② 从机制核心环节入手质疑：降总胆固醇≠达到高低密度胆固醇的特定比例→不一定降低心脏病风险；③ 用"不一定"而非"一定否定"来削弱，因机制可能成立也可能不成立 |
| 高频错因 | 只看表面话题相关（如B选项"不是每个种类"），忽视机制核心；误选"他因"（如D选项其他食物也能降风险） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

类比理解：结论"人多→市场繁荣"，削弱"要看能消费的人多还是不消费的人多"——同样切断了"人多"直接到"繁荣"的机制。
