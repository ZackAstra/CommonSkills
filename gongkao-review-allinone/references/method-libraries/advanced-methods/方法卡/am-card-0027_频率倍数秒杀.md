# 方法卡：频率倍数秒杀
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 频率倍数秒杀 |
| 适用题型 | 数量关系-频率/概率（抓娃娃等频率问题） |
| 触发场景 | 题干给出频率（如1/16变为1/10），问总次数 |
| 步骤逻辑 | 1.频率=成功次数/总次数，分母即为总数的约束 2.最终频率的分母决定总数是该数的倍数 3.用选项验证：总数减去新抓到的次数，看是否符合初始频率的倍数关系 |
| 高频错因 | 不理解频率即分母代表总数；不利用倍数关系猜题 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
讲解中演示：原频率1/16，再抓2次全中后频率变为1/10。总数必为10的倍数，减2后必为16的倍数。验证：50-2=48（不是16倍数），40-2=38（不是），50-2=48（不是），60-2=48=16×3（是）→选50不对→60对→选C(50)。实际上50-2=48=16×3，所以选50。核心：用分母约束做倍数筛选。
