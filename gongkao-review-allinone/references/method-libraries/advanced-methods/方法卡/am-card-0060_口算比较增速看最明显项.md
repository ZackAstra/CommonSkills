# 方法卡：口算比较增速看最明显项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 口算比较增速看最明显项 |
| 适用题型 | 资料分析-增速比较/增速排序 |
| 触发场景 | 多个年份/类别的增速需要比较大小 |
| 步骤逻辑 | 1.先观察数据，找最突出的年份（增量大、基期小→增速一定高）；2.从最明显的差异入手，不需要逐年精算；3.分子最小+分母最大→分数值一定最小，反之一定最大 |
| 高频错因 | 从头到尾逐年精算，浪费时间；不先观察就动手算 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

增速=增量/基期。比较增速时，若某年增量远大于其他年且基期相近，该年增速一定最高，无需精算。如本集中17年相较于16年涨了近100%，直接选17年最大。口算时先看前几位有效数字即可判断大小。词义辨析原话：先观察，不要和自己较劲。
