# 方法卡：或关系否一推一逆推

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 或关系否一推一逆推 |
| 适用题型 | 形式推理——逆推题，已知"A或B"要推出确定结论 |
| 触发场景 | 题干给出若干"或"条件和"如果…那么"条件，问"可以推出以下哪项"，结论尚未确定，需要反向推导 |
| 步骤逻辑 | ① 写出目标结论（如"小李教德语"）；② 利用或关系"否一推一"：想从A或B推出A，就否定B（小钱不教德语→小李教德语）；③ 若选项中无此中间结论，继续沿条件链推导，用逆否（A→B等价于非B→非A）；④ 推导链上任何一个中间结论成立都能作为正确答案，选项一般给出最后一步；⑤ 不要跳步蒙猜推理终点，出题人可能从中间截断 |
| 高频错因 | 跳步猜推理终点（如直接猜最后一个人的结果），被出题人从中间截断出题打败；忘记"或关系否一推一"和"逆否"两个核心转化工具 |

| confidence | high |

## 补充说明

第18题核心：条件①小钱教德语→小孙不教俄语；条件②小孙不教俄语→小赵不教法语；条件③小赵教法语或小周不教英语。目标推出"小李教德语"。第一步：或关系否一推一，否定"小钱教德语"→小钱不教德语→小李教德语；第二步：由①逆否，小孙教俄语→小钱不教德语；第三步：由②逆否，小赵教法语→小孙教俄语；第四步：由③否一推一，小周教英语→小赵教法语。C选项"小周教英语"正确。推导链上任一步都可能成为正确答案，不要只猜最后一步。
