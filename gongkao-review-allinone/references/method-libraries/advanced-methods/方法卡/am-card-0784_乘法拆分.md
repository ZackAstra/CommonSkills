# 方法卡：乘法拆分

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘法拆分 |
| 适用题型 | 资料分析-乘法-一个数乘以百分数（尤其90%-110%、45%-55%、15%附近） |
| 触发场景 | 遇到A乘以百分数，且百分数靠近50%、100%、或10%/5%/1%等好算节点时 |
| 步骤逻辑 | 1. 将百分数拆成好算部分+小调整（如98%拆为100%-2%，49%拆为50%-1%，103%拆为100%+3%）2. 先算好算部分（一半、自身、十分之一等）3. 用"一个包子=百分之一"估算小调整部分 4. 加减得到近似结果，对照选项选最近的 |
| 高频错因 | 拆分方向选错导致计算更复杂；小调整部分估算过于粗糙 |

| confidence | medium |

## 补充说明

"包子法"是强化方法的核心比喻：把一个数看成100个百分之一，每个百分之一就是一个"包子"。例如624的1%就是6.24（一个包子的价格），减掉两个包子就是减12.48。乘以98%就是"自身减两个包子"，乘以49%就是"一半减一个包子"，乘以103%就是"自身加三个包子"。强化方法特别强调不要死心眼，如98.67%可以当98.7%甚至按"自身减一点三个包子"来算，带小数点反而可能更好算。该方法在百分数靠近50%、100%、或个位百分比时最有效。
