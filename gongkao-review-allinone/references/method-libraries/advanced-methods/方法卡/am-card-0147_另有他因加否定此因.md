# 另有他因+否定此因

## 方法名
另有他因+否定此因

## 适用题型
判断推理-削弱题（题干将A认定为B的原因，选项需质疑该因果关系）

## 触发场景
题干：研究发现A和B相关，推测A导致B。选项需要找最能削弱/质疑的

## 步骤逻辑
1. **单纯的另有他因**：指出C也能导致B → 有一定削弱力度，但未否定A的原因
2. **单纯的否定此因**：直接说A不会导致B → 有削弱，但缺乏替代解释
3. **最强削弱 = 另有他因 + 否定此因**：如"添加剂才是主要因素" → 既提出了新原因C，又用"主要"否定了原原因A的主导地位
4. 力度排序：**另有他因+否定此因 > 单纯另有他因 ≈ 单纯否定此因 > 反向论据**
5. 看到选项中有"主要因素""根本原因"等表述 + 另提他因 → 力度最强，直接选

## 高频错因
- 只看是否"另有他因"就选，忽略了"主要因素"同时否定了原原因
- 选了单纯的反向论据（如"低脂肪也有好处"）而错过既有他因又否定此因的选项
