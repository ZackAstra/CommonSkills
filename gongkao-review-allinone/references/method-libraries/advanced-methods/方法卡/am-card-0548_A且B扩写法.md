# 方法卡：A且B扩写法

| 字段 | 内容 |
|------|------|
| 方法名 | A且B扩写法（隐含信息补全） |
| 适用题型 | 逻辑判断——真话假话题（主语互斥场景） |
| 触发场景 | 某人说"我抽中了X"，隐含其他人没抽中X；需利用此隐含信息建立与其他陈述的逻辑关系 |
| 步骤逻辑 | 1. 将排他性陈述扩写：如"乙抽中红桃"→"乙抽中红桃 且 丙抽中非红桃"（A且B） |
| | 2. 观察另一陈述恰好对应B（如丙说"我抽中非红桃"=B） |
| | 3. 利用约束推理：只有1人说谎→若B假则A且B必假→推出两个假人，与题干矛盾→B必真 |
| | 4. 由B真得到确定信息，继续后续推理 |
| 高频错因 | ①只看表面文字，未意识到"我抽中X"暗含"其他人没抽中X"②不会将扩写后的逻辑与约束条件（几真几假）结合推理 |
| 来源文件 | source-0070.md |
| confidence | high |

**补充说明：**
- 本质是利用排他性条件（花色互不相同）补全隐含信息，将两个看似无关的陈述用A且B形式关联。
- 只有出现排他性/互斥约束时才能使用此法，不适用于普通的真假话问题。
