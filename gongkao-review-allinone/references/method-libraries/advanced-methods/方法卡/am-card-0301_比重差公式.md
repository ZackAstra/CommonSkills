# 方法卡：比重差公式

| 字段 | 内容 |
|------|------|
| 方法名 | 比重差公式 |
| 适用题型 | 资料分析-比重差（如"比重比上年上升/下降多少百分点"） |
| 触发场景 | 题目问现期比重与基期比重的差值，单位为百分点 |
| 步骤逻辑 | 1. 识别考比重差 → 2. 找部分增速(RA)和整体增速(RB) → 3. 套公式：比重差 = (小A/大B) × (RA - RB)，其中小A为基期部分值，大B为现期整体值 → 4. RA-RB判断升降方向，小A/大B估算幅度 |
| 高频错因 | 混淆比值差和比值增长率（带单位是比重差，带百分号是比值增长率） |
| 来源文件 | source-0040.md |
| confidence | high |

补充说明：公式结果单位为百分点。当小A/大B很小时（如部分占整体不到5%），比重差一定很小。可先用RA-RB判断方向，再用小A/大B估算幅度，不需精算。
