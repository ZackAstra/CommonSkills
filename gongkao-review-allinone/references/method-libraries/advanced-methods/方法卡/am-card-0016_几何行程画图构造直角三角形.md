# 方法卡：几何行程画图构造直角三角形
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 几何行程画图构造直角三角形 |
| 适用题型 | 数量关系-几何行程（划船绕岛、正北正南方向类） |
| 触发场景 | 题干出现"正北""正南""绕岛""相切"等方向描述 |
| 步骤逻辑 | 1.画图标注各主体位置（岛、湖、出发点、目标点） 2.找相切点→连接半径→构造直角三角形 3.利用勾股数/特殊角计算直角边 4.总路程=弧长+直角边长 |
| 高频错因 | 搞混"岛"和"湖"的主体；不画图直接算 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
讲解中强调：几何行程默认简单题、必做题型。会画图+知道常见勾股数(3-4-5, 1-√3-2, 7-24-25, 5-12-13, 8-15-17)就能做。以绕岛划船为例：绕岛弧长=60×2π×(120/360)=40π≈126，直角边=60√3≈104，合计≈230，÷60换算分钟得3分49秒。
