# 方法卡：间接因果竞争食物

- **方法名**：间接因果竞争食物
- **适用题型**：归因题（A不吃B但A增多B减少）
- **触发场景**：题干质疑"不吃直接吃B的动物A不可能导致B减少"时
- **步骤逻辑**：
  1. A不吃B不代表A对B无影响
  2. 若A和B竞争同一食物C，A增多 → C被A大量消耗 → B因缺少食物而减少
  3. 这是间接因果：通过争夺共同资源（食物、栖息地等）产生影响
  4. 选项只要说明A和B有共同食物/资源，即可支持"A导致B减少"
- **高频错因**：被"不吃"迷惑，认为不吃就不可能导致减少
- **来源文件**：source-0039.md
- **confidence**：high

补充说明：经典例子——胡狼不吃眼镜蛇，但胡狼吃沙鼠，沙鼠也是眼镜蛇的食物。胡狼增多→沙鼠减少→眼镜蛇饿死。逻辑链为"我把你饭吃了，你饿死了"。
