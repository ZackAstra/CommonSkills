# 方法卡：或关系一真则真

- **方法名**：或关系一真则真
- **适用题型**：真假推理题（"只有一人说真话/只有一条为真"类）
- **触发场景**：题干给出若干条件并限定"只有一真/只有一假"，其中出现A和"A或B"的配对
- **步骤逻辑**：
  1. 找出题干中"A"和"A或B"的配对关系
  2. 因为A为真则A或B必为真（或关系一真则真）
  3. 若题限定"只有一真"，则A必须为假（否则A和A或B同时为真，违反条件）
  4. A为假后，再结合其他条件继续推理
- **高频错因**：不识别A与A或B的同真关系，逐个假设试错浪费时间
- **来源文件**：source-0039.md
- **confidence**：high

补充说明：此为真假推理的高频秒杀技巧。如条件丙为"不去文化馆"，条件甲为"不去文化馆或不去档案馆"，则丙真则甲必真。若限定只有一真，丙必为假，即去了文化馆。
