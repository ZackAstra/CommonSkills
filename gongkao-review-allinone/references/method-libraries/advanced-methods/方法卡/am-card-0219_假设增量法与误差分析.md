# 方法卡：假设增量法与误差分析

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设增量法与误差分析 |
| 适用题型 | 资料分析——已知现期和增速求增量，选项间距较大 |
| 触发场景 | 选项间差距较大（如间距800+），需要快速估算增量；或配合份数法、假设分配使用 |
| 步骤逻辑 | ① 选一个好算的增量假设值（让基期凑整）；② 反推基期 = 现期 - 假设增量；③ 用基期×增率验算增量；④ 分析误差 = 假设偏差×增率，判断是否影响选项判断 |
| 高频错因 | 不做误差分析就下结论；假设值离选项太远导致误差不可控 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

词义辨析在第14题演示了这个方法：假设增量4910→基期刚好3万→验算3万×18.4%≈5开头→选B。误差分析核心：假设值与各选项的差只有1000~2000，乘以增率后误差仅200~360，在选项间距800以内可接受。与假设分配本质一致，区别在于"直接假设增量"而非"逐步分配"。
