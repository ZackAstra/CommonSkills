# 方法卡：归因题分组看程度副词法

- **方法名**：归因题分组看程度副词法
- **适用题型**：归因类论证题（支持/削弱），题干为对比实验
- **触发场景**：题干结论出现"大量""过量""显著"等程度副词；实验涉及吃/没吃、多/少等分组
- **步骤逻辑**：
  1. 读结论时注意是否有程度副词（如"大量食用"而非"食用"）
  2. 确定分组依据：不是"吃vs没吃"，而是"大量vs不大量"
  3. 支持/削弱选项的分组必须与结论的分组一致
  4. 若选项分组与结论分组不匹配（如按"吃没吃过"分组而非"量"），则为分组错误
- **高频错因**：忽略程度副词，把分组按常识理解为"吃vs没吃"，选了分组错误的选项
- **来源文件**：source-0038.md
- **confidence**：high

> 补充：Q6中"大量食用荔枝"→分组是"大量组"vs"非大量组"。B选项"限制了数量"（少吃时不患病）正是按"大量vs少量"分组的正向支持。C选项"吃过荔枝"只按"吃没吃过"分组，与题干"大量"不符，属分组错误。此为课程单元"分组正确可秒杀"的母题。
