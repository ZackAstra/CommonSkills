# 叠数速算法

## 适用题型
资料分析-速算

## 触发场景
乘数为叠数（十位=个位，如 66、77、44、55、11、22、33 等）

## 步骤逻辑
1. 看到叠数，拆成"十位数×个位数"
2. 先算：**被乘数 × (叠数/11)**，得到第一个积
3. 将第一个积错位写一份（右移一位），两者相加即得结果
4. 例：66×8 → 先算 8×6=48 → 错位写 48+48 → 528；44×9 → 4×9=36 → 36+36 → 396

## 高频错因
- 忘记错位相加，直接当普通乘法算
- 把叠数拆成整百+个位去乘，计算量大且易错
