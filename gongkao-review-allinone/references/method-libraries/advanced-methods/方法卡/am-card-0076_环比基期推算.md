# 环比基期推算（负增速→加自身分数）

- **方法名**: 环比基期推算（负增速→加自身分数）
- **适用题型**: 资料分析 - 已知现期和环比增速求基期
- **触发场景**: 题目给当月数据和环比增速（如下降33.1%），求上月数值
- **步骤逻辑**:
  1. 环比增速为负，如 -33.1% ≈ -1/3
  2. 现期 : 基期 = (1+R) : 1 = 2 : 3（下降1/3意味着现期是基期的2/3）
  3. 基期 = 现期 ÷ (1+R) = 现期 + 现期×(1/3 - 0.2%) ≈ 现期 + 现期/3
  4. 可先按粗略分数（如1/3）算，再微调误差
- **高频错因**: 把环比和同比搞混；增速是负数时忘记基期比现期大
