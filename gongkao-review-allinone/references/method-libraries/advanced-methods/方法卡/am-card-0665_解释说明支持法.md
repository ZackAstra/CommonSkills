# 方法卡：解释说明支持法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 解释说明支持法 |
| 适用题型 | 逻辑判断——支持题（需要解释为什么结论成立） |
| 触发场景 | 题干给出一个观点或现象，需要找能解释为什么这个观点正确的选项 |
| 步骤逻辑 | ① 读完选项后有"豁然开朗"的感觉；② 选项解释了为什么题干的结论成立；③ 不是重复论据，而是从另一个角度解释 |
| 高频错因 | 选了重复论据的选项（重复不是解释说明）；选了话题不一致的选项 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 解释说明是支持题的一种。例如：题干"水源变化是形成多个古城的原因"→选项"一旦水量减少耕地沙化，人们就寻找新绿洲再建城"，读完就明白为什么水源变化会导致多个古城。注意：① 重复论据不是解释说明（如"水源确实变化了"）；② 要从因果机制上解释，而不是简单重复结论。
