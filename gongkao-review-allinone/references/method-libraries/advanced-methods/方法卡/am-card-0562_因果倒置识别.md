# 方法卡：因果倒置识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 因果倒置识别 |
| 适用题型 | 判断推理——归因削弱题（对比实验类：A组有X，B组无X，A组更Y，归因为X→Y） |
| 触发场景 | 题干将X归因为Y的原因；需要找最强削弱选项 |
| 步骤逻辑 | ① 提取归因结构：因为X所以Y（如适量饮酒→健康）；② 优先排查因果倒置选项：是否存在"本来就有Y的人才去做X"（如身体健康的人更倾向饮酒）；③ 因果倒置是最强削弱力度之一，遇到即可秒选，无需再比较其他选项 |
| 高频错因 | 被"不明确选项"（如一半加强一半削弱的选项）干扰；忽略了因果倒置是力度最强的削弱方式 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q9（适量饮酒vs健康）B选项"身体健康的人更倾向于适量饮酒"直接反转因果。A选项"酒精对某些疾病有负面作用"是典型的不明确选项（前半加强后半削弱，综合为零）。D选项分组不一致（高纬度/低纬度 vs 饮酒/不饮酒）直接排除。
