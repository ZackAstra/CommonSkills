# 方法卡：比值升降速判法

| 字段 | 内容 |
|------|------|
| 方法名 | 比值升降速判法 |
| 适用题型 | 资料分析-判断比值上升/下降趋势（如"平均值比上年高/低""比重上升/下降"） |
| 触发场景 | 题目问比值（平均值、占比等）是上升还是下降，不需要精确值 |
| 步骤逻辑 | 1. 识别所求为比值（分子÷分母） → 2. 找分子增速和分母增速 → 3. 分子增速 > 分母增速 → 比值上升；分子增速 < 分母增速 → 比值下降 |
| 高频错因 | 把分子分母搞反；负数增速比较时忘记负号方向（-30% > -38%意味着分子增速更大） |
| 来源文件 | source-0040.md |
| confidence | high |

补充说明：此法只需比较两个增速大小即可，不需要计算比值。注意负数情况：-30% > -38%，即-30%的绝对值小但数值更大。
