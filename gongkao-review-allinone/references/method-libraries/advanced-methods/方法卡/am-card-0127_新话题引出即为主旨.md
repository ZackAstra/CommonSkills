# 方法卡：新话题引出即为主旨

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 新话题引出即为主旨 |
| 适用题型 | 言语理解-中心理解题 |
| 触发场景 | 文段中间通过"因此""由此"等词引出一个新话题（常带双引号标注），后文围绕该新话题展开 |
| 步骤逻辑 | 1. 留意文段中是否出现了带引号或明显标记的新概念/新话题 2. 观察后文是否全部围绕该新话题展开 3. 如果是，新话题就是文段主旨 4. 选项必须包含该新话题关键词 |
| 高频错因 | 只关注前面的背景描述，忽略中间提出的新话题才是核心 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第4题（非遗生产性保护）是典型示范。前文讲"非遗具有生产性"，然后通过"因此"引出带双引号的"生产性保护的理念"，后文全部围绕"生产性保护"展开。此时主旨不是前面的背景，而是这个新话题。注意：需判断新话题是被论证支撑的重点，还是仅为反面论证的一部分（见"反面论证识别"卡）。本学习材料中"快餐式翻译"虽是新话题但属于反面论证，不能选。
