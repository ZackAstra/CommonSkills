# 方法卡：排序题占位优先法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排序题占位优先法 |
| 适用题型 | 排列排序——给出多人相对位置关系，确定最终排列 |
| 触发场景 | 题干给出多人左右/前后关系，其中某些条件占据较多位置（如间隔3人=占5个位置），需要快速定位 |
| 步骤逻辑 | ① 先处理已确定位置的元素（如"甲在最左边"）；② 剩余元素中，优先处理"占位最多"的条件（间隔越长→可能性越少→确定性越高）；③ 结合排除条件（如"戊不在最右边"）进一步缩小范围，逐步确定全部位置 |
| 高频错因 | 从最不确定的元素开始排导致反复试错；忽略附加排除条件（如"不在最右"）导致多解 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q12示例：7个位置，甲固定在最左。戊在丁的右边间隔3人→丁…戊占5个位置，6个剩余位中只能放在2-3-4-5-6或3-4-5-6-7。戊不在最右（7号位）→排除后面那组→锁定丁=2、戊=6。剩余位置逐个填入乙丙庚己即可。
