# 假设分配/小丑法求基期

## 基本信息
- **方法名**: 假设分配/小丑法求基期
- **适用题型**: 资料分析 - 基期值计算
- **触发场景**: 已知现期值和增长率求基期值；增长率较小（如5%-10%），需要快速估算
- **confidence**: high

## 步骤逻辑
### 假设分配法
1. 设基期为一个"好算"的整数（如取100、700等）
2. 用基期 × 增长率算出增量
3. 基期 + 增量 = 现期，与题目现期做差微调
4. 最终得到近似基期值

### 小丑法
1. 基期 ≈ 现期 × (1 - r + r²)，其中 r 为增长率
2. 即除以(1+r) ≈ 乘以(1 - r + r²)
3. r² 用"7%的平方≈0.49取0.4"之类近似
4. 适合增长率6%-10%的范围

## 高频错因
- 假设分配时取的初始值不合适，导致计算量大
- 小丑法中 r² 的近似取值偏差过大
- 两种方法混用导致公式混乱
