# 方法卡：比重差三步秒杀

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重差三步秒杀 |
| 适用题型 | 资料分析——题干含"百分点"且问比重上升/下降多少 |
| 触发场景 | 看到"比重……百分点"→一定是比重差题型（注意：百分点≠百分号） |
| 步骤逻辑 | ①先算 R1-R2（部分增率-整体增率）：正→比重上升，排掉下降选项；负→比重下降，排掉上升选项；②剩余两个选项通常差距极大（十倍级），只需看部分占整体的现期比重×(R1-R2)的数量级即可选；③公式中的 1/(1+R1) 因选项差距大通常可忽略不计 |
| 高频错因 | 把"百分点"混淆为"百分号"从而误用比值增长率公式；第一步判断方向后未利用剩余选项差距极大的特征直接选 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

强化方法称此为资料分析最简单的题型，目标20~30秒完成。Q7演示：R1-R2=-2.5%，排掉上升选项；部分/整体≈1/10，1/10×2.5%≈0.25个百分点，直接选D。1+R1差6%而选项差900%，根本不用管。第19题基期比重计算中也可先用比重差公式快速估算差值，再从现期比重反推基期比重。
