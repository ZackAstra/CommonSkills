# 方法卡：否一推一法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 否一推一法 |
| 适用题型 | 逻辑判断——逆推题（涉及"或"关系，想让某一方成立） |
| 触发场景 | 题干有"A或B"的关系，问"怎样才能让A成立" |
| 步骤逻辑 | ① 对于A或B，想让A成立，就否B（不吃西瓜→只能吃葡萄）；② 对于A或B，想让B成立，就否A；③ 原理：或关系至少一个成立，否了一个，另一个必然成立 |
| 高频错因 | 搞反了否的方向；不理解"或"关系的含义 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 否一推一是逆推的常用技巧。原理：A或B至少一个成立，如果否了A，那B必然成立。例如："孙老师教语文或吴老师教语文"，想让孙老师教语文→否吴老师不教语文。配合逆推使用：从目标出发，一步步往前推，遇到"或"关系就用否一推一。
