# 方法卡：肯后不推前

- **方法名**：肯后不推前
- **适用题型**：翻译推理题（涉及充分/必要条件判断）
- **触发场景**：需要判断"结果正确能否推出条件正确"时
- **步骤逻辑**：
  1. 原命题 A → B 中，肯前（A成立）可推出B
  2. 否后（B不成立）可推出非A（逆否）
  3. 肯后（B成立）不能推出A——可能A成立，也可能只是巧合/蒙对
  4. 否前（A不成立）不能推出B——可能其他条件也能导致B
- **高频错因**：把"做对了"等同于"识别出了正确答案"，忽略可能蒙对的情况
- **来源文件**：source-0039.md
- **confidence**：high

补充说明：词义辨析用颜色识别的例子说明——拿对了红球可能是识别出了红色，也可能是蒙对的。但拿错了方块（形状错）则一定说明没识别出形状。所以"一定为真"的选项只能从否后（拿错→没识别）入手，不能从肯后（拿对→识别了）入手。
