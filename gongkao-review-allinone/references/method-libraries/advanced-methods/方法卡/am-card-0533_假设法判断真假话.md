# 方法卡：假设法判断真假话——从"要么都/要么都没"入手假设

## 适用题型
真假话/达标判断题（逻辑判断）

## 触发场景
题干给出多个关于"谁达标/谁没达标"的条件，其中一个条件是"两人要么都达标要么都没达标"

## 步骤逻辑
1. 先找最特殊的条件——"要么都达标要么都没达标"只能二选一，适合假设
2. 假设"都没达标" → 顺着所有条件推一遍
3. 若推出矛盾（如"必须有1人达标但两人都没达标"冲突）→ 假设不成立
4. 因此"都达标"成立 → 得到确定信息 → 继续代入其他条件推理
5. 推完所有能推的 → 对照选项选出答案

## 高频错因
- 从普通条件入手推不出来就放弃
- 不敢假设，想一步到位推出所有信息

第17题。条件三"2和3要么都达标要么都没达标"最特殊。假设都没达标 → 1必须达标（条件二）→ 4必须没达标（条件五）→ 3和4都没达标，但条件五要求至少一个达标 → 矛盾。所以2和3都达标 → 2达标 → 选B。
