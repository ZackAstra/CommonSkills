# 方法卡：矛盾关系推导未出现数据

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 矛盾关系推导未出现数据 |
| 适用题型 | 资料分析——材料中未直接给出的分类数据 |
| 触发场景 | 题干问"省内流动""非某类"等材料中无直接数据的分类，而材料给出了其矛盾对立项及占比 |
| 步骤逻辑 | ①识别两个分类是否为矛盾关系（如跨省 vs 省内，在外出整体内互补）→②用已知部分及其占整体比重反求整体（部分÷占比=整体）→③整体减已知部分即得所求 |
| 高频错因 | 误将两个分类当作独立数据源，未识别矛盾互补关系导致多算一步 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

此方法本质是"部分+部分=整体"的互补思想。验证方法：可用全国数据把已知的两部分相加，确认等于整体。第五题综合分析中再次使用了同一逻辑：中部外出农民工中跨省占55.6%，省内=1-55.6%<50%，故"不到五成"正确。
