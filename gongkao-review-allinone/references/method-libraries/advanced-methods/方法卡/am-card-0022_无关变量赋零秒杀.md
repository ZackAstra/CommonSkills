# 方法卡：无关变量赋零秒杀
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 无关变量赋零秒杀 |
| 适用题型 | 数量关系-流水行船/追及问题（条件不足型） |
| 触发场景 | 行船题中船速或水速未在题干中给出，答案与该变量无关 |
| 步骤逻辑 | 1.判断谁是无关变量（题干中未给出的速度） 2.令无关变量=0 3.理解赋零的物理含义：船速为0则船随水漂（水到哪船到哪），水速为0则物停原地 4.直接用剩余条件计算 |
| 高频错因 | 不会判断谁是无关变量；不理解赋零的物理意义 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
讲解中演示两道对比题：第19套第4题——题干只给水速1m/s和时间10min，未给船速→船速为无关变量→令船速=0→船随水漂，水走600m船也走600m，返程同样600m，共1200m。第20套第4题——题干给船速5km/h，未给水速→水速为无关变量→令水速=0→浮标停原地，4÷5=0.8小时，追上后再考虑双倍。猜题辅助：先算简单条件得出600或0.8，找选项中对应倍数。
