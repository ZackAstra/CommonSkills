# A推B用非A且B反驳

- **方法名**: A推B用非A且B反驳
- **适用题型**: 判断推理 > 论证相似/反驳方式一致
- **触发场景**: 题干给出"A→B"并用"非A且B"来反驳，要求选反驳方式一致的选项
- **步骤逻辑**:
  1. 把题干观点翻译成 A→B（如"不了解历史→必定重复错误"）
  2. 题干反驳用了"非A且B"（如"了解了历史→仍然重复错误"），这是**错误的**反驳
  3. 逐个翻译选项的反驳结构，找同样用"非A且B"来反驳的
  4. 排除A∧¬B（正确反驳方式，与题干不一致）和无关结构
- **高频错因**: 混淆"正确的反驳"和"题干要求的反驳"——题目要求的是找跟题干**错得一样**的选项
