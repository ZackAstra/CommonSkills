# 方法卡：比重差公式

## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 比重差公式 |
| 适用题型 | 资料分析-某部分占总体比重比上年高/低多少个百分点 |
| 触发场景 | 题目出现"比重比上年同期高/低多少百分点" |
| 步骤逻辑 | 1. 识别题型为比重差<br>2. 找到R1（部分增速）和R2（总体增速）<br>3. 计算R1 - R2的正负判断升降方向，排除反向选项<br>4. 计算A/B（现期部分/总体）的比值<br>5. 套公式：比重差 = (R1 - R2) / (1 + R1) × (A/B) |
| 高频错因 | R1和R2找反；A/B找错（部分和总体混淆）；忽略1+R1导致精度不够 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明
- R1-R2为正则比重上升，为负则下降，可先用来排除选项方向。
- 当A/B接近50%且R1-R2较小时，结果可能卡在选项边界，需要精算。
- 精算时保留三位有效数字，公式右边(R1-R2)/(1+R1)接近1时用拆分法处理。
- 另一种变体公式（带基期比重的）也可以用，但强化方法偏好本公式因为不需要额外算基期。
