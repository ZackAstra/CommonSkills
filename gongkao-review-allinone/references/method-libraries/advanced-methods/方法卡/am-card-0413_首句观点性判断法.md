# 方法卡：首句观点性判断法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 首句观点性判断法 |
| 适用题型 | 中心理解（意在强调/最想表达/概括最准确） |
| 触发场景 | 文段首句为总起句，需判断首句是客观事实还是作者观点，以决定后面的论证部分能否省略 |
| 步骤逻辑 | ① 看首句是否有观点性（作者主观判断、对策呼吁、评价好坏）；② 若首句有观点性（如"不应该""大家都快去"），后面的解释说明/原因分析仅为论证，可省略，主旨=首句；③ 若首句无观点性（如"课程很多人买""没有成为主流"），后面的原因解释与结果是并重的，主旨需概括前后所有内容 |
| 高频错因 | 首句无观点性时仍只抓首句，漏掉后面的原因解释，导致主旨片面 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

核心区分举例：「四海今年的课程很多人买」= 客观事实，无观点性，果因并重需概全；「大家都快去买四海的课」= 有观点性（对策/呼吁），后面的"一方面…另一方面…"仅为论证，可省。考场上用10秒判断首句性质，决定后面读多细。
