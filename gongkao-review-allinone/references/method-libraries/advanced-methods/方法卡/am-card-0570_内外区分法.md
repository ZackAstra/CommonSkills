# 方法卡：内外区分法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 内外区分法 |
| 适用题型 | 加强削弱——两个观点分别归因于"内部"和"外部" |
| 触发场景 | 题干出现两种对立归因（如体内筛选 vs 从外界摄入；用药导致 vs 食物带入），需要判断选项支持哪一方 |
| 步骤逻辑 | ① 先把两个观点拆成"内因"和"外因"两条线；② 看清题目问支持还是削弱哪个观点；③ 逐个选项判断它归到哪条线、方向是否匹配；④ 若选项方向不明（如A选项"中毒"不确定是否与细菌相关），按最不利方向归类，只要不是支持目标方向就排除 |
| 高频错因 | 没有先做内外分类就直接逐项判断；选项含模糊概念（如"中毒"）时无法区分是削弱还是无关，误判方向 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第1题：人体内抗菌性细菌，一方认为是用药内部筛选，另一方认为是吃含菌肉食。D选项（饲养者加抗生素）属外因线，是必要条件支持。A选项"食用肉食中毒"——若因细菌则是削弱（既涉及内也涉及外），若非细菌则无关，无论如何都不可能是支持，排除。
必要条件作为支持力度有限但方向正确（Q1的D选项）。
