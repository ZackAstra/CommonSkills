# 方法卡：分析论证部分非重点

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 分析论证部分非重点 |
| 适用题型 | 言语理解-中心理解题 |
| 触发场景 | 文段中出现"例如""也就是说""解释说明"或对前一句的支撑展开时 |
| 步骤逻辑 | 1. 判断某句话是否在支撑/论证前面的某个观点 2. 如果是论证部分（举例、解释说明、具体分析），则非重点 3. 论证部分出的选项一定是"出处有误"，优先排除 4. 真正的主旨是被论证支撑的那句话 |
| 高频错因 | 把论证部分的具体内容当成主旨，选了出处有误的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

强化方法在第2题（举例论证）、第4题（解释说明生产性含义）、第6题（反面论证也是论证）、第13题（作家行动和演讲是对观点的论证）、第14题（学术同行和公众两个层面论证结合的好处）、第15题（不同类型众创空间论证差异化）中反复强调。判断方法：看该句是否在"支撑别人"——如果是为了说明前一句而存在的，就是论证部分。在选项比较时，出处来自论证部分的选项比出处来自主旨句的选项"瑕疵更大"，优先选后者。
