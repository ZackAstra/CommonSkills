# 方法卡：科普文与说理文的选项匹配

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 科普文与说理文的选项匹配 |
| 适用题型 | 中心理解——需先判断文段类型再选选项 |
| 触发场景 | 文段为纯客观事实描述（无作者观点/倾向），或文段为说理类（有观点/对策/意义表述）；选项混搭了中性表述和观点性表述 |
| 步骤逻辑 | ① 判断文段类型：科普文=无观点性（如"越来越多作家思考定位"是客观事实）；说理文=有观点性（如"翻译模式促进了跨境传播"是意义评价）；② 科普文→不能选有观点性的选项（对策、意义、评价类）；说理文→不能选纯中性的选项（背景、客观事实）；③ 两类文段的选项池不交叉 |
| 高频错因 | 科普文中选了对策或评价性表述；说理文中选了纯客观事实的表述；分不清"客观事实"和"作者观点"的边界 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

区分方法：客观事实=已发生/大家公认的事（"今天下雨""课程很多人买"）；观点=作者的主观判断/倾向/评价（"田野是符合孩子天性的土壤""翻译模式太好了"）。如果拿不准，反问"这是所有人都认可的事实吗？"——不是→就是观点。
