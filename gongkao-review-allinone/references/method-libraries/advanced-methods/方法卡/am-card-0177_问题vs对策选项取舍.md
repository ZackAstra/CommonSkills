# 方法卡：问题vs对策选项取舍

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 问题vs对策选项取舍 |
| 适用题型 | 言语理解——片段阅读主旨题（文段只有问题无对策时） |
| 触发场景 | 文段提出了问题/批评了某种现象但未给出明确对策，选项中既有"概括问题"类也有"给出对策"类 |
| 步骤逻辑 | ① 若原文有对策→必选对策选项（对策>问题）；② 若原文没有对策，只有问题→概括问题或给傻瓜对策都可接受，两者不会同时出现在同一题中；③ 傻瓜对策=原文问题的简单反面（如"不够努力"→"要更努力"），不要发散；④ 选项中若有一个有致命问题（概括不准或对策太宽泛），选另一个 |
| 高频错因 | 坚信"一定要选对策"，在原文无对策时仍勉强选一个宽泛对策；在原文有对策时选了概括问题的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第11题是典型例题：原文说"教育违背孩子成长规律"，只有问题没有对策。A"防止揠苗助长式教育"是傻瓜对策，B"教育要遵循成长规律"也是对策表述。最终选B，因为B更贴近总结句原文用词。但D"教育方式需要转变"太宽泛、不如B具体，被排除。关键原则：问题和对策不会同时成为正确选项，排除有致命问题的那个。
