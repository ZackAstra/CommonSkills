# 不定方程-尾数法

- **适用题型**: 不定方程中目标值有特定小数/个位数，或系数含特定尾数特征
- **触发场景**: 方程右边含小数（如40.6），但某些项必为整数，需通过尾数反推某变量的取值
- **步骤逻辑**:
  1. 识别方程中哪些项必为整数，确定小数部分只能由某一项产生
  2. 分析该项系数的尾数特征（如1.7乘以几尾数是6）
  3. 逐步枚举可能的尾数取值（1.7x8尾数为6）
  4. 结合总量限制确定最终取值
- **高频错因**: 没注意到整数项不可能产生小数部分，导致把所有未知数混在一起分析；尾数枚举不全或算错

- **补充说明**: 例题8中1.7X+3Y+4Z=40.6，因3Y和4Z必为整数（不能买零点几根笔），0.6必来自1.7X。分析1.7乘几尾数为6，得X=8或18。结合"总数尽量多→买便宜的尽量多→X尽量大"，X=18。再用奇偶法解3Y+4Z=10，得Y=2、Z=1，共21支。
