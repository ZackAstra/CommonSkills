# 增速差额=基期×增长率简化差额计算

## 基本信息
- **方法名**: 增速差额=基期×增长率简化差额计算
- **适用题型**: 资料分析 - 差额变化量
- **触发场景**: 求两年间某指标的差额变化（如城乡收入差的变化量）；差额 = 基期×(倍数-1) = 基期×增长率
- **confidence**: high

## 步骤逻辑
1. 差额 = 城镇 - 农村 = 农村×倍差 - 农村 = 农村×(倍差-1)
2. (倍差-1) 就是增长率，所以差额 = 基期量 × 增长率
3. 不需要分别求城镇和农村再相减，一步到位
4. 两年差额之差可用因式分解或"一加一减"技巧简化（如两数幅度接近10%以内可互调使一个因数相等，提公因式后减法更简单）

## 高频错因
- 分别算城镇和农村再做减法，步骤多容易出错
- 忘记倍差不减一（求"值"时直接乘倍差，求"差额"时才减一）
- 思维惯性：前面题减一，后面不减一时也跟着减一
