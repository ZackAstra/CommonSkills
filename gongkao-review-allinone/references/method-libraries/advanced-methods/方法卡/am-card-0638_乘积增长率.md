# 方法卡：乘积增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘积增长率 |
| 适用题型 | 资料分析——求总产量、总收入等乘积量的增长率（材料未直接给出） |
| 触发场景 | 题目问某乘积量（如总产量=单产×面积、收入=销量×单价）的增长率；材料中有占比图 |
| 步骤逻辑 | ① 识别：找不着量→想表达式→A=B×C→乘积增长率；或"有占比想乘积"；② 确定R1、R2（谁先谁后无所谓）；③ 套公式：R = R1 + R2 + R1×R2；④ R1×R2通常很小可估算 |
| 高频错因 | 混淆比值和乘积；忘记R1×R2项 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 公式与间隔增长率相同：R = R1 + R2 + R1×R2。两种考法：①有实际含义（总产量=单产×面积）；②部分=整体×占比（材料有占比图时）。识别口诀："有占比想乘积"。R1×R2一般很小（两个10%相乘才1%），可先算R1+R2看选项是否能直接选。
