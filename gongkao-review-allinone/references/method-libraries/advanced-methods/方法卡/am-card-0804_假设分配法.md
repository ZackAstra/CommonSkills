# 方法卡：假设分配法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配法 |
| 适用题型 | 资料分析——已知现期和增长率，求基期和增长量 |
| 触发场景 | 增长率较小（约30%以下），或一道题需求多个基期/多个增长量 |
| 步骤逻辑 | ① 分配第一步：给"师傅"（基期）分一个整数（如分800），用该数×增长率算出"徒弟"（增量）（如800×8%=64），现期-已分=余数；② 分配第二步：对余数取整修正（参照10%/5%/20%快速估），师傅减/加调整，徒弟对应增/减；③ 余数极小（个位）则略过不分；④ 最终基期和增量同时得出 |
| 高频错因 | ① 用乘法由一份求基期导致误差放大（应用减法：b-x）；② 余数小时仍纠结细分，拖慢速度；③ 下降时忘把增量写负 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

师傅=基期，徒弟=增量，挣的钱=现期，分配比例=增长率。核心思想"抓大放小"：第一步分大头，第二步修正余数，余数越小误差越可控。与四幺五的区别：四幺五依赖精确分数，假设分配适用于任何近似增长率。实际考试中第二步往往"略"即可，因选项间距通常容许个位误差。增长率超过30%时余数中徒弟占比变大，需配合四幺五或平分修正，见"高增长率平分法"卡。
