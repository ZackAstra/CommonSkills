# 方法卡：前提假设-否定代入法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提假设-否定代入法 |
| 适用题型 | 判断推理-逻辑判断-前提假设类 |
| 触发场景 | 题目问"哪项是所需假设""哪项是前提"，选项难以直接判断时 |
| 步骤逻辑 | 1. 对选项做否定 2. 若否定后结论不成立→该选项是必要前提，可选 3. 若否定后结论仍可成立→该选项只是"有它更好"，不选 |
| 高频错因 | 把"有它更好"（加强题答案）当成前提假设答案；忽略前提假设选的是必要条件而非充分条件 |

| confidence | high |

## 补充说明

前提假设类的正确答案是必要条件，不是充分条件。否定代入法是验证手段：把选项否定后看结论还能不能成立。"没它不行"=必要条件=正确答案；"有它更好"=充分条件=一般加强题答案，不能选。
