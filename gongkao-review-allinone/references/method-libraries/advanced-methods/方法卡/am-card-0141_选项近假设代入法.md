# 方法卡：选项近假设代入法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 选项近假设代入法 |
| 适用题型 | 资料分析·求基期/增量（选项差距极小，≤10%） |
| 触发场景 | 算基期或增量时发现ABCD数值非常接近（差距约1%），直除/假设分配都费时 |
| 步骤逻辑 | 1. 观察选项差距，确认差距极小（≤10%） 2. 随意选一个好算的选项当基期值 3. 用假设基期×实际增率算出近似增量 4. 用现期减增量得近似基期，匹配选项 |
| 高频错因 | 误认为必须精算基期；不敢大胆假设；不先看选项就盲目直除 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第1题中选项差距仅约1%。讲解中解释了原理：选项最大差值(1690-1630=60)乘以增率8.4%产生的误差仅约5，而选项间距至少20，所以用任意选项值代入算增量再反推基期是完全可靠的。选1670是因为1670≈1/6000便于口算。核心要点：选项越近，代入越安全，因为小差距乘以小增率产生的误差更小。
