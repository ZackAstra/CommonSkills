# 方法卡：有效数字快速判断

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 有效数字快速判断 |
| 适用题型 | 资料分析——除法/乘法选择题，选项量级一致 |
| 触发场景 | 选项在同一量级（如都是几千或都是几十），首位或第二位不同，不需要精确计算 |
| 步骤逻辑 | ① 观察选项是否在同一量级；② 若是，只保留2~3位有效数字做运算；③ 不管单位和小数点；④ 匹配选项的有效数字 |
| 高频错因 | 误判选项量级差异导致方向错误；有效数字精度不够选错选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

学习材料多次强调"不用管量级"：第12题（23:57）15万÷4，选项都是三万几；第14题（28:15）349÷6.5，选项间距大；第19题（48:30）479÷301，选项都是几千。核心原则：当选项量级一致时，只关注有效数字差异即可快速作答。
