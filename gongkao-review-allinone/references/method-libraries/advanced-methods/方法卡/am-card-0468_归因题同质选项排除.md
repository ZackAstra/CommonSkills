# 归因题同质选项排除

- **方法名**: 归因题同质选项排除
- **适用题型**: 判断推理 > 削弱质疑（归因题/对比实验归因）
- **触发场景**: 题干将结果归因于X，选项中有两个都提出"另有他因"且质疑角度类似（各针对一个子群体）
- **步骤逻辑**:
  1. 先看是否有选项提出"另有他因"（针对不同子群体分别质疑）
  2. 若有两个选项质疑方式同质（如A质疑AB型、C质疑O型，都是用个体差异而非血型来解释），则同质选项一起排除
  3. 寻找更根本的质疑——直接否定此因（如"蚊子选目标跟血型无关"）
  4. 否定此因 > 另有他因（片面）；否定此因更全面
- **高频错因**: 看到一个"另有他因"就觉得有力，没发现还有另一个同质选项；未比较力度就选
