# 方法卡：盐水精算-假设分配求基期增量

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水精算-假设分配求基期增量 |
| 适用题型 | 资料分析——盐水混合（已知城镇/农村增速求总体增速，或类似两部分混合求整体） |
| 触发场景 | ① 判定为盐水题型；② 选项差距极小（如B和C仅差1%），居中+偏向+现期替代均无法区分；③ 必须精算 |
| 步骤逻辑 | ① 判定题型：给部分增速求整体增速→盐水；② 观察选项差距，若极小则排除估算路径；③ 对每个部分分别做假设分配，同时求出基期A和增量X；④ 总增量=X1+X2，总基期=A1+A2；⑤ 整体增速=总增量/总基期，精算首位锁定答案 |
| 高频错因 | ① 选项差距小却仍用现期替代估算，导致精度不够选错；② 假设分配后忘记还原量级（如19.3写成193未还原为23.5）；③ 第一题错导致第四题连环错 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

盐水题约六七成可通过居中+偏向直接秒，二三成用十字交叉/线段可解，仅极少数需精算。精算时假设分配的优势在于一步同时得到A和X，避免多次计算。此方法适用于选项差距在0.5%以内的高难度盐水题。
