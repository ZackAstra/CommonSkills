# 趋势法比较比值大小

## 字段

| 字段 | 内容 |
|------|------|
| **方法名** | 趋势法比较比值大小 |
| **适用题型** | 资料分析 - 比重/比值排序题 |
| **触发场景** | 给多个指标的基期值和增速，要求按某个比值（如占总体比重）由大到小排序 |
| **步骤逻辑** | 1. 比值 = 部分 / 整体，整体相同时直接比部分大小即可<br>2. 部分不同时，看部分的基期值和增速的相对关系<br>3. 分子增得快（增速更高）则分数变大，分母增得快则分数变小<br>4. 只需比较分子增速与分母增速的差异趋势，无需精确计算 |
| **高频错因** | 拿现期值直接比大小而不考虑增速对趋势的影响；误以为增速大则比值一定大 |
| **来源文件** | internal-source |
| **confidence** | high |
