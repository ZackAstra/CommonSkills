# 方法卡：乘积增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 乘积增长率 |
| 适用题型 | 资料分析——求乘积关系量的增长率（如总产量=面积×单产，收入=单价×销量，部分=整体×占比） |
| 触发场景 | 题目要求的增长率对应一个量，材料中找不到该量，但能表达为两个已知量的乘积 A=B×C |
| 步骤逻辑 | ① 想表达式确认是A=B×C形式；② 找R1、R2（乘积里谁是R1无所谓，因为公式对称）；③ 套公式 R = R1 + R2 + R1×R2；④ 乘积项通常很小，选项远时可不算 |
| 高频错因 | R1×R2的符号搞错（正×负=负，负×负=正）；和比值增长率的公式混淆 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

与间隔增长率公式完全相同但含义不同。两种常见题型：(1)有实际含义的乘法关系（总产量=面积×单产，出口总额=出口量×均价）；(2)部分=整体×占比（材料有比重表格时求某部分增长率）。R1和R2作用对称，谁先谁后无所谓。两百分数相乘的速算：把一个换成小数消百分号，另一个百分号留作单位。
