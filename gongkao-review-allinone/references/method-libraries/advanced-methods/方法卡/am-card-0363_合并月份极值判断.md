# 合并月份极值判断

## 字段

| 字段 | 内容 |
|------|------|
| **方法名** | 合并月份极值判断 |
| **适用题型** | 资料分析 - 查找比较类 |
| **触发场景** | 材料中1-2月合并为一个数据，问某指标最低/最高月份在哪个季度 |
| **步骤逻辑** | 1. 将1-2月合计数除以2，得到月均值<br>2. 月均值一定介于两个月之间（一大一小或两相同）<br>3. 无论哪种情况，至少有一个月 ≤ 月均值<br>4. 用月均值与其他单月数据比较，判断极值归属 |
| **高频错因** | 忽略1-2月是合计数，误以为是一个月的数据直接参与比较 |
| **来源文件** | internal-source |
| **confidence** | high |
