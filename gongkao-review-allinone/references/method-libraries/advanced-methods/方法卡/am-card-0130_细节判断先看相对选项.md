# 方法卡：细节判断先看相对选项

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节判断先看相对选项 |
| 适用题型 | 言语理解-细节判断题（原文相符/不符） |
| 触发场景 | 做细节判断题时，先扫描选项找最可能正确/错误的选项 |
| 步骤逻辑 | 1. 先看选项找有比较/对比表述的（如"高于""先于""重于""升华"） 2. 有对比表述的选项错误概率高 3. 找正确答案时，优先看用词最"相对/委婉"的选项 4. 找错误答案时，优先看有比较/绝对化表述的选项 |
| 高频错因 | 直接逐个比对原文，浪费时间；或者不敢选委婉选项、轻易选了有对比的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第9题（爱国观念历史演变）中，B"爱国观念是忠贞思想的进一步升华"和C"先于且忠于且重于"都含对比/比较表述。强化方法直接判断"这两个选项错的概率很高，先看AD"。第11题（书法与长寿）中A"书法家的寿命要高于普通人"和C"专注度要求更高"同理。先看相对选项、跳过有比较的选项，是细节题的快速筛选策略。注意："升华""高于""重于"等比较级词汇在原文如果没有明确对应，大概率是错误选项。
