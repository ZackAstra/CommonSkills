# 方法卡：跨年难度趋势判断法
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 跨年难度趋势判断法 |
| 适用题型 | 资料分析 / 省考难度波动分析、备考心态调整 |
| 触发场景 | 想知道某省明年会更难还是更简单；或对历年行测难度变化做判断时 |
| 步骤逻辑 | 1. 收集同一省份连续多年进面分段占比数据<br>2. 观察80+/70-80/60-70/60-各分段的占比走势<br>3. 占比上升=该年偏简单，占比下降=该年偏难<br>4. 得出结论：难度没有单调趋势，在波动中变化 |
| 高频错因 | 用一两年数据线性外推"越来越难"或"越来越简单"；忽略每年出题组会回调的机制 |
| 来源文件 | internal-source|
| confidence | high |
## 补充说明
词义辨析用山东23-26四年数据做示范：23年正常→24年极难（70+仅143人/3.1万）→25年回升→26年又简单。核心观点：今年某省考得简单，明年命题组很可能回调加难度；今年考得特别难，明年可能放松。不存在"越来越难"或"越来越简单"的长期趋势。竞争压力增大是因为报考人数增加，不是题目变难。
