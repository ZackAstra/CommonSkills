# 指标公式化与乘积增长率

## 基本信息
- **方法名**: 指标公式化与乘积增长率
- **适用题型**: 资料分析 - 增长率（间接指标）
- **触发场景**: 题目问的指标在材料中找不到，但能通过相关指标的乘积/比值表示出来（如"城镇收入"由"农村收入×倍差"表示），且需求增长率
- **confidence**: high

## 步骤逻辑
1. 找不到指标 → 找与其相关的 → 用公式表示（加减乘除关系）
2. 若指标 = A × B，则增长率 R = RA + RB + RA×RB（乘积增长率公式）
3. 分别算两个相关指标的增速，代入公式
4. 若 RA 和 RB 都较小，乘积项 RA×RB 可忽略

## 高频错因
- 找不到指标就慌，想不到去找相关指标
- 将乘积关系误认为比值关系，用错公式
- 倍差的增速方向搞反（倍差下降应取负值）
