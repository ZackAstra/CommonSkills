# 乘积增长率识别法

## 适用题型
资料分析-日均产量/进口量等"日均"类材料的月度增长率

## 触发场景
材料给出"日均"数据，题目要求月度（当月）增长率或环比增长率

## 步骤逻辑
1. 识别公式：月产量 = 日均产量 × 天数
2. 这是两个因子的乘积，月产量的增速用乘积增长率公式：R = R1 + R2 + R1×R2
3. R1 = 日均的增长率，R2 = 天数的增长率
4. 天数增长率：30天→31天 = +3.3%，31天→30天 = -3.3%（即 1/30）
5. 两个 R 叠加即可，R1×R2 通常很小可忽略
6. 日均材料（原油产量/进口量/加工量）几乎必考此知识点

## 高频错因
- 直接用日均的增长率当月增长率，忽略天数变化
- 用同比增长率代替环比增长率
- 不知道 1/30 ≈ 3.3% 这个常用值
