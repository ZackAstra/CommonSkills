# 容斥交集最大最小法

## 适用题型
资料分析-调查问卷/百分比材料中"既A又B"的占比范围

## 触发场景
题目问"既愿意X又倾向于Y"的人占比范围；或给出多个百分比选项判断交集区间

## 步骤逻辑
1. 交集**最大值** = min(A, B)，即让小的完全被大的包含
2. 交集**最小值** = A + B - 100%（两者尽量远离时的最小重叠）
3. 若最小值为负数，说明交集可以为零（两者可以不重叠）
4. 用文氏图辅助理解：圈越大越可能包含另一个圈
5. 江苏省考常考此类题型，连续多年出现

## 高频错因
- 最小值公式记反（不是 |A-B|，是 A+B-100%）
- 混淆"不在同一整体"的百分比（不同人群的百分比可以直接相加超过100%）
