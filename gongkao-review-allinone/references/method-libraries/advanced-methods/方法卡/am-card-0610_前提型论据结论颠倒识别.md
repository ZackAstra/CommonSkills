# 方法卡：前提型论据结论颠倒识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提型论据结论颠倒识别 |
| 适用题型 | 判断推理——前提假设类（行文逻辑反常） |
| 触发场景 | 按原文顺序读，论据推出结论的逻辑不通顺（如"雅思重要→英语水平不够不录取"） |
| 步骤逻辑 | ① 按顺序读完后发现推导逻辑不通；② 尝试颠倒：前面变成结论，后面变成论据；③ 确认颠倒后逻辑成立（"英语水平不够→不录取"为论据，推出"雅思重要"为结论）；④ 此时再找论据与结论之间的断点，正常搭桥 |
| 高频错因 | 机械按原文顺序认定论据结论，导致断点识别错误；忽略"英语水平"这一突兀关键词 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

颠倒后：论据"英语水平不达标→不录用"，结论"雅思成绩很重要"。断点在"英语水平"与"雅思成绩"之间，选"雅思成绩能反映英语水平"搭桥。
