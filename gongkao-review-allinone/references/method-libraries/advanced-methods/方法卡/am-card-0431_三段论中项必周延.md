# 方法卡：三段论-中项必周延

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 三段论-中项必周延 |
| 适用题型 | 判断推理-逻辑判断-三段论 |
| 触发场景 | 三段论题目中，前三项判断（量词/肯否/主体）无法排除所有错误选项时，用周延做终极排除 |
| 步骤逻辑 | 1. 找中项：结论中没有出现的那个项 2. 判断周延：被"所有"或"不是"修饰→周延；被"有些"或"是"修饰→不周延 3. 中项必须至少在一处被周延，否则排除该选项 |
| 高频错因 | 不理解周延的定义；把"有些A是B"中的B当成周延了 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

背诵口诀：中项=结论中没出现的项；周延=被"所有"或"不是"修饰过。实际做题时，前三项排除法通常已够用，周延是最后兜底手段。理解困难可以先死记硬背，用多了自然理解。
