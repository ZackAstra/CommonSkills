# 方法卡：由大引小抓小话题

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 由大引小抓小话题 |
| 适用题型 | 言语理解——中心理解题 |
| 触发场景 | 文段开头讲一个大话题（如"传记"），后文用"正是""然而"等引导语将话题缩小到具体子话题（如"中国古典传记"），且尾句用强调词或指代词总结 |
| 步骤逻辑 | ① 识别文段是否"由大引小"：开头话题范围大，后面通过强调词/转折缩小到具体话题；② 小话题才是文段重点论述的对象，选项主题词应选小话题而非大话题；③ 区分"由大引小"和"举例"：由大引小的尾句有强调词（如"正是"），且小话题是文段最终的落脚点 |
| 高频错因 | 选了大话题的选项（出处有误/背景段）；误把"由大引小"当成"举例子"，导致选错主题词；选项用"最为"等绝对化表述（如"最为生动的记载"） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第4题(00:19:43)是典型例题：文段从"传记"引到"中国古典传记"，尾句用"正是"强调"中国古典传记"的生命活力展现。A选项说"传记"主题词过大且用了"最为"的绝对化表述，B选项精准选了"中国古典传记"作为主题词。注意区分"由大引小"和"例子"：例子不会有强调词放在尾句，也不会用"正是"来总结。
