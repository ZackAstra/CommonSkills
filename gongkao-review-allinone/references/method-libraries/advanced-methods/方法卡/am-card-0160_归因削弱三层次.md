# 方法卡：归因削弱三层次——否定因果/因果倒置/举反例

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 归因削弱三层次——否定因果/因果倒置/举反例 |
| 适用题型 | 判断推理——削弱类（因果归因型论证，含对比实验） |
| 触发场景 | 结论为"A导致B"或"A是B的原因"，需要削弱因果关系 |
| 步骤逻辑 | ① 否定因果（最强，极少出现）：直接断开因果联系，如"巨大火山形成和重力、频率无关"；② 因果倒置（力度很大）：把因和果反过来，如"不是学习时长导致兴趣高，而是兴趣高才导致学习时长长"；③ 举反例——无因有果/有因无果（力度较弱，最常见）：如金星重力相近但火山不高，实际检验因是否真正成立。出题人倾向用举反例，因力度弱需要辨别 |
| 高频错因 | 把"有因无果"看反成"无因无果"导致加强（如金星重力相近≠重力低，实际是无因无果的加强）；忽略因果倒置选项，选了力度更弱的举反例 |

| confidence | high |

## 补充说明

因果倒置力度通常大于他因削弱和举反例。第14题（学习时长→语文成绩）：D选项"兴趣高的学生才乐意花时间学语文"是因果倒置，力度强于C选项（他因削弱）。注意：归因题中的"只有才"不要翻译为形式逻辑推理关系，应理解为因果关系。
