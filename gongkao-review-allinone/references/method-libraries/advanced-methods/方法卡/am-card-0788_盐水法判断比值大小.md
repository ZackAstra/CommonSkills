# 方法卡：盐水法判断比值大小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水法判断比值大小 |
| 适用题型 | 资料分析-综合分析题/比值大小判断-判断混合后比值是否超过某阈值 |
| 触发场景 | 题目给出两组数据混合后的比值，需快速判断是否大于/小于某个常见比例（如75%） |
| 步骤逻辑 | 1. 将分子分母拆成两部分：一部分恰好等于目标比例，另一部分单独看 2. 如(3300+13)/(4400+85)，3300/4400恰好=75% 3. 单看第二部分13/85不到75%，混合后会拉低整体 4. 因此最终比值不到75%；反之若第二部分高于阈值则整体会上升 |
| 高频错因 | 拆分后两部分比例关系判断错误；忘记混合稀释/浓缩的方向 |

| confidence | medium |

## 补充说明

强化方法用盐水浓度和打游戏胜率做比喻：一大杯浓度75%的盐水掺一小杯不到75%的盐水，混合后浓度一定低于75%。同理，前4400局赢3300局（胜率75%），后85局只赢13局（胜率远低于75%），总胜率必然下降。反之，若后28局赢了26局（胜率超75%），总胜率就会上升。该方法主要用于综合分析题的第五小题，快速判断"是否超过X%"类问题，无需精确计算。
