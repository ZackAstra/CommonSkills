# 方法卡：预设答案避免逐项比对

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 预设答案避免逐项比对 |
| 适用题型 | 言语理解-中心理解题 |
| 触发场景 | 抓到主旨后，面对四个选项需要快速筛选时 |
| 步骤逻辑 | 1. 读完文段后先根据主旨预设答案方向（如"对策表述"） 2. 用预设方向快速扫描选项，形式不符的直接排除 3. 不要逐个分析每个选项"为什么对/为什么错" 4. 只在剩余选项中做最终比较 |
| 高频错因 | 不预设答案，逐个分析选项，把中心理解题做成细节判断题，浪费时间且容易被无中生有选项迷惑 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第2题中C选项"共享经济时代在线教育将成为一种常态"完全是无中生有，但如果逐项分析就会浪费时间去全文搜索。强化方法说："你要是去判断这个C为什么错，你还得带进去全部看一遍，你会发现根本就没写这个C。"预设答案是中心理解题和细节判断题的本质区别——中心理解题先抓主旨再匹配选项，而不是像细节判断题那样逐项比对原文。
