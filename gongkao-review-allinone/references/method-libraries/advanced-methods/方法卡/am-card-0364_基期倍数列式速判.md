# 基期倍数列式速判

## 字段

| 字段 | 内容 |
|------|------|
| **方法名** | 基期倍数列式速判 |
| **适用题型** | 资料分析 - 两个指标的基期倍数判断 |
| **触发场景** | 已知A和B的现期值及各自增速，问A是B的几倍（基期口径） |
| **步骤逻辑** | 1. 列式：(A/B) × (1+rB)/(1+rA)<br>2. 先判断 A/B 的大致范围（大于1还是小于1）<br>3. 再判断 (1+rB)/(1+rA) 是否大于1<br>4. 两部分相乘后快速判断整体范围，结合选项选最近值 |
| **高频错因** | 拿现期倍数直接当基期倍数，忽略增速差异对倍数的修正 |
| **来源文件** | internal-source |
| **confidence** | high |
