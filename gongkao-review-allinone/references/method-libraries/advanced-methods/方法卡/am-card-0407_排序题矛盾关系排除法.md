# 方法卡：排序题矛盾关系排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 排序题矛盾关系排除法 |
| 适用题型 | 语句排序题 |
| 触发场景 | 两个句子内容存在矛盾/对立关系（一个说"很多人推测有很大差异"，另一个说"只有一个主要区别"），需判断谁先谁后 |
| 步骤逻辑 | ① 先找首句（排除有明确衔接词、依赖其他句子内容的选项）；② 若两个句子存在矛盾关系，先判断哪句是"引出旧认知"、哪句是"纠正/细化"——旧认知在前，纠正其后（"很多人推测有差异"在前→"其实只有一个主要区别"在后）；③ 用连接词验证顺序（"不仅…还…"=先5后6）；④ 用层次分析排除（若某句内容属于更高层次，不能放在低层次内容前面作为过渡） |
| 高频错因 | 把"不仅…还…"的过渡句误当首句；把矛盾关系的两句话顺序搞反（先讲结论再讲旧认知就不通顺）；没注意句间的内容层次（文化层面的句子不能被"武功"包含） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

排序题的三个排除层次：① 首句排除（有衔接词的不能当首句）；② 矛盾关系定先后（旧认知→新认知）；③ 内容层次验证（文化层面的句子不能归入武功层面）。第16题中"不仅是一种武功更是一种传统文化"看似能做过渡句，但后面的内容（道法自然、恬淡宁静）属于文化层面而非武功层面，无法承上启下。
