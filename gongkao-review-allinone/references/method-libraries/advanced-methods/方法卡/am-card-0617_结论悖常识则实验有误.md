# 方法卡：结论悖常识则实验有误

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 结论悖常识则实验有误 |
| 适用题型 | 判断推理——削弱/质疑（结论明显违反常识） |
| 触发场景 | 实验结论如"努力完全没有意义""能力只由基因决定"等明显违背常识 |
| 步骤逻辑 | ① 结论有悖常识 → 100%实验做错了；② 往选项中找实验本身的问题（测量方式、样本选取等）；③ 与实验无关的选项（如讲个体心理偏差）直接排除 |
| 高频错因 | 被选项的"看起来相关"迷惑（如D"能力差的个体会低估练习时间"跟实验本身无关）；选了讨论基因但未质疑实验方案的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

题中实验用手指模拟快节奏测音乐能力，而手指灵活性受遗传影响（双胞胎差不多），导致结果相同不代表能力相同。另有共因：两组结果相同可能是共同的其他因素（如测量方式天花板效应），而非能力无差异。
