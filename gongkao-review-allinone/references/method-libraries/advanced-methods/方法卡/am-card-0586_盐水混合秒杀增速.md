# 方法卡：盐水混合秒杀增速

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 盐水混合秒杀增速 |
| 适用题型 | 资料分析——求另一部分增速；判断哪个季度/区间增速最高 |
| 触发场景 | 已知总体增速和其中一个部分增速，求另一部分增速；或给出每月增速，问哪个季度增速最高 |
| 步骤逻辑 | ① 判定题型：总体由两部分混合而成→盐水模型；② 先求已知部分的量（总体-另一部分），用量之比+距离之比求解；③ 对于"哪个季度增速最高"：混合增速介于成分增速之间，混合增速最大的季度直接秒杀（因为只有它能把混合增速拉到最高） |
| 高频错因 | 混合增速介于两成分增速之间，但忘了混合增速离量大的一方更近；判断季度时不需要逐月精算，看混合增速在哪最高即可 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

盐水模型是词义辨析体系的核心工具之一。第6题用盐水求另一部分增速：总体240/增速0.4%，三产231/增速1%，得1~2产量9，再用份数比例求增速（负14.6%）。第9题则是直接看三个季度各自的混合增速，哪个最大就选哪个——这是盐水的秒杀用法。
