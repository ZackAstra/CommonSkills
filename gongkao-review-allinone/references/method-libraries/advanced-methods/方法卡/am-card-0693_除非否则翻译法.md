# 方法卡：除非否则翻译法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 除非否则翻译法 |
| 适用题型 | 逻辑判断——翻译推理题（涉及"除非...否则..."句式） |
| 触发场景 | 题干或选项出现"除非A否则B""A否则B""必须A否则B"等表述 |
| 步骤逻辑 | ① 记忆口诀：否A则B（谜底在谜面上）；② "除非A否则B"翻译成非A推B；③ "A否则B"翻译成非A推B（把A插到否则中间，变成否A则B）；④ "必须A否则B"="除非A否则B"=非A推B |
| 高频错因 | 把"除非否则"翻译成A推B（方向搞反）；记不住口诀 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 除非否则翻译的关键是"否A则B"。例如："除非努力，否则考不上"=不努力→考不上。"必须努力，否则考不上"=不努力→考不上。"努力吧，否则考不上"=不努力→考不上。三种说法一个意思。注意：除非和必须在这个句式里可以互换。
