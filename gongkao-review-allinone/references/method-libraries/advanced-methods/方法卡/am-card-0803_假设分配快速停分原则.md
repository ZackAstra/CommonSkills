# 方法卡：假设分配快速停分原则

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配快速停分原则 |
| 适用题型 | 资料分析——假设分配法的效率优化 |
| 触发场景 | 假设分配第一步完成后余数很小（个位数），需判断是否继续细分 |
| 步骤逻辑 | ① 第一步分完后余数个位（如剩4、剩2），直接略过不分，全给"师傅"（基期）；② 余数的百分之几（增量部分）已经微乎其微，不影响选项判断；③ 把精度控制力放在最后一步，中间步骤该略就略 |
| 高频错因 | 余数小时仍纠结细分，反而拖慢速度且误差不会显著改善 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

讲解中用"直除类比"解释：直除时最后个位也不会算完，假设分配同理。判断标准是"能不能选出正确答案"而非"算得绝对精确"。在选项差距大的题中，甚至第二步整个略过都可以直接选答案。
