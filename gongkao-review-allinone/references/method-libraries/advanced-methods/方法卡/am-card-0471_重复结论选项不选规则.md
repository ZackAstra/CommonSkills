# 重复结论选项不选规则

- **方法名**: 重复结论选项不选规则
- **适用题型**: 判断推理 > 支持/质疑（力度比较）
- **触发场景**: 选项内容与题干结论高度重合（换了说法本质一样）；需区分支持题和质疑题
- **步骤逻辑**:
  1. 最能支持题：重复论据/重复结论的选项一般不选，力度不够，通常有更强选项
  2. 不能支持题：重复结论虽力度弱，但仍算"有一定支持力度"，强于无关项（无关=0），一般也不选
  3. 类比支持：通过举例类比来支持，力度也弱，最能不能支持题和不能支持题一般都不选
  4. 关键区分：弱力度（有）vs 无关项（零），不能支持题应选无关项而非弱力度
- **高频错因**: 把"重复结论不能选"死记硬背，不区分支持题和质疑题的语境
