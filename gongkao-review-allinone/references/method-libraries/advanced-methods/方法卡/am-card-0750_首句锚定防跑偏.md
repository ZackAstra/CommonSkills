# 方法卡：首句锚定防跑偏

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 首句锚定防跑偏 |
| 适用题型 | 言语理解——片段阅读（主旨/意图题） |
| 触发场景 | 文段后部出现强关联词（但是、因此、所以），容易被带跑偏而忽略首句已确立的重点方向 |
| 步骤逻辑 | ① 读首句时就确立方向——判断首句是对策、问题还是背景引入；② 如果首句已含对策（前对策结构），锚定此处，后续关联词只是补充说明或免责提示；③ 后文的"但是+因此"双重Buff不代表就是文段重点，需结合整体行文脉络判断 |
| 高频错因 | 被后文强关联词（"但是""因此"）双重叠加带跑偏，放弃首句锚定的方向；没有先判断首句就随波逐流读完全文 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

"免责声明"现象：文段先给出对策建议，后文用"但是"补充说明该方法有局限性、需要和别的方法印证——此时主要意图仍是推荐该方法，补充说明只是提醒谨慎使用。不要因为最后几句话就否定全文主旨。核心原则是"整体把握"而非"单纯看一个关联词"。
