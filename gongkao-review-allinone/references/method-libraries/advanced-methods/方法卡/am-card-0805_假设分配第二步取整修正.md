# 方法卡：假设分配第二步取整修正

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 假设分配第二步取整修正 |
| 适用题型 | 资料分析——假设分配法的第二步操作 |
| 触发场景 | 假设分配第一步完成后有余数待分，需快速决定第二步给"徒弟"多少 |
| 步骤逻辑 | ① 看余数，取参照率（5%/10%/20%）估算：如余34，实际r=8%<10%，用10%估得3.4→向下取整给3；② 若r>参照率则向上取整（如r=12%>10%，10%估得2.4→向上取3或4）；③ 余数极小（个位）直接略过不分 |
| 高频错因 | ① 搞反向上/向下方向（实际r大于参照率要向上取整）；② 余数小时仍细分小数点，拖慢速度 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

参照率是脑子里的"好算锚点"：1%、5%、10%、20%、50%。向上/向下取决于实际增长率与参照率的大小关系。不纠结最后差1~2，因为选项间距通常远大于此。讲解中提到："最后一步是要提速的"，该略就略。
