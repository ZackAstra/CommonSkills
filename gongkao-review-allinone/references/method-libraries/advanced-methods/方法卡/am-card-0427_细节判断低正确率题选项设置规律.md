# 方法卡：细节判断低正确率题选项设置规律

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节判断低正确率题选项设置规律 |
| 适用题型 | 言语理解——细节判断题 |
| 触发场景 | 做细节判断题时正确率偏低（60%以下），需判断哪项有致命错误 |
| 步骤逻辑 | ① 正确率高的细节题（70%+）错误选项很明确，其他选项完全没问题；② 正确率低的细节题（60%-）一定有一个选项有致命问题（故意设的陷阱），同时其他选项都有小瑕疵；③ 小瑕疵包括：表述稍显绝对、稍有无中生有、概念偷换不明显；④ 致命问题包括：违背常识、两句话杂糅、主语/客体偷换；⑤ 做题策略：先找致命问题项排除，再在有小瑕疵的选项中选"问题最小"的 |
| 高频错因 | 被小瑕疵选项"好像没说到"的疑虑吓退，反而选了有致命问题的选项；在两个都有瑕疵的选项间纠结，没意识到要按错误严重程度排序 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第2题（高清修复技术，正确率偏低）完美验证了这个规律。B选项"高清修复技术更新发展迅速"有致命问题——把"新技术不断发展让高清修复技术出现"杂糅成了"高清修复技术在快速发展"，属于偷换概念。同时A选项"是一种图像处理技术"和D选项"传统技术难以大批量修复老片"都有小瑕疵（原文表述不完全一致），但符合常识、没有致命错误。强化方法的核心洞察：出题人不会把致命错误选项单独设置——如果只有一项有问题、其他项都很完美，那正确率就高了。低正确率的题一定是"一重多轻"的选项格局。
