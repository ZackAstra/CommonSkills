# 方法卡：比重趋势比较

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比重趋势比较 |
| 适用题型 | 资料分析——比重升降判断、占比趋势比较 |
| 触发场景 | 问"占比是否高于上年同期""比重是否上升"，给出部分增速和总体增速 |
| 步骤逻辑 | ① 识别比重的分子（部分）和分母（总体）；② 找出分子增速和分母增速；③ 分子增速 > 分母增速 → 比重上升；分子增速 < 分母增速 → 比重下降 |
| 高频错因 | 把部分增速和总体增速搞反；多个指标时找错哪一个是分子、哪一个是分母 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

整个学习材料多次出现此方法（第1题 00:57~02:23，第9题 16:55~17:37），是资料分析最高频的比重题型。核心就一句话：比增速大小，不需要算具体比重值。
