# 方法卡：商人赔钱有利可图解释法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 商人赔钱有利可图解释法 |
| 适用题型 | 逻辑——解释说明类（题干问"为什么某企业/商家在亏损的情况下仍然坚持某业务"） |
| 触发场景 | 题干描述某项业务持续亏损，但商家始终不放弃，问最能解释此行为的选项 |
| 步骤逻辑 | ① 核心判断：商人逐利，赔钱还做必然"有利可图"——要么能带来未来利润，要么能带动其他盈利业务；② 排除"万能解释"：如"国家规定必须做""相信未来会好"这类解释力度弱的选项；③ 最优解释：捆绑销售/交叉补贴/引流效应——该项亏损业务能为其他高利润业务带来客户 |
| 高频错因 | 选"法律规定必须做"——虽然能解释为什么不放弃，但解释力弱且生硬，不如"通过捆绑其他盈利业务"有说服力；只看到题干说的亏损业务本身，忽略了整体商业布局 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

讲解中用交强险的例子说明：保险公司交强险亏损还坚持做，因为车主买交强险时通常同时购买商业险，商业险利润丰厚可以覆盖交强险亏损。类比：饭店亏本卖某个菜品是为了引流带动其他高利润菜品。做此类题要"站在一定高度上看问题"——不要只盯着亏损业务本身，要看整体利益格局。
