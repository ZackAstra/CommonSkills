# 方法卡：科普介绍四大选项类型排除法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 科普介绍四大选项类型排除法 |
| 适用题型 | 言语理解——主旨题（科普介绍类文段） |
| 触发场景 | 文段为科普介绍类（介绍某事物的特点/原理/关系，无对策），选项中出现原因类、具体类、区别比较联系类、历程类四种类型时 |
| 步骤逻辑 | ① 判断文段为科普介绍类（无对策，纯介绍）；② 选项若属于四大类型之一，需要匹配对应文段结构才能选：原因类——文段在分析因果；具体类——文段有具体细节展开；区别比较联系类——文段有双主语对比；历程类——文段有清晰时间轴；③ 若选项类型与文段结构不匹配，直接排除；④ 特别注意：历程类选项（讲"起源与发展"）基本都是陪跑，除非原文有清晰的时间发展脉络 |
| 高频错因 | 看到选项"听起来合理"就选，不验证选项类型是否匹配文段结构；选了历程类选项而原文没有时间轴 |

## 补充说明

第5题（数学家可遇不可求）是典型：选项A"解释数学家可遇不可求的现象"属于原因类，而文段全篇在分析"为什么数学家可遇不可求"（天赋+抵制诱惑），文段是因、选项是果，完全匹配。选项B"说明天赋对于数学研究的意义"只对应一方面，片面。选项D"强调基础数学发展面临的困境"是历程类的变体，原文根本没谈发展困境。第15题（围棋与太极文化）中，选项D"围棋的起源与发展"是典型历程类陪跑选项，原文没有时间轴，直接排除。强化方法指出：这四大类型选项在科普介绍类中经常作为干扰项出现，掌握它们的匹配条件能快速排除。
