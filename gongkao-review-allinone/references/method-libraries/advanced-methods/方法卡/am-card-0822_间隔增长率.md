# 方法卡：间隔增长率

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 间隔增长率 |
| 适用题型 | 资料分析——两年时间间隔的增长率（如18年比16年） |
| 触发场景 | 题目中比较的两个时间点隔了一年（或一个间隔），如"22年比20年""18年3月比16年3月"；选项是百分数 |
| 步骤逻辑 | ① 画三个时间点小图（如18→17→16）；② 找R1（近段增速）和R2（远段增速）；③ 套公式 R = R1 + R2 + R1×R2；④ 两个百分数相乘：把一个换成小数或分数，消一个百分号 |
| 高频错因 | 忘记R1×R2项；负增长率时负负得正搞错符号；两个时间间隔不等时误判不能用 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

R1和R2的作用完全对称，谁先谁后无所谓。两个时间间隔不需要相等（如1月→4月→12月也行），但需要三个连续时间点。R1×R2通常很小，有时即使不算也能排除选项（如两段相加已超过最大选项）。负增长时特别注意符号：(-R1)+(-R2)+(-R1)×(-R2)，最后一项负负得正。
