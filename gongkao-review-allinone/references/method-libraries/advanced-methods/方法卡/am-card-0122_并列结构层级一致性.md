# 方法卡：并列结构层级一致性

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 并列结构层级一致性 |
| 适用题型 | 言语理解-语句填入/排序题/中心理解题 |
| 触发场景 | 文段中出现分号、"并列""一方面...另一方面""除了...除了..."等并列标志时 |
| 步骤逻辑 | 1. 识别并列结构的标志（分号、相同句式、并列关联词） 2. 判断并列的两句话层级是否一致（同一逻辑层面、同一话题角度） 3. 层级不一致的不能构成并列 4. 语句填入题中，填入内容须与并列的另一部分在话题和结构上平行 5. 排序题中，并列的两部分必须紧邻且层级对等 |
| 高频错因 | 仅从语感判断流畅性，忽略并列的两部分必须在不同层面/角度，不能重复同一话题 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

强化方法在第2题（举例论证中的并列）、第5题（语句填入，分号表并列）、第16题（排序）中反复使用此方法。第16题是典型案例：选项C将"不能减少座椅数量"与"座椅数量要满足客流量需要"并列，两部分都在讲座椅数量，不符合"层级一致"要求，因此错。而选项A将"首要功能满足休息需要"与"座椅数量满足客流量需要"并列，是不同功能层面，层级一致。排序题中尤其要注意：语感读通不代表结构正确，必须从结构层面判断。
