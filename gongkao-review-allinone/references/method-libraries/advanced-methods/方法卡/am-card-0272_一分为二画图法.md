# 方法卡：一分为二画图法

- **方法名**：一分为二画图法
- **适用题型**：集合关系推理题（所有A都是B / 所有C都不是B）
- **触发场景**：题干出现"所有A都是B"且"所有C都不是B"的对立陈述时
- **步骤逻辑**：
  1. 找到题干中的一对对立判断：如"所有A都是B" vs "所有C都不是B"
  2. 以B和非B为界画一条竖线，左右分为两个区域
  3. 左侧写"是B"的集合（A在这里），右侧写"非B"的集合
  4. 内部再根据题干条件标注子集关系（如好友圈、咨询公司圈）
  5. 对不确定位置的人画在线上（骑墙派）
  6. 根据选项判断各人物所在区域
- **高频错因**：画实线表示范围已确定，导致被题目条件反推翻；不确定的范围应用虚线或画在线上
- **来源文件**：source-0039.md
- **confidence**：high

补充说明：核心思路是抓住一个二分标准（如喜欢/不喜欢）将所有人分类到两个区域，再根据每个人的具体条件确定其位置。虚线表示不确定的范围边界，骑墙派（可能在A也可能在B）画在线上表示位置不确定。
