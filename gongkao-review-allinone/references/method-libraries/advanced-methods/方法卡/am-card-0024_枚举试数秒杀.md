# 方法卡：枚举试数秒杀
## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 枚举试数秒杀 |
| 适用题型 | 数量关系-各类可枚举的题型（几何花盆、三角形计数等） |
| 触发场景 | 看起来是难题但选项数据少（几十个数以内）且枚举思路清晰 |
| 步骤逻辑 | 1.判断选项数据量是否可枚举 2.建立枚举框架（如三角形从最长边开始向下枚举） 3.逐一验证约束条件（如三角形两边之和大于第三边） 4.汇总计数 |
| 高频错因 | 枚举时遗漏或重复；不懂得按顺序系统枚举 |

| confidence | high |
## 补充说明
讲解中演示：最长边为9的整数三角形，从999开始向下枚举，99x有9种，98x有7种，97x有5种，96x有3种，95x有1种，等差数列9+7+5+3+1=25。花盆问题同理：枚举三角形数和平方数找差为9的一对。核心原则：方程不一定会解，但试数无脑可行。
