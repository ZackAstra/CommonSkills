# 方法卡：一分为二画图法（所有/有些推理）

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 一分为二画图法（所有/有些推理） |
| 适用题型 | 判断推理——翻译推理类（含"所有""有些"的推理题） |
| 触发场景 | 题干给出多条"所有A都是B""有些A是B"类命题，问哪项能/不能推出 |
| 步骤逻辑 | ① 用"所有A都是B"的B（如"不精通印尼语"）画线一分为二，分为B区域和非B区域；② 将每句话涉及的集合逐个标注到图中（圈的位置按包含/交叉/互斥关系确定）；③ "所有A都是B"→A整个圈在B区域内；"有些A是B"→虚线圈与B有交叉；④ 画完图后，看选项能否在图中找到对应实例（小人），能找到则可推出，找不到则推不出；⑤ 逆否命题同真同假，可辅助定位 |
| 高频错因 | 逐句逐选项组合尝试，浪费时间且易遗漏；画图时忘记用逆否命题补充信息；不确定"推不出"还是"我没推出"而纠结 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

Q17为此方法典型应用。五句话涉及英语、印尼语、西班牙语、韩语四语种关系。画图后四个选项一眼可判断：A(小绿)、C(小紫)、D(小兰)均可在图中找到实例，B在印尼语区域中找不到"不精通西班牙语"的例子故推不出。比逐句组合法快得多。
