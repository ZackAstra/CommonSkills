# 方法卡：前观点加反面论证等于总分总

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前观点加反面论证等于总分总 |
| 适用题型 | 言语理解-中心理解题/语句填入题 |
| 触发场景 | 文段第一句提出明确观点，中间出现与该观点对立的新话题（反面），最后一句回归观点 |
| 步骤逻辑 | 1. 识别第一句是否为明确观点（如"翻译工作需要工匠精神"） 2. 判断中间部分是否为反面论证（新话题与前观点对立） 3. 若是反面论证，该部分为"分"，非重点 4. 前观点即为主旨，最后一句往往会"回扣"该观点 5. 选项选回扣前观点的表述 |
| 高频错因 | 把反面论证中的新话题当成主旨，选了出自有误出处的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第6题（翻译与工匠精神）是典型示范。第一句提出"翻译工作需要工匠精神"（前观点），中间讲"快餐式翻译和人工智能翻译"，这与工匠精神完全对立，属于反面论证。强化方法强调判断方法：如果中间新话题与前观点是相反/对立关系，则为反面论证，目的是支撑前观点（"没有工匠精神的不行"），而非提出新观点。最后用"所以"回扣主旨。此结构很常见，"前观点喜欢在最后再回扣一下"。
