# 方法卡：因果结构最佳选项法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 因果结构最佳选项法 |
| 适用题型 | 言语理解——主旨概括（果因/因果结构文段） |
| 触发场景 | 文段结构为"先讲结果/现象→后分析原因"或"先说原因→得出结果"时，选择最佳概括选项 |
| 步骤逻辑 | ① 判断文段是否为果因或因果结构；② 最佳选项应同时体现"果"和"因"——格式为"某某结果的原因"或"某某现象的成因"；③ 只体现果的选项不够（漏了原因）；④ 只体现因的选项也不够（漏了结果）；⑤ 若无完美选项，优先选有"原因"二字的，因为"原因"二字可概括散落的多个原因点 |
| 高频错因 | 只选体现结果的选项（如"人类认知能力有优势"），忽略了大篇幅的原因分析；把因果结构的引出语（如"人脑究竟有什么独到之处"）当成重点，而非后面真正的分析 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

- "原因"两个字可以概括散落在文段各处的多个原因点，即使原因分散，用"原因"一词就全部概括进来了。
- 因果结构中的引出语（如"有什么独到之处"）是设问/承上启下，不是重点——后面的解释才是重点。
- 背景中出现的因果词汇不等于正文重点。例如首句提到"加强伦理规范研究"，但这只是背景，正文的问题才是重点。
