# 方法卡：另有他因vs解释说明区分法

- **方法名**：另有他因vs解释说明区分法
- **适用题型**：归因类论证题（支持/削弱）
- **触发场景**：题干给出因果关系（A导致B），选项看似在说另一个因素C
- **步骤逻辑**：
  1. 看选项中C因素与A因素的关系——是A导致C（链条关系）还是A和C并列存在
  2. 若A→C→B（如玩手机→睡眠不足→情绪问题），这是**解释说明**，本质在解释因果链条，支持因果
  3. 若A和C同时存在且互不导致（如长时间玩手机的人**同时**睡眠不足），这是**另有他因**，削弱因果
  4. 关键判断：C因素是由A导致的？还是与A并列独立存在的？
- **高频错因**：把解释说明（链条关系）误当成另有他因（并列关系），选错削弱项
- **来源文件**：source-0038.md
- **confidence**：high

> 补充：用糖尿病类比帮助理解——"玩手机导致睡眠不足导致情绪问题"是链条解释，支持原因果；"玩手机的人同时还不睡觉"是另有他因，削弱原因果。区分核心在于C是A的结果还是A的"同伴"。
