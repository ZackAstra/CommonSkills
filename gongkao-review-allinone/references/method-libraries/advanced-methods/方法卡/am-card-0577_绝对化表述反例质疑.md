# 方法卡：绝对化表述反例质疑

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 绝对化表述反例质疑 |
| 适用题型 | 加强削弱——题干结论含"不可避免""迅速""一定会"等绝对化表述 |
| 触发场景 | 题干断言某事物"不可避免的迅速淡出"，选项中出现一个看似微小但实际覆盖了题干断言范围的反例 |
| 步骤逻辑 | ① 识别题干的绝对化表述（不可避免/迅速/所有）；② 绝对化表述只需一个反例即可被削弱，力度很强；③ 看选项是否有严谨性加码（如"近几年不会更新换代""扮演重要角色"）——这恰恰是出题人为了让你觉得"太小了不敢选"而设的干扰；④ 类比类选项（过去经历住了冲击→将来也行）力度极低，排除 |
| 高频错因 | 觉得反例太小（如"自动售货机"）不敢选，不知道绝对化表述下一个反例力度就很强；把类比质疑当成有效削弱（"以前储蓄卡也没替代硬币"=过去≠将来，力度极低） |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第16题核心：题干"硬币不可避免的迅速淡出"=绝对化。D选项"自动售货机只支持硬币且近几年不会换"=一个反例即够。选项加码"扮演重要角色""近几年不会更新换代"不是让力度变弱，而是出题人设的心理干扰。B选项（储蓄卡时代也这样预测）=类比=过去经验不适用于新情况，力度极低。C选项（面值不高方便找零）=说明过去的流通原因，但信用卡和移动支付不需要找零，帮不上忙。
