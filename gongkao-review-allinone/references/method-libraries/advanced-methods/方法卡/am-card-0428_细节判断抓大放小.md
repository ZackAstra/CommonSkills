# 方法卡：细节判断抓大放小

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 细节判断抓大放小 |
| 适用题型 | 言语理解——细节判断题（偏难题） |
| 触发场景 | 四个选项中，一个有严重错误（违背常识/原文矛盾），另一个只是稍有瑕疵（轻微无中生有/表述不够精确但符合常理） |
| 步骤逻辑 | ① 偏难细节判断常设"一重一轻"两个有瑕疵的选项；② 重瑕疵：违背常识、与原文直接矛盾、故意设置的陷阱；③ 轻瑕疵：稍有过度推断或表述不够精确，但完全符合常理常识；④ 选重瑕疵的那个作为错误项（即排除它），轻瑕疵选项若无致命问题可作为答案；⑤ 判断标准：哪个错得更严重、更不可原谅 |
| 高频错因 | 纠结于"选项好像没原文原话"而排除了符合常识的正确选项；选了"看起来有出处但实际偷换概念"的严重错误项 |

| confidence | high |

## 补充说明

第2题是典型例题。B选项"高清修复技术更新发展迅速"犯了杂糅错误（把"新技术不断发展"和"高清修复技术出现"拼接），属于严重错误。A选项"是一种图像处理技术"虽然原文没有原话，但完全符合常识（高清修复本质就是图像处理）。强化方法强调：偏难细节判断只要正确率偏低，就一定有一个选项有致命问题、其他选项有瑕疵的设置。出题人逻辑：致命错误项已经这么明显了，其他选项就不会设置得很完美，否则没有区分度。"正确率低的细节题一定有一个严重错误项+几个有小瑕疵但符合常理的选项"是核心判据。
