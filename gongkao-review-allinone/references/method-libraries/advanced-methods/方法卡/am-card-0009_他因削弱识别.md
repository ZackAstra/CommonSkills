# 方法卡：他因削弱的识别

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 他因削弱的识别与判断 |
| 适用题型 | 判断推理——削弱加强类（他因削弱） |
| 触发场景 | 题目为因果类论证（A导致B），选项中出现"另有他因"式削弱 |
| 步骤逻辑 | ① 识别因果论证：题干结论中存在因果关系；② 区分他因削弱与无关项：他因削弱必须指出另一个可能导致结果的原因，且该原因与原论证的因构成竞争关系；③ 判断标准：实验类论证中，他因削弱表现为"实验未控制变量"——存在另一个未被控制的变量也影响了结果；④ 排除：不是归因的题不能谈因果 |
| 高频错因 | 将"另有他因"与"因果倒置"混淆；将非因果类论证误判为因果类，错误使用他因削弱 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

"实验没控制变量"是他因削弱的经典表述。例如：实验组改善了空气质量，但同时改善了公共交通，到底哪个导致了结果改善？这就是他因削弱。
