# 方法卡：以偏概全归谬质疑

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 以偏概全归谬质疑 |
| 适用题型 | 加强削弱——题干由个别案例推出普遍结论，或结论含"一个国家""所有"等绝对化表述 |
| 触发场景 | 题干举了一个例子（如中国加入WTO后经济增长）就推出一般性结论（加入WTO对一个国家有加速作用），问哪个最能质疑 |
| 步骤逻辑 | ① 识别逻辑漏洞：以偏概全（个例→普遍）；② 找反例选项：其他国家加入WTO后经济增速无明显变化；③ 判断BD是否为同质选项（同为他因类削弱），若同质则一起排除；④ 慎重对待"同时发生"——时间同时不是削弱而是支持（效果立竿见影） |
| 高频错因 | 选了"中国经济增长与加入WTO几乎同时发生"（实际是支持选项）；选了同质他因选项中的一个却没意识到另一个也能选 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第15题核心：中国一个例子→"一个国家"的一般结论=以偏概全。C选项举印度、巴西反例直接命中漏洞。B和D都是"其他因素（技术/市场/资本）推动中国经济"=他因，同质选项，要选都选要排除都排除。同质选项判断法：选了B却选不了D就说明B也不该选。另外，"同时发生"不是削弱——恰好同时说明WTO效果立竿见影，是支持。
