# 用历史趋势质疑当前数据

- **方法名**: 用历史趋势质疑当前数据
- **适用题型**: 判断推理 > 削弱质疑（措施有效性归因）
- **触发场景**: 题干称"采取措施后某指标上涨X%"，归功于该措施
- **步骤逻辑**:
  1. 题干漏洞：只看今年vs去年，没看历史趋势
  2. 质疑方向：过去N年每年都涨X%以上，今年只涨了X%，说明措施可能无效甚至拖后腿
  3. 选项含时间跨度（近5年/均/每一年）是关键信号词——保证质疑力度
  4. 否定此因（整体上可能没用）> 另有他因（只是其中一个原因）> 细节质疑
- **高频错因**: 被另有他因（如新机器）干扰，忽略更根本的否定此因；不看选项中的时间跨度信号词
- **来源文件**: internal-source
- **confidence**: high
