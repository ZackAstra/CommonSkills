# 方法卡：高位叠加

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 高位叠加 |
| 适用题型 | 资料分析-加法-多个数字求和 |
| 触发场景 | 三个及以上数字相加，需要快速求和时 |
| 步骤逻辑 | 1. 不抄数，从最左边（千位/百位）开始逐位相加 2. 每位结果像楼梯台阶一样错开写（千位结果后补三个零的位置感） 3. 利用等差数列等技巧加速中间位计算 4. 加到足够区分选项时即可停止，不必精确到个位 |
| 高频错因 | 错位书写时对齐错误；不习惯从左往右加导致思维混乱 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

高位叠加是强化方法从2012-2013年就开始教授的方法。核心优势有三：1）不用抄数，省去把五六个数字重新抄写的时间；2）减少进位干扰；3）可以在中途停下来，根据选项设置灵活取舍。课上演示了实际做题时可以加到百位后，把零头凑成几个整百，再结合选项快速锁定答案。熟练后可以比尾数法更灵活地在任意位截断。
