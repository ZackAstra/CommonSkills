# 方法卡：前提题优先级——搭桥>修补漏洞>必要条件

| 字段 | 内容 |
|------|------|
| 方法名 | 前提题优先级——搭桥>修补漏洞>必要条件 |
| 适用题型 | 逻辑判断——前提假设题 |
| 触发场景 | 多个选项都看似可以当前提，需按优先级排序择优 |
| 步骤逻辑 | 1. 第一优先：搭桥——连接论据和结论中断开的概念（断点处直接建桥） |
| | 2. 第二优先：修补漏洞——补充论据中缺失的隐含条件 |
| | 3. 第三优先：必要条件——结论成立的最低限度必要前提 |
| | 4. 排除"完美条件"——力度过强的充分条件不是前提（如"所有人都被抓到"不是"罚款有效"的前提） |
| 高频错因 | ①选了完美条件当前提（力度越强越好的错误思维）②有搭桥时不选搭桥，去选其他类型 |
| 来源文件 | source-0070.md |
| confidence | high |

**补充说明：**
- 前提=必要条件，不是充分条件。完美条件（如"所有人全上岸"对应"一半以上上岸"）是充分条件，力度过强，不是前提。
- 否定代入法验证前提：否定搭桥/修补漏洞/必要条件→结论不成立→确认是前提；否定完美条件→结论仍可成立→排除。
