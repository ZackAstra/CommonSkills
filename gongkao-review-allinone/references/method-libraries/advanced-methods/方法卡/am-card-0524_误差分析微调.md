# 方法卡：误差分析微调

## 基本信息
| 字段 | 值 |
|------|-----|
| 方法名 | 误差分析微调 |
| 适用题型 | 资料分析-估算后结果卡在两个选项之间 |
| 触发场景 | 粗算结果落在两个选项边界附近，无法直接判断 |
| 步骤逻辑 | 1. 明确近似取值的方向（把32.4%当成33.3%，降幅扩大）<br>2. 推导近似对中间结果的影响方向（降幅扩大→增量算大→基期算大）<br>3. 反向修正最终结果（减去的基期偏大→最终结果应偏大）<br>4. 根据修正方向选择正确选项 |
| 高频错因 | 忽略近似方向导致修正方向反了；不确定哪些量是精确的哪些有误差 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明
- 误差分析的核心逻辑链：近似方向 → 中间量偏移方向 → 最终结果偏移方向。
- 本例中，-32.4%被近似为-33.3%（降幅扩大），导致增量（下降量）被算大，基期被算大，最终1月数据=总量-3月-2月（2月被高估）→结果应比粗算值略大。
- 误差分析通常只需判断"大一点"或"小一点"，不需要精确修正数值。
