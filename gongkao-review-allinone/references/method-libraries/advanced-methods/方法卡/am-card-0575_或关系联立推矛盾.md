# 方法卡：或关系联立推矛盾

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 或关系联立推矛盾 |
| 适用题型 | 形式推理——多个"或"条件联立，要求推出必然结论 |
| 触发场景 | 条件①为"教育或生态至少投资其一"（A或B），条件②的前提为"至少一种不投资"（非A或非B），且条件②的后件与条件①的前件有重叠（如"投资生态"） |
| 步骤逻辑 | ① 写出条件①：A或B→结论C；② 写出条件②：非A或非B→(D且非E)；③ 观察条件②后件中的D是否能启动条件①的前件（如"投资生态"触发"教育或生态"）；④ 若能则直接联立，不需要逆否；⑤ 联立后若推出矛盾（如同时要投资和不投资人工智能），则说明条件②前提不成立；⑥ 非A或非B不成立 → A且B（教育且医药必然投资） |
| 高频错因 | 机械逆否第一个条件（把A或B逆否为非A且非B），而忽略了可以直接联立；或者推出矛盾后不知道该否定哪一步 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第3题核心：条件②"非教育或非医药→投资生态且非人工智能"，其中"投资生态"能启动条件①的前件。联立后：非教育且投资生态→推出投资人工智能（由条件①），但条件②又要求非人工智能→矛盾。因此"非教育"不成立，教育必然投资，进而由条件①推出人工智能和能源也投资。最终四个领域：教育、医药、人工智能、能源均为必然投资。
