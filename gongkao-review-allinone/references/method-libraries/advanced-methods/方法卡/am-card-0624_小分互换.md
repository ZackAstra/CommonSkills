# 方法卡：小分互换

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 小分互换 |
| 适用题型 | 资料分析——乘法中乘数为常见百分比（25%、33.3%、12.5%等） |
| 触发场景 | 看到乘以常见百分比时，换成分数变成除法 |
| 步骤逻辑 | ① 将百分比换成分数（如25%=1/4）；② 乘法变除法（如×25%变成÷4）；③ 只关注有效数字，忽略量级 |
| 高频错因 | 常用分数对应百分比记错；过度关注量级浪费时间 |
| 来源文件 | internal-source|
| confidence | medium |

## 补充说明

[?] 需记忆的常用对应：50%=1/2，33.3%=1/3，25%=1/4，20%=1/5，16.7%=1/6，14.3%=1/7，12.5%=1/8，11.1%=1/9，2/7=28.6%，3/7=42.9%。乘以25时也应想到÷4，因为资料分析99%的情况不需要关注量级。
