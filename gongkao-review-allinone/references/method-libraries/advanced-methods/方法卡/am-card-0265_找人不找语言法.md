# 方法卡：找人不找语言法

- **方法名**：找人不找语言法（逆向等价思维）
- **适用题型**：条件匹配/多人多语言共通题
- **触发场景**：问"三个人都会说的语言是什么"；条件给出的是谁会说什么、谁不会说什么
- **步骤逻辑**：
  1. 问法问的是语言，但直接找语言很难（需逐个尝试）
  2. 逆向思考：语言是人说的，找到"哪三个人有共语"即可用排除法确定语言
  3. 利用条件中"甲丙需要翻译"→甲丙无共语→三人不能同时含甲丙→只剩甲乙丁或乙丙丁
  4. 条件"乙丙丁谈不到一起"→排除乙丙丁→三人只能是甲乙丁
  5. 用"乙不会说英语""丁不会说日语"等条件排除语言选项
- **高频错因**：被问法带偏，执着于找语言本身，画表逐个试，浪费大量时间
- **来源文件**：source-0038.md
- **confidence**：high

> 补充：核心是逻辑等价转换——"找语言"等价于"找人"。问法改变时要警惕解题方向：如果问"可以推出"可能要画表，但问"三个人都会说的语言"则应先找人再排除语言。画表太慢，思路切题点才是提速关键。
