# 方法卡：对比时间归因回归时间法

- **方法名**：对比时间归因回归时间法
- **适用题型**：归因类论证题（支持/削弱），涉及时间前后对比
- **触发场景**：题干通过时间对比得出因果结论（如去年A，今年B，所以某因素导致B）；问削弱/最不能削弱
- **步骤逻辑**：
  1. 识别题干是否在做时间对比归因（过去vs现在）
  2. 要削弱该归因，他因选项**必须回归时间**才有力度
  3. 若他因选项未涉及时间变化（如"一直存在"的因素），则无法解释"为什么现在和过去不同"
  4. 直接用"回归时间"检验：选项是否能回答"之前也这样，为什么现在变了？"
- **高频错因**：选了看似有道理但他因没有回归时间的选项（如"一直存在"的因素），无法解释时间差异
- **来源文件**：source-0038.md
- **confidence**：high

> 补充：Q9中"许多业主认为它一直存在"——如果一直存在，为什么去年和今年有变化？无法解释时间差异，所以不能削弱。正确削弱选项必须能解释"去年和今年为何不同"。
