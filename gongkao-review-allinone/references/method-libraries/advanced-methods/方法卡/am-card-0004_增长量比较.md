# 方法卡：增长量比较——大大则大与一大一小看倍数

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 增长量比较：大大则大与一大一小看倍数 |
| 适用题型 | 资料分析——比较增长量大小 |
| 触发场景 | 题目给出多个主体的现期值（B）和增长率（R），要求比较增长量（X）大小 |
| 步骤逻辑 | ① 第一步：大大则大——若 B 大且 R 大，则 X 一定大，可直接判定；② 第二步：一大一小看倍数——若一个主体 B 更大但 R 更小，比较两者的倍数关系：计算 B 的倍数和 R 的倍数，若 R 的倍数能覆盖 B 的倍数差（考虑分母 1+R），则可判断大小 |
| 高频错因 | 未考虑增长量公式中分母 (1+R) 的影响，直接用 B×R 而非 B×R/(1+R) 比较；忽略倍数关系而仅凭直觉判断 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

此方法适用于所有增长量比较题型，是资料分析中最基础的比较口诀。当选项中出现"一大一小"（即一个主体现期值大但增长率小）的情况时，需要用倍数关系进一步判断。
