# 方法卡：削峰填谷判断平均数

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 削峰填谷判断平均数 |
| 适用题型 | 资料分析——判断多个数的平均值是否超过/低于某个特定值 |
| 触发场景 | 给出多年数据，问年均值是否超过某数，不需要精确计算 |
| 步骤逻辑 | ① 假设目标值为平均数；② 算每个数据与目标值的差值（多的为正，少的为负）；③ 比较正差之和与负差之和：正多则平均数高于目标值，负多则低于 |
| 高频错因 | 习惯性把所有数加起来除以个数，浪费时间；忘记比较正负差值的大小关系 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

例：四个年份收入数据，判断年均是否超过5800。以5800为基准，分别算差值——某年多了17，某年少了19，某年少了9，某年多了15。少的总量（28）大于多的总量（32...实际上此例中多的少），判断即可出结果。无需逐个加总再除。
