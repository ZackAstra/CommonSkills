# 盐水三排序法

## 适用题型
资料分析-已知两部分增长率和整体增长率，推断另一部分大小关系

## 触发场景
材料给出上半年增速、一季度增速，问二季度增速与一季度的关系；或任何"整体由两部分构成"的增长率排序问题

## 步骤逻辑
1. 整体增长率一定在两个部分之间（加权平均）
2. 将整体值放在中间，标出已知部分的位置
3. 整体 > A → 整体 < B（B 的增速快才能把整体拉高）
4. 整体 < A → 整体 > B（B 的增速慢才被 A 拉高）
5. 知道任意两个的大小关系，就能推第三个
6. 若问"B 是否大于 A"：只需看整体在 A 的哪一侧即可

## 高频错因
- 误以为整体增长率是简单的算术平均
- 不知道"整体一定在中间"这个核心原则
