# 方法卡：接语题抓背景加新

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 接语题抓背景加新 |
| 适用题型 | 言语理解-接语选择题（下文推断题） |
| 触发场景 | 最后一句出现"以前""过去""之前"等时态标记，暗示下文应转向"现在/新的变化" |
| 步骤逻辑 | 1. 直接看最后一句 2. 发现末句有"以前/之前"等时态对比标志 3. 下文必然要讲"现在/新"的变化 4. 选项中找带"新"字或体现变化的表述 5. 同时注意话题一致性：新内容必须围绕文段主题 |
| 高频错因 | 只抓"新"忽略话题一致性，选了话题跑偏的选项 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第18题（城市形象传播/短学习材料）是典型示范。最后一句"在短学习材料出现之前"出现时态标记，暗示下文要讲短学习材料出现之后的新变化。选项B"新的传播形式"和D"新景象"都带"新"，但B缺少"城市"这个核心话题词（被出题人故意删掉来迷惑），D"城市形象传播在短学习材料新势力下的新景象"既带"新"又保持了话题一致。强化方法强调这是"背景+新"结构的固定考法，在第二套卷子中就讲过。
