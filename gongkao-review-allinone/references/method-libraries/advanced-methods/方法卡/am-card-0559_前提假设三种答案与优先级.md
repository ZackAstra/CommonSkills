# 方法卡：前提假设三种答案与优先级

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 前提假设三种答案与优先级 |
| 适用题型 | 判断推理——前提假设类 |
| 触发场景 | 题目问"补充以下哪项前提""基于哪项假设"等 |
| 步骤逻辑 | ① 读完题干判断论据与论点是否有关联性；② 三种正确答案按优先级依次选择：断点搭桥（论据与论点无逻辑关联时，在两者之间搭桥）> 修补漏洞（论据论点看似有关联但暗含因果方向等漏洞时补上）> 必要条件（既无断点也无漏洞时，选"没有它一定不行"的选项）；③ 若三种同时出现，优先选搭桥 |
| 高频错因 | 选了普通支持而非必要前提；在有断点或漏洞时去选必要条件；纠结选项细节而忽略题型对应的答案模式 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

第1题（格陵兰岛蛇纹石）为断点搭桥典型——"蛇纹石"与"海底大陆"无关联，需搭桥"蛇纹石由板块挤压海底大陆形成"。附加题（狗镁离子）为修补漏洞典型——论据有因果方向漏洞（镁离子是因还是果），需补"焦虑症不会使镁离子升高"。第7题（电影节评比）为必要条件典型——论据论点无明显漏洞，需"每部影片都能分到某一类型"作为前提。
