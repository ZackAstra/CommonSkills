# 方法卡：单位带入计算

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 单位带入计算 |
| 适用题型 | 资料分析·涉及单位换算的计算题（如万元/亩、元/平方米） |
| 触发场景 | 看到题目中要求的单位与材料单位不一致，特别是"每亩""每公顷"等母单位 |
| 步骤逻辑 | 1. 计算时把原始单位带在数字旁边 2. 逐个换算直到与题目要求单位一致 3. 确认右边单位=题目要求单位后才开始算数值 |
| 高频错因 | 忘记换算直接用原始单位数除；1公顷=15亩没记住；万和亿混用 |

| confidence | high |

## 补充说明

第7题出让单价=成交价÷面积，材料给的是"亿元/万公顷"，要求"万元/亩"。讲解中演示：5.89亿=58900万，26万公顷=26×15=390万亩，58900÷390≈151万元/亩。正确率低于50%的题型往往与单位有关。必须背的换算：1公顷=15亩。
