# 方法卡：分割谬误识别法

- **方法名**：分割谬误识别法
- **适用题型**：推理方式/论证结构相似题（类比推理）
- **触发场景**：题干甲说"XX群体有Y特征"，乙用个体反驳；问哪项对话方式最相似
- **步骤逻辑**：
  1. 识别题干中甲的表述是**集合概念**（如"杭州人美""人们没信仰"），描述的是群体整体特征
  2. 乙把集合概念**误解为每个个体都有该特征**，然后用个例反驳
  3. 这种错误叫**分割谬误**：集合特征 ≠ 个体特征
  4. 在选项中找同样的结构：集合表述→误解为个体→个例反驳
  5. 排除不含此结构的选项（如"你的受贿金额"是个体非集合；"别人"虽是集合但乙没把它当个体处理）
- **高频错因**：把"偷换概念"当万能答案；无法区分分割谬误和话题转移、类比不当等其他逻辑错误

- **confidence**：high

> 补充：Q18关键区分——D选项"影响别人"中乙说"你不是别人"，乙并未把"别人"这个集合理解为每个人，而是认为"你"不在"别人"这个集合中，所以不是分割谬误。C选项"人们没信仰"→乙说"你就是人，你有信仰"，乙把"人们"理解为每个人，从集合中挑了个例反驳，是分割谬误。
