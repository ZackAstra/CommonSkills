# 方法卡：比较要说两边法

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 比较要说两边法 |
| 适用题型 | 逻辑判断——支持/质疑题（涉及比较、竞争力、优劣） |
| 触发场景 | 题干结论涉及比较（如"竞争力下降""比XX更好""更可能"），需要支持或质疑 |
| 步骤逻辑 | ① 识别比较：题干结论是否涉及两个对象的比较；② 检查两边：选项是否同时涉及比较的双方；③ 只说一边不够：如"H国竞争力下降"需同时说H国和"其他国家"的情况 |
| 高频错因 | 选项只说了比较的一边（如只说H国原材料上涨，没说其他国家如何）；选了"大家都一样"的选项（无法区分优劣） |

## 补充说明

[?] 比较要说两边是支持/质疑题的重要原则。例如：题干说"H国原材料上涨→竞争力下降"，要支持需说"其他国家通过创新保持低价"（两边都说到）。只说H国上涨不够，因为如果全世界都上涨，H国竞争力不变。类似：题干说"简单题做错了→竞争力下降"，需说"竞争对手做对了"（两边）。
