# 方法卡：包子法计算占比

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 包子法计算占比 |
| 适用题型 | 资料分析——求某部分占总体的百分比 |
| 触发场景 | 需要算占比，选项差异较大或需要判断是否超过某个阈值（如5%、90%） |
| 步骤逻辑 | ① 统一分子分母单位；② 算分母的1%（一个包子）；③ 看分子里有多少个包子 → 即为百分之几；④ 对比选项 |
| 高频错因 | 单位不统一导致计算错误；对阈值（如5%）判断不准 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

学习材料中多次使用（第2题 03:17~03:51，第10题 19:18~20:53，第17题 43:00）。核心是把"占比"转化为"看分子里面有多少个分母的1%"，口算即可。例：1788 里有多少个 336？超5个 → 大于5%。
