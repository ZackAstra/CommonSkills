# 方法卡：真假分析题从假推真

## 基本信息

| 字段 | 值 |
|------|-----|
| 方法名 | 真假分析题从假推真 |
| 适用题型 | 判断推理——真假分析（已知真假话数量，推理事实） |
| 触发场景 | 题目给出若干人说的话，告知其中有几句真话几句假话，要求推出实际情况 |
| 步骤逻辑 | ① 找矛盾：先找出互为矛盾的两个命题（必一真一假）；② 利用已知真假数：若告知"只有一句真话"，而矛盾对中必有一真，则其他命题全为假；③ 从假推真：假的命题不能直接用，必须先找其矛盾命题（即为真），再用真命题往下推；④ 推出矛盾→确定真假→推出事实 |
| 高频错因 | 假命题直接往下推而不先找矛盾变为真；忘记"推出必须是已知真推"的原则 |
| 来源文件 | internal-source|
| confidence | high |

## 补充说明

"推出必须是已知真为真"是逻辑推理的基本原则。假命题推出的任何结论都不可靠，必须先通过矛盾关系将假命题转化为真命题。
