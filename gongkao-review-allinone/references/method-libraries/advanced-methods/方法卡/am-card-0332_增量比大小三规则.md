# 增量比大小三规则

| 字段 | 内容 |
|------|------|
| **方法名** | 增量比大小三规则 |
| **适用题型** | 资料分析 - 增量（增长量）比较 |
| **触发场景** | 需要比较多个部分的增量大小，如贡献率最低/最高的选择题 |
| **步骤逻辑** | 1. **B大R大则X大**：基数B大且增速R大 → 增量X一定更大（与增速大小无关）<br>2. **一大一小看倍数**：一个B大R小、另一个B小R大 → 分别算B的倍数和R的倍数，倍数更大的那个X更大<br>3. **两倍时看B**：B和R的倍数相同（如都是2倍）→ 基数B更大的X更大<br>4. 实操：先排除明显不符合的选项，再用倍数关系二选一 |
| **高频错因** | ①一大一小时只看增速不看倍数 ②混淆"增量大"和"增速大" ③没意识到B的决定性更强 |
