# 强化方法库入口

> RedSkill 版：本包方法卡已剥离 source_quote/时间戳/来源类型；下文涉及 source_quote 的核验要求按历史/源仓字段理解，运行以方法论字段 + card id/文件名 source anchor 为准，禁止伪造。

这是强化方法（AdvancedMethods）的方法库，用于讲解、复盘和溯源强化方法的方法。

**这不是题库。** 如需词义辨析练习题，按 `artifacts/current/question-banks/templates/` 导入用户自备题库。

## 核心索引

- `按题型索引.md`：按模块（资料分析、判断推理、数量关系、言语理解）检索方法卡。
- `字段规范与批处理纪律.md`：方法卡字段定义、source_quote 规范、置信度规则。
- `去重索引.md`：29 组内容级重复的去重记录。

## 调用规则

1. **优先按题型查**：读 `按题型索引.md` 定位相关方法卡。
2. **方法依据以 source anchor 为准**：以方法卡方法论字段 + card id/文件名 source anchor 支撑；输出方法依据摘要 + source anchor（本包已剥离 source_quote，不要求逐句核验、禁止伪造）。
3. **低质量卡不得作为强依据**：`source_quote` 缺失、非原文、或超过 30 字的卡，不得作为"强化方法原方法"的强依据。可标注"疑似，待核"。
4. **低置信转写来源卡置信度上限 medium**：低置信转写来源的卡，如数字或术语存疑，必须标注"据转写材料，术语/数字待核"。
5. **无覆盖时说清楚**：如果方法库没有覆盖用户问的题型或方法，必须明确说"方法库无依据"，不得用通用常识冒充强化方法。
