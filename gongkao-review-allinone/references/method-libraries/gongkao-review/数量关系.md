# 数量关系

> RedSkill 版：本文方法要点由原始讲解转写提炼而成，已移除逐句转写原文与时间戳锚点；方法依据以本文方法论 + 文件名为 source anchor，禁止伪造转写或锚点。

## 适用场景
数学运算、数字推理等数量关系题目。适用于需要建立方程、代入验证、特值赋值、找规律的场景。

## 核心规则（方法要点）

### 倍数与特性
利用和倍/差倍关系、倍数特性缩小范围；蒙选项时若某量必为 3 的倍数（或其他倍数），可据此排除大半选项。

### 方程法
设未知数列方程求解；但方程较慢，能用代入、比例或份数解决时优先，不必硬列。

### 代入排除法
从选项代入题干验证，常比列方程快；优先代中间值或便于计算的特殊值，符合即选。

### 蒙题策略
时间不足时，先用奇偶性、倍数、尾数等排除部分选项再蒙，提高命中率；不纠缠难题。

### 尾数法
选项尾数不同时，只算个位/尾数即可定位答案，适用加减及尾数唯一的乘法。

### 数字推理
遇事不决先做差；熟记常见规律（等差、等比、和数列、平方/立方、质数）。

### 乘法技巧
拆分、凑整口算；若选项间存在明显乘法倍数关系，可直接利用。

### 估算技巧
线段法/粗估，按选项间距控制精度，差距大可粗估、差距小才精算。

### 资料分析相关速算
增长率、比重、基期、间隔增长率、百化分、截位直除等，见 `资料分析.md`，此处不重复。

## 高频错因
### 解法选择失误
- **表现**: 该代入排除却硬列方程，或该精算却乱蒙，导致超时或算错
- **原因**: 未先评估题目结构与选项特征就动笔
- **修正策略**: 先判断“代入/特值/方程/蒙题”哪种最快，再下手；难题果断跳过

## 判断流程
1. 读题判断题型（工程/行程/排列组合/利润等）
2. 选择解法：代入/特值/方程/蒙题
3. 计算或推理
4. 验证答案合理性
5. 不会则跳题或蒙题
