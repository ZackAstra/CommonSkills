# 按题型查方法

> RedSkill 版：本文为按题型导航索引，方法要点由原始讲解转写提炼而成，已移除逐句转写原文与时间戳锚点；方法依据以方法论 + 文件名为 source anchor，禁止伪造转写或锚点。

## 言语理解 → 见 `言语理解.md`
主旨找主题句（首尾句/转折后/对策句）；转折后是重点；并列要信息完整；细节理解防偷换（主体/范围/时间/程度）；主题词验证选项是否覆盖核心话题。

## 逻辑填空 → 见 `逻辑填空.md`
看空前空后语境，识别转折/递进/并列/对应；动宾·主谓·偏正搭配验证；感情色彩匹配；最有把握的空先排除。

## 资料分析 → 见 `资料分析.md` / `资料分析技巧索引.md`
增长率 = 现期/基期−1；基期 = 现期/(1+r)；比重升降看部分增速 vs 整体增速；间隔增长率 r1+r2+r1×r2；速算用截位直除/百化分/尾数法，按选项间距控精度。

## 数量关系 → 见 `数量关系.md`
优先代入排除/特值，其次方程；倍数、尾数、奇偶特性缩选项；时间不够用排除后蒙题。

## 判断推理 → 见 `判断推理.md`
图推先定规律再套选项；定义抓核心要件逐项比对；类比先定词间关系再二级辨析；逻辑翻译题干后代入验证。

## 错因诊断 → 见 `错因诊断.md`
按错因家族诊断：偷换概念、想太多（过度推理）、策略失误、词汇盲区、审题定位、计算估算失误。
