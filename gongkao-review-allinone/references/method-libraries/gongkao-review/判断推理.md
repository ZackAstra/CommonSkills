# 判断推理

> RedSkill 版：本文方法要点由原始讲解转写提炼而成，已移除逐句转写原文与时间戳锚点；方法依据以本文方法论 + 文件名为 source anchor，禁止伪造转写或锚点。

## 适用场景
图形推理、定义判断、类比推理、逻辑判断等判断推理题目。适用于需要分析图形规律、概念关系、逻辑结构的场景。

## 核心规则（方法要点）

### 图形推理
先看元素组成（数量/种类/位置/样式/属性），再定规律类型；常见考点：对称轴、旋转翻转、求同存异、数量关系（点线面）、封闭区域。规律先行，再套选项。

### 定义判断
提取定义核心要件（主体/对象/方式/目的/条件），逐项比对，缺要件即排除；不纠缠与要件无关的细节。

### 类比推理
先确定词间关系（并列/对应/包含/种属/属性/功能/语法），再做二级辨析；坚持主体一致、方向一致、关系一致。

### 逻辑判断
翻译题干为逻辑式后代入验证；削弱/加强先锁定论点与论据的缺口，再判断选项作用方向。

### 排除法
先排除明显不符主体、要件或词间关系的选项，再在剩余项中精比；推不出明确结论的直接排除。

## 高频错因
### 过度推理（想太多）
- **表现**: 脑补题干没有的信息，越想越偏，套“上帝视角”
- **修正策略**: 回归原文逐项验证；思路越简单越接近命题人

### 偷换概念
- **表现**: 选项把题干的主体/范围/顺序/时态悄悄替换
- **修正策略**: 逐字比对选项与题干，重点警惕范围、主体、时序偷换

## 判断流程
1. 图推：观察元素组成→看样式/位置/属性规律
2. 定义：提取核心要件→逐一对比选项
3. 类比：确定词间关系→二级辨析
4. 逻辑：翻译题干→代入验证
