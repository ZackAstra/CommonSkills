## 速算技巧一句话索引

- **增长率计算**：增长率 = 现期/基期 − 1；先判量级再决定是否精算。
- **比重计算**：比重 = 部分/整体；升降看“部分增速 vs 整体增速”。
- **倍数计算**：A 是 B 的几倍 = A/B；利用倍数关系缩选项。
- **增长量比较**：增长量 = 基期×增长率；基数大且增速大者最大。
- **误差控制**：差值/比重变化用基期算更准；估算前看选项间距能否容错。
- **基期计算**：基期 = 现期/(1+r)；多步题先求基期。
- **比重差计算**：两期比重差 ≈ 现期比重×(部分增速−整体增速)/(1+整体增速)。
- **间隔增长率**：r = r1 + r2 + r1×r2。
- **除法技巧**：能除则除，配合截位。
- **平均数计算**：平均数 = 总量/份数；区分平均数与平均数增长率。
- **估算技巧**：按选项间距控制精度。
- **年均增长率**：(末/初)^(1/n) − 1，可用总增长率÷n 近似或代入。
- **截位直除**：保留前几位有效数字直接相除。
- **两期比重**：部分增速大于整体则比重上升。
- **方程法**：能比例/份数就不列方程。
- **乘法技巧**：拆分凑整口算。
- **代入法**：选项代入公式验证。
- **现期值**：差值/比重变化优先用基期，少用现期。
- **百化分**：百分数化近似分数加速。
- **尾数法**：尾数不同只算个位定位。
- **放缩法**：分子分母同向加减使变整数，修正分数接近 1 时最优。
- **口算技巧**：练三位数加减与简单乘除。
- **蒙题策略**：用比例/尾数排除后再蒙。
- **混合增长率**：整体增速在两部分之间，偏向占比大者。
- **速算方法**：分析优先于硬算。
- **加减法**：三位数加减一开始就算准。
- **数字推理**：遇事不决先做差。
