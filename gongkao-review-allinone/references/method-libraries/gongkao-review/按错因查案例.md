# 按错因查案例

> RedSkill 版：本文方法要点由原始讲解转写提炼而成，已移除逐句转写证据与时间戳锚点；详细错因家族见 `错因诊断.md`，方法依据以方法论 + 文件名为 source anchor，禁止伪造转写或锚点。

## 按错因家族快速查修正策略

- **逻辑关系误判** → 遇到转折词（但/然而/却）立即标记转折后为重点；并列要信息完整。
- **审题定位失误** → 读题划出“时间/主体/单位/问法”四要素再作答。
- **蒙题/放弃策略** → 蒙题选表述最温和、限定最多的选项；难题超时果断跳过。
- **过度思考（想太多）** → 找到主旨句优先同义替换，不过度抠细节。
- **选项陷阱** → 逐项验证主体是否一致、范围是否偷换、程度是否匹配。
- **细节误读** → 圈出题干时间、单位、限定词后再回原文定位。
- **词汇盲区** → 不认识的词先降权，字面拆字 + 语境推断，平时积累生词。
- **计算/估算失误** → 资料题先确认时间/单位/主体再列式；按选项间距控精度。
- **策略失误** → 难题超过 2 分钟果断跳过，标记后回头再做。
- **主题词偷换** → 回到原文主题词，核对每个选项的主体是否一致。
