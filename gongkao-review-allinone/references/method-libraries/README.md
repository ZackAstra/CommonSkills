# Method Libraries

> RedSkill 版：本包方法卡已剥离 source_quote/时间戳/来源类型；下文涉及 source_quote 的核验要求按历史/源仓字段理解，运行以方法论字段 + card id/文件名 source anchor 为准，禁止伪造。

这里放综合方法库及底层方法分区，供复盘引擎和 skills 调用。

默认入口：[`综合方法库.md`](综合方法库.md)

质量门槛：[`方法质量规则.md`](方法质量规则.md)

使用时先看综合入口的动态择优规则，再到具体分区查候选方法，并按质量门槛筛选。不要写死某个分区优先。

| 目录 | 内容 |
|---|---|
| `gongkao-review/` | 公考复盘方法库 |
| `advanced-methods/` | 强化方法库 |
| `data-notes/` | 资料分析专项方法库 |

使用原则：

- 方法 claims 必须来自具体分区，以 source anchor（card id/文件名）支撑（本包已剥离 source_quote，不要求逐句核验）。
- 对用户输出“方法依据”摘要 + source anchor，默认不展示原始转写。
- A/B 级方法可作为讲解依据；C 级只作检索线索；D 级不采用。
- 如果多个分区都命中，按题型匹配度、依据质量、流程完整度、当前题适配度动态择优。
- 不能把通用模型推理冒充为方法库方法。
