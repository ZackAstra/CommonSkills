# 倍数与比例

## 适用题型

问 A 是 B 的几倍、A 比 B 多几倍、A 与 B 的比例、A 超过 B 的 n 倍、混合比例、平均数倍数。

## 方法卡

### 1. 倍数语言先翻译

```text
A 是 B 的 n 倍: A / B = n
A 与 B 的比例: A : B
A 比 B 多 n 倍: A / B - 1 = n
A 超过 B 的 n 倍: A > B × n
```

### 2. 现期倍数

先找 A、B，再算 `A/B`。如果问“多几倍”，最后要减 1。

### 3. 平均数倍数

平均数形如 `A/B`。两个平均数求倍数时:

```text
(A/B) ÷ (C/D) = (A/C) × (D/B)
```

优先约分，减少计算量。

### 4. 混合比例/盐水思想

总体比例落在两个部分比例之间，且偏向基期量/权重更大的一方。可用线段距离反推两个部分规模比。

## 高频错因

- “多 n 倍”忘记减 1。
- 把比例 `A:B` 当作 `A/B - 1`。
- 混合比例只判断范围，不判断偏向。
