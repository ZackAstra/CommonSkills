# 一般增长率

confidence: high

## 适用题型

资料分析中问增长率、增速、增幅、增长幅度、下降幅度、百分点变化、增长率比较。

## 触发场景

- 给现期和基期，求增长率。
- 给现期和增长量，求增长率。
- 给增长率和百分点，求另一期增长率。
- 比较多个对象的增长率大小。
- 图表中要求判断趋势、排序、查找个数、降幅比较。

## 方法卡

### 1. 基础概念

- 增长率可正可负。
- `增长 n 倍` 对应 `增长率 = n`；`是 n 倍` 对应 `增长率 = n - 1`。
- 百分数表示比例；百分点表示百分数的变化量。
- 增长幅度、下降幅度、变化幅度，本质都要先判断方向和绝对变化。

### 2. 增长率公式

```text
增长率 = 增长量 / 基期
增长率 = 增长量 / (现期 - 增长量)
增长率 = 现期 / 基期 - 1
```

### 3. 给百分点时先还原基期增长率

- 增速上升/下降: 用现期增长率加减百分点。
- 降幅扩大/收窄: 先把“下降”当负增长，再判断绝对值扩大还是缩小。
- 给“现期 r、百分点变化，求基期 r”时，先判方向，再加减。

### 4. 比较增长率

- 给现期、基期: 比较 `现期/基期`，倍数越大增长率越大。
- 给现期、增长量: 比较 `增长量/基期`，也可转成 `增长量/(现期-增长量)`。
- 倍数差异明显时直接比倍数；不明显时看前后列、口算差距。

## 高频错因

- 把“是 n 倍”和“增长 n 倍”混用。
- 把百分点当百分数直接乘除。
- 降幅扩大/收窄时忘记下降是负增长。
- 增长率比较时直接比较增长量，忽略基期。
