# 间隔增长率

来源: 资料分析专项
来源文件: `间隔增长率.pdf`
来源页码: p1-p2
confidence: high

## 适用题型

隔一年/隔一期增长率、间隔倍数、间隔基期、间隔现期、间隔增长量、逆向求某期增长率。

## 方法卡

### 1. 核心公式

```text
R = r1 + r2 + r1 × r2
```

若 `|r1|`、`|r2|` 都小于 10%，乘积项通常小于 1 个百分点，可按选项差距决定是否忽略。

### 2. 间隔倍数

```text
是 n 倍 = 间隔增长率 + 1
多 n 倍 = 间隔增长率
```

### 3. 间隔基期

1. 先估算间隔增长率 `R`。
2. 再用 `现期 = 基期 × (1+R)` 反推基期。

### 4. 间隔现期

保持某增长率不变、隔一期问具体值:

```text
现期 = 基期 × (1 + 间隔增长率)
```

### 5. 间隔增长量

先估算间隔增长率，再百化分求增长量。

### 6. 逆向求某期增长率

已知间隔增长率 `R` 和其中一期增长率 `r1`:

```text
r2 = (R - r1) / (1 + r1)
```

判断符号:

- 当 `R > r1` 时，`r2 > 0`。
- 当 `R < r1` 时，`r2 < 0`。

## 高频错因

- 只算 `r1+r2`，漏乘积项。
- “是 n 倍”和“多 n 倍”混淆。
- 已知两年平均增长率时，没有先转成间隔增长率。
- 逆向求增长率时把分母写成 `1+R`。
