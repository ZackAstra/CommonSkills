# 年均增长率

来源: 资料分析专项
来源文件: `年均增长率.pdf`
来源页码: p1-p2
confidence: high

## 适用题型

比较或计算年均增长率，尤其是多年复合增长。

## 方法卡

### 1. 年份差相同，比较年均增长率

年份差相同:

```text
基期 × (1+r)^n = 现期
```

比较年均增长率时，直接比较:

```text
现期 / 基期
```

现期/基期越大，年均增长率越大。

### 2. 年份差不同

年份差不同，不能直接比较现期/基期。要看:

```text
(1+r)^n = 现期 / 基期 = 1 + 增长量 / 基期
```

需要结合 n 比较。

### 3. r 小于 10% 的估算

可用近似:

```text
年均 r ≈ 总增长率 / 年份差
```

但由于复利存在，`总增长率/年份差` 通常偏大，选项应向小选。

### 4. r 大于 10% 的估算

增长率较大时，用平方、立方、四次方估算，不要简单除年份差。

常用平方:

```text
11²=121
12²=144
13²=169
14²=196
15²=225
16²=256
17²=289
18²=324
19²=361
20²=400
```

常用三次/四次近似:

```text
1.2³≈1.7
1.3³≈2.2
1.4³≈2.7
1.2⁴≈2.0
1.3⁴≈2.9
1.4⁴≈3.8
```

## 高频错因

- 把年均增长率当作总增长率除年份个数，忽略复利。
- 年份差数错。
- 年份差不同时仍直接比较现期/基期。
- r 较大时仍使用小 r 近似。
