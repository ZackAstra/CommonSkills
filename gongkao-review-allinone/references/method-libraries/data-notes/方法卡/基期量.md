# 基期量

来源: 资料分析专项
来源文件: `基期量.pdf`
来源页码: p1-p2
confidence: high

## 适用题型

给现期、增长量、增长率、同比/环比，求上一期或某一基期量。

## 方法卡

### 1. 基础关系

- 同比: 上年同期。
- 环比: 上一周期。
- 基期、现期、增长量、增长率四者要先定位清楚。

### 2. 基期三公式

```text
基期 = 现期 - 增长量
基期 = 增长量 / 增长率
基期 = 现期 / (1 + 增长率)
```

### 3. 小增长率化除为乘

当 `|r| <= 5%` 且选项差距允许时:

```text
A / (1 + r) ≈ A × (1 - r) = A - A×r
A / (1 - r) ≈ A × (1 + r) = A + A×r
```

适用条件: 选项前位相同、第二位接近，且 `4% <= |r| <= 5%` 时尤其要注意误差方向。

### 4. 基期和差

基期和差常见形式:

```text
A/(1+a) ± B/(1+b)
```

- 分母相近时可先估。
- 分母不同且差距较大时，不要直接用现期和差代替基期和差。

### 5. 与比重结合

求部分基期或整体基期时，先分清:

- 部分现期、部分增长率。
- 整体现期、整体增长率。
- 现期比重或基期比重。

再选公式，避免把部分增长率套到整体上。

## 高频错因

- 同比、环比定位错。
- 增长率为负时仍用 `1+r` 的正增长直觉。
- 小 r 估算时不看选项差距。
- 部分/整体增长率混用。
