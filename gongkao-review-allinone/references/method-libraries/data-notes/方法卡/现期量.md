## 适用题型

给基期、增长量或增长率，推未来某年/月的现期量；或问追上、超过、达到几倍、名义与实际增长。

## 方法卡

### 1. 现期追赶

常见条件:

- 保持增长量不变。
- 保持增长率不变。

常见问法:

- 到哪一年首次超过某数。
- A 何时追上 B。
- A 与 B 差距在哪一年进入某范围。
- A 何时达到 B 的 n 倍。

保持增长量不变时:

```text
未来现期 = 当前现期 + 年数差 × 每年增长量
```

追赶类:

```text
所需年数 ≈ 当前差距 / 增长量差
```

若问达到 `B 的 n 倍`，要把目标写成 `A >= nB` 后再整理。

### 2. 保持增长率不变

```text
未来现期 = 基期 × (1 + r)^n
```

如果增长率较小，可用连续增长估算；如果增长率较大，要计算乘方。

### 3. 不给增长率时

- 如果现期、基期倍数关系明显，先判断倍数。
- 如果倍数不明显，可以看增长量是否变大，或用“大作小看”的方式估计趋势。

### 4. 名义增长率和实际增长率

```text
1 + 名义增长率 = (1 + 实际增长率) × (1 + CPI增长率)
名义增长率 ≈ 实际增长率 + CPI增长率 + 实际增长率×CPI增长率
```

名义增长通常大于扣除物价后的实际增长。

## 高频错因

- 保持增长量不变和保持增长率不变混用。
- 追赶题没有先写“差距/增长量差”。
- 到 n 倍时没有把目标式子写成 `A >= nB`。
- 名义增长率、实际增长率、CPI 三者关系混乱。
