# 混合增长率

来源: 资料分析专项
来源文件: `混合增长率.pdf`
来源页码: p1-p3
confidence: high

## 适用题型

整体由部分组成，已知部分增长率，求整体增长率或反推部分量比例。

## 触发场景

常见拆分:

- 进口 + 出口 = 进出口
- 城镇 + 农村 = 全国
- 邮政 + 电信 = 邮电
- 移动 + 固定 = 电信
- 人民币 + 外币 = 本外币
- A + 非 A = 总体

时间拆分:

- 一季度 = 1-2月 + 3月
- 全年 = 1-11月 + 12月

差值转化:

```text
顺差 = 出口 - 进口
逆差 = 进口 - 出口
出口 = 进口 + 顺差
进口 = 出口 + 逆差
```

## 方法卡

### 1. 范围规律

```text
最小部分增长率 < 总体增长率 < 最大部分增长率
```

总体增长率偏向基期量更大的一方。

注意: 只靠范围只能排除，不能判断偏向。

### 2. 加权公式

若部分基期为 A、B，增长率为 ra、rb:

```text
R = (A×ra + B×rb) / (A+B)
A/B = (rb - R) / (R - ra)
```

若给的是现期 A'、B':

```text
(A'/(1+ra)) / (B'/(1+rb)) = (rb - R) / (R - ra)
```

当 `ra`、`rb` 相差不大时，`(1+rb)/(1+ra) ≈ 1`，可近似用现期比。

### 3. 线段法

把两个部分增长率放在线段两端，总体增长率在线段中间。距离越近，说明对应部分权重越大。

## 高频错因

- 只判断范围，不判断偏向。
- 用现期量代替基期量时不看部分增长率差距。
- 进出口、顺差、逆差的拆分关系写错。
- 多者混合时忘记总体仍落在最小和最大之间。
