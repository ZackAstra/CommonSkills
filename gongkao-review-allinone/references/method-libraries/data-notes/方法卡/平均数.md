# 平均数

来源: 资料分析专项
来源文件: `平均数.pdf`
来源页码: p1-p2
confidence: high

## 适用题型

现期平均数、基期平均数、两期平均数比较、两期平均数差、平均数倍数、中位数、众数。

## 方法卡

### 1. 识别平均数

看到这些词，优先想到平均数:

- 均
- 每
- 单位面积
- 人均

平均数本质:

```text
平均数 = 分子 / 分母
```

例如人均收入 = 收入 / 人数。

### 2. 现期平均数

直接找分子、分母，做分数比较或计算。

### 3. 基期平均数

给现期分子 A、分母 B，分子增长率 a、分母增长率 b:

```text
基期平均数 = A / B × (1+b) / (1+a)
```

### 4. 两期平均数比较

比较分子增长率 `a` 和分母增长率 `b`:

```text
a > b: 平均数上升
a < b: 平均数下降
a = b: 平均数不变
```

### 5. 两期平均数差

```text
两期平均数差 = A / B × (a-b) / (1+a)
```

### 6. 平均数倍数

两个平均数相比:

```text
(A/B) ÷ (C/D) = (A/C) × (D/B)
```

若不给分母，先找分母相同的平均数，再用倍数关系补齐。

### 7. 中位数和众数

- 中位数: 排序后中间位置。
- 众数: 出现次数最多。

## 高频错因

- 只看到“收入/产量”就算总量，漏掉“人均/每/单位面积”。
- 两期平均数比较时把分子、分母增长率放反。
- 基期平均数修正项写反。
