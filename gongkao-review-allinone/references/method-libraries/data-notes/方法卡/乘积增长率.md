# 乘积增长率

来源: 资料分析专项
来源文件: `乘积增长率.pdf`
来源页码: p1
confidence: high

## 适用题型

两个因素相乘形成总量，问总量增长率。

## 触发场景

- 总额 = 单价 × 数量
- 产量 = 单产 × 面积
- 部分 = 总体 × 比重
- 其他形如 `A = B × C` 的指标

## 方法卡

若 `A = B × C`，B 的增长率为 `b`，C 的增长率为 `c`，则:

```text
A 的增长率 = b + c + b × c
```

若其中一个因素不变，则总量增长率等于另一个因素的增长率。

## 判断流程

1. 先把题干指标拆成乘积关系。
2. 分别找两个因子的增长率。
3. 套 `b + c + b×c`。
4. 选项差距大时，乘积项可估算；但两个增长率都不小时不能漏掉。

## 高频错因

- 只算 `b+c`，漏掉 `b×c`。
- 没先识别“总额/产量/部分”背后的乘积结构。
- 一个因子不变时仍硬套复杂计算。
