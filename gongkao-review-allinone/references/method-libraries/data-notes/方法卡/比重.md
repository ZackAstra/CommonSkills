# 比重

来源: 资料分析专项
来源文件: `比重.pdf`
来源页码: p1-p2
confidence: high

## 适用题型

现期比重、基期比重、两期比重比较、两期比重差、饼状图比重。

## 方法卡

### 1. 基础公式

```text
比重 = 部分 / 整体
增长贡献率 = 部分增长量 / 总体增长量
产销率 = 销量 / 产量
```

### 2. 现期比重

- 给部分量、总体量: 直接除。
- 比较比重: 估计比较，分母越大分数不一定越大，要同时看分子。
- 图形题: 看清是现期还是基期，饼图角度/面积只是辅助。

### 3. 基期比重

给现期部分 A、整体 B，部分增长率 a，整体增长率 b:

```text
基期比重 = A / B × (1+b) / (1+a)
```

步骤:

1. 先算现期比重 `A/B`。
2. 再看修正项 `(1+b)/(1+a)`。
3. 判断比现期比重大还是小。

### 4. 两期比重比较

看部分增长率 `a` 与整体增长率 `b`:

```text
a > b: 比重上升
a < b: 比重下降
a = b: 比重不变
```

### 5. 两期比重差

```text
两期比重差 = A / B × (a-b) / (1+a)
```

其中 A/B 是现期比重，a 是部分增长率，b 是整体增长率。

## 高频错因

- 部分增长率和整体增长率放反。
- 问“上升/下降”时还在硬算比重。
- 两期比重差忘记除以 `1+a`。
- 把增长贡献率当普通比重。
