# 增长量

来源: 资料分析专项
来源文件: `增长量.pdf`
来源页码: p1-p4
confidence: high

## 适用题型

求增长量、减少量、平均增长量、指定增长量、增长量比较、增长量倍数、增长贡献率、拉动率。

## 方法卡

### 1. 基本公式

```text
增长量 = 现期 - 基期
增长量 = 现期 / (1 + r) × r
减少量 = 现期 / (1 - |r|) × |r|
```

### 2. 给现期和增长率

先百化分:

```text
若 r = 1/N
增长量 = 现期 / (N + 1)
减少量 = 现期 / (N - 1)
```

若 `|r| <= 5%` 且选项差距大:

```text
增长量 ≈ 现期 × r
误差 ≈ 现期 × r²
```

### 3. 平均增长量

```text
平均增长量 = (现期 - 基期) / 年份差
```

年份差按时间轴数间隔，不按年份个数机械数。

### 4. 指定增长量

判断“增长量大于某数有几个”:

```text
现期 - 基期 > 指定增长量
等价于 基期 + 指定增长量 < 现期
```

图表题可直接看柱间高度差。

### 5. 增长量比较

给现期和基期:

- 柱状图: 看柱间高度差。
- 折线图: 看斜率/差值。
- 表格: 先找单位，再排序。

给现期和增长率:

```text
增长量 = 现期 / (1+r) × r
```

- 现期大且 r 大，则增长量一定大。
- 一大一小时，用百化分或倍数比较。

### 6. 多项增长

总体增长量等于各部分增长量之和。有升有降时，先抵消，再计算。

### 7. 增长贡献率和拉动率

```text
增长贡献率 = 部分增长量 / 总体增长量
拉动率 = 部分增长量 / 总体基期
```

## 高频错因

- 求增长量时错用 `现期×r` 当精确值。
- 平均增长量年份差数错。
- 只看增长率大，不看现期规模。
- 增长贡献率和拉动率分母混淆。
