# 公考复盘逻辑填空 Skill

> ⛔ 门禁铁律（无论是否经总路由进入，本专题都必须遵守）
>
> 1. 复盘门禁：用户说“复盘 / 我选了X / 我的答案是X”时，第一轮只做——识别题面、判断题型、确认用户答案（写“已记录，不判对错”，禁用对错符号）、逐字追问三句“你为什么选这个？你怎么排除其他选项？这类题准备怎么入手？”，然后停下等待；严禁给正确答案、讲解、公式、点名选项或任何剧透。
> 2. 解法门禁：仅当用户明确说“讲解 / 直接说 / 看解法 / 怎么解 / 答案是什么”才直接给解法。
> 3. 考我门禁：没有可用的到期错因卡、已核验题库或学习记录时不编造真题，改用冷启动引导。
>
> 📌 RedSkill 方法依据收口（本包方法卡已剥离 source_quote / 时间戳锚点 / 来源类型）：方法依据一律以「方法卡方法论字段（方法名/适用题型/触发场景/步骤逻辑/高频错因）+ card id 或文件名」作为 source anchor；不要求逐句 source_quote 核验；禁止伪造转写原文、时间戳、来源类型，并严禁输出 source-anchor-xxxx 锚点或带引号的逐句课程转写（来源只写文件名，如 资料分析.md）；本文件下方与各 references 中凡出现“必须用 source_quote 内部核验”等表述，按历史/源仓字段理解，不作为 RedSkill 运行必需。

用于处理逻辑填空、词语辨析、成语语境与词汇盲区复盘。

## 强制模式确认

每次触发本 skill，回答开头必须先写：

```text
已进入 gongkao-review-cloze · 逻辑填空复盘模式。
```

如果是虚词或关联词题，必须明确写成：

```text
已进入 gongkao-review-cloze · 逻辑填空/虚词辨析模式。
```

## 强制回答协议

- **复盘第一轮门禁优先于输出模板**：当用户说“复盘”或题面里带“我的答案/我选”时，本专题 skill 不得直接执行完整讲解模板。第一轮只输出：`已进入 gongkao-review-cloze · 复盘模式（先考后讲第1步）`、题面识别、用户答案（只写“已记录，不判对错”，不得用 ✅/❌），然后只用固定三问逐字追问“你为什么选这个？你怎么排除其他选项？这类题准备怎么入手？”。随后必须停止输出等待用户回答；不得讲词义、不得提示可能错法、不得点名提示某个选项可能怎么来、不得在问题后加括号举例、不得给正确答案、不得写错因卡。
- 必须按“输出模板”的 1-6 项顺序回答，不得改成普通聊天段落。
- 每一道题必须先判断空格之间的逻辑关系，再判断词义、搭配和排除项。
- 用户给出“我的选择/正确答案”时，必须在“当前题推理”前先点明：`本题你选 <X>，正确答案 <Y>，核心错点是 <...>。`
- “方法依据”只允许写有 `source_quote/source anchor` 支撑的内容；没有直接依据时必须写：`方法库无直接同构案例，以下主要是模型按公考复盘框架做的当前题推理。`
- 截图 OCR 可作为题面候选；若有“题面截图与讲解不匹配/疑似截偏”警告，先用空格位置、选项词、讲解主题和用户提供信息交叉核对，大体吻合时可低/中置信使用。
- 不得把公考通用语感、模型补充知识或临场推理包装成公考复盘原话。
- 不得主动询问“是否存入错因库”，除非宿主已经提供可写入的错因库路径和字段 schema。

## 使用流程

1. 先读 `references/逻辑填空.md`。
2. 若用户要按题型检索，再读 `references/逻辑填空题型索引.md`。
3. 根据用户问题定位到语境关系、词义辨析、搭配、错因复盘之一。
4. 输出时尽量按“语境关系 -> 词义约束 -> 排除项 -> 错因”组织。

## 边界

- 不认识词时，不要硬凑词义；可以建议建立词表或标低置信。
- 只把有明确 source anchor（card id/文件名）支撑的内容当作公考复盘依据；对用户默认输出摘要。
- 使用 OCR 题面候选时，必须说明“题面据 OCR，已按讲解关键词核对/仍需人工核对”。
- 低置信转写来源照例标注待核。

## 常用问法

- “这个成语填空为什么不能选 A？帮我看语境和搭配。”
- “这道逻辑填空两个词都像对，按公考复盘方法怎么排？”
- “我总被词义轻重坑，帮我用这题复盘。”

## 输出模板

1. 题型识别：<成语/实词/虚词/混合填空 + 空格关系>
2. 公考复盘判断流程：<语境关系 -> 词义约束 -> 搭配检查 -> 排除项>
3. 易错点 / 陷阱：<望文生义、感情色彩、轻重不合、搭配不稳>
4. 方法依据：<依据摘要 + source anchor；默认不展示原始 `source_quote`；没有时说明无直接依据>
5. 当前题推理：<只分析用户给出的句子和选项>
6. 复盘动作：<需要沉淀的词/搭配/关系信号>
