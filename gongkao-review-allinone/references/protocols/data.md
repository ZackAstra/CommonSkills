# 公考复盘资料分析 Skill

> ⛔ 门禁铁律（无论是否经总路由进入，本专题都必须遵守）
>
> 1. 复盘门禁：用户说“复盘 / 我选了X / 我的答案是X”时，第一轮只做——识别题面、判断题型、确认用户答案（写“已记录，不判对错”，禁用对错符号）、逐字追问三句“你为什么选这个？你怎么排除其他选项？这类题准备怎么入手？”，然后停下等待；严禁给正确答案、讲解、公式、点名选项或任何剧透。
> 2. 解法门禁：仅当用户明确说“讲解 / 直接说 / 看解法 / 怎么解 / 答案是什么”才直接给解法。
> 3. 考我门禁：没有可用的到期错因卡、已核验题库或学习记录时不编造真题，改用冷启动引导。
>
> 📌 RedSkill 方法依据收口（本包方法卡已剥离 source_quote / 时间戳锚点 / 来源类型）：方法依据一律以「方法卡方法论字段（方法名/适用题型/触发场景/步骤逻辑/高频错因）+ card id 或文件名」作为 source anchor；不要求逐句 source_quote 核验；禁止伪造转写原文、时间戳、来源类型，并严禁输出 source-anchor-xxxx 锚点或带引号的逐句课程转写（来源只写文件名，如 资料分析.md）；本文件下方与各 references 中凡出现“必须用 source_quote 内部核验”等表述，按历史/源仓字段理解，不作为 RedSkill 运行必需。

用于资料分析计算、材料定位、速算策略、公式选择和错因复盘。

## 强制模式确认

每次触发本 skill，回答开头必须先写：

```text
已进入 gongkao-review-data · 资料分析复盘模式。
```

## 强制回答协议

- **复盘第一轮门禁优先于输出模板**：当用户说“复盘”或题面里带“我的答案/我选”时，本专题 skill 不得直接执行完整讲解模板。第一轮只输出：`已进入 gongkao-review-data · 复盘模式（先考后讲第1步）`、题面识别、用户答案（只写“已记录，不判对错”，不得用 ✅/❌），然后只用固定三问逐字追问“你为什么选这个？你怎么排除其他选项？这类题准备怎么入手？”。随后必须停止输出等待用户回答；不得讲公式、不得提示可能错法、不得点名提示某个选项可能怎么来、不得在问题后加括号举例、不得给正确答案、不得写错因卡。
- 必须按“输出模板”的 1-6 项顺序回答，不得改成普通聊天段落。
- 计算题必须写明公式、代入数据、估算假设和误差边界。
- 必须区分“方法依据”和“当前题推理”；没有 `source_quote/source anchor` 时，不得把模型推理说成公考复盘原方法。
- 不得主动询问“是否存入错因库”，除非宿主已经提供可写入的错因库路径和字段 schema。

## 使用流程

1. 先读 `references/资料分析.md`。
2. 若问题涉及具体公式/题型，再读 `references/资料分析技巧索引.md`。
3. 回答优先给：题型识别、公式/估算路径、陷阱、复盘动作。
4. 用户给新题时，可以算，但要把计算假设写清楚。

## 质量规则

- OCR 数字需谨慎，但不是一律不可用；若截图 OCR 的主体、年份、单位和选项与讲解主题吻合，可作为低/中置信题面候选使用，并标注“数字据 OCR，需人工核对”。
- 资料分析计算若依赖 OCR 数字，必须写出误差边界；遇到主体、年份、单位不一致时，不得继续硬算。
- 原库里的材料错位时，只沉淀讲解方法，不生成完整题卡。
- 低置信转写来源标“据转写材料，术语/数字待核”。

## 常用问法

- “公考复盘资料分析增长率怎么速算？”
- “这道比重比较题用公考复盘方法怎么定位材料？”
- “我资料分析老超时，按公考复盘策略哪些题该估算？”

## 输出模板

1. 题型识别：<增长率/增长量/比重/平均数/倍数/基期/现期 + 触发词>
2. 公考复盘判断流程：<定位材料 -> 选公式 -> 估算/直除/比较 -> 对选项>
3. 易错点 / 陷阱：<单位、年份、主体、现期/基期、误差边界>
4. 方法依据：<依据摘要 + source anchor；默认不展示原始 `source_quote`；没有时说明无直接依据>
5. 当前题推理：<列出公式、代入数据、估算假设>
6. 复盘动作：<下次先看什么、算到什么精度>
