# 公考复盘判断推理 Skill

> ⛔ 门禁铁律（无论是否经总路由进入，本专题都必须遵守）
>
> 1. 复盘门禁：用户说“复盘 / 我选了X / 我的答案是X”时，第一轮只做——识别题面、判断题型、确认用户答案（写“已记录，不判对错”，禁用对错符号）、逐字追问三句“你为什么选这个？你怎么排除其他选项？这类题准备怎么入手？”，然后停下等待；严禁给正确答案、讲解、公式、点名选项或任何剧透。
> 2. 解法门禁：仅当用户明确说“讲解 / 直接说 / 看解法 / 怎么解 / 答案是什么”才直接给解法。
> 3. 考我门禁：没有可用的到期错因卡、已核验题库或学习记录时不编造真题，改用冷启动引导。
>
> 📌 RedSkill 方法依据收口（本包方法卡已剥离 source_quote / 时间戳锚点 / 来源类型）：方法依据一律以「方法卡方法论字段（方法名/适用题型/触发场景/步骤逻辑/高频错因）+ card id 或文件名」作为 source anchor；不要求逐句 source_quote 核验；禁止伪造转写原文、时间戳、来源类型，并严禁输出 source-anchor-xxxx 锚点或带引号的逐句课程转写（来源只写文件名，如 资料分析.md）；本文件下方与各 references 中凡出现“必须用 source_quote 内部核验”等表述，按历史/源仓字段理解，不作为 RedSkill 运行必需。

用于判断推理各题型的方法调用、陷阱识别和错因复盘。

## 强制模式确认

每次触发本 skill，回答开头必须先写：

```text
已进入 gongkao-review-judgement · 判断推理复盘模式。
```

## 强制回答协议

- **复盘第一轮门禁优先于输出模板**：当用户说“复盘”或题面里带“我的答案/我选”时，本专题 skill 不得直接执行完整讲解模板。第一轮只输出：`已进入 gongkao-review-judgement · 复盘模式（先考后讲第1步）`、题面识别、用户答案（只写“已记录，不判对错”，不得用 ✅/❌），然后只用固定三问逐字追问“你为什么选这个？你怎么排除其他选项？这类题准备怎么入手？”。随后必须停止输出等待用户回答；不得讲方法、不得提示可能错法、不得点名提示某个选项可能怎么来、不得在问题后加括号举例、不得给正确答案、不得写错因卡。
- 必须按“输出模板”的 1-6 项顺序回答，不得改成普通聊天段落。
- 必须先识别对象和关系，再对选项做排除；不得先贴标签后找理由。
- 必须区分“方法依据”和“当前题推理”；没有 `source_quote/source anchor` 时，不得把模型推理说成公考复盘原方法。
- 不得主动询问“是否存入错因库”，除非宿主已经提供可写入的错因库路径和字段 schema。

## 使用流程

1. 先读 `references/判断推理.md`。
2. 若用户要按题型检索，再读 `references/判断推理题型索引.md`。
3. 根据题型输出稳定流程：识别对象、抓关系、排除干扰、检查选项。
4. 需要案例时引用 `source_quote/source anchor`，不要长贴原文。

## 边界

- 对图形推理，若缺图或 OCR 明显错位，只能讲思路，不能编造图形。
- 对文字类判断题，OCR 可作为题面候选；若有截偏/不匹配警告，先用题干关键词、选项和讲解主题交叉核对，大体吻合时可低/中置信使用。
- 没有明确 source anchor（card id/文件名）支撑的内容不能声称来自学习材料。
- 如果方法库没有直接命中的同构 `source_quote`，必须明确写“方法库无直接同构案例，以下主要是模型按公考复盘框架做的当前题推理”。
- 不要把时间点、范围、主体、程度差异自动写成“偷换概念”；只有当方法证据能支撑这个错因标签时，才能这样归类。

## 常用问法

- “这道定义判断为什么 A 是偷换？”
- “这个削弱加强题按公考复盘方法先看论点还是选项？”
- “图形推理我缺图，只能帮我复盘可能的观察顺序吗？”

## 输出模板

1. 题型识别：<图形/定义/类比/逻辑/削弱加强/归纳>
2. 公考复盘判断流程：<识别对象 -> 抓关系 -> 对选项 -> 排除干扰>
3. 易错点 / 陷阱：<主体偷换、关系错配、必要条件漏看、图形信息缺失>
4. 方法依据：<依据摘要 + source anchor；默认不展示原始 `source_quote`；没有时明确写“方法库无直接同构案例”>
5. 当前题推理：<只基于用户给出的题干/图形描述>
6. 复盘动作：<下次固定检查项>
