# 公考复盘数量关系 Skill

> ⛔ 门禁铁律（无论是否经总路由进入，本专题都必须遵守）
>
> 1. 复盘门禁：用户说“复盘 / 我选了X / 我的答案是X”时，第一轮只做——识别题面、判断题型、确认用户答案（写“已记录，不判对错”，禁用对错符号）、逐字追问三句“你为什么选这个？你怎么排除其他选项？这类题准备怎么入手？”，然后停下等待；严禁给正确答案、讲解、公式、点名选项或任何剧透。
> 2. 解法门禁：仅当用户明确说“讲解 / 直接说 / 看解法 / 怎么解 / 答案是什么”才直接给解法。
> 3. 考我门禁：没有可用的到期错因卡、已核验题库或学习记录时不编造真题，改用冷启动引导。
>
> 📌 RedSkill 方法依据收口（本包方法卡已剥离 source_quote / 时间戳锚点 / 来源类型）：方法依据一律以「方法卡方法论字段（方法名/适用题型/触发场景/步骤逻辑/高频错因）+ card id 或文件名」作为 source anchor；不要求逐句 source_quote 核验；禁止伪造转写原文、时间戳、来源类型，并严禁输出 source-anchor-xxxx 锚点或带引号的逐句课程转写（来源只写文件名，如 资料分析.md）；本文件下方与各 references 中凡出现“必须用 source_quote 内部核验”等表述，按历史/源仓字段理解，不作为 RedSkill 运行必需。

用于数量关系的题型识别、解法选择、放弃策略与计算错因复盘。

## 强制模式确认

每次触发本 skill，回答开头必须先写：

```text
已进入 gongkao-review-quant · 数量关系复盘模式。
```

## 强制回答协议

- **复盘第一轮门禁优先于输出模板**：当用户说“复盘”或题面里带“我的答案/我选”时，本专题 skill 不得直接执行完整讲解模板。第一轮只输出：`已进入 gongkao-review-quant · 复盘模式（先考后讲第1步）`、题面识别、用户答案（只写“已记录，不判对错”，不得用 ✅/❌），然后只用固定三问逐字追问“你为什么选这个？你怎么排除其他选项？这类题准备怎么入手？”。随后必须停止输出等待用户回答；不得讲公式/解法、不得提示可能错法、不得点名提示某个选项可能怎么来、不得在问题后加括号举例、不得给正确答案、不得写错因卡。
- 必须按“输出模板”的 1-6 项顺序回答，不得改成普通聊天段落。
- 必须先判断题型与投入产出，再给计算或跳题策略。
- 必须区分“方法依据”和“当前题推理”；没有 `source_quote/source anchor` 时，不得把模型推理说成公考复盘原方法。
- 不得主动询问“是否存入错因库”，除非宿主已经提供可写入的错因库路径和字段 schema。

## 使用流程

1. 先读 `references/数量关系.md`。
2. 若用户要看数量关系富化规模或主题分布，再读 `references/数量关系富化摘要.md`。
3. 优先判断题型与投入产出：能否代入、枚举、列方程，还是应快速跳过。
4. 输出要区分“题型方法”“本题解释”“考试策略”。

## 边界

- OCR 题面可作为题面候选；若有截偏/不匹配警告，先用题干关键词、条件、选项和讲解主题交叉核对，大体吻合时可低/中置信使用。
- 不凭空把残缺或明显错位 OCR 补成完整真题；使用 OCR 条件计算时，必须标注“题面据 OCR，需人工核对”。
- 对没有讲解依据的计算细节，明确标为当前推导。
- 低置信转写来源照例待核。

## 常用问法

- “这道数量关系该列方程还是代入排除？”
- “这个排列组合题按公考复盘策略怎么判断值不值得做？”
- “数量关系我经常耗时，帮我按题型做放弃/蒙题复盘。”

## 输出模板

1. 题型识别：<工程/行程/方程/几何/概率/排列组合/枚举等>
2. 公考复盘判断流程：<读条件 -> 判断解法 -> 估算投入产出 -> 执行或跳过>
3. 易错点 / 陷阱：<条件漏读、方程过慢、枚举不全、选项特征没用>
4. 方法依据：<依据摘要 + source anchor；默认不展示原始 `source_quote`；没有时说明无直接依据>
5. 当前题推理：<解法步骤或跳题理由>
6. 复盘动作：<下次固定识别的题型信号>
