# 公考复盘方法库路由 Skill

> ⛔ 门禁铁律（无论是否经总路由进入，本专题都必须遵守）
>
> 1. 复盘门禁：用户说“复盘 / 我选了X / 我的答案是X”时，第一轮只做——识别题面、判断题型、确认用户答案（写“已记录，不判对错”，禁用对错符号）、逐字追问三句“你为什么选这个？你怎么排除其他选项？这类题准备怎么入手？”，然后停下等待；严禁给正确答案、讲解、公式、点名选项或任何剧透。
> 2. 解法门禁：仅当用户明确说“讲解 / 直接说 / 看解法 / 怎么解 / 答案是什么”才直接给解法。
> 3. 考我门禁：没有可用的到期错因卡、已核验题库或学习记录时不编造真题，改用冷启动引导。
>
> 📌 RedSkill 方法依据收口（本包方法卡已剥离 source_quote / 时间戳锚点 / 来源类型）：方法依据一律以「方法卡方法论字段（方法名/适用题型/触发场景/步骤逻辑/高频错因）+ card id 或文件名」作为 source anchor；不要求逐句 source_quote 核验；禁止伪造转写原文、时间戳、来源类型，并严禁输出 source-anchor-xxxx 锚点或带引号的逐句课程转写（来源只写文件名，如 资料分析.md）；本文件下方与各 references 中凡出现“必须用 source_quote 内部核验”等表述，按历史/源仓字段理解，不作为 RedSkill 运行必需。

这个 Skill 是公考复盘方法库的入口。它负责全局规则和方法库定位，不承担学科分发。

## 工作目录

本项目资料通常安装在：

- 技能目录：`.claude/skills/gongkao-review-*`
- 人类可读入口：`artifacts/current/method-libraries/gongkao-review/入口.md`

## 触发后先做什么

1. 先读 `references/公考复盘方法库入口.md`，只取与问题相关的部分。
2. 用户问文件结构或索引含义时，再读对应专题 `references/` 或 `artifacts/current/method-libraries/`。
3. 需要证据时优先用 `rg` 搜专题 `references/` 或 `artifacts/current/method-libraries/`。

## 回答原则

- 这是“讲解驱动”的方法库，不是完整真题库；但截图 OCR 可以作为“题面候选”参与复盘。
- OCR 不再一律降为不可用：即使标注“题面截图与讲解不匹配/疑似截偏”，也要先结合题干关键词、选项、讲解主题和用户提供信息交叉核对；大体吻合时可低/中置信使用。
- 方法依据以 source anchor（card id/文件名）为准（本包已剥离 source_quote）；对用户默认输出方法依据摘要 + source anchor。
- 遇到 低置信转写来源，要提醒“转写待核”或“据转写材料，术语/数字待核”。
- 不凭空补全缺失题面；若使用 OCR 题面候选，必须标注“题面据 OCR，已按讲解关键词核对/仍需人工核对”。
- 不把公考通用常识包装成公考复盘方法。

## 方法卡变式出题（回路 A，填题库空缺）

题库为空或不足时，可把方法卡当“出题素材库”，从其 `高频错因 / 触发场景 / 步骤逻辑` 字段构造**方法工作流题**，只出四类：① 公式/方法选择 ② 触发词识别 ③ 陷阱预判 ④ 归因。

- **不生成仿真计算新题**（答案不可靠 + 仿真过近原题有版权风险）。
- 每道题必须标注固定三段：`非真题 · 方法自测 · 不计真题正确率`。
- 结果记入 `review-engine/弱点档案/` 的方法掌握度，不计入真题正确率。
- 模板见 `artifacts/current/question-banks/templates/方法工作流题-template.md`。

## 输出模板

1. 查询目标：<用户要找的方法/字段/索引/证据>
2. 应读资料：<入口/数据字典/具体 reference>
3. 全局约束：OCR 可作题面候选但需交叉核对；`source_quote` 仅作内部核验；转写待核；不凭空补题面
4. 方法依据：<依据摘要 + source anchor；默认不展示原始 `source_quote`>
5. 下一步建议：<继续查证/转为错因卡/交给对应专题 skill>
