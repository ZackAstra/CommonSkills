# 复盘引擎说明

本目录承载通用学习引擎，先挂载公考复盘方法库，后续可挂载强化方法等独立方法库。

## 文件结构

- `MISSION.md`：考公总目标。正式内容必须先问用户再生成。
- `学习者画像.md`：全局索引层，给出错因摘要并链接到各弱点档案；不堆细节。
- `错因卡/`：事件层，每道题一张标准错因卡，供后续复习扫描。
- `弱点档案/`：知识点层，按 `模块-题型-核心考点` 聚合同一考点的反复错误（见“弱点档案与回写”）。
- `reference/`：正向沉淀层，借鉴 teach 的 glossary/cheat-sheet——`个人方法速查卡.md`（已掌握方法）、`术语表.md`（已学术语）。
- `学习记录/`：借鉴 teach 的 learning-records，只记录已证明的理解、纠正的误区、重要先验知识或目标变化。

## 三种意图

- 存档：只识别题面并存错因卡，不讲解、不考。
- 解法：调方法库直接讲解并存卡，不考用户。
- 复盘：先考后讲，第一轮只提问并停下；用户回答后才调方法库。

用户说“复盘这道题”“用公考复盘复盘”“我选了X”“我的答案是X”等表达时，默认进入【复盘】意图。

## 复盘门禁（优先于任何专题输出模板）

第一轮只允许：

1. 识别题面。
2. 判断题型。
3. 确认用户答案（只写“已记录，不判对错”，不得用 ✅/❌）。
4. 只用固定三问逐字追问：你为什么选这个？你怎么排除其他选项？这类题准备怎么入手？
5. 立刻停止输出，等待用户回答。

第一轮绝不调方法库、绝不讲公式、绝不提示可能错法、绝不点名提示某个选项可能怎么来、绝不在问题后加括号举例、绝不给正确答案、绝不写错因卡、绝不剧透。即使模型已经知道答案，也不能说。只有用户明确说“讲解”“直接说”“看解法”“怎么解”“答案是什么”时，才进入【解法】意图。

## 整页拍照输入

用户上传整页题目照片，或说“帮我看这张错题页”“这页题帮我整理一下”时，先识别并切题，不直接讲答案。

第一轮只输出识别清单：

- 识别到几道题
- 每题题型（能判断才写）
- 用户作答（能看见才写）
- 可见正确答案/解析（能看见才写）
- 看不清处标“请核对”

然后只问：

```text
识别到 X 道题，其中 X 道可判定，X 道待核对（先收着，不判对错）。
要我怎么处理？①整理存档 ②只讲错题 ③逐题复盘
```

待核对题只保存题面候选和问题说明，不判对错，不生成错因卡，不进入间隔复习。等用户补拍答案页、补充正确答案或确认题面后，再转为正式题目/错因卡。

## 题库导入

用户说“把这页加入题库”“把这张图加入题库”“把这个 PDF 加入题库”“把这个 doc 加入题库”“导入题库”“收进题库”等表达时，进入【题库导入】意图。

题库导入是很薄的自动化层，只做 OCR/文本提取、切题、答案识别、核验标记、结构化保存和导入报告；不讲解、不复盘、不考用户，也不把题库内容当作方法库证据。

默认保存文件：

- 项目归档：`artifacts/current/question-banks/总题库.md`
- 用户运行环境兜底：`复盘引擎/题库/总题库.md`

导入规则：

- 图片/截图：先 OCR，再按题号、选项、答案区切题。
- PDF：优先提取内嵌文本；扫描版再 OCR；保留页码备注。
- DOC/DOCX：提取正文后按标题、题号、选项切题。
- 每批导入都追加到总题库，不分散生成多个题库文件；除非用户明确要求拆分。
- 导入报告写入同一个总题库的 `导入记录 / Import Log` 区域。

自动判题默认 fail-closed。只有题干完整、选项完整、答案明确、题数与答案数匹配、OCR/文本提取无疑点时，才可标记 `可自动判题: true`。答案缺失、答案歧义、题答数量不一致、OCR 未核验、页面疑似截偏时，一律标记 `可自动判题: false` 与 `状态: 待核对`。

如果某一页或某一段答案看起来覆盖整批题目，但答案数多了或少了，不要局部采信；整页/整批先标记待核对，并在报告里写清楚“题数 X，答案数 Y，答案页暂不采纳”。

导入报告固定包含：来源类型、识别题数、识别答案数、可自动判题数、待核对数、保存路径、需要用户核对的问题。

## 方法依据规则

所有方法必须来自对应方法库。本包方法卡已剥离 `source_quote`/时间戳/来源类型，方法依据以方法论字段 + source anchor（card id/文件名）为准、不要求逐句核验、禁止伪造；复盘输出统一写“方法依据”，内容为清洗后的依据摘要 + source anchor。本包无原始转写可展示。若转写口语化、疑似错字或断句混乱，只输出清洗摘要并标注“转写待核”。方法库没有依据时必须明说“方法库无依据”。

调用方法卡前必须先执行 `artifacts/current/method-libraries/方法质量规则.md`：A/B 级可作为讲解依据，C 级只作继续检索的线索，D 级跳过。若没有 A/B 级候选，不要硬讲成“方法库依据”，应写“方法库无稳定依据”，再把模型推理单独标明。

## 状态读取与最近发展区（ZPD）

**仅在进入【考我】或【复盘】意图时**，开场先读 `学习者画像.md` + 到期 `错因卡/` + `弱点档案/`，然后先输出一句：

```text
已读到你最近弱点：<模块-题型-核心考点>（错 N 次），本次按【难度档 X】考你。
```

再出题。难度档取自对应弱点档案的 `难度档` 字段（基础 / 中等变式 / 进阶）。

**适用边界**：只有【考我】【复盘】才读状态、报弱点。【解法】【存档】、单纯问“这题答案是什么”等，不读状态、不报弱点，避免每轮啰嗦。

### 状态读取路径铁律

用户只说“考我 / 复习 / 再考我一轮”或“用 gongkao-review 考我”时，必须进入【考我】流程，不得退回普通聊天。进入【考我】后，先以当前工作目录为根实际读取/列举状态文件，不得只凭记忆判断“没有材料”。

读取顺序：

1. 项目标准路径：`artifacts/current/review-engine/学习者画像.md`、`artifacts/current/review-engine/弱点档案/*.md`，必要时再查 `artifacts/current/review-engine/错因卡/*.md` 与 `artifacts/current/review-engine/学习记录/*.md`。
2. WorkBuddy / 用户运行态路径：`.workbuddy/memory/学习者画像.md`、`.workbuddy/memory/弱点档案/*.md`、`.workbuddy/memory/错因卡/*.md`、`.workbuddy/memory/*.md`。
3. 旧运行目录：`复盘引擎/学习者画像.md`、`复盘引擎/弱点档案/*.md`、`复盘引擎/错因卡/*.md`、`复盘引擎/学习记录/*.md`。

只有这些候选路径都实际不存在或不可读时，才允许输出冷启动，并应说明已检查的路径族。`reference/个人方法速查卡.md` 是掌握后写入的正向沉淀文件，缺失不代表没有错因卡、弱点档案或学习记录，也不得因此判定“没有学习材料”。

### 考我快路径（避免长扫描）

用户只说“考我/复习”时，先只读：

1. `artifacts/current/review-engine/学习者画像.md`
2. `artifacts/current/review-engine/弱点档案/*.md`

不要在开场阶段扫描方法库、题库全文或全部错因卡正文。若读到任一弱点档案，必须在 10 行内直接出 1 道方法工作流题：

```text
已读到你最近弱点：<模块-题型-核心考点>（错 N 次），本次按【难度档 X】考你。
[非真题 · 方法自测 · 不计真题正确率]
题：<根据弱点档案的“下次出题策略 / 每次错法 / 方法掌握度”提出一个公式选择、触发词、陷阱预判或错因归因问题；不得编带数值、年份、企业/GDP等材料场景、四个选项或需要计算具体结果的仿真题，必须用纯概念问法>
```

用户回答后，才允许读取对应方法卡、错因卡或题库材料做判定与讲解。

## 弱点档案与回写

错因卡是事件层；弱点档案是知识点层，把同一考点的反复错误聚合起来驱动后续出题。

- 聚合 key 与文件名统一为 `模块-题型-核心考点`，例如 `资料分析-增长-间隔增长率`。
- 核心考点必须取规范名，优先复用方法库 `按题型索引.md` 中的标准考点名；禁止同义异写各写一份（如“间隔增长率/隔年增长率/R=r1+r2+r1r2”）。
- 新建前先按聚合 key 检索是否已有近义档案；命中则并入既有档案，同义写法记入档案的 `别名` 字段，不另立档。
- 回写链：复盘一题 → 写/更新错因卡 → 自动并入对应弱点档案（次数+1、追加“本次怎么错”、更新难度档）→ 摘要冒泡到学习者画像（链接该弱点档案）。
- 模板见 `弱点档案/弱点档案-template.md`。

### 自动回写默认规则

- 当宿主已经暴露可写的 `review-engine/`、`复盘引擎/` 或 `.workbuddy/memory/` 路径时，回写默认自动发生，不等待用户再补“存档”“更新错因卡”“把这次过关记上”之类口令。
- 自动回写覆盖两类场景：
  1. 错因卡生成/存档后：立即落盘错因卡、弱点档案、学习者画像。
  2. 考我 / 方法工作流题批改后：若本轮对应的错因卡唯一明确，则立即把复习记录、掌握度变化、自拦机制和必要的画像/弱点变化追加回去。
- 只有在以下情况才允许追问：没有可写路径、写权限失败、目标错因卡不唯一、或当前材料不足以判断应写入哪张卡。

### 回写执行协议（必须落盘）

如果当前环境有文件写入能力，复盘完成后必须按顺序实际写入：

1. `artifacts/current/review-engine/错因卡/YYYY-MM-DD-模块-题型-短标题.md`
2. `artifacts/current/review-engine/弱点档案/<模块-题型-核心考点>.md`
3. `artifacts/current/review-engine/学习者画像.md`

弱点档案最小字段：`聚合key / 别名 / 出错次数 / 难度档 / 掌握判定 / 下次出题策略`，并在“每次错法”链接本次错因卡。学习者画像至少更新“反复出现的错因”“各模块强弱”“最近发展区建议”三张表。未满足确认掌握门槛时，不写 `reference/个人方法速查卡.md`。

最终回答前必须自检三类文件是否存在并已更新；任何一步失败，都要说明失败路径和原因，不能口头假装完成。

**手动同步协议（纯 Markdown，不使用脚本）**：写完错因卡或更新掌握状态后，按固定顺序手动校准——先更新对应弱点档案，再更新学习者画像，最后视掌握门槛决定是否写个人方法速查卡，改完逐一核对三处口径一致。本包不含、也不要调用或生成任何脚本（Python/Shell 等）。

## 确认掌握判定（写死，不凭模型感觉）

只有满足以下**任一**条件，才允许把方法写入 `reference/个人方法速查卡.md`：

1. 用户对该题/该方法回答正确，**且能说出关键步骤**（不只给对答案，还能复述方法流程）；或
2. 同一聚合 key 考点**连续答对 2 次**。

不满足时，弱点档案 `掌握判定` 最多记到“巩固中”，不回流速查卡。满足后：方法进 `个人方法速查卡.md`（方法名 — 一句话要点 — 来源方法卡 anchor），生词/术语进 `reference/术语表.md`。

### 掌握升级执行协议

当某个弱点档案升级为 `已掌握` 时，必须同步：

1. 更新 `学习者画像.md` 中对应考点的当前水平和下一步，不能继续显示“未掌握”。
2. 新建或更新 `reference/个人方法速查卡.md`（不是 `*-template.md`），追加 `方法名 — 一句话要点 — 来源方法卡/source anchor`。
3. 用户展示了非平凡理解时，可在 `学习记录/` 新增 learning-record。
4. 最终自检弱点档案、画像、速查卡三处状态一致。
5. 如果 learning-record / 日志 / 验收总结来自多题考我或题库自动判分，先以当前批次的精确分数 `x/y` 为唯一准绳；写百分比时必须由同一分数换算。若没核到精确分数，就不要写百分比概括。

## 方法卡变式题（方法工作流题）

题库为空或不足时，可从方法库方法卡的 `高频错因 / 触发场景 / 步骤逻辑` 字段构造**方法工作流题**，作为出题兜底。只出四类：① 公式/方法选择 ② 触发词识别 ③ 陷阱预判 ④ 归因（上次为什么错）。

fail-closed：
- **不生成仿真计算新题**（答案不可靠 + 仿真过近原题有版权风险）。
- 每道方法工作流题必须显式标注固定三段，不可省略：`非真题 · 方法自测 · 不计真题正确率`。
- 其结果记入弱点档案的“方法掌握度”，不计入真题正确率统计。

## 间隔复习

全程使用 Markdown 字段手动维护，不使用任何脚本。复习到期判断靠人工查看 `下次复习` 字段并手动排序更新；卡片变多时按日期分组维护，仍不引入脚本。

“考我/复习”的取题优先级：

1. 到期错因卡：`review-engine/错因卡/` 或 `复盘引擎/错因卡/`（有完整原题+已核验答案则遮答案复测；否则考其记录的方法工作流）。
2. 总题库中的已核验题目：`artifacts/current/question-banks/总题库.md` 或 `复盘引擎/题库/总题库.md`。
3. 方法卡变式题（方法工作流题，见上）——填补题库空缺的兜底来源。
4. 私有项目中已有的已核验题库。
5. 学习者画像、弱点档案和学习记录，用来考方法流程、触发词、公式选择和错因辨析。

用户导入题只有同时满足 `可自动判题: true` 和 `答案核验: 已核验`，才可以进入“考我”的自动判题。标记为 `状态: 待核对`、`可自动判题: false`、`答案核验: 未核验`、`无答案` 或 `题答不匹配` 的题，只能用于人工核对或整理，不能自动出题判分。

没有任何到期错因卡、可用题库、可用学习记录时，不生成伪真题，也不得生成普通言语题、仿真真题、仿真计算题或自编材料题，改用冷启动兜底引导：

```text
现在还没有可考材料。①拍一道你最近的错题　②或选一个题型，我用方法卡给你出 3 道方法工作流题热身。
```
