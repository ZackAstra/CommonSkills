# 中国电信央企风格PPT规范

## 一、配色方案

### 正式汇报/政企方案（government）
| 元素 | 色值 | 用途 |
|------|------|------|
| 电信主蓝 | #0077BE | 标题、重点色块、章节号背景 |
| 浅蓝渐变 | #3399D6 | 渐变装饰、辅助色 |
| 深灰文字 | #333333 | 正文文字 |
| 浅灰底色 | #F5F7FA | 页面背景 |
| 纯白 | #FFFFFF | 文字反白、背景 |

禁止使用：大红、亮黄、荧光色。

### 数字化/云网/算力/AI（marketing）
同government方案，可增加浅科技银(#C0C8D0)作为线条/光效点缀。

### 党建/合规/企业文化（party）
| 元素 | 色值 | 用途 |
|------|------|------|
| 电信主蓝 | #0077BE | 主色 |
| 正红点缀 | #C00000 | 章节号背景、标题栏、角标、分隔线 |
| 深灰文字 | #333333 | 正文 |
| 米白 | #FFF8F0 | 底色 |

红色仅用于标题栏/角标/分隔线，不大面积铺色。

## 二、字体规范

| 用途 | 字体 | 字号(pt) |
|------|------|---------|
| 封面大标题 | 微软雅黑 Bold | 28-36 |
| 页面标题 | 微软雅黑 Bold | 22-26 |
| 一级正文 | 微软雅黑 Regular | 14-16 |
| 注释/备注 | 微软雅黑 Regular | 10-12 |
| 目录英文 | Times New Roman | 22-44 |
| 章节号 | Times New Roman Bold | 20 |

严禁：艺术字体、花体、手写体。

## 三、版式布局

### 黄金规则
- 留白优先，左右上下留足空白
- 统一模板：顶部标题栏 + 中间内容区 + 底部页脚(LOGO + 页码)
- 一页只讲1个核心主题
- 文字：一段一观点，短句分点，拒绝大段长文
- 数据：图表代替纯文字
- 一页不超过8行纯文字

### 页脚
- 中国电信LOGO + 页码 + 单位/部门（政企场景必备）

## 四、配图与图标

- 图标：线性简约商务图标，扁平化优先
- 主题匹配：通信、网络、基站、云、算力、大数据、AI、5G
- 正式汇报：城市全景、机房、办公、合作握手（高清、低饱和度）
- 科技类：抽象数字线条、网络拓扑、云脉络、微光科技底纹（浅色调）
- 禁止：模糊图、网红图、夸张特效图、表情包

## 五、动效

- 静态PPT（90%场景）：零复杂动画，仅简单出现/淡出
- 路演宣讲：可加轻微线条流动、渐变光效，全程克制
- 分割线/边框：细蓝线/细灰线，简约直角边框
- 禁止：花哨3D、翻转、弹跳动画

## 六、模板页类型映射

模板文件包含7页，分为3种页面类型：

| 类型 | 模板Slide索引 | 描述 |
|------|-------------|------|
| 封面 | 0 | 主标题 + 副标题(组名) + 日期 |
| 目录 | 1, 3, 5 | "目 录 / CONTENTS" + 3个章节条目 |
| 章节标题页 | 2, 4, 6 | 章节号+标题 + 描述文字 |

### 生成新PPT时的rearrange映射

对于N个section：
- `0, 1, 2, 2, 2, ...`（封面 + 目录 + N个章节标题页）
- 每个章节标题页复用模板slide-2

### 内容上限
- 目录页最多显示3个章节条目（模板限制）
- 章节标题页的描述文字建议不超过60字

## 七、避坑总结

1. 全册最多3种主色，不混用
2. 一页不超过8行纯文字，能用图表不用文字
3. 不使用3D/翻转/弹跳动画
4. 图标/图片风格全程统一，不混搭写实+卡通
5. 页眉页脚/LOGO/页码格式保持一致
