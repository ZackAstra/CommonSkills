## 问答式生成流程

### 第1步：需求收集（最多2轮问答）

**第1轮 - 核心信息：**
- PPT类型（工作汇报/项目方案/案例分享/产品宣传）
- 主题/标题
- 目标受众（领导/同事/客户）
- 预计页数

**第2轮 - 补充信息：**
- 是否有上传的素材文件/截图
- 是否有指定模板（检查 assets/templates/ 目录）
- 特殊要求（必须包含的数据、特定章节等）
- 交付时间要求

> 如果用户一次性提供了充分信息，跳过追问直接进入下一步。

### 第2步：素材摘录与内容提取

从用户上传的文件和截图中提取内容。

**文件类型处理：**

| 文件类型 | 提取方法 | 重点关注 |
|----------|----------|----------|
| Word/PDF | 读取全文，提取标题、段落、数据 | 核心观点、关键数据、结论 |
| Excel | 读取表格，识别数据维度 | 关键指标、趋势、对比数据 |
| 图片/截图 | 使用图片理解能力识别 | 文字内容、图表数据、视觉信息 |
| 已有PPT | 读取现有结构和内容 | 页面结构、已有内容、可复用素材 |

**摘录原则：**
- 保留原始数据的准确性，不篡改数字
- 标注信息来源（哪个文件/哪页）
- 识别文件间的关联信息
- 过滤无关内容，聚焦PPT主题

### 第3步：内容联想与组合

基于摘录内容，进行联想和结构化。

1. **信息归类**：将摘录内容按PPT结构归类
2. **逻辑串联**：建立内容间的逻辑关系
3. **补充完善**：识别信息缺口，向用户确认或合理补充
4. **内容大纲**：生成逐页内容大纲

### 第4步：大纲生成与确认

将生成的PPT大纲呈现给用户确认：

```
## PPT大纲（共X页）

P1 封面：[标题] - [汇报人/单位] - [日期]
P2 目录：[章节列表]
P3 [章节名]：[核心内容要点]
P4 [章节名]：[核心内容要点]
...
```

询问用户："以上大纲是否需要调整？"

用户可能提出的调整：
- 增删页面
- 调整页面顺序
- 修改某页内容重点
- 合并或拆分章节

确认后进入生成步骤。

### 第5步：生成PPT

大纲确认后，调用 pptx 技能生成PPT。

- 按 `references/ppt-types.md` 中对应类型的结构填充内容
- 如 `assets/templates/` 有模板文件，优先使用模板
- 否则按 `references/visual-standards.md` 中的电信视觉规范生成
- 生成后告知用户文件路径

### 第6步：生成后检查

生成完成后，自检以下内容：
- [ ] 总页数是否符合用户要求
- [ ] 每页标题是否完整
- [ ] 数据是否准确（与素材一致）
- [ ] 是否有空白页或内容不足的页面
- [ ] 图表是否正确渲染

## 问答式修改流程

### 修改交互模式

用户通过自然语言指令修改已生成的PPT，无需提供技术参数。

**常见修改指令示例：**

| 指令类型 | 示例 | 执行方式 |
|----------|------|----------|
| 内容更新 | "把第3页的数据更新为..." | 定位页面，替换数据 |
| 增加页面 | "在第5页后面加一页讲XXX" | 在指定位置插入新页 |
| 删除页面 | "删掉第10页" | 移除指定页面 |
| 图表修改 | "把第7页的图表换成柱状图" | 替换图表类型 |
| 布局调整 | "调整第4页为左右分栏" | 修改页面版式 |
| 样式修改 | "所有标题字体加大" | 批量修改样式 |
| 内容补充 | "在第6页补充XXX内容" | 在指定页面添加内容 |
| 顺序调整 | "把第8页移到第5页前面" | 调整页面顺序 |

### 修改执行步骤

1. **理解意图**：明确用户要改什么、改成什么样
2. **确认范围**：如指令模糊，简要确认（"你是想把第3页整页替换，还是只更新数据？"）
3. **执行修改**：调用 pptx 技能进行修改
4. **反馈结果**：告知用户修改完成，说明改了什么

### 批量修改处理

当用户一次提出多个修改需求时：
1. 逐条列出理解，请用户确认
2. 按顺序逐条执行
3. 完成后统一汇报结果，列出每条修改的状态

### 修改后状态同步
- 每次修改后告知用户当前PPT总页数
- 如有重大结构调整（增删页面、调整顺序），重新展示更新后的大纲
- 如用户持续修改，保持上下文，理解"第X页"指当前最新状态

## 内容摘录与联想方法

### 从文件摘录内容的方法

**结构化文件（Word/PDF）：**
1. 识别文档标题和章节结构
2. 提取每节的核心观点和数据
3. 记录关键引用和数据来源
4. 识别可用于PPT的图表和表格
5. 标注文档中的重点标注（加粗、高亮内容）

**数据文件（Excel）：**
1. 识别数据维度和指标名称
2. 提取关键数据和趋势方向
3. 计算衍生指标（同比、环比、占比、增长率等）
4. 识别适合可视化的数据组合
5. 标注异常值或特殊节点

**图片/截图：**
1. 使用图片理解能力识别图片内容
2. 提取文字信息（标题、标签、数据）
3. 识别图表类型和数据值
4. 描述图片可用的场景和位置
5. 判断图片质量是否适合放入PPT

### 内容联想方法

**纵向联想（深化）：**
- 从现象到原因：数据变化 → 分析驱动因素
- 从结果到影响：成效 → 推广价值和复制意义
- 从当前到未来：现状 → 发展趋势和规划
- 从局部到整体：单个指标 → 综合评价

**横向联想（扩展）：**
- 从单个到整体：具体案例 → 行业趋势
- 从本地到全局：区域数据 → 全国对比
- 从本业务到关联业务：交叉分析和协同效应
- 从内部到外部：内部实践 → 行业标杆对比

**组合方法：**
- 将不同来源的信息按主题整合
- 识别信息间的因果关系，构建逻辑链
- 构建"问题-举措-成效"或"背景-方案-收益"的叙事线
- 用数据支撑每个论点，避免空洞描述
- 识别信息缺口，主动向用户提问补充

### 内容质量检查清单

生成大纲前，逐项检查：
- [ ] 每页内容是否有明确主题
- [ ] 数据是否标注来源
- [ ] 逻辑链是否完整（有因有果）
- [ ] 是否有信息缺口需要向用户确认
- [ ] 内容密度是否均衡（避免某页过满或过空）
- [ ] 是否符合所选PPT类型的写作要点
