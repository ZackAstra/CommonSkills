## 配色方案

### 主色调

| 色彩 | 色值 | 用途 |
|------|------|------|
| 电信蓝 | #0066CC | 标题、主图形、强调色 |
| 深蓝 | #003366 | 封面背景、深色区域 |
| 天蓝 | #3399FF | 次级标题、图标 |
| 浅蓝 | #E6F2FF | 背景色块、表格隔行 |

### 辅助色

| 色彩 | 色值 | 用途 |
|------|------|------|
| 橙色 | #FF6600 | 重点强调、数据高亮 |
| 绿色 | #00CC66 | 正向数据、成功指标 |
| 红色 | #CC3333 | 负向数据、风险提示 |
| 灰色 | #666666 | 辅助文字、说明文字 |

### 使用原则
- 单页颜色不超过3种主色
- 蓝色系为主，橙/绿/红仅用于数据强调
- 背景以白色或浅蓝为主，避免深色背景（封面除外）
- 渐变色谨慎使用，保持商务质感

- 数据数字建议使用 Arial，视觉更紧凑

## 版式布局

### 通用原则
- 上方1/4区域放标题
- 中间1/2区域放主要内容
- 下方1/4区域放注释或页脚
- 页边距保持一致（上下1.5cm，左右2cm）

### 常见版式

1. **标题+正文版**：标题在上，正文分点列出。适用于文字内容较多的页面。
2. **左右分栏版**：左侧文字说明，右侧图表/图片。适用于图文结合的内容。
3. **图表为主版**：大图表居中，底部简短说明。适用于数据展示页。
4. **数据看板版**：多组数据卡片排列。适用于核心指标概览。
5. **流程图版**：横向或纵向流程图为主。适用于实施路径、业务流程。
6. **对比版**：左右或上下对比展示。适用于前后对比、竞品对比。

### 页面元素规范
- **页码**：右下角，格式"X/Y"
- **页脚**：左下角放公司/部门名称
- **Logo**：封面右上角或左上角
- **分隔线**：标题下方用电信蓝色细线分隔
- **背景**：正文页白色背景，封面可用深蓝渐变

## 图表规范

### 图表类型选择

| 数据类型 | 推荐图表 | 适用场景 |
|----------|----------|----------|
| 趋势对比 | 折线图 | 时间序列数据、增长趋势 |
| 分类对比 | 柱状图 | 多类别数据对比、排名 |
| 占比构成 | 饼图/环形图 | 构成比例、预算分配 |
| 关联关系 | 散点图 | 变量相关性分析 |
| 流程步骤 | 流程图 | 实施路径、业务流程 |
| 层级结构 | 组织架构图 | 组织结构、系统架构 |
| 时间计划 | 甘特图 | 项目排期、实施计划 |
| 对比分析 | 表格/矩阵 | 前后对比、方案对比 |

### 图表样式
- 配色使用电信蓝色系，主数据用电信蓝，对比数据用天蓝或橙色
- 数据标签清晰可读，字号不小于12pt
- 坐标轴标签简洁，避免过长文字
- 避免使用3D效果（除非特定需求）
- 图表标题简明扼要，位于图表上方
- 图例放置在图表底部或右侧，不遮挡数据

### 图表配色方案
```
单系列图表：  电信蓝 #0066CC
双系列对比：  电信蓝 #0066CC + 橙色 #FF6600
三系列对比：  电信蓝 #0066CC + 天蓝 #3399FF + 橙色 #FF6600
多系列对比：  按蓝色深浅渐变（#003366 → #0066CC → #3399FF → #66B5FF → #99CCFF）
正负数据：    绿色 #00CC66（正） + 红色 #CC3333（负）
```

## 图片与图标

### 图片使用
- 使用高清图片（不低于300dpi）
- 图片风格统一（实景照或矢量图，不混用）
- 图片需有简短说明文字
- 避免使用带水印的图片
- 图片大小适配页面布局，不拉伸变形

### 图标使用
- 使用统一风格的图标集（推荐线性图标）
- 图标颜色与页面主色调一致
- 功能性图标简洁明了，一眼可识别
- 装饰性图标不过度使用，避免喧宾夺主
- 图标尺寸统一，视觉对齐

### 示意图规范
- 架构图：分层展示，用颜色区分层级
- 流程图：方向一致（从左到右或从上到下），节点形状统一
- 关系图：连线清晰，避免交叉
- 所有示意图配简短文字说明
