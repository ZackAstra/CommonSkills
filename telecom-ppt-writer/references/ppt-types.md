## 工作汇报类

### 适用场景
季度/年度工作总结、阶段性工作进展汇报、专项工作汇报等面向上级领导或同级部门的汇报。

### 标准结构（15-20页）

| 页码 | 内容 | 写作角度 |
|------|------|----------|
| P1 | 封面 | 标题+汇报人+日期 |
| P2 | 目录 | 概括性列出汇报内容 |
| P3-P4 | 工作概述 | 总体情况、核心指标完成情况 |
| P5-P8 | 重点工作进展 | 按工作模块分页，每页聚焦一个重点 |
| P9-P11 | 数据与成效 | 量化成果，对比展示 |
| P12-P13 | 问题与挑战 | 客观分析，提出解决思路 |
| P14-P15 | 下阶段计划 | 目标+路径+时间节点 |
| P16 | 请求与建议 | 需要领导支持的事项 |
| P17-P20 | 附录 | 详细数据、补充材料 |

### 写作要点
- 开门见山：首页或第二页即给出核心结论
- 数据说话：每个论点配数据支撑
- 对比展示：用"前后对比""同比环比"突出成效
- 问题导向：不回避问题，但必须附解决方案
- 语言风格：简洁正式，避免口语化

### 写作角度清单
- [ ] 总体目标完成率是否清晰呈现
- [ ] 每项重点工作是否有量化成效
- [ ] 问题分析是否有数据支撑
- [ ] 下阶段计划是否有明确时间节点
- [ ] 是否有需要领导决策的事项

## 项目方案类

### 适用场景
项目立项方案、技术方案、业务提案、实施计划等。

### 标准结构（12-18页）

| 页码 | 内容 | 写作角度 |
|------|------|----------|
| P1 | 封面 | 项目名称+编制单位+日期 |
| P2 | 目录 | 方案结构导航 |
| P3 | 项目背景 | 为什么要做，解决什么问题 |
| P4 | 项目目标 | SMART原则，量化目标 |
| P5-P6 | 现状分析 | 痛点分析，市场/业务现状 |
| P7-P10 | 方案设计 | 核心方案，技术架构/业务流程 |
| P11-P12 | 实施路径 | 分阶段计划，里程碑 |
| P13-P14 | 资源需求 | 人力、资金、技术资源 |
| P15 | 风险评估 | 风险识别+应对措施 |
| P16 | 预期成效 | 量化收益预测 |
| P17-P18 | 附录 | 补充材料 |

### 写作要点
- 背景铺垫：清晰阐述立项必要性
- 方案具体：避免空泛，给出可执行细节
- 逻辑严密：从问题到目标到方案到路径到收益，环环相扣
- 风险可控：主动识别风险而非回避

### 写作角度清单
- [ ] 背景是否说明了立项必要性
- [ ] 目标是否符合SMART原则
- [ ] 方案是否有技术架构图或业务流程图
- [ ] 实施路径是否有明确里程碑
- [ ] 风险是否配有应对措施
- [ ] 预期成效是否有量化预测

## 案例分享类

### 适用场景
标杆案例、创新实践、经验分享、获奖案例申报等。

### 标准结构（10-15页）

| 页码 | 内容 | 写作角度 |
|------|------|----------|
| P1 | 封面 | 案例标题+单位+日期 |
| P2 | 案例概述 | 一页说清案例全貌 |
| P3 | 背景与挑战 | 面临的问题和困难 |
| P4-P5 | 创新举措 | 核心做法，分点阐述 |
| P6-P7 | 实施过程 | 关键步骤，流程图展示 |
| P8-P10 | 成效与亮点 | 量化成果，对比数据 |
| P11 | 经验总结 | 可复制可推广的要点 |
| P12-P13 | 推广应用 | 复制推广情况 |
| P14-P15 | 附录 | 补充材料 |

### 写作要点
- 故事性：有背景-挑战-举措-成效的完整叙事线
- 突出创新：明确"新"在哪里
- 数据佐证：成效必须有量化数据
- 可复制性：总结出可推广的经验

### 写作角度清单
- [ ] 背景与挑战是否描述清晰
- [ ] 创新举措是否有"关键点"说明
- [ ] 实施过程是否有流程图
- [ ] 成效是否有实施前后对比数据
- [ ] 是否有规模与收入拉动数据
- [ ] 是否有全国复制推广情况
- [ ] 经验总结是否提炼出可复制要点

## 产品业务宣传类

### 适用场景
产品推介、业务宣讲、营销方案、客户提案等。

### 标准结构（12-16页）

| 页码 | 内容 | 写作角度 |
|------|------|----------|
| P1 | 封面 | 产品/业务名称+slogan |
| P2 | 目录 | 宣讲结构 |
| P3 | 行业趋势 | 市场背景，发展机遇 |
| P4-P5 | 产品/业务介绍 | 核心功能，价值主张 |
| P6-P7 | 方案优势 | 与竞品对比，差异化优势 |
| P8-P9 | 应用场景 | 典型场景，客户案例 |
| P10-P11 | 技术架构 | 技术能力展示 |
| P12 | 合作模式 | 商业模式，合作方式 |
| P13 | 成功案例 | 标杆客户，实施效果 |
| P14-P16 | 附录 | 详细参数，补充材料 |

### 写作要点
- 价值导向：始终围绕客户价值
- 场景驱动：用具体场景说明产品价值
- 视觉突出：多用图表、架构图
- 行动引导：结尾给出明确的合作邀请

### 写作角度清单
- [ ] 行业趋势是否与产品价值关联
- [ ] 产品功能是否用场景化方式呈现
- [ ] 优势是否有竞品对比
- [ ] 技术架构是否清晰
- [ ] 是否有标杆客户案例
- [ ] 合作模式是否明确

## 页数弹性调整规则

当用户指定页数与标准结构不同时：
- **减少页数**：合并附录、压缩现状分析、精简实施过程
- **增加页数**：扩展数据成效、增加案例细节、丰富附录内容
- 保持核心叙事逻辑不变（背景-举措-成效/问题-方案-收益）
