# 无障碍设计指南（Accessibility Guide）

本文件规范 PPT 的无障碍设计，确保内容对色盲、弱视、听障和认知障碍用户可访问。

## 色彩无障碍

### 对比度要求

| 元素 | 最低对比度 | 推荐对比度 | 标准 |
|---|---|---|---|
| 正文文字与背景 | 4.5:1 | 7:1 | WCAG AA / AAA |
| 大文字（≥18pt 或 ≥14pt Bold）与背景 | 3:1 | 4.5:1 | WCAG AA Large |
| 图标/图形元素与背景 | 3:1 | 4.5:1 | WCAG 2.1 SC 1.4.11 |
| 装饰性元素 | 无要求 | — | — |

### 色盲安全配色

| 色盲类型 | 影响人群 | 禁止配色组合 | 替代方案 |
|---|---|---|---|
| 红绿色盲（Protanopia/Deuteranopia） | 男性 ~8% | 红+绿并排 | 蓝+橙 / 蓝+红 |
| 蓝黄色盲（Tritanopia） | <1% | 蓝+黄并排 | 红+绿 / 紫+橙 |
| 全色盲（Achromatopsia） | 极少 | 任何仅靠颜色区分的信息 | 加形状/图案/文字标签 |

**铁律**：永远不要仅靠颜色传达信息。颜色 + 形状/文字/图案 三重编码。

## 文字无障碍

### 字号下限

| 元素 | 最低字号 | 推荐字号 |
|---|---|---|
| 正文 | 18pt | 20-24pt |
| 标题 | 28pt | 32-36pt |
| 脚注/来源 | 10pt | 12pt |
| 图表标签 | 12pt | 14pt |

### 字体选择

- 避免装饰性字体（Comic Sans / Papyrus / 花体字）——可读性差
- 推荐无衬线字体（思源黑体 / 雅黑 / Inter）——屏幕可读性优
- 字重：正文用 Regular/Medium，避免 Light（太细看不清）

### 行距

- 最低 1.2 倍，推荐 1.3-1.5 倍
- 段落间距 ≥ 行距的 0.5 倍

## 图片无障碍

### Alt 文本

每张图片必须添加 Alt 文本（替代文字）：

- **内容图片**：描述图片传达的信息（"2024 年营收增长趋势折线图，从 120 亿增长至 180 亿"）
- **装饰图片**：Alt 设为空（`alt=""`），屏幕阅读器跳过
- **图表**：Alt 包含数据结论（"柱状图显示 Q4 营收最高，达 5.2 亿"）

### PowerPoint 中设置 Alt 文本

```python
from pptx.util import Inches
shape = slide.shapes.add_picture(img_path, left, top, width, height)
# 设置 Alt 文本
shape._element.attrib['descr'] = '描述文字'
```

## 结构无障碍

### 阅读顺序

- PowerPoint 的阅读顺序由元素添加顺序决定（非视觉位置）
- 确保标题 → 正文 → 图片 → 脚注 的添加顺序
- 使用"审阅 → 检查辅助功能"验证阅读顺序

### 标题层级

- 每页必须有标题（用于屏幕阅读器导航）
- 标题使用"标题"占位符（非文本框），确保语义正确

### 链接

- 链接文字应有描述性（"查看 2024 年度报告"而非"点击这里"）
- 超链接在 PPT 中用"插入 → 链接"添加

## 动画无障碍

- 动画不应是理解内容的必要条件
- 闪烁频率 > 3Hz 的动画可能触发光敏癫痫（禁止）
- 自动播放的动画应提供暂停/停止方式

## 电信品牌无障碍

- 电信红 #E60012 在白色背景上对比度 5.3:1（满足 AA）
- 电信红在浅灰 #F9FAFB 背景上对比度 5.0:1（满足 AA）
- 海军蓝 #1B3A5C 在白色背景上对比度 8.7:1（满足 AAA）
- 金色 #FFB800 在白色背景上对比度 1.8:1（**不满足 AA**，仅用于大文字或装饰）

## 检查清单

- [ ] 所有文字与背景对比度 ≥ 4.5:1
- [ ] 图表配色使用色盲安全方案
- [ ] 颜色不是唯一的信息传达方式
- [ ] 所有图片有 Alt 文本
- [ ] 每页有标题
- [ ] 正文字号 ≥ 18pt
- [ ] 行距 ≥ 1.2 倍
- [ ] 无闪烁动画
