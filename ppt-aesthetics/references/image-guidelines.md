# 图片使用指南（Image Guidelines）

本文件规范 PPT 中图片的选择、处理和使用，确保视觉专业度。

## 图片选择原则

### 1. 相关性优先

- 图片必须与页面内容直接相关，不使用纯装饰性图片
- 每张图片应回答"这张图帮助观众理解了什么？"
- 若无法回答，删除该图片

### 2. 真实感 > 图库感

| 优先级 | 图片类型 | 示例 |
|---|---|---|
| 1 | 真实产品截图/照片 | 实际界面、真实场景 |
| 2 | 定制插画/信息图 | 与品牌风格一致的插画 |
| 3 | 高质量图库照片 | Unsplash / Pexels（避免过度使用的图库照） |
| 4 | AI 生成图片 | 仅当无法获得真实图片时，需人工审核 |
| ✗ | 剪贴画/卡通 | ClipArt / 2000 年代风格卡通图标 |

### 3. 情绪一致性

- 全 deck 图片情绪统一（要么全部明亮温暖，要么全部冷峻专业）
- 不在同一 deck 中混用温馨家庭照和冷色科技图

## 技术规范

### 分辨率

| 用途 | 最低分辨率 | 推荐分辨率 | 格式 |
|---|---|---|---|
| 全出血背景图 | 1920×1080 | 2560×1440 | JPG（质量 ≥ 85%） |
| 内容区图片（占 50% 页面） | 960×540 | 1280×720 | JPG/PNG |
| 图标/小图 | 128×128 | 256×256 | PNG/SVG |
| 截图 | 1× 显示分辨率 | 2× 显示分辨率 | PNG |

### 宽高比

| 用途 | 推荐比例 | 说明 |
|---|---|---|
| 全出血背景 | 16:9 | 与幻灯片比例一致 |
| 双栏配图 | 4:3 或 1:1 | 右栏配图 |
| 人物肖像 | 3:4 | 半身照 |
| 风景/场景 | 16:9 或 21:9 | 宽幅 |

**铁律**：绝不拉伸图片。若比例不匹配，裁剪而非变形。

### 文件大小

- 单张图片 ≤ 2MB（PPT 总体积控制）
- 全出血背景用 JPG（PNG 体积过大）
- 截图和含文字的图片用 PNG（JPG 压缩导致文字模糊）

## 图片处理

### 裁剪规则

1. **主体居中**：裁剪时保持主体在画面中心或黄金分割点
2. **视线方向留白**：人物照片在视线方向留 1/3 空间
3. **统一比例**：同页多张图片使用相同宽高比

### 圆角处理

- 图片圆角统一为 8pt（0.11in）
- 全出血图片不加圆角
- 同 deck 所有圆角图片使用相同圆角半径

### 遮罩处理

- 图片上叠加文字时，必须加半透明遮罩（70-80% 黑色）
- 遮罩渐变优于纯色遮罩（从透明到 80% 黑）
- 遮罩区域仅覆盖文字所在位置，不遮盖整张图片

## 图片在布局中的使用

### 全出血图片页

- 图片占满整页（0, 0, 13.33, 7.5）
- 文字放在底部 1/3，加遮罩
- 图片主体应在上方 2/3（不被文字遮挡）

### 双栏配图

- 图片占满右栏（与左栏文字顶部对齐）
- 图片宽度 = 右栏宽度（不留白边）
- 图片高度 = 内容区高度

### 卡片内图片

- 图片占卡片上半部分（60% 图片 + 40% 文字）
- 图片宽度 = 卡片宽度（不留白边）
- 图片与文字之间无间距（图片底边即文字区顶边）

## AI 生成图片规范

- AI 生成图片需人工审核（可能存在不合理细节）
- 不使用明显 AI 风格的图片（过度光滑、不自然的光影）
- 在备注页标注"AI 生成图片"（透明度要求）
- 优先使用真实照片，AI 图片仅作为补充

## 反模式

| 反模式 | 问题 | 修复 |
|---|---|---|
| 图片拉伸变形 | 不专业 | 锁定宽高比或裁剪 |
| 低分辨率图片 | 模糊/马赛克 | 替换为高分辨率版本 |
| 水印图片 | 版权风险+不专业 | 购买授权或使用免费图库 |
| 剪贴画 | 过时 | 替换为现代图标或照片 |
| 图片浮在文字旁 | 无对齐参考 | 占满右栏或全出血 |
| 图片上无遮罩加文字 | 不可读 | 加半透明遮罩 |
| 同页图片比例不一致 | 视觉混乱 | 统一裁剪为相同比例 |
| 图片与内容无关 | 视觉噪音 | 删除或替换 |
