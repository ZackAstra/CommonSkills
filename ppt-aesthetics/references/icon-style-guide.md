# 图标风格指南（Icon Style Guide）

本文件规范 PPT 中图标的使用风格，确保全 deck 图标视觉统一。

## 风格选择

| 风格 | 特征 | 适用场景 | 推荐图标库 |
|---|---|---|---|
| 线性（Outline） | 1.5-2px 描边，无填充 | 科技/互联网/现代商务 | Phosphor Icons / Lucide / Heroicons |
| 填充（Filled） | 实心，无描边 | 营销/产品发布/强调 | Material Icons (Filled) / Font Awesome (Solid) |
| 双色（Duotone） | 主色填充 + 次色背景 | 数据报告/仪表盘 | Phosphor Duotone / Font Awesome Duotone |
| 扁平（Flat） | 纯色无渐变无阴影 | 极简/Apple 风格 | iOS SF Symbols / Tabler Icons |

**铁律**：一份 PPT 只用一种风格，不混用。

## 尺寸规范

| 用途 | 尺寸 | 说明 |
|---|---|---|
| 卡片内图标 | 32×32pt（0.44in） | 与标题文字等高 |
| 列表项目符号 | 16-20pt | 比正文小 2-4pt |
| 封面装饰图标 | 48-64pt | 视觉焦点 |
| 页脚/小标注 | 12-14pt | 辅助信息 |

## 颜色规范

- 图标颜色使用 deck 主色或中性色，不引入新颜色
- 线性图标：描边用主色，背景透明
- 双色图标：前景用主色，背景用主色 10% 透明度
- 禁止：彩色图标（每个图标不同颜色）、渐变图标

## 对齐规范

- 图标在容器内水平+垂直居中
- 图标与相邻文字垂直居中对齐
- 多个图标横向排列时，间距统一（推荐 0.3in）

## 格式规范

| 格式 | 推荐度 | 说明 |
|---|---|---|
| SVG | ★★★★★ | 矢量无损，可改色，体积小 |
| EMF | ★★★★ | Windows 原生矢量格式，PPT 插入不模糊 |
| PNG @2x | ★★★ | 位图，需 2 倍分辨率（64px 图标用 128px PNG） |
| ICO | ★★ | 仅 Windows，尺寸有限 |
| JPG | ✗ | 不支持透明，图标必有白底，禁止使用 |

## 插入方式

1. **SVG → EMF 转换**（推荐）：用 Inkscape 或 CloudConvert 将 SVG 转 EMF，插入 PPT 后可无损缩放和改色
2. **SVG 直接插入**：PowerPoint 365+ 支持 SVG 直接插入，但旧版本不兼容
3. **PNG @2x 插入**：确保图标物理尺寸 = 显示尺寸 / 2（如显示 32pt，图片 64px）

## 反模式

| 反模式 | 问题 | 修复 |
|---|---|---|
| 混用线性+填充图标 | 视觉不一致 | 统一为一种风格 |
| 图标尺寸不一致 | 粗糙感 | 统一为 32pt |
| 彩色图标（每色一个） | 配色杂乱 | 全部改为主色 |
| 图标拉伸变形 | 不专业 | 锁定宽高比 |
| JPG 图标带白底 | 透明区域变白 | 换 PNG/SVG |
| 不同图标库混用 | 线条粗细/风格不统一 | 用同一套图标库 |
