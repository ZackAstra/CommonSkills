# 多语言排版规范（Multilingual Typography）

本文件规范 PPT 中多语言混排（中英、中日韩、中阿等）的排版规则。

## 中英混排

### 字体分设

每个文本 run 必须同时指定拉丁字体和东亚字体：

```xml
<a:rPr lang="zh-CN">
  <a:latin typeface="Inter"/>
  <a:ea typeface="Source Han Sans CN"/>
</a:rPr>
```

### 间距规则

| 规则 | 示例 |
|---|---|
| 中英文之间加半角空格 | "用 iPhone 拍照"（非"用iPhone拍照"） |
| 中文与数字之间加半角空格 | "增长 23%"（非"增长23%"） |
| 英文单位与数字保留空格 | "23 kg" / "100 Mbps" |
| 百分号前不加空格 | "23%"（非"23 %"） |
| 全角标点后不加空格 | "你好，世界"（非"你好， 世界"） |

### 字号平衡

- 中文字号通常比英文大 1-2pt（中文字符密度高，同字号视觉偏小）
- 推荐正文：中文 20pt + 英文 18pt
- 推荐标题：中文 36pt + 英文 32pt

### 标点规则

| 场景 | 规则 | 示例 |
|---|---|---|
| 纯中文段落 | 全角标点 | "这是中文，使用全角。" |
| 纯英文段落 | 半角标点 | "This is English, use half-width." |
| 中英混排 | 中文部分全角，英文部分半角 | "使用 iPhone，体验更好" |
| 括号 | 中文内容用全角，英文内容用半角 | "（备注）" / "(note)" |

## 中日韩（CJK）混排

| 语言 | 推荐字体 | 备注 |
|---|---|---|
| 简体中文 | Source Han Sans CN / Microsoft YaHei | — |
| 繁体中文 | Source Han Sans TW / PingFang TC | 港澳台场景 |
| 日文 | Source Han Sans JP / Hiragino Sans | `<a:ea>` 设为日文字体 |
| 韩文 | Source Han Sans KR / Apple SD Gothic | `<a:ea>` 设为韩文字体 |

> 思源黑体家族覆盖全部 CJK 字符，是跨 CJK 语言混排的最佳选择。

## 中阿混排（阿拉伯语）

- 阿拉伯语为从右到左（RTL）书写方向
- PowerPoint 支持 RTL 文本：`<a:rPr dir="rtl">`
- 中阿混排时，阿拉伯文本段设 `dir="rtl"`，中文文本段保持 `dir="ltr"`
- 阿拉伯数字（0-9）在 RTL 段落中仍从左到右显示

## 竖排文本

- 中文竖排：`<a:bodyPr vert="vert270">`
- 仅适用于封面标题或装饰性文字
- 竖排文本中英文需旋转 90° 或改用中文表述

## 多语言 deck 结构

当 PPT 需要支持多语言时：

| 策略 | 说明 | 适用场景 |
|---|---|---|
| 单文件多语言 | 每页包含所有语言版本，用动画切换 | 双语会议 |
| 多文件分发 | 每种语言独立 PPT | 国际化产品 |
| 主语言+附录 | 主 deck 用一种语言，附录页提供翻译 | 政府公文 |

## 反模式

| 反模式 | 问题 | 修复 |
|---|---|---|
| 中文文本未设 CJK 字体 | 回退到宋体，视觉灾难 | 添加 `<a:ea>` 指定 CJK 字体 |
| 中英文无空格 | 视觉粘连，难读 | 添加半角空格 |
| 混用全角/半角标点 | 排版不统一 | 按语言规则统一 |
| 英文段落用中文字体渲染 | 字符间距异常 | 分设拉丁字体 |
| RTL 文本未设 dir | 显示顺序错误 | 添加 `dir="rtl"` |
