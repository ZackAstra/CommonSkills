# 图表美学（Data Visualization on Slides）

本文件规定 PPT 中图表的视觉规范——遵循 Edward Tufte 的"数据墨水比"原则，最大化信息密度，最小化视觉噪音。

## 核心原则：数据墨水比（Data-Ink Ratio）

> 一张图表的视觉元素中，应该尽可能多地用于表达数据，尽可能少地用于装饰。
> —— Edward Tufte, *The Visual Display of Quantitative Information*

| 元素类型 | 保留 / 删除 |
|---|---|
| 数据本身（柱、线、点）| 保留 |
| 坐标轴标签、刻度 | 保留（但简化）|
| 网格线 | 删除主网格；保留极淡辅助线（5-10% 灰）|
| 图表边框 | 删除 |
| 数据标签 | 直接标在数据上（避免图例与数据分离）|
| 3D 效果 | 删除（一律）|
| 阴影、渐变填充 | 删除 |
| 图表标题 | 保留，作为结论句而非描述句 |

## 1. 柱状图 / 条形图

### 视觉规范
- **柱宽 : 间距 = 2 : 1**（柱占 2/3，间距占 1/3）
- **不要 3D**：3D 柱状图会扭曲数值感知（前沿柱看起来比后景柱大）
- **颜色**：单系列用主色；多系列用主色 + 辅助色（最多 4 系列）
- **强调**：所有柱用次要色灰，仅 1 根关键柱用主色或强调色
- **数据标签**：直接标在柱顶（不要图例 + 数值的双重视线）
- **Y 轴**：从 0 起（柱状图不能截断 Y 轴，否则误导）
- **排序**：分类数据按值降序排列；时间数据按时间升序

### 反例 → 正例
```
❌ 5 系列 × 12 个月柱状图，红黄蓝绿紫，3D 倾斜
✅ 1 系列柱状图（关键月份高亮），平面，Y 轴从 0，数据标签在柱顶
```

## 2. 折线图

### 视觉规范
- **线宽**：1.5-2pt 主线；次要线 1pt 或虚线
- **颜色**：主线主色；次要线次要色或灰
- **数据点**：关键点标圆点（直径 6-8px），非关键点不标
- **网格线**：仅水平网格，10-15% 灰
- **图例**：直接标在线条末端（"末端标签"），不要分离图例
- **Y 轴范围**：可截断（与柱状图不同），但需在 Y 轴上明确标注
- **多线**：最多 4 条；超过用分面（small multiples）

### 反例 → 正例
```
❌ 6 条线挤一张图，彩虹色，图例在底部，3D 网格
✅ 1 条主线（主色）+ 1 条基准线（灰虚线），末端标签，淡水平网格
```

## 3. 饼图（强烈建议改用条形图）

### 何时还能用饼图
- 仅 2-3 个分类
- 强调"份额"概念（如市场份额 60% vs 40%）
- 数值差异显著（不要画 5 个 20% 的饼）

### 视觉规范
- **不要 3D 饼图**——3D 会扭曲面积感知
- **不要分离扇区**（除了强调 1 个扇区）
- **数据标签**：直接标在扇区上（百分比 + 类别名）
- **颜色**：主扇区主色，其余次要色；不要彩虹色
- **排序**：从 12 点钟方向顺时针按值降序
- **小份额合并**：< 5% 的扇区合并为"其他"

### 何时改用条形图
- 4+ 分类
- 分类数值接近（饼图无法区分 22% vs 25%）
- 需要精确读数

### 反例 → 正例
```
❌ 7 个扇区的 3D 饼图，分离式，彩虹色，图例分离
✅ 改用水平条形图，按值降序，单色 + 强调色高亮关键条
```

---

## 4. 散点图 / 气泡图

### 视觉规范
- **点大小**：5-8px 直径；气泡图第三维 10-40px
- **透明度**：60-80%（防重叠遮挡）
- **颜色**：单组主色；多组主色 + 辅助色 + 强调色（最多 3 组）
- **趋势线**：仅当有显著相关性时添加；R² 标注在线旁
- **轴标签**：必须包含单位（"收入 (USD M)"而非"收入"）
- **四象限标注**：用淡虚线划分四象限并标注（如"高增长高份额"）

### 反例 → 正例
```
❌ 500 个点不透明，无趋势线，无象限标注
✅ 透明点 + 趋势线 + R² + 四象限虚线 + 关键点高亮标注
```

## 5. 表格

### 视觉规范
- **去框线**：仅保留表头下方 1 条线和表尾 1 条线（Tufte 风格）
- **行间距**：1.3-1.5 倍行高
- **数字右对齐**，文字左对齐，表头居中或左对齐
- **数字用等宽字体**（DIN / Arial / Helvetica），便于对齐
- **斑马纹**：可选，10% 灰交替（不要 50% 灰——太刺眼）
- **关键单元格高亮**：主色背景 + 白字，或主色边框
- **表格不应跨页**：超过 8 行就拆分或改用图表

### 反例 → 正例
```
❌ 全框线表格，居中对齐数字，10 行 8 列塞一页
✅ Tufte 风格（仅 2 条横线），数字右对齐等宽字体，关键行高亮
```

## 6. 仪表盘 / KPI 卡片

### 视觉规范
- **每张卡**：1 个 KPI 数字（24-36pt Bold）+ 1 行说明（12-14pt）+ 1 个迷你趋势
- **卡片间距**：0.2-0.3in
- **数字格式**：千分位（1,234,567）/ 单位（¥1.2M / 23.4K）
- **趋势颜色**：涨用主色或绿（中国市场习惯：涨红跌绿）；跌用强调色或红
  - 注意：中国市场 A 股惯例 **涨红跌绿**（与欧美相反），金融 PPT 默认遵循中国惯例
- **迷你图**：sparkline，1pt 线宽，无坐标轴

### 布局
- 4 卡 2×2：每卡 5.8 × 3.0in
- 6 卡 3×2：每卡 3.8 × 3.0in
- 8 卡 4×2：每卡 2.8 × 3.0in
- 超过 8 个 KPI：分页，不要堆一页

## 7. 颜色编码（数据语义）

| 数据类型 | 推荐色板 |
|---|---|
| 顺序型（如收入梯队）| 主色单色渐变（深 → 浅）|
| 分类型（如产品线）| 离散色板（主色 + 辅助 + 强调 + tint）|
| 发散型（如同比涨跌）| 涨色（红/绿）+ 中性灰 + 跌色（绿/红）|
| 强调型（如本年 vs 去年）| 本年主色 + 去年浅灰 |

### 中国金融惯例（重要）
- **股票涨 → 红色**；**股票跌 → 绿色**（与欧美相反）
- 金融 PPT 默认遵循中国惯例，除非用户明确要求欧美风格
- 货币：默认用 ¥ (CNY/RMB)

## 8. 字号建议（图表元素）

| 元素 | 字号 | 备注 |
|---|---|---|
| 图表标题（结论句）| 18-22pt | 不要"销售数据"这种描述句，要"Q3 销售同比增长 23%"这种结论 |
| 坐标轴标签 | 12-14pt | 包含单位 |
| 数据标签 | 11-14pt | 直接标在数据上 |
| 图例 | 11-12pt | 末端标签优先 |
| 注释 / 数据来源 | 9-10pt | 底部，浅灰 |

---

## 9. 必备元素：So what?

每张数据图下方必须有 1 句结论（"So what?"）：

```
[ 图表 ]

So what? Q3 销售同比增长 23%，主要由产品 A 在华东区驱动。
```

**字号**：14-16pt，强调色。
**位置**：图表正下方，左对齐。
**作用**：观众不会自己解读图表——你必须告诉他该看出什么。

## 10. 在评分流程中的角色

### 评分阶段（视觉模型 + 结构分析）
检测以下图表反模式：
- 3D 图表（任何类型）→ `professional_polish -2`
- 图表无标题或标题是描述句而非结论句 → `visual_hierarchy -1`
- 6+ 系列挤一张图 → `content_density -2`
- 饼图超过 5 个扇区 → `content_density -1`
- 图表无数据来源 → `professional_polish -1`
- 颜色彩虹色板 → `color_discipline -2`
- 表格全框线 + 居中对齐数字 → `professional_polish -2`

### 修复阶段
- `fix_ppt.py` 目前不修改图表内容（python-pptx 修改图表有限）
- 推荐工作流：检测出图表反模式后，**人工或 AI 重新生成图表**，再插入 PPT
- 颜色统一可借 `fix_ppt.py --colors --palette <id>` 部分实现（图表系列颜色受 theme 控制）
