# PPT 逐页规划参考文档

> 阶段：Phase 2 — 设计审批后、制作 PPT 之前
> 目标：将设计构思拆解为逐页蓝图（布局 + 配图 + 文字），产出可执行的台本

## 1. 输入

来自 Phase 1（ppt-brainstorming）的设计审批结果：
- 叙事线
- 页面大纲（标题列表）
- 风格/配色/字体选择
- 预估页数

## 2. 逐页蓝图格式

每页需规划以下要素：

```yaml
页码: N
标题: "本页标题"
布局: cover | title-only | title+text | title+2col | full-image | ending
文字:
  - 主体文字内容（精简，每条 < 20 字）
  - 关键数据/引用（加粗标记）
配图:
  类型: none | diagram | photo | screenshot | icon-grid
  描述: "配图的内容描述"
  位置: right | full | center
  来源: PIL生成 | ImageGen | 截图 | 本地文件
视觉重点: 本页最想让听众看到什么？
```

## 3. 布局选择指南

| 布局 | 适用场景 | 文字量上限 | 配图建议 |
|------|----------|------------|----------|
| cover | 封面 | 标题+1行副标题 | 全幅背景或留白 |
| title-only | 幕封/概览 | 标题+1行副标题 | 可选装饰 |
| title+text | 主体内容页 | 5-6 行要点 | right 或无 |
| title+2col | 对比/并列 | 左右各 3-4 行 | 无 |
| full-image | 数据展示/流程图 | 标题+2行说明 | full |
| ending | 结尾页 | 感谢语/联系方式 | 可选装饰 |

## 4. 配图规划

### 4.1 配图类型决策树

```
这页内容是否包含流程/结构/对比？
├─ 是 → 生成结构化示意图（PIL/diagram-drawing）
│       流程 → 流程图
│       结构 → 层次图/架构图
│       对比 → 对比柱状图/阶梯图
│       时间线 → 时间线图
└─ 否 → 是否需要概念性配图？
    ├─ 是 → ImageGen 生成概念图
    └─ 否 → 不加配图，依靠排版和卡片容器
```

### 4.2 配图覆盖率门禁

配图页面占总页数的比例应 ≥ 30%：
- **< 30%**：红色警告，信息传达过于依赖文字
- **30%-50%**：黄色提醒，尚可但建议增加配图
- **≥ 50%**：绿色合格

使用 `gate_image_coverage.py` 检查。

### 4.3 配图质量标准

- 分辨率 ≥ 800×600 像素
- 宽高比 ≤ 3.5:1（避免过度扁平）
- 内容与页面主题强相关
- 配色与 PPT 整体风格协调

## 5. 文字精简原则

### 5.1 控制文字量

| 场景 | 每页要点数 | 每条字数 |
|------|-----------|----------|
| 演讲型 | 3-4 条 | ≤ 15 字 |
| 汇报型 | 5-6 条 | ≤ 20 字 |
| 展板型 | 7-8 条 | ≤ 25 字 |

### 5.2 避免的反模式

- `wall_of_text`：单页 > 60 词或 > 400 字符
- `too_many_bullets`：单页 > 6 条要点
- `bullet_soup`：所有要点长度相近，无分组

### 5.3 文字分组策略

当要点超过 4 条时，按主题分为 2-3 组：
- 每组加小标题
- 组内要点保持一致的缩进和字号
- 不同组之间增加间距

## 6. 台本产出

规划完成后，产出台本蓝图供 Phase 3 使用。台本格式：

```
=== 台本蓝图 ===
风格：[选定的风格]
配色：[主色/辅色/强调色 HEX]
字体：[中文字体]+[西文字体]

--- 第 1 页 ---
标题：xxx
布局：cover
文字：[标题] + [副标题]
配图：无

--- 第 2 页 ---
标题：xxx
布局：title+text
文字：
  · 要点1
  · 要点2
  · 要点3
配图：02_timeline.png (right)
...
```

获得台本审批后，进入 Phase 3（ppt-execution）。
