# PPT 布局模板库（16:9 标准 + 4:3 适配）

本文件提供 8 套经过验证的版式布局，每套含元素位置（英寸）、字号、对齐方式，可直接用 `python-pptx` 复刻或作为人工设计参考。

## 画幅规格

| 画幅 | 宽 (in) | 高 (in) | 像素 @96DPI | 宽高比 |
|---|---|---|---|---|
| **16:9 宽屏**（默认） | 13.33 | 7.5 | 1280×720 | 1.778 |
| **4:3 标准** | 10.0 | 7.5 | 960×720 | 1.333 |

> **趋势**：16:9 已成为主流（投影仪、笔记本、电视均为 16:9）。4:3 仅在老式投影仪或特定政府/学术场景需要。本文件以 16:9 为主，4:3 为适配补充。

### 4:3 适配规则

从 16:9 转换到 4:3 时：
1. **高度不变**（7.5in），宽度从 13.33in 缩至 10.0in
2. **页边距不变**（左/右 0.67in，上/下 0.5in）
3. **内容区宽度缩窄**：12.0in → 8.66in（减少 28%）
4. **字号不变**（4:3 投影距离通常更近，字号无需放大）
5. **双栏布局**：50/50 分栏变窄，槽宽从 0.5in 缩至 0.3in
6. **三栏布局**：4:3 下不推荐三栏，改为双栏或单栏堆叠
7. **全出血图片**：图片裁剪为 4:3 比例（10.0×7.5in）

### 4:3 快速换算表

| 元素 | 16:9 left | 16:9 width | 4:3 left | 4:3 width |
|---|---|---|---|---|
| 页面标题 | 0.67 | 12.0 | 0.67 | 8.66 |
| 左栏（50/50） | 0.67 | 5.7 | 0.67 | 4.0 |
| 右栏（50/50） | 6.85 | 5.8 | 5.0 | 4.33 |
| 左栏（60/40） | 0.67 | 7.4 | 0.67 | 5.4 |
| 右栏（60/40） | 8.57 | 4.1 | 6.37 | 2.96 |
| 图表区（数据页） | 0.67 | 7.5 | 0.67 | 5.5 |
| 洞察区（数据页） | 8.5 | 4.2 | 6.5 | 2.83 |
| 全出血图片 | 0 | 13.33 | 0 | 10.0 |
| 结论句 | 1.0 | 11.3 | 0.8 | 8.4 |

## 通用规则

### 安全页边距
| 边 | 推荐值 | 硬下限 |
|---|---|---|
| 左 / 右 | 0.67in（约 64px @ 96DPI）| 0.5in |
| 上 | 0.5in | 0.3in |
| 下 | 0.5in | 0.3in |

内容区可用空间：**12.0 × 6.5in**（13.33 - 2×0.67 宽，7.5 - 2×0.5 高）

### 12 列网格
- 每列 ≈ 0.89in，槽（gutter）≈ 0.17in
- 常用列组合：12（满宽）/ 6+6（二分）/ 4+8（侧栏）/ 4+4+4（三分）/ 3+6+3（三分带侧栏）

### 视觉重心
- 16:9 幻灯片的视觉重心略高于几何中心（约 40% 高度处）
- 标题应在上方 1/3 区域，主内容在中间 1/3，留底部 1/3 呼吸

## 布局 5：数据 + 洞察页（麦肯锡风格）

```
┌─────────────────────────────┬───────────────┐
│                             │ 洞察标题       │
│                             │ (24pt Bold)   │
│      图表（占 60% 宽）      │               │
│                             │ 关键发现 1     │
│                             │ 关键发现 2     │
│                             │ 关键发现 3     │
│                             │               │
│  数据来源（10pt）           │ So what?      │
│                             │ (16pt 强调色) │
└─────────────────────────────┴───────────────┘
```

**元素位置**：
| 元素 | left | top | width | height |
|---|---|---|---|---|
| 图表 | 0.67 | 1.0 | 7.5 | 5.0 |
| 图表标题 | 0.67 | 0.5 | 7.5 | 0.4 |
| 数据来源 | 0.67 | 6.2 | 7.5 | 0.3 |
| 洞察标题 | 8.5 | 1.0 | 4.2 | 0.6 |
| 关键发现列表 | 8.5 | 1.7 | 4.2 | 3.5 |
| So what? 句 | 8.5 | 5.3 | 4.2 | 1.0 |

**核心**：洞察比图表更重要——图表只是证据，洞察是结论。每页必须有 "So what?" 句。
**禁忌**：图表占满全页却没有洞察文字——观众不知道该看出什么。

## 反模式：避免这些布局

### ❌ "三等卡片"（Three Equal Cards）
```
┌──────┐  ┌──────┐  ┌──────┐
│  A   │  │  B   │  │  C   │
│      │  │      │  │      │
└──────┘  └──────┘  └──────┘
```
**为什么是反模式**：3 个等大卡片没有视觉层级，观众不知道先看哪个。AI 默认生成这种布局。
**修复**：让 1 个卡片更大/更突出（主推方案），另外 2 个缩小并淡化。

### ❌ "项目符号海洋"
```
• 要点 1
• 要点 2
• 要点 3
• 要点 4
• 要点 5
• 要点 6
• 要点 7
• 要点 8
```
**为什么是反模式**：观众读不完，注意力在第 4 条就耗尽。
**修复**：拆成 2 页；或砍到 3-4 条核心，其余放备注页。

### ❌ "图片浮在文字旁"
**为什么是反模式**：图片无对齐参考，像随手贴上去的。
**修复**：图片要么占满右栏（与文字顶对齐），要么全出血。

### ❌ "标题 + 一大段文字"
**为什么是反模式**：PPT 不是 Word，观众不会读段落。
**修复**：拆成要点；或用一张图配一句话总结。

### ❌ "页眉页脚挤满 Logo"
**为什么是反模式**：每页 Logo + 公司名 + 页码 + 日期 + 演讲者——视觉噪音。
**修复**：仅页码放右下角小字；Logo 只放封面和封底。

## 与 fix_ppt.py 的关系

`fix_ppt.py` 目前不会自动套用布局（布局意图无法机械判断）。布局模板的作用是：
1. **评分阶段**：检测反模式布局（`three_equal_cards` / `wall_of_text` / `no_margins`）
2. **人工/AI 修复阶段**：参考本文件的尺寸表，用 `python-pptx` 重新摆位
3. **新建 PPT 阶段**：直接套用上述尺寸创建新幻灯片

后续可扩展 `fix_ppt.py` 增加 `--layout <id>` 参数，把现有内容重新摆位到指定布局模板中。
