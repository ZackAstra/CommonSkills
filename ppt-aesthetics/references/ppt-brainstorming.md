# PPT 设计构思参考文档

> 阶段：Phase 1 — 制作任何新 PPT 之前
> 目标：构思内容结构与视觉方案，获得用户审批后才能进入制作

## 1. 输入收集

在开始设计前，必须明确以下信息：

| 项目 | 说明 | 必需？ |
|------|------|--------|
| 主题/标题 | PPT 的核心主题 | 是 |
| 受众 | 谁会看这个 PPT？（技术/管理层/客户） | 是 |
| 场景 | 演讲/汇报/转发送审/展板 | 是 |
| 时长 | 演讲多少分钟？决定页数 | 建议 |
| 风格偏好 | 电信红/暗色/纸墨/瑞士风等 | 否（未指定则展示选项） |
| 参考素材 | 旧 PPT/文档/网页链接 | 否 |

## 2. 内容结构设计

### 2.1 核心叙事线

用一句话概括"听众最应该记住什么"。所有页面围绕这条线展开：

```
叙事线 = 痛点/背景 → 核心方案 → 细节支撑 → 价值总结
```

### 2.2 页面大纲

- 每页只承载一个核心观点
- 页数估算：演讲型 1 页/分钟，汇报型可更密集
- 必须包含：封面 + 结尾页
- 建议结构：10-20% 开场 + 60-70% 主体 + 10-20% 收束

### 2.3 章节切分

使用幕封（section divider）页分隔大章节，让听众有节奏感：

```
[封面] → [概述幕封] → [内容页×N] → [案例幕封] → [案例页×N] → [总结幕封] → [总结] → [结尾]
```

## 3. 视觉方案设计

### 3.1 风格选择

如果用户未指定风格，需展示风格选项让用户选择（禁止擅自默认）。常见风格：

- 电信红白：品牌场景，#E60012 为主色
- 纸墨风：衬线字体 + 暖调背景，适合学术/文化
- 瑞士国际主义：无衬线 + 网格点阵，适合技术/数据
- 暗色风格：深底 + 亮字，适合发布会/科技感

### 3.2 配色确定

遵循 60-30-10 法则：
- **60% 主色**：背景/大面积区域
- **30% 辅色**：卡片/次要区域
- **10% 强调色**：关键标题/CTA 按钮

### 3.3 字体确定

根据风格选择字体配对（参考 `font-pairings.md`）：
- 中文主字体 + 西文主字体
- 字号阶梯规划（Major Third 1.25× 递增）

## 4. 设计审批

### 4.1 审批清单

向用户展示以下内容，确认后才可进入下一阶段：

- [ ] 叙事线一句话
- [ ] 页面大纲（标题列表）
- [ ] 风格 + 配色 + 字体选择
- [ ] 预估页数和制作时间

### 4.2 审批结果

- **通过** → 进入 Phase 2（ppt-planning）
- **需修改** → 调整后重新审批
- **未批准禁止制作** → 不得创建任何 PPTX 文件

## 5. 常见反模式

| 反模式 | 表现 | 避免 |
|--------|------|------|
| 边想边做 | 没有审批就打开 PPTX | 必须先审批 |
| 堆砌一切 | 把所有内容都塞进去 | 每页一个核心观点 |
| 风格跳轴 | 一套 PPT 混多种风格 | 全程统一风格 |
| 忽视受众 | 给高管看代码细节 | 匹配受众层次 |
